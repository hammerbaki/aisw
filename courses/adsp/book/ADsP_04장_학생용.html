표 데이터와 데이터 마트

2027학년도 「빅데이터개론」의 준비 중인 교재입니다. 편집 상태를 검토하기 위해 미리 공개한 것으로, 수업 전에 내용과 순서가 바뀔 수 있습니다.

학사 5주차 · 교재 04 · 3부 데이터 분석 · ADsP 3과목 데이터분석 > R기초와 데이터 마트 (R기초, 데이터 마트)

이 장은 표에서 행과 열을 고르고, 묶어 집계하고, 형태를 바꾸고, 두 표를 결합하여 분석용 표인 데이터 마트를 만드는 과정을 다룬다. 시험은 R의 자료 구조, 함수와 패키지의 역할, 요약 변수와 파생 변수의 구분, 짧은 코드나 출력의 뜻을 묻는다.

3부의 첫 장이며 실습 노트북을 처음 여는 장이다. 1절은 「파이썬 기초」 12~13장의 표 연산을 되짚고, 2~5절은 자료 구조, 선택, 형태 변환, 결합을 다루며, 7절은 같은 일을 R로 실행한 출력을 해석한다.

학습 목표

  1. CSV 파일을 DataFrame으로 읽고 「파이썬 기초」의 표 연산을 적용한 결과를 해석한다.
  2. 조건 둘을 &와 |로 이은 선택의 결과를 행 수로 설명한다.
  3. 넓은 표와 긴 표를 구분하고, pivot_table과 melt가 서로 반대 방향의 변환임을 출력으로 확인한다.
  4. 결합 방식(inner, left, right, outer)과 키의 중복에 따라 결과의 행 수와 결측값이 달라지는 까닭을 설명한다.
  5. 데이터 마트의 뜻과 요약 변수·파생 변수의 구분을 설명하고, R의 str, aggregate, merge, table 출력과 데이터 마트용 R 패키지의 역할을 읽는다.

수업의 흐름

  2. 개념과 따라 하기(1~5절). 따라 하기마다 결과의 크기를 예상한 뒤 실행하여 견준다.
  3. 중심 실습(6절). 고객 한 명이 한 행인 마트를 만든다.
  4. R 출력 해석과 문항(7절, 주간 문항 세트). 연습 문제(9절)와 세트의 11~20번은 수업 뒤에 푼다.

1. 「파이썬 기초」 표 데이터의 되짚기

배경과 쓰임. 기관과 기업이 표를 주고받는 가장 흔한 형식이 CSV(comma-separated values)이며 공통 규칙은 RFC 4180에 있다. 한 줄이 레코드 하나이고 값은 쉼표로 나누며, 값 안에 쉼표나 줄바꿈이 있으면 큰따옴표로 감싼다. 이를 어긴 줄은 열이 밀리므로 읽은 직후에 shape와 head를 본다.

1.2 「파이썬 기초」에서 익힌 연산

연산 코드 이 표에서의 뜻

2. 자료 구조: Series와 DataFrame

배경과 쓰임. 데이터베이스, R의 데이터 프레임, pandas의 DataFrame은 모두 “한 열에는 한 가지 자료형”을 지킨다. 금액 열이 문자열로 읽혀 합계가 구해지지 않거나 우편번호의 앞자리 0이 사라지는 일이 흔하다. pandas는 3.0(2026년 1월 발표)부터 문자열 열을 str로 읽으며, 앞의 판은 object로 표시하였다.

3. 행과 열의 선택

배경과 쓰임. 행의 선택은 SQL의 WHERE 절, 열의 선택은 SELECT 절에 해당한다. pandas 문서의 「SQL과의 비교」는 WHERE를 불리언 색인으로 옮기고 조건 둘을 &(AND)와 |(OR)로 잇는다. 조건을 잘못 이으면 오류 없이 다른 행이 남으므로 행 수로 점검한다.

3.1 조건에 의한 행의 선택

열에 조건을 적으면 행마다 참·거짓이 정해지고, 이 Series를 대괄호에 넣으면 참인 행만 남는다.

3.2 조건 둘의 결합

조건이 둘 이상이면 조건마다 괄호로 감싸고 &(그리고)나 |(또는)로 잇는다. 다음은 “가전인가”(c1)와 “20만 원 이상인가”(c2)의 참인 행 수다.

참·거짓의 Series에 sum()을 쓰면 참인 행의 수가 나온다. |의 결과는 84 + 32 - 24 = 92다. &의 결과는 작은 쪽 조건(32)을 넘을 수 없고, |의 결과는 큰 쪽 조건(84)보다 적을 수 없다.

4. 그룹별 집계와 표의 형태 변환

배경과 쓰임. 그룹별 집계는 SQL의 GROUP BY에 해당한다. Wickham(2014)은 분석에 알맞은 표를 “변수 하나가 열 하나, 관측 하나가 행 하나, 관측 단위의 종류 하나가 표 하나”로 정리하고 tidy data라 불렀다. 연도나 지역을 열로 펼친 통계표는 긴 표로 바꾸어 분석하고, 보고할 때 넓은 표로 되돌린다.

5. 표의 결합과 데이터 마트

배경과 쓰임. 업무 자료는 주문, 고객, 상품처럼 시스템마다 따로 저장되고 분석할 때 키로 결합한다. pandas 사용자 안내서의 「Merge, join, concatenate and compare」 장은 how를 SQL의 조인(inner는 INNER JOIN, left·right는 LEFT·RIGHT OUTER JOIN, outer는 FULL OUTER JOIN)에 대응시키고, 키가 두 표에 모두 여러 번 나오면 결과가 모든 짝(곱집합)이 되어 크게 늘 수 있다고 경고한다. 같은 열을 가진 표를 아래로 잇는 일은 결합이 아니라 연결이며 concat이 맡는다(SQL의 UNION ALL).

5.1 결합 방식

두 표에 함께 있어 행을 짝짓는 기준 열을 키(key)라 한다. 결합 방식은 한쪽 표에만 있는 키를 어떻게 다루는가로 나뉜다.

방식 (how) 남는 행 짝이 없는 쪽의 값
inner (기본값) 두 표에 모두 있는 키의 행 해당 없음
left 왼쪽 표의 행 모두 오른쪽 표에서 온 열이 결측값
right 오른쪽 표의 행 모두 왼쪽 표에서 온 열이 결측값
outer 두 표의 행 모두 짝이 없는 쪽의 열이 결측값

작은 표 둘로 확인한다. 표 b에는 K3이 두 행 있다.

a = pd.DataFrame({"고객ID": ["K1", "K2", "K3", "K4"], "지역": ["서울", "부산", "대구", "광주"]})
b = pd.DataFrame({"고객ID": ["K2", "K3", "K3", "K5"], "금액": [30000, 12000, 8000, 50000]})
for how in ["inner", "left", "right", "outer"]:
    print(how, pd.merge(a, b, on="고객ID", how=how).shape)
print(pd.merge(a, b, on="고객ID", how="outer", indicator=True))

left (5, 3)
right (4, 3)
outer (6, 3)

3     K3  대구   8000.0        both
4     K4  광주      NaN   left_only
5     K5   NaN  50000.0  right_only

[그림 자리: 결합 방식 넷에 따라 남는 키의 도식] 작은 표 a(K1~K4)와 b(K2, K3, K3, K5)의 키를 두 열로 나란히 적고, inner, left, right, outer의 네 칸마다 결과에 남는 키를 색으로 칠한 도식. a의 K3 한 행이 b의 K3 두 행과 각각 선으로 이어져 결과에서 두 행이 되는 것을 표시하고, 짝이 없는 칸은 빈칸(NaN)으로 그린다. 그림 안의 글자는 키 이름과 방식 이름(inner, left, right, outer)만 쓴다. 만들 곳: 도식 편집기.

결과의 행 수는 짝이 있는 키마다 두 표의 행 수를 곱한 값의 합에, 방식이 남기는 짝 없는 행을 더한 것이다. inner는 K2(1 × 1)와 K3(1 × 2)의 3행이고, left는 K1, K4를, right는 K5를, outer는 셋을 모두 더한다. indicator=True는 출처를 적은 _merge 열을 붙인다. 정수 열 금액은 결측값이 생겨 실수(30000.0)로 바뀌었다. 키 하나에 행 하나가 대응하면 1:1, 한쪽의 행 하나에 다른 쪽의 행 여럿이 대응하면 1:N 결합이다.

5.3 데이터 마트

데이터 마트(data mart)는 특정한 주제나 부서의 분석에 맞추어 필요한 자료만 모아 정리한 소규모 저장소로, 전사 자료를 통합한 데이터 웨어하우스에서 필요한 부분을 가져와 만든다(교재 01의 2절). 분석에서는 분석 대상 하나가 한 행이 되도록 변수를 모은 분석용 표를 데이터 마트라 부른다. 뒤의 장의 회귀 분석, 분류 분석, 군집 분석은 모두 이런 표를 입력으로 받는다.

5.4 요약 변수와 파생 변수

구분 요약 변수 파생 변수
뜻 수집한 원자료를 분석 목적과 분석 단위에 맞게 종합(집계)한 변수. 건수, 합계, 평균, 최댓값 같은 집계로 만든다 분석하는 사람이 특정한 조건이나 함수(계산식)를 적용하여 뜻을 부여한 변수
성격 기준이 집계 방법뿐이어서 누가 만들어도 값이 같다. 여러 분석 모형에 다시 쓸 수 있다(재활용성이 높다) 기준을 정하는 사람에 따라 값이 달라질 수 있다(주관적일 수 있다). 기준이 논리적으로 타당해야 한다
변수 만드는 방법 구분
구매 횟수 고객별 거래 건수 요약 변수
총 구매 금액, 평균 구매 금액 고객별 금액의 합계, 평균 요약 변수
최근 거래일 고객별 거래일의 최댓값 요약 변수
품목군별 구매 금액 고객과 품목군별 금액의 합계 요약 변수
우수 고객 여부 총 구매 금액이 정한 기준 금액 이상인가 파생 변수

구분의 기준은 “집계만 하였는가, 분석하는 사람이 정한 조건이나 계산식이 더해졌는가”다. 파생 변수는 기준(예: 50만 원)과 그 까닭을 마트의 설명 문서에 함께 적는다.

7.6 데이터 마트에 쓰는 R 패키지

출제 범위의 패키지 넷이다. 집필 환경에 설치되어 있지 않아 출력을 싣지 않으며, 역할은 각 패키지의 CRAN 문서로 확인하였다(11절).

패키지 역할 기억할 것
reshape 표의 형태를 바꾸고 집계한다 CRAN의 설명은 “melt와 cast 두 함수만으로” 자료를 재구성하고 집계한다는 것이다. melt는 식별 변수를 남기고 나머지 열을 변수 이름과 값의 두 열로 풀어 긴 표를 만들고, cast는 긴 표를 넓은 표로 다시 짜며 집계 함수를 함께 적용할 수 있다
sqldf R의 데이터 프레임을 SQL 문으로 다룬다 내부의 데이터베이스(기본 SQLite)에서 SQL 문을 실행하고 결과를 데이터 프레임으로 돌려준다. 예: sqldf("select 품목군, sum(금액) from tx group by 품목군")
plyr 나누고(split), 적용하고(apply), 합친다(combine) 함수 이름의 첫 글자가 입력, 둘째 글자가 출력의 자료 구조다. a는 배열, l은 리스트, d는 데이터 프레임, m은 여러 인자의 입력, r은 반복 실행, _는 출력하지 않음이다. ddply는 데이터 프레임을 받아 데이터 프레임을, ldply는 리스트를 받아 데이터 프레임을 낸다
data.table 데이터 프레임을 확장한 표. 큰 자료를 빠르게 다룬다 집계, 정렬, 결합이 빠르다. setkey로 키를 정하면 그 열의 순서로 정렬해 두고 이진 탐색으로 찾는다

plyr는 은퇴(retired) 상태이나, 시험은 네 패키지의 이름과 역할을 묻는다.

9. 연습 문제

답에는 계산의 과정이나 판단의 근거를 함께 쓴다. 정답과 채점 기준은 교수가 수업 뒤에 알린다.

연습 1. (결합의 행 수) 회원 표 m에는 회원 M1~M5가 한 행씩 있다. 주문 표 o에는 주문 7건이 있으며, 주문한 회원은 M1이 2건, M2가 1건, M4가 3건, M7이 1건이다. M7은 회원 표에 없다. pd.merge(m, o, on="회원ID", how=방식)의 행 수를 inner, left, right, outer에 대하여 계산하고, left의 결과에서 주문 정보가 결측값인 행의 수를 쓴다.

연습 2. (요약 변수와 파생 변수) 온라인 강의 플랫폼에 수강 기록 표(열: 수강생ID, 강의ID, 수강일, 시청시간(분), 완료여부)가 있다. 수강생 한 명이 한 행인 마트에 넣을 다음 변수 여섯을 요약 변수와 파생 변수로 나누고, 각각 근거를 한 줄로 쓴다.

변수 만드는 방법
총 시청 시간 수강생별 시청시간의 합계
수강 강의 수 수강생별 강의ID의 수
최근 수강일 수강생별 수강일의 최댓값
완료율 완료한 강의 수 ÷ 수강 강의 수
주말형 수강생 여부 주말에 시청한 시간이 총 시청 시간의 절반 이상인가
평균 시청 시간 수강생별 시청시간의 평균

연습 3. (결합 방식의 판단) 다음 세 요청마다 고객 표(cust)와 고객별 집계 표(cnt)를 어느 방식으로 결합할지 고르고, 까닭과 결과에서 확인할 값을 쓴다.

  1. 거래가 있는 고객을 대상으로 연령대별 평균 구매 금액을 구한다.
  2. 가입하였으나 한 해 동안 한 번도 구매하지 않은 고객의 목록을 만든다.
  3. 거래 내역에 고객 표에 없는 고객ID가 섞여 있는지 점검한다.

10. 정리

주제 기억할 것
분석 단위 표의 한 행이 나타내는 대상. 집계는 분석 단위를 바꾸고 형태 변환은 값의 자리만 바꾼다
자료 구조 Series와 DataFrame은 R의 벡터와 데이터 프레임에 해당한다. 벡터는 한 가지 자료형, 데이터 프레임은 열마다 다른 자료형. 위치는 파이썬이 0부터, R이 1부터 센다
선택 &는 둘 다, |는 하나라도. |의 행 수 = 두 조건의 행 수의 합 - 겹치는 행 수
그룹별 집계 나누기, 적용하기, 합치기. 결과의 행 수는 묶는 기준의 값(조합)의 가짓수다
넓은 표와 긴 표 넓은 표 → 긴 표는 melt, 긴 표 → 넓은 표는 pivot_table(R reshape의 cast). 긴 표의 행 수 = 넓은 표의 행 수 × 펼친 열의 수
결합 inner는 공통 키만, left·right는 한쪽 표 전부, outer는 양쪽 전부. 짝이 없는 칸은 결측값, 키가 중복되면 행이 는다. R의 merge는 기본이 inner, all.x = TRUE가 left다
데이터 마트 분석 대상 하나가 한 행이 되도록 변수를 모은 분석용 표
요약 변수와 파생 변수 요약 변수는 원자료를 집계한 변수로 재활용성이 높다. 파생 변수는 조건이나 함수로 뜻을 부여한 변수로 주관적일 수 있어 논리적 타당성이 필요하다
R 패키지 reshape(melt, cast), sqldf(SQL 문), plyr(나누기·적용·합치기, 함수 이름의 두 글자는 입력과 출력), data.table(빠른 처리, setkey)
