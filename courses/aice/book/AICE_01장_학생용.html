데이터 불러오기와 구성 파악

2027학년도 「비즈니스빅데이터분석」의 준비 중인 교재입니다. 편집 상태를 검토하기 위해 미리 공개한 것으로, 수업 전에 내용과 순서가 바뀔 수 있습니다.

학사 2주차 · 교재 01 · 1부 데이터 분석 · 출제 분야: 데이터 분석 > 필요 라이브러리 설치, 데이터 구성 및 특성 파악, 데이터 품질 점검

AICE Associate의 시험지는 표 데이터 한 건을 받아 라이브러리를 불러오고 파일을 읽는 문항으로 시작한다. 이어지는 문항은 자료의 크기, 자료형, 결측치, 범주별 빈도 같은 구성을 확인하고 그 결과를 지정된 변수에 저장하게 한다. 시험지 전체가 첫 문항의 결과 위에 쌓이므로, 이 단계에서 파일을 읽지 못하거나 변수 이름을 잘못 지정하면 뒤의 모든 문항이 영향을 받는다.

본 장은 pandas로 CSV 파일을 읽고 자료의 구성과 품질을 코드로 확인하는 방법을 다룬다. 내용은 선수 과목에서 한 번 사용해 본 수준이므로, 중점은 시험 문항의 형식에 맞추어 답을 산출하고 저장하는 연습에 있다. 본 장에서 작성하는 명세표와 품질 점검의 결과는 3장(결측치·이상치 처리)의 출발점이 된다.

학습 목표

  1. 데이터 분석에 쓰는 라이브러리를 관용 별칭으로 불러오고, 설치 여부와 판 번호를 확인한다.
  2. read_csv로 CSV 파일을 읽어 앞뒤의 행을 확인하고, 경로, 인코딩, 구분자의 오류를 메시지로 구분한다.
  3. 자료의 크기, 자료형, 요약 통계, 결측치 수, 고유값 수, 중복 행 수를 코드로 확인하고, info()와 describe()의 출력을 읽어 품질 문제를 찾는다.
  4. 열을 선택하고, 하나 이상의 조건으로 행을 선택한다.
  5. 빈도 집계, 그룹별 집계, 정렬로 물음의 답을 산출하여 지정된 변수에 저장한다.
  6. 모르는 함수의 사용법을 공식 문서에서 찾고, 시험의 답안 규칙에 맞추어 답을 작성한다.

1. 라이브러리 불러오기와 설치

1.1 import와 별칭

데이터 분석에 쓰는 라이브러리는 관용 별칭으로 불러온다. 시험의 첫 문항은 “pandas를 별칭 pd로 불러온다”처럼 별칭까지 지정하는 경우가 많다. 다른 이름을 쓰면 뒤 문항의 코드가 그 이름을 찾지 못하므로 별칭은 지시를 그대로 따른다.

라이브러리 관용 별칭 용도 본 과목의 장

matplotlib.pyplot plt 그림, 축, 제목, 범례 2장, 8장, 10장

import 모듈 as 별칭은 모듈을 불러와 별칭에 연결한다. 이후의 코드는 별칭을 통하여 함수를 부른다(pd.read_csv). scikit-learn은 필요한 함수와 클래스만 from sklearn.model_selection import train_test_split처럼 불러오는 것이 관례이다. 판 번호는 모듈의 __version__ 속성에 있다.

  • 확인 3 출력이 세 줄이고, 각 줄이 라이브러리 이름과 판 번호(예: pandas 3.1.1)이다. 판 번호는 실습 환경에 따라 다를 수 있다.

1.2 설치 명령과 판 번호 확인

출제 범위의 첫 항목은 “필요 라이브러리 설치”이다. 노트북에서는 셀에 %pip install 이름을 적어 설치한다. %는 매직 명령 표시로, 현재 커널의 파이썬 환경에 설치하게 한다. !pip은 운영 체제의 셸에서 실행되어 커널과 다른 환경에 설치될 수 있다.

%pip install seaborn
상황 대응
ModuleNotFoundError: No module named '...' 설치되지 않았다. %pip install 이름으로 설치한 뒤 커널을 다시 시작하고 import를 다시 실행한다
설치 이름과 import 이름이 다르다 scikit-learn은 pip install scikit-learn으로 설치하고 import sklearn으로 불러온다

2. CSV 파일의 구조와 읽기

2.1 CSV 파일의 구조

CSV(comma-separated values)는 한 줄이 한 행이고, 쉼표로 열을 구분하는 텍스트 파일이다. 첫 줄은 열 이름(머리글)이다. 값이 비어 있는 칸은 쉼표 사이에 아무것도 없고(,,), pandas는 이를 결측치(NaN)로 읽는다. 파일 안에서는 숫자도 모두 글자이며, 자료형은 pandas가 읽으면서 열마다 추정한다.

CSV 파일을 읽는 일은 세 가지를 정하는 일이다. 글자를 해석할 인코딩(encoding), 열을 나누는 구분자(sep), 머리글의 위치(header, 기본값은 첫 줄)이다. 파일을 저장한 프로그램이 다른 방식을 썼으면 이 가운데 하나를 지정한다. 2.4절의 오류는 모두 이 셋 가운데 하나가 맞지 않아 생긴다.

계산의 원리: 값 일곱 개의 손 계산

자료 2, 4, 4, 5, 7, 9, 30으로 여덟 값의 계산을 따라간다. 마지막 값 30은 다른 값보다 훨씬 크게 넣었다.

행 계산 값
count 값의 개수 7
mean (2 + 4 + 4 + 5 + 7 + 9 + 30) ÷ 7 = 61 ÷ 7 8.714…
min, max 가장 작은 값, 가장 큰 값 2, 30

  • churn의 평균 0.194는 이탈한 회원(1)의 비율이 약 19.4%라는 뜻이다. 0과 1로 된 열의 평균은 1의 비율이다.

4. 열 선택과 조건에 의한 행 선택

4.1 열 선택

대괄호 안에 열 이름 하나를 쓰면 그 열이 시리즈(Series)로, 열 이름의 리스트를 쓰면 데이터프레임으로 선택된다. 대괄호가 두 겹인 것은 바깥 대괄호가 선택을, 안쪽 대괄호가 리스트를 뜻하기 때문이다.

쓰는 법 결과 출력의 모양
df["grade"] 시리즈 머리글 없음, 마지막 줄에 Name:과 dtype:
df[["grade"]] 열이 하나인 데이터프레임 머리글 grade가 있다
df[["customer_id", "grade"]] 데이터프레임 머리글 두 개

4.2 조건에 의한 행 선택

비교식 df["grade"] == "VIP"는 행마다 True나 False를 담은 시리즈를 만든다. 이 시리즈를 대괄호에 넣으면 True인 행만 남는다. 이를 불리언 인덱싱(boolean indexing)이라 한다. 걸러진 결과는 원래의 인덱스를 그대로 유지하며, 0부터 다시 매겨지지 않는다.

# [예제 13]
vip = df[df["grade"] == "VIP"]
vip.shape
(228, 17)

조건이 둘 이상이면 각 조건을 괄호로 감싸고 &(그리고), |(또는), ~(부정)로 잇는다. 괄호가 필요한 까닭은 &가 ==보다 먼저 계산되기 때문이다. 조건을 변수에 먼저 저장하면 코드가 짧아지고 오류를 찾기 쉽다.

# [예제 14]
cond = (df["grade"] == "VIP") & (df["churn"] == 1)
len(df[cond])
26

VIP 회원 228명 가운데 이탈한 회원은 26명이다. 여러 값 가운데 하나에 해당하는 행은 isin으로 고른다. loc[행 조건, 열 목록]은 행과 열을 한 번에 선택한다.

# [예제 15]
df.loc[df["payment"].isin(["Mobile", "Point"]), ["customer_id", "payment"]].head(3)
   customer_id payment
1       C01009  Mobile
8       C02072   Point
11      C02914  Mobile

4.3 and를 쓰면 생기는 오류

파이썬의 and와 or는 값 하나의 참과 거짓을 판단하는 연산자이다. 시리즈 전체에 and를 쓰면 pandas는 3,030개의 참·거짓을 하나로 줄일 방법을 알 수 없어 오류를 낸다. 시험의 오류 정정 문항에서 자주 쓰이는 유형이다.

# [예제 16]
df[df["grade"] == "VIP" and df["churn"] == 1]
ValueError: The truth value of a Series is ambiguous. Use a.empty, a.item(), a.any() or a.all().

정정하는 방법은 and를 &로 바꾸고 각 조건을 괄호로 감싸는 것이다.

연산 값 하나 시리즈
그리고 and &
또는 or |
부정 not ~

and를 &로 바꾸기만 하고 괄호를 빠뜨리면 &가 ==보다 먼저 계산되어 다른 오류가 난다(4.4절 표). 메시지가 무엇이든 처방은 같다. 조건마다 괄호를 씌운다.
