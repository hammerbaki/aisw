오리엔테이션

2027학년도 「비즈니스빅데이터분석」의 준비 중인 교재입니다. 편집 상태를 검토하기 위해 미리 공개한 것으로, 수업 전에 내용과 순서가 바뀔 수 있습니다.

학사 1주차 · 교재 00 · 과목 안내와 사전 진단

본 과목의 목표는 AICE Associate의 취득이다. AICE Associate는 표 데이터 한 건을 받아 탐색, 전처리, 모델링, 평가의 순서로 이어지는 14문항을 90분 안에 파이썬 코드로 해결하는 실기 시험이다. 학기 전체의 교재는 이 시험지의 순서를 따라 구성되어 있다. 한 학기는 시험지 한 장을 처음부터 끝까지 천천히 풀어 가는 과정이 된다.

1주차는 진도를 나가지 않는다. 본 자료는 과목의 운영(목표, 주차 편성, 평가, 생성형 AI의 사용 기준, 실습 환경), 시험의 형식과 응시 규정, 학기 말의 일정을 안내한다. 이어서 완성된 풀이 한 편을 시연하여 학기 전체의 흐름을 보이고, 학기 공통 자료를 소개한다. 끝으로 과제인 사전 진단을 안내한다. 사전 진단의 결과는 2주차부터의 진행 속도를 정하는 데 쓰인다.

학습 목표

  1. 과목의 목표, 16주의 편성, 수업 한 회의 진행 방식, 평가 항목과 비율을 설명한다.
  2. AICE Associate의 형식(문항 수, 시간, 합격 기준, 출제 분야와 배점)과 시험지의 구성을 설명하고, 배점표에서 문항당 점수와 감점의 크기를 계산한다.
  3. 응시 규정(제한적 오픈북의 범위, 금지 행위와 제재, 응시 중 유의사항)을 설명하고 본 과목의 답안 규칙과 연결한다.
  4. 2027년 시험 일정 가운데 본 과목이 목표로 하는 회차와, 응시 전에 할 일(접수, 사전 환경점검)을 파악한다.
  5. 시험지의 흐름(탐색, 전처리, 모델링, 평가)과 학기 각 장의 대응을 설명한다.
  6. 실습 환경에서 라이브러리의 설치 여부와 자료 파일의 위치를 확인하고, 사전 진단을 풀어 제출한다.

0. 실습 준비

1주차의 실습은 두 가지이다. 사전 진단 노트북을 열어 실습 환경이 갖추어졌는지를 확인하는 일과, 노트북이 자료 파일을 찾을 수 있는지를 확인하는 일이다. 이 절의 셀은 수업 시간(운영안의 순서 5)에 함께 실행한다. 서버에 접속하는 방법과 라이브러리를 설치하는 방법은 다루지 않는다. 그것은 부록 A에 있다.

환경 확인을 1주차에 하는 데에는 이유가 있다. 2주차부터는 매주 노트북의 첫 셀에서 라이브러리를 불러오고 자료를 읽는다. 이 첫 셀이 실패하면 그 주의 실습 전체가 멈춘다. 시험에서도 같다. 시험지의 첫 문항이 라이브러리 불러오기와 파일 읽기이고, 이 문항의 실패가 뒤 문항으로 번진다(2.4절). 1주차에 환경의 문제를 찾아 2주차 전에 해결하면, 2주차부터는 수업 시간을 내용에 쓸 수 있다.

0.1 노트북 열기

  1. 부록 A의 안내에 따라 실습 환경(학교의 Jupyter 서버)에 접속한다.
  2. 파일 목록에서 courses/aice/book/ 폴더로 들어가 AICE_00주차_실습_학생용.ipynb를 연다. 파일 이름이 비슷한 AICE_00주차_학생용.md는 이 강의안이며 노트북이 아니다. 노트북 파일의 확장자는 .ipynb이다.
  3. 노트북이 열리면 화면 오른쪽 위에 커널(노트북의 코드를 실행하는 파이썬 프로그램)의 이름이 표시된다. 이 이름이 Python 3인지 본다. 커널을 고르라는 창이 나오면 Python 3를 고른다.
  4. 노트북의 맨 위 설명 셀을 읽는다. 사전 진단의 구성(문항 15개), 자료, 시간, 참고할 수 있는 것, 제출 방법이 적혀 있다.

[그림 자리: Jupyter의 파일 목록과 열린 사전 진단 노트북] 왼쪽은 파일 목록에서 courses/aice/book/을 연 화면이고 AICE_00주차_실습_학생용.ipynb가 강조되어 있다. 오른쪽은 노트북을 연 화면이며 제목 셀 # [0장] 사전 진단과 오른쪽 위의 커널 이름 Python 3, 셀 실행 단추(삼각형)에 표시를 한다. 학교 Jupyter 서버에서 찍는다.

  • 확인 1 노트북의 첫 셀에 제목 [0장] 사전 진단이 보이고, 그 아래에 구성, 자료, 시간, 참고, 제출의 다섯 항목이 있다.
  • 확인 2 화면 오른쪽 위(또는 아래쪽 상태 표시줄)의 커널 이름이 Python 3이고, 상태가 실행 중이 아닌 대기(빈 원)로 표시된다.

셀은 클릭하여 고른 뒤 Shift+Enter로 실행한다. 실행 중인 셀의 왼쪽에는 [*]가 표시되고, 실행이 끝나면 [1], [2]처럼 실행한 순서의 번호로 바뀐다. 번호는 셀이 노트북에서 놓인 순서가 아니라 실행된 순서이다. 위의 셀을 건너뛰고 아래 셀을 먼저 실행하면 번호가 뒤섞이고, 위의 셀에서 만든 변수가 없어 오류가 난다(0.4절).

0.2 라이브러리의 설치 여부와 판 번호

노트북 1절의 셀을 실행한다. 이 셀은 본 과목이 쓰는 일곱 라이브러리의 설치 여부와 판 번호를 출력한다.

from importlib.metadata import version, PackageNotFoundError

for name in ["numpy", "pandas", "matplotlib", "seaborn", "scikit-learn", "xgboost", "tensorflow"]:
    try:
        print(name, version(name))
    except PackageNotFoundError:
        print(name, "설치되어 있지 않다")
numpy 2.5.4
pandas 3.1.1
matplotlib 3.11.2
seaborn 0.13.2
scikit-learn 1.9.1
xgboost 3.4.1
tensorflow 2.21.0

이 셀은 라이브러리를 실제로 불러오지 않는다. 파이썬 표준 라이브러리 importlib.metadata의 version 함수는 설치된 패키지의 정보(메타데이터)에서 판 번호만 읽어 오고, 그 패키지가 설치되어 있지 않으면 PackageNotFoundError를 낸다. 셀은 이 오류를 try와 except로 받아 설치되어 있지 않다를 출력한다. 그래서 tensorflow처럼 불러오는 데 시간이 오래 걸리는 라이브러리도 순식간에 확인할 수 있고, 설치되지 않은 라이브러리가 있어도 셀이 멈추지 않는다.

version 함수에는 불러오는 이름이 아니라 설치 이름을 준다. scikit-learn은 import sklearn으로 불러오지만 설치 이름은 scikit-learn이다. 설치 이름 대신 불러오는 이름을 주면 설치되어 있어도 PackageNotFoundError가 난다(0.4절의 오류 3).

pandas의 큰 판은 출력의 모양에 영향을 준다. pandas 3.x에서는 문자열 열의 자료형이 str로, 2.x에서는 object로 표시된다. 강의안의 출력은 3.x의 것이므로, 학교 환경이 2.x이면 일부 출력이 강의안과 다르게 보인다(교재 01의 3.2절).

  • 확인 3 1절 셀의 출력이 일곱 줄이고, numpy, pandas, matplotlib, seaborn, scikit-learn의 다섯 줄에 판 번호가 있다. 이 다섯 가운데 설치되어 있지 않다가 있으면 2주차 전에 설치해야 한다.
  • 확인 4 pandas 줄의 첫 숫자를 읽어 2와 3 가운데 어느 것인지 적어 둔다.

파이썬 자체의 판은 다음 셀로 확인한다. 이 셀은 사전 진단 노트북에 없으므로, 필요하면 1절 셀 아래에 셀을 하나 추가하여 실행한 뒤 지운다.

  • 확인 5 출력이 Python 3.으로 시작한다. 확인한 뒤에는 추가한 셀을 지운다. 작업용으로 추가한 셀을 지우는 습관은 시험의 답안 규칙(2.7절)과 같다.

0.3 자료 폴더와 파일의 확인

노트북 2절의 첫 두 셀을 실행한다. 첫 셀은 자료 폴더의 위치를 변수 DATA에 저장하고, 둘째 셀은 그 폴더에 실습 자료 세 파일이 있는지를 확인한다.

DATA = "../kit/data/AICE_공통/"   # 자료 폴더의 위치
import os

for name in ["customers.csv", "laptops.csv", "loans.csv"]:
    print(name, os.path.exists(DATA + name))
customers.csv True
laptops.csv True
loans.csv True

DATA의 값 "../kit/data/AICE_공통/"은 노트북이 있는 폴더(courses/aice/book/)에서 본 상대 경로이다. ..은 한 단계 위의 폴더(courses/aice/)를 뜻하고, 거기서 kit/data/AICE_공통/으로 내려간다. 끝의 /는 뒤에 파일 이름을 이어 붙이기 위한 것이다. os.path.exists는 주어진 경로에 파일이나 폴더가 있으면 True, 없으면 False를 돌려준다. 파일을 열지 않으므로 오류가 나지 않는다.

  • 확인 6 둘째 셀의 출력 세 줄이 모두 True로 끝난다.

파일이 있는 것과 파일을 읽을 수 있는 것은 다르다. 파일의 첫 줄을 글자 그대로 읽어 보면, 파일이 열리는지와 글자가 깨지지 않는지를 함께 확인할 수 있다. 아래 셀은 pandas를 쓰지 않고 파이썬의 open으로 파일을 열어 첫 줄만 읽는다. 이 셀도 노트북에 없으므로 필요하면 셀을 추가하여 실행하고 지운다.

# [예제 6]

0.4 흔한 오류

환경 확인과 파일 확인에서 나는 오류는 몇 가지로 모인다. 아래의 메시지는 모두 교재의 실행 환경에서 해당 코드를 실제로 실행하여 얻은 것이다. 오류 메시지는 여러 줄로 나오지만, 마지막 줄만 읽으면 대부분 원인을 알 수 있다. 마지막 줄의 콜론 앞이 오류의 이름이고 뒤가 내용이다.

오류 1. 라이브러리를 불러오기 전에 썼다. import pandas as pd를 실행하지 않은 채 pd를 쓰면 다음 오류가 난다.

# [예제 1]
pd.__version__
NameError: name 'pd' is not defined

오류 2. 경로 변수를 만들기 전에 썼다. 2절의 첫 셀(DATA = ...)을 실행하지 않고 파일을 열면 다음 오류가 난다.

# [예제 2]
open(DATA + "laptops.csv", encoding="utf-8")
NameError: name 'DATA' is not defined

두 오류는 모두 NameError이다. 이름(변수, 별칭)이 아직 만들어지지 않았다는 뜻이다. 셀의 코드가 틀린 것이 아니라 앞의 셀을 실행하지 않은 것이 원인인 경우가 대부분이다. 노트북을 다시 열었을 때, 그리고 커널이 다시 시작되었을 때 모든 변수가 사라지므로 이 오류가 난다. 노트북을 처음부터 다시 실행하면 해결된다.

오류 3. 설치 이름 대신 불러오는 이름으로 판을 물었다.

# [예제 3]
from importlib.metadata import version

version("sklearn")
PackageNotFoundError: No package metadata was found for sklearn

scikit-learn은 설치되어 있지만, 설치 이름이 scikit-learn이므로 sklearn이라는 이름의 패키지 정보는 없다. 1절의 셀처럼 설치 이름으로 묻는다.

오류 4. 모듈 이름의 철자가 틀렸다.

# [예제 4]
import sklearn.model_selections
ModuleNotFoundError: No module named 'sklearn.model_selections'

ModuleNotFoundError는 라이브러리가 설치되어 있지 않을 때와, 이름의 철자가 틀렸을 때 모두 난다. 이 예에서는 sklearn은 있으나 그 아래의 model_selection을 model_selections로 잘못 적었다. 메시지의 따옴표 안을 한 글자씩 읽어 어느 부분이 틀렸는지를 찾는다. 철자가 맞는데도 이 오류가 나면 그 라이브러리가 설치되어 있지 않은 것이다(부록 A.3).

오류 5. 파일 이름의 철자가 틀렸다.

# [예제 7]
open(DATA + "laptop.csv", encoding="utf-8")
FileNotFoundError: [Errno 2] No such file or directory: '../kit/data/AICE_공통/laptop.csv'

오류 6. 폴더 경로 끝의 /가 빠졌다.

# [예제 8]
DATA2 = "../kit/data/AICE_공통"
open(DATA2 + "laptops.csv", encoding="utf-8")

결과 읽기: 배점표를 읽는 법

배점표는 세 열을 함께 읽는다. 「문항 수」는 범위로, 「배점」은 분야의 합으로 주어지므로, 한 문항의 무게는 두 값을 나누어 구한다. 문항 수가 적을수록 한 문항이 무겁다. 세 분야의 문항 수를 더하면 14가 되어야 하므로, 범위 안의 조합은 (6, 4, 4), (5, 5, 4), (5, 4, 5)의 세 가지뿐이다.

묻는 것 읽는 자리 이 표의 값
한 문항이 가장 무거운 분야 배점 ÷ 문항 수가 가장 큰 행 AI 모델링(문항 수가 4이면 문항당 10점)
한 문항이 가장 가벼운 분야 배점 ÷ 문항 수가 가장 작은 행 데이터 분석(문항 수가 6이면 문항당 5점)
잃어도 되는 점수 100에서 합격 기준을 뺀다 20점
한 분야를 통째로 포기할 수 있는가 각 분야의 배점과 20점을 비교한다 없다. 가장 작은 분야도 30점이다
본 과목의 어느 장이 어느 분야인가 마지막 열 01~02, 03~05, 06~10

손 계산의 결과는 다음과 같다. 데이터 분석은 30을 6과 5로 나누어 5점에서 6점, 데이터 전처리는 30을 5와 4로 나누어 6점에서 7.5점, AI 모델링은 40을 5와 4로 나누어 8점에서 10점이다. 90분을 14문항으로 나누면 한 문항에 쓸 수 있는 시간은 평균 6.4분 남짓이다. 같은 계산을 코드로 하면 다음과 같다.

감점 계산의 예 [선택]

# [예제 11]
# 분야 배점을 문항 수의 범위로 나눈 문항당 점수(추산)
print("데이터 분석", 30 / 6, "~", 30 / 5)
print("데이터 전처리", 30 / 5, "~", 30 / 4)
print("AI 모델링", 40 / 5, "~", 40 / 4)
print("문항당 평균 시간(분)", round(90 / 14, 1))
데이터 분석 5.0 ~ 6.0
데이터 전처리 6.0 ~ 7.5
AI 모델링 8.0 ~ 10.0
문항당 평균 시간(분) 6.4
  • 확인 8 출력의 세 분야 범위(5.0 ~ 6.0, 6.0 ~ 7.5, 8.0 ~ 10.0)가 위의 손 계산과 같고, 문항당 평균 시간이 6.4이다.

다음은 놓친 문항의 조합에 따라 합격과 불합격이 갈리는 예이다. 두 시험지는 모두 가상의 예이며, 실제 시험의 문항 수 조합은 회차마다 다를 수 있다. 문항당 점수는 분야 배점을 그 시험지의 문항 수로 나눈 추산이다.

손 계산은 다음과 같다. 시험지 A(문항 수 6, 4, 4)에서 데이터 분석 한 문항(30 ÷ 6 = 5점)과 AI 모델링 두 문항(40 ÷ 4 = 10점, 두 문항이면 20점)을 놓치면 잃은 점수는 25점이고 남은 점수는 75점이다. 시험지 B(문항 수 5, 4, 5)에서 데이터 전처리 한 문항(30 ÷ 4 = 7.5점)과 AI 모델링 한 문항(40 ÷ 5 = 8점)을 놓치면 잃은 점수는 15.5점이고 남은 점수는 84.5점이다.

# [예제 12]
# 가상의 시험지 A: 문항 수 6, 4, 4. 데이터 분석 1문항과 AI 모델링 2문항을 놓쳤다
lost_a = 30 / 6 * 1 + 40 / 4 * 2
print("시험지 A 잃은 점수", lost_a, "남은 점수", 100 - lost_a)

# 가상의 시험지 B: 문항 수 5, 4, 5. 데이터 전처리 1문항과 AI 모델링 1문항을 놓쳤다
lost_b = 30 / 4 * 1 + 40 / 5 * 1
print("시험지 B 잃은 점수", lost_b, "남은 점수", 100 - lost_b)
시험지 A 잃은 점수 25.0 남은 점수 75.0
시험지 B 잃은 점수 15.5 남은 점수 84.5
  • 확인 9 시험지 A의 남은 점수가 75.0, 시험지 B의 남은 점수가 84.5이다. 둘 가운데 합격 기준(80점)을 넘는 것은 B뿐이다.

두 예에서 놓친 문항의 수는 A가 셋, B가 둘이다. A는 놓친 문항이 하나 더 많을 뿐이지만, 그 가운데 둘이 AI 모델링이어서 합격선 아래로 내려갔다. 이 계산이 보여 주는 것은 두 가지이다. 첫째, AI 모델링 두 문항을 놓치면 다른 분야를 모두 맞혀도 여유가 거의 남지 않는다. 둘째, 앞 문항의 실패가 뒤 문항으로 번지면(2.4절) 놓치는 문항의 수가 한꺼번에 늘어난다. 시험지 앞쪽의 가벼운 문항이라도 뒤 문항의 입력을 만드는 문항이면 실제 무게는 그 문항의 점수보다 크다.

2.4 시험지의 구성

공식 샘플 문항(회귀 문제 한 건, 분류 문제 한 건)에서 확인되는 시험지의 구성은 다음과 같다.

  1. 도입부. 업무 상황(분야와 목표), 유의사항, 데이터의 열 설명이 있다.
  2. 분야의 순서. 문항은 데이터 분석, 데이터 전처리, AI 모델링의 순서로 나온다.
  3. 가이드. 문항마다 가이드가 붙어 대상 데이터프레임, 사용할 함수나 설정값, 결과를 저장할 변수 이름을 지정한다.
  4. 결과의 연쇄. 한 문항의 결과 데이터프레임이 다음 문항의 대상이 된다. 예를 들어 원본에서 이상치를 제거한 표가 결측치 처리의 대상이 되고, 그 결과가 인코딩의 대상이 된다.

[그림 자리: AICE 시험지 화면의 문항과 답안 셀] 시험 전용 페이지에서 한 문항이 표시된 모습. 문항 번호와 지시문, 가이드(대상 데이터프레임, 설정값, 저장할 변수 이름), 그 아래의 답안 셀 하나에 각각 표시를 한다. 공식 사이트의 샘플 문항 웹 보기나 접수 후의 사전 환경점검 화면에서 찍는다. 샘플 문항의 이용 조건(무단 복제 금지)을 확인한 뒤 싣고, 허락되지 않으면 화면 구성을 본뜬 도식으로 대신한다.

문항의 형식은 네 가지이다. 가이드의 조건대로 코드를 처음부터 쓰는 작성, 주어진 코드의 빈칸을 채우는 빈칸 채우기, 실행되지 않거나 틀린 결과를 내는 코드를 고치는 오류 정정, 출력이나 그래프에서 읽은 값을 지정된 변수에 저장하는 답 변수이다. 네 형식의 예와 연습은 교재 01의 7절에서 다룬다.

결과의 연쇄 때문에 앞 문항의 실수는 뒤 문항으로 번진다. 첫 문항(라이브러리 불러오기와 파일 읽기)에서 실패하면 시험지 전체가 영향을 받는다. 0절에서 환경과 파일을 먼저 확인한 까닭이 여기에 있다. 본 과목이 학기 내내 한 벌의 자료를 이어서 가공하는 까닭도 같다(5절).

2.7 응시 중 유의사항과 본 과목의 답안 규칙

수험자 가이드의 Associate 응시 중 유의사항은 다음 다섯 가지이다.

  1. 답안은 하나의 셀에만 작성한다. 작업용으로 추가한 셀은 제출 전에 지운다. 여러 셀로 제출하면 채점되지 않는다.

본 과목은 이 다섯 가지를 수업의 답안 규칙으로 삼고, 모든 연습과 시험에 같은 규칙을 적용한다. 한 문항의 답은 한 셀에 쓰고, 변수 이름은 가이드를 그대로 따르며, 답은 손으로 옮겨 적지 않고 코드로 구하여 저장한다. 제출 전에는 커널을 다시 시작하고 처음부터 실행하여 같은 결과가 나오는지 확인한다. 자세한 규칙은 교재 01의 7.2절과 부록 B에 있다.

사전 환경점검은 접수를 마친 응시자에게만 열리고, 기간은 2.8절의 최신 자료 자리에 있다. 15주차의 수업일이 이 기간에 들지 않으면 수업에서는 절차만 안내하고, 점검은 각자 수행하여 결과를 제출한다.

이 절에서는 교수가 완성된 노트북 한 편을 위에서 아래로 실행하여 보인다. 수강생은 실습하지 않고 흐름을 본다. 노트북은 학기 공통 자료(5절)를 처음 읽는 셀에서 시작하여, 정제와 인코딩, 분할과 스케일링을 거쳐 모델의 학습과 평가로 끝난다. 시험지 한 장의 흐름과 같고, 학기 전체의 목차와도 같다.

  2. 코드는 짧다. 각 단계는 대부분 몇 줄의 함수 호출이다. 어려운 것은 코드의 길이가 아니라, 가이드가 지정한 대상과 설정값과 변수 이름을 정확히 지키는 일이다.
  3. 모델의 학습에는 시간이 걸린다. 격자 탐색과 신경망의 학습은 다른 셀보다 오래 걸린다. 시험의 90분 안에서 이 시간을 미리 계산해 두어야 한다(교재 11).

파일 크기 업무 상황 쓰는 곳

6. 사전 진단

사전 진단은 1주차의 과제이다. 성적에 반영하지 않는다. 결과는 두 곳에 쓰인다. 첫째, 2주차부터의 편성을 기준 편성(예 A)으로 진행할지, 교재 01을 두 주에 나누는 편성(예 B)으로 바꿀지를 정한다(1.2절). 둘째, 개념 문항의 결과에 따라 교재 03, 05, 06, 07의 도입부에서 설명할 분량을 정한다.

6.1 구성

노트북 AICE_00주차_실습_학생용.ipynb에서 푼다. 자료는 laptops.csv이다.

절 문항 내용 답하는 방법
1 실습 환경 확인(라이브러리의 설치 여부와 판 번호) 셀을 실행한다
2 1~9 pandas의 기초 조작: 파일 읽기, 크기, 결측치 세기, 조건에 의한 행 선택(조건 하나, 조건 둘), 열 선택, 값별 빈도, 그룹별 평균, 정렬 코드를 작성하여 지정된 변수에 저장한다
3 10~15 개념 확인: 결측치, 데이터 분할의 이유, 분류와 회귀의 구분(두 문항), 평가 지표의 뜻(두 문항) 보기의 번호를 답 변수(예: d10 = 2)에 저장한다
4 걸린 시간과 자가 채점 시간을 적고 셀을 실행한다

6.2 푸는 방법

  • 60분 안팎을 기준으로 한 번에 끝까지 푼다. 걸린 시간을 4절의 minutes에 적는다.
  • 공식 문서(pandas 등)는 참고하여도 된다. 생성형 AI, 검색으로 찾은 코드, 다른 사람의 도움은 쓰지 않는다(1.5절). 지금의 수준을 정확히 재야 편성을 바르게 정할 수 있다.
  • 한 문항의 답은 한 셀에 작성하고, 문항이 지정한 변수 이름을 그대로 쓴다. 시험의 답안 규칙과 같다.
  • 풀지 못한 문항은 비워 두고 다음 문항으로 넘어간다. 개념 문항을 모르면 답 변수를 None으로 둔다.

6.3 자가 채점과 제출

4절의 자가 채점 셀은 답 변수의 값을 정해진 꼴의 글자로 바꾼 뒤 해시 값으로 비교한다. 셀 안에는 정답이 적혀 있지 않다. 문항마다 맞음 또는 틀림 또는 미응답을 출력하고, 끝에 pandas 문항(1~9)의 정답 수와 전체 정답 수, 걸린 시간을 출력한다.

자가 채점 셀은 모든 문항을 푼 뒤 한 번만 실행하고, 결과를 보고 답을 고치지 않는다. 고친 답은 지금의 수준을 나타내지 않는다. 틀린 문항은 2주차 수업에서 함께 확인한다.

제출물. 실행을 마친 노트북 파일. 1절의 환경 확인 출력과 4절의 자가 채점 출력이 있어야 한다. 제출 기한은 2주차 수업 전날이다.

6.4 진행 단계

사전 진단은 아래의 다섯 단계로 진행한다. 단계마다 끝에 확인할 것이 있다. 확인이 화면과 다르면 다음 단계로 넘어가기 전에 해당 단계의 「막힐 때」 표를 본다.

단계 1. 시작 시각을 적고 1절과 2절 첫 두 셀을 실행한다

  1. 시작 시각을 종이에 적어 둔다. 걸린 시간을 4절에 적기 위함이다.
  2. 노트북을 위에서부터 차례로 실행한다. 1절의 환경 확인 셀, 2절의 DATA 셀, 파일 확인 셀이 차례로 실행된다. 0절에서 이미 실행하였더라도, 노트북을 다시 열었으면 변수가 사라졌으므로 다시 실행한다.
  • 확인 11 2절의 파일 확인 셀의 출력 세 줄이 모두 True이다.

단계 2. pandas 문항 1~9를 순서대로 푼다

  1. 문항 1에서 pandas를 불러오고 자료를 lap에 읽는다. 문항 2~9는 모두 lap을 쓰므로, 문항 1의 셀이 오류 없이 실행되어야 뒤 문항을 풀 수 있다.
  2. 각 문항의 지시문에서 세 가지를 찾아 표시한 뒤 코드를 쓴다. 대상(어느 데이터프레임, 어느 열), 조건(이상, 같음, 두 조건), 저장할 변수 이름(d2, d3 …)이다.
  3. 답을 저장한 셀의 끝에서 변수를 출력하거나 셀의 마지막 줄에 변수를 두어, 값이 화면에 나오게 한다. 자가 채점은 변수의 값을 보므로 출력은 채점에 쓰이지 않지만, 자기 답을 눈으로 확인하기 위하여 출력한다.
  4. 한 문항에 10분 넘게 막히면 셀을 비워 두거나 지금까지 쓴 코드를 남긴 채 다음 문항으로 넘어간다.
  • 확인 12 문항 1의 셀이 오류 없이 실행되어 표의 앞 3행이 출력되었고, 열 이름이 0.3절에서 읽은 머리글의 순서와 같다.
  • 확인 13 문항 2~9의 셀마다 지시문이 정한 변수 이름(d2~d9)이 셀 안에 그대로 있다. D2, d_2, ans2처럼 다른 이름을 쓴 셀이 없다.

단계 3. 개념 문항 10~15를 푼다

  1. 보기를 모두 읽고 옳은 것 하나의 번호를 고른다.
  2. 셀의 None을 지우고 번호를 정수로 적는다(d10 = 2처럼). 따옴표를 붙여 "2"로 적으면 글자가 되어 정수와 다르게 취급된다.
  3. 셀을 실행한다. 답을 적기만 하고 실행하지 않으면 변수의 값이 바뀌지 않는다.
  • 확인 14 문항 10~15의 셀이 모두 실행되어 왼쪽에 실행 번호가 붙어 있다. 모르는 문항은 None으로 남아 있다.

단계 4. 걸린 시간을 적고 자가 채점 셀을 한 번 실행한다

  1. 시작 시각에서 지금까지 걸린 시간을 분 단위의 정수로 계산하여 minutes = None의 None 자리에 적고 그 셀을 실행한다.
  2. 자가 채점 셀을 한 번 실행한다.
  3. 결과를 보고 답을 고치지 않는다(6.3절).
  • 확인 15 자가 채점의 출력이 열여덟 줄이다. 문항별 열다섯 줄, pandas 문항(1~9) 정답 수, 전체 정답 수, 걸린 시간(분)의 세 줄이며, 마지막 줄의 값이 None이 아니라 적은 정수이다.

단계 5. 저장하고 제출한다

  1. 노트북을 저장한다(File 메뉴의 Save 또는 Ctrl+S).
  2. 작업용으로 추가한 셀(0.2절과 0.3절에서 추가한 셀)이 남아 있으면 지우고 다시 저장한다.
  3. 강의에서 안내한 방법으로 노트북 파일(.ipynb)을 제출한다. 강의안(.md)이나 화면 캡처를 제출하지 않는다.

문항 2에서 TypeError: 'tuple' object is not callable 크기를 구하는 속성에 괄호를 붙였다 공식 문서에서 그 속성의 쪽을 찾아 사용 예를 본다. 속성은 괄호 없이 쓴다
출력이 문항의 지시와 다르게 보인다(행이 너무 많거나 적다) 조건이 틀렸거나 지시의 일부(정렬의 방향, 행의 수)를 놓쳤다 지시문의 세 가지(대상, 조건, 변수 이름)를 다시 대조한다
자가 채점에서 풀었다고 생각한 문항이 틀림 또는 미응답 변수 이름이 다르거나, 값의 형태(정수, 데이터프레임, 시리즈)가 지시와 다르다 고치지 않고 그대로 제출한다. 2주차에 원인을 함께 확인한다
자가 채점 셀에서 NameError 자가 채점 셀이 아닌 그 위의 셀(minutes)을 실행하지 않았다 minutes 셀을 실행한 뒤 자가 채점 셀을 다시 실행한다

6.5 자가 채점 출력의 읽기

자가 채점 셀의 출력은 세 부분으로 읽는다. 첫 열다섯 줄은 문항별 결과이고, 다음 두 줄은 정답 수이며, 마지막 줄은 걸린 시간이다. 출력의 각 줄은 셀의 print 문이 정한 꼴을 따른다.

묻는 것 읽는 자리 읽는 법
어느 문항을 틀렸는가 문항 N 줄의 끝 틀림 또는 미응답인 문항의 번호를 적는다. 비워 둔 문항과 틀린 문항은 구분되지 않는다
pandas의 기초 조작은 어느 정도인가 pandas 문항(1~9) 정답 수 줄 9문항 가운데 맞힌 수이다
개념 문항은 몇 개 맞혔는가 전체 정답 수에서 pandas 문항 정답 수를 뺀다 6문항 가운데 맞힌 수이다
시험의 속도와 견주어 어떤가 걸린 시간(분) 줄 시험은 14문항을 90분에 푼다. 15문항을 90분 넘게 걸렸으면 속도를 함께 연습해야 한다

예를 들어 출력이 pandas 문항(1~9) 정답 수: 6 / 9, 전체 정답 수: 10 / 15, 걸린 시간(분): 75라면(가상의 예), 개념 문항의 정답 수는 10 - 6 = 4이다. 이 수강생은 pandas 문항 셋과 개념 문항 둘을 놓쳤고, 시험의 문항당 평균 시간(6.4분)보다 조금 느리다.

틀린 문항은 다음 자리에서 다시 공부한다. 사전 진단을 제출한 뒤에 본다.
