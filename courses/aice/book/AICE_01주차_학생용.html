[1주차] 데이터 불러오기와 구성 파악

비즈니스빅데이터분석

1주차

데이터 불러오기와 구성 파악

2027학년도 「비즈니스빅데이터분석」의 준비 중인 교재입니다. 편집 상태를 검토하기 위해 미리 공개한 것으로, 수업 전에 내용과 순서가 바뀔 수 있습니다.

학사 2주차 · 교재 01 · 1부 데이터 분석 · 출제 분야: 데이터 분석 > 필요 라이브러리 설치, 데이터 구성 및 특성 파악, 데이터 품질 점검

AICE Associate의 시험지는 표 데이터 한 건을 받아 라이브러리를 불러오고 파일을 읽는 문항으로 시작한다. 이어지는 문항은 자료의 크기, 자료형, 결측치, 범주별 빈도와 같은 구성을 확인하게 하고, 그 결과를 지정된 변수에 저장하게 한다. 이 단계에서 파일을 읽지 못하거나 변수 이름을 잘못 지정하면 뒤의 모든 문항이 영향을 받는다. 시험지 전체가 첫 문항의 결과 위에 쌓이기 때문이다.

본 장은 pandas로 CSV 파일을 읽고 자료의 구성과 품질을 코드로 확인하는 방법을 다룬다. 내용 자체는 선수 과목에서 한 번 사용해 본 수준이므로, 본 장의 중점은 새 기능의 학습보다 시험 문항의 형식에 맞추어 답을 산출하고 저장하는 연습에 있다. 본 장에서 작성하는 명세표와 품질 점검의 결과는 3장(결측치·이상치 처리)의 출발점이 된다.

학습 목표

  1. 데이터 분석에 쓰는 라이브러리를 관용 별칭으로 불러오고, 설치 여부와 판 번호를 확인한다.
  2. CSV 파일의 구조와 경로를 이해하고, read_csv로 파일을 읽어 앞뒤의 행을 확인한다.
  3. 자료의 크기, 자료형, 요약 통계, 결측치 수, 고유값 수, 중복 행 수를 코드로 확인하고 품질 문제를 찾는다.
  4. 열을 선택하고, 하나 이상의 조건으로 행을 선택한다.
  5. 빈도 집계, 그룹별 집계, 정렬로 물음의 답을 산출하여 지정된 변수에 저장한다.
  6. 모르는 함수의 사용법을 공식 문서에서 찾고, 시험의 답안 규칙에 맞추어 답을 작성한다.

1. 라이브러리 불러오기와 설치

1.1 import와 별칭

데이터 분석에 쓰는 라이브러리는 관용적인 별칭으로 불러온다. 시험의 첫 문항은 “pandas를 별칭 pd로 불러온다”처럼 별칭까지 지정하는 경우가 많다. 지정된 별칭과 다른 이름을 쓰면 뒤 문항의 코드가 그 이름을 찾지 못하므로, 별칭은 지시를 그대로 따른다.

라이브러리 관용 별칭 용도 본 과목의 장
numpy np 배열과 수치 계산 전 장
pandas pd 표 데이터의 읽기, 선택, 집계, 가공 1~5장
matplotlib.pyplot plt 그림, 축, 제목, 범례 2장, 8장, 10장
seaborn sns 통계 그래프 2장, 8장
sklearn (별칭 없음, 필요한 것만 from으로) 전처리, 모델, 평가 4~8장
tensorflow tf 신경망 9~10장 
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

print("pandas", pd.__version__)
print("numpy", np.__version__)
print("seaborn", sns.__version__)
pandas 3.1.1
numpy 2.5.4
seaborn 0.13.2

import 모듈 as 별칭은 모듈 전체를 별칭으로 불러온다. 반면 scikit-learn은 필요한 함수와 클래스만 from sklearn.model_selection import train_test_split처럼 불러오는 것이 관례이다. 판 번호는 모듈의 __version__ 속성에 있다. 셀의 마지막 줄이 값만 적힌 식이면 노트북은 그 값을 출력한다. 아래 셀은 print 없이 판 번호를 출력한다.

import sklearn

sklearn.__version__
'1.9.1'

2. CSV 파일의 구조와 읽기

2.1 CSV 파일의 구조

CSV(comma-separated values)는 한 줄이 한 행이고, 쉼표로 열을 구분하는 텍스트 파일이다. 첫 줄은 열 이름(머리글)이다. 아래 셀은 pandas를 쓰지 않고 파일의 앞 세 줄을 그대로 출력한다.

DATA = "../kit/data/AICE_공통/"   # 자료 폴더의 위치

with open(DATA + "customers.csv", encoding="utf-8") as f:
    for i in range(3):
        print(f.readline().rstrip())
customer_id,age,gender,region,grade,tenure_months,visits_per_month,avg_session_min,cart_items,coupon_use_rate,app_user,payment,cs_calls,last_login_days,marketing_agree,annual_spend,churn
C02493,30.0,F,Gyeonggi,VIP,45,18.6,14.0,7,0.16,N,Card,2,16,Y,436.5,0
C01009,43.0,M,Incheon,Gold,50,13.1,19.3,5,0.06,N,Mobile,1,14,N,282.6,0

출력에서 세 가지를 확인한다. 첫째, 첫 줄은 17개의 열 이름이다. 둘째, 값이 비어 있는 칸은 쉼표 사이에 아무것도 없다(,,). pandas는 이를 결측치(NaN)로 읽는다. 셋째, 숫자와 글자가 섞여 있으나 파일 안에서는 모두 글자이다. 자료형은 pandas가 읽으면서 열마다 추정한다.

2.2 경로

DATA = "../kit/data/AICE_공통/"의 ..은 한 단계 위의 폴더를 뜻한다. 노트북이 있는 폴더(courses/aice/book/)에서 세 단계 올라가 assets/data/AICE_공통/으로 내려간다. 경로를 변수 하나에 저장해 두면 자료 폴더의 위치가 바뀌어도 그 한 줄만 고치면 된다. 시험에서는 파일의 경로가 문항에 주어지므로, 주어진 문자열을 그대로 사용한다.

오류 메시지 원인
FileNotFoundError: [Errno 2] No such file or directory 경로나 파일 이름의 오타, 확장자 누락, 현재 폴더의 오해
UnicodeDecodeError: 'utf-8' codec can't decode byte ... 파일의 문자 인코딩이 UTF-8이 아니다. 한글 윈도우에서 저장한 파일은 encoding="cp949"로 읽는다
ParserError: Error tokenizing data 구분자가 쉼표가 아니거나 행마다 열의 수가 다르다. sep 인자를 확인한다

pd.read_csv는 CSV 파일을 읽어 데이터프레임(DataFrame)을 돌려준다. 결과를 변수에 저장하지 않으면 읽은 내용이 남지 않는다. 시험에서는 저장할 변수 이름을 지정하므로(예: df), 그 이름을 그대로 쓴다. 맨 왼쪽의 0, 1, 2, …는 행의 이름인 인덱스로, 파일에 없던 것을 pandas가 붙인 것이다. 열이 많으면 화면의 너비에 맞추어 여러 줄로 나뉘어 출력되고, 줄 끝의 \는 다음 줄로 이어진다는 표시이다.

인자 뜻 기본값 쓰는 경우
sep 열의 구분자 "," 탭으로 구분된 파일은 sep="\t"
encoding 문자 인코딩 UTF-8 한글 윈도우에서 저장한 파일은 "cp949"
index_col 인덱스로 쓸 열 없음 회원 번호를 행 이름으로 쓰려면 index_col="customer_id"
usecols 읽을 열의 목록 모든 열 필요한 열만 읽을 때

4.1 열 선택

4.2 조건에 의한 행 선택

비교식 df["grade"] == "VIP"는 행마다 True나 False를 담은 시리즈를 만든다. 이 시리즈를 대괄호에 넣으면 True인 행만 남는다. 이를 불리언 인덱싱(boolean indexing)이라 한다.

vip = df[df["grade"] == "VIP"]
vip.shape
(228, 17)

조건이 둘 이상이면 각 조건을 괄호로 감싸고 &(그리고), |(또는), ~(부정)로 잇는다. 괄호가 필요한 까닭은 &가 ==보다 먼저 계산되기 때문이다. 조건을 변수에 먼저 저장하면 코드가 짧아지고 오류를 찾기 쉽다.

cond = (df["grade"] == "VIP") & (df["churn"] == 1)
len(df[cond])
26

VIP 회원 228명 가운데 이탈한 회원은 26명이다. 여러 값 가운데 하나에 해당하는 행은 isin으로 고른다. loc[행 조건, 열 목록]은 행과 열을 한 번에 선택한다.

df.loc[df["payment"].isin(["Mobile", "Point"]), ["customer_id", "payment"]].head(3)
   customer_id payment
1       C01009  Mobile
8       C02072   Point
11      C02914  Mobile

4.3 and를 쓰면 생기는 오류

파이썬의 and와 or는 값 하나의 참과 거짓을 판단하는 연산자이다. 시리즈 전체에 and를 쓰면 pandas는 3,030개의 참·거짓을 하나로 줄일 방법을 알 수 없어 오류를 낸다. 시험의 오류 정정 문항에서 자주 쓰이는 유형이다.

df[df["grade"] == "VIP" and df["churn"] == 1]
ValueError: The truth value of a Series is ambiguous. Use a.empty, a.item(), a.any() or a.all().

정정하는 방법은 and를 &로 바꾸고 각 조건을 괄호로 감싸는 것이다. 오류 메시지의 마지막 줄(ValueError: The truth value of a Series is ambiguous)을 읽으면 원인을 짐작할 수 있다. 오류 메시지는 마지막 줄부터 읽는다.

연산 값 하나 시리즈
그리고 and &
또는 or |
부정 not ~

5.5 정렬한 결과에서 행 꺼내기

데이터프레임을 정렬하면 인덱스는 원래의 행 번호를 그대로 유지한다. 정렬한 결과의 첫 행을 iloc[0]으로 꺼내면 정렬 순서의 첫 행이, loc[0]으로 꺼내면 원래 0번이었던 행이 나온다. 정렬한 뒤 위치로 꺼낼 때에는 iloc을 쓴다.

6. 공식 문서의 구성과 검색

시험은 제한적 오픈북이다. 시험지 안에서 열 수 있는 일곱 곳의 공식 문서(NumPy, pandas, matplotlib, seaborn, scikit-learn, TensorFlow, XGBoost)만 참고할 수 있고, 검색 엔진, 생성형 AI, 개인 노트는 쓸 수 없다. 함수의 인자를 모두 외울 수는 없으므로, 공식 문서에서 필요한 부분을 빨리 찾는 능력이 점수에 직접 영향을 준다.

pandas의 문서는 크게 두 부분으로 구성된다.

부분 내용 쓰는 경우
User Guide 주제별 설명과 예제(입출력, 선택, 결측치, 그룹별 집계 등) 무엇을 써야 할지 모를 때
API reference 함수와 메서드 하나마다 한 쪽. 인자, 반환값, 예제 함수 이름은 알고 인자를 모를 때

API reference의 한 쪽은 언제나 같은 순서로 구성된다. 함수의 서명(인자와 기본값), 한 줄 요약, Parameters(인자마다 자료형과 뜻), Returns(돌려주는 값), See also(관련 함수), Examples(예제)이다. 인자의 이름과 기본값을 찾을 때에는 서명과 Parameters를, 사용법이 헷갈릴 때에는 Examples를 먼저 본다. 예를 들어 value_counts의 쪽에서 normalize를 찾으면 “Return proportions rather than frequencies”라는 설명과 기본값 False를 확인할 수 있다.

찾는 것 pandas 문서에서 찾는 위치
CSV 읽기의 인자 API reference > Input/output > pandas.read_csv
결측치 처리 User Guide > Working with missing data
조건에 의한 선택 User Guide > Indexing and selecting data > Boolean indexing
그룹별 집계 User Guide > Group by: split-apply-combine
메서드 하나의 인자 API reference > DataFrame 또는 Series > 메서드 이름

노트북 안에서는 함수 이름 뒤에 ?를 붙여 실행하거나(pd.read_csv?), 괄호 안에 커서를 두고 Shift+Tab을 누르면 같은 설명을 볼 수 있다. 이 설명은 라이브러리에 들어 있는 문서이므로 시험 환경에서도 쓸 수 있는지는 응시 규정을 따른다.

7. 문항의 형식과 답안 규칙

7.1 문항의 네 가지 형식

AICE Associate의 공개 샘플 문항에서 확인되는 문항의 형식은 네 가지이다. 본 과목의 연습 문항과 시험 문항도 이 네 형식으로 출제한다.

형식 요구하는 것 예
작성 가이드의 조건대로 코드를 처음부터 작성한다 “등급별 연간 구매액의 평균을 구하여 grade_mean에 저장한다”
빈칸 채우기 주어진 코드의 빈칸을 채워 실행한다 df.___("grade")["churn"].mean()
오류 정정 실행되지 않거나 결과가 틀린 코드를 고친다 4.3절의 and 오류
답 변수 출력이나 그래프에서 읽은 값을 지정된 변수에 저장한다 “이탈 비율이 가장 높은 등급을 ans에 저장한다”

7.2 답안 규칙

AICE 수험자 가이드가 정한 응시 중 유의사항을 수업의 규칙으로 삼는다.

  1. 한 문항의 답은 한 셀에 작성한다. 작업용으로 추가한 셀은 제출 전에 지운다. 여러 셀에 나누어 작성하면 채점되지 않는다.
  2. 변수 이름과 파일 이름은 가이드를 그대로 따른다. ans1을 Ans1이나 answer1로 쓰면 채점 도구가 찾지 못한다.
  3. 답은 코드로 구하여 저장한다. 출력에서 읽은 값이라도 가능하면 idxmax()처럼 코드로 구한다. 손으로 옮겨 적으면 오타가 생기고, 앞 단계가 바뀌었을 때 값이 갱신되지 않는다.
  4. 앞 문항의 결과를 덮어쓰지 않는다. 가이드가 새 변수에 저장하라고 하면 원본 변수를 고치지 않는다. 뒤 문항이 원본을 다시 쓸 수 있다.
  5. 위에서 아래로 실행했을 때 같은 결과가 나와야 한다. 셀을 이리저리 다시 실행하면 변수의 상태가 화면과 달라진다. 제출 전에 커널을 다시 시작하고 처음부터 실행하여 확인한다.

8. 중심 실습: 공통 자료의 명세표와 물음 5개

노트북 AICE_01주차_실습_학생용.ipynb의 2부에서 수행한다. 학기 공통 자료의 구성을 코드로 정리하고, 물음의 답을 지정된 변수에 저장한다.

준비. 단계 1의 셀을 실행하여 자료를 df에 읽는다.

절차.

단계 할 일 답을 담을 변수

단계 2의 명세표는 세 시리즈(df.dtypes, df.nunique(), df.isna().sum())를 열로 묶은 데이터프레임이다. 세 시리즈 모두 열 이름을 인덱스로 가지므로, 딕셔너리로 묶어 pd.DataFrame에 넘기면 열 이름을 기준으로 맞추어진다.

변수 물음
