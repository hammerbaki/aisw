AICE Associate의 데이터 전처리 문항은 앞 문항이 만든 데이터프레임을 받아 가이드가 지정한 처리를 하고, 그 결과를 다시 지정된 변수에 저장하게 한다. 이상치를 조건이나 사분위수 범위로 제거하고, 결측치가 있는 행을 삭제하거나 다른 값으로 대체하며, 필요 없는 열을 삭제하고 인덱스를 다시 매기는 일이 대표적이다. 한 문항의 결과가 다음 문항의 입력이 되므로, 한 단계에서 행 수가 어긋나면 그 뒤의 인코딩, 분할, 모델의 점수가 모두 달라진다.

본 장은 1장과 2장에서 찾은 품질 문제(중복 행, 결측치, 불가능한 값, 이상치, 식별자 열)를 처리하는 방법을 다룬다. 함수마다 인자의 뜻과 결과의 행 수를 확인하고, 처리 결과를 변수에 다시 저장하는 습관을 익힌다. 중심 실습에서 작성하는 정제본 df_clean(2940행 16열, 결측치 0)은 4장(인코딩)부터 10장까지 모든 장의 출발점이 된다.

학습 목표

  1. 열별·행별 결측치의 수를 집계하고, dropna의 subset, how, thresh 인자로 삭제할 행을 정한다.
  2. 수치형 열은 평균이나 중앙값으로, 범주형 열은 최빈값으로 결측치를 대체하고, 대체값의 선택 기준을 설명한다.
  3. 업무상 불가능한 값을 조건으로 제거하고, 결측치를 남길지를 조건에 반영한다.
  4. 사분위수 범위(IQR)로 이상치의 경계를 계산하여 경계 밖의 행을 제거한다.
  5. 열을 삭제하고, drop_duplicates의 subset과 keep으로 중복 행을 삭제하며, 인덱스를 재설정한다.
  6. 처리 결과를 변수에 다시 저장하고, 원본을 copy로 보존하며, inplace를 쓰지 않는 이유를 설명한다.

1. 결측치의 집계와 결측 행의 삭제

1.1 열별, 행별 결측치의 수

결측치(missing value)는 값이 기록되지 않은 칸이다. pandas는 결측치를 NaN(문자열 열은 None도)으로 표시하며, isna()는 어느 표시이든 True로 판정한다. 처리 방법을 정하려면 열별 결측치의 수와 행별 결측치의 수를 따로 센다. 한 열에 몰려 있으면 그 열만 다루면 되고, 여러 열에 흩어져 있으면 행을 지우는 처리의 손실이 커진다.

sum()과 any()에 axis=1을 주면 열 방향이 아니라 행 방향으로 계산한다. isna().any(axis=1)은 결측치가 하나라도 있는 행에서 True이고, isna().sum(axis=1)은 행마다 결측치의 수이다.

axis 계산 방향 isna().sum(axis=...)의 결과
0 (기본값) 위에서 아래로, 열마다 열마다 결측치의 수
1 왼쪽에서 오른쪽으로, 행마다 행마다 결측치의 수 
# [예제 3]
na = df.isna().sum()
print(na[na > 0])
print(df.isna().any(axis=1).sum())
print(df.isna().sum(axis=1).value_counts())

1.2 dropna와 주요 인자

dropna()는 결측치가 있는 행을 삭제한 새 데이터프레임을 돌려준다. 원본은 바뀌지 않는다.

인자 뜻 기본값
subset 결측치를 검사할 열의 목록 모든 열
how "any": 검사한 열 가운데 하나라도 결측이면 삭제. "all": 모두 결측일 때만 삭제 "any"
thresh 결측이 아닌 값이 이 수 이상인 행만 남긴다. how와 함께 쓸 수 없다 없음
axis 1이면 행 대신 결측치가 있는 열을 삭제한다 0 
# [예제 4]
print(df.dropna().shape)
print(df.dropna(subset=["annual_spend"]).shape)
print(df.dropna(subset=["age", "gender"]).shape)
print(df.dropna(subset=["age", "gender"], how="all").shape)
print(df.dropna(thresh=16).shape)
(2711, 17)
(3018, 17)
(2895, 17)
(3028, 17)
(3019, 17)

인자를 주지 않으면 모든 열을 검사하므로 319행이 삭제되어 2,711행이 남는다. subset=["annual_spend"]는 연간 구매액이 결측인 12행만 삭제한다. age와 gender 가운데 하나라도 결측인 행을 지우면 2,895행이, 둘 다 결측인 행만 지우면 3,028행이 남는다. 이 자료는 17열이므로 thresh=16은 결측치가 하나 이하인 행을 남기며, 결측치가 둘인 11행이 삭제된다.

dropna의 결과는 행의 수로 확인하고, 삭제된 행의 수가 1.1절의 집계와 맞는지 대조한다(예: annual_spend의 결측치 12개).

  • 확인 3 다섯 줄이 차례로 (2711, 17), (3018, 17), (2895, 17), (3028, 17), (3019, 17)이다.

셀이 멈추고 오류가 난다 KeyError: ['annul_spend'] subset의 열 이름 오타 df.columns를 출력하여 철자를 맞춘다

오류는 없으나 행 수가 그대로이다 (없음) 결과를 변수에 다시 저장하지 않았다 df = df.dropna(...)(6.1절)

1.3 결측의 유형과 처리 방법의 선택

결측 행의 삭제는 간단하지만 자료를 잃는다. 지울지 채울지는 “값이 왜 비었는가”에 따라 결과의 치우침이 달라진다. 통계학은 결측이 생기는 방식을 결측 여부가 무엇과 관련되어 있는가로 세 가지로 나눈다(Rubin, 1976).

유형 뜻 예 행을 지우거나 대표값으로 채울 때
완전 무작위 결측(MCAR) 결측 여부가 어떤 값과도 관련이 없다 서버 장애로 임의의 기록 몇 건이 저장되지 않았다 표본이 줄 뿐 남은 자료의 분포는 치우치지 않는다

2. 평균·중앙값·최빈값에 의한 대체

2.1 대체값의 선택

fillna(값)은 결측치를 주어진 값으로 채운 새 시리즈(또는 데이터프레임)를 돌려준다. 대체값은 열의 성격에 따라 고른다.

열 대체값 구하는 코드
수치형, 분포가 대칭에 가깝고 극단값이 없다 평균 df["열"].mean()
수치형, 분포가 치우쳤거나 극단값이 있다 중앙값 df["열"].median()
범주형(문자열) 최빈값 df["열"].mode()[0]

mean()과 median()은 결측치를 빼고 계산한다(skipna=True가 기본값). 평균은 극단적인 값에 끌려가지만 중앙값은 그렇지 않다. 원본의 age는 평균이 40.31세, 중앙값이 38.0세인데, 999세 같은 입력 오류가 평균을 끌어올린 결과이다. 그래서 중심 실습은 이상치를 먼저 제거한 뒤 중앙값으로 대체한다.

2.2 수치형 열의 대체

한 열을 대체한 결과는 그 열에 다시 저장한다. 아래 셀은 원본을 복사한 d에서 age를 대체하므로 원본 df의 결측치는 그대로 남는다.

# [예제 5]
d = df.copy()
d["age"] = d["age"].fillna(d["age"].median())
print(df["age"].isna().sum(), d["age"].isna().sum())
97 0
  • 확인 4 출력이 97 0이다. 앞의 97은 원본 df의 결측치 수이고 뒤의 0은 복사본 d의 결측치 수이다. 두 값이 모두 0이면 d = df로 이름만 붙여 원본까지 바꾼 것이다(6.2절).

2.3 범주형 열의 대체와 mode()[0]

mode()는 최빈값을 하나의 값이 아니라 시리즈로 돌려준다. 가장 많은 값이 둘 이상일 수 있기 때문이다. 값 하나를 꺼내려면 [0]을 붙인다.

# [예제 6]
print(df["gender"].mode())
d = df.copy()
wrong = d["gender"].fillna(d["gender"].mode())
right = d["gender"].fillna(d["gender"].mode()[0])
print(wrong.isna().sum(), right.isna().sum())
0    F
Name: gender, dtype: str
40 0

[0]을 빠뜨린 wrong은 오류 없이 결측치 40개를 그대로 남긴다. fillna에 시리즈를 주면 같은 인덱스의 값끼리 맞추어 채우는데, 최빈값 시리즈의 인덱스는 0 하나뿐이어서 0번 행이 결측일 때에만 그 행이 채워지기 때문이다. 오류 정정 문항에서 자주 쓰이는 유형이다.

2.4 여러 열의 한 번 대체

데이터프레임의 fillna에 {열 이름: 대체값}의 사전을 주면 여러 열을 열마다 다른 값으로 한 번에 대체한다. 예를 들어 d.fillna({"visits_per_month": d["visits_per_month"].median(), "gender": d["gender"].mode()[0]})는 두 열을 채우고, 사전에 없는 열의 결측치는 그대로 남긴다. d.fillna(0)처럼 값 하나를 주면 모든 열을 같은 값으로 채우므로, 열마다 대체값이 다른 이 자료에는 쓰지 않는다.

2.5 대체가 분포에 주는 영향

대체는 비어 있는 칸에 그럴듯한 값을 넣는 일이지 실제 값을 되찾는 일이 아니다. 같은 값을 여러 칸에 넣으면 분포가 바뀐다. 평균으로 채우면 평균은 그대로이지만, 채운 칸은 평균과의 거리(편차)가 0이어서 편차 제곱합에 더하는 것이 없는데 나누는 수(n - 1)는 커지므로 표준편차가 작아진다. 중앙값으로 채워도 채운 값이 분포의 가운데에 몰리므로 표준편차가 작아진다. pandas의 std()는 n - 1로 나누는 방식(ddof=1)이 기본값이다. 실제 자료의 avg_session_min(결측치 61개)으로 비교한다.

3. 조건에 의한 이상치 제거

3.1 업무상 불가능한 값

이상치는 두 종류로 나누어 다룬다. 하나는 업무상 있을 수 없는 값(나이 0세와 999세, 음수의 구매액)이고, 다른 하나는 가능하지만 다른 값들과 동떨어진 값이다. 앞의 것은 업무의 기준으로 정한 조건으로, 뒤의 것은 4절의 사분위수 범위로 제거한다.

# [예제 8]
print((df["age"] < 19).sum(), (df["age"] > 80).sum())
print(df.loc[(df["age"] < 19) | (df["age"] > 80), "age"].value_counts())
print((df["annual_spend"] <= 0).sum())
4 6
age
999.0    6
0.0      4
Name: count, dtype: int64
5

19세 미만인 값이 4개, 80세 초과인 값이 6개이며, 모두 0과 999이다. 연간 구매액이 0 이하인 값은 5개이다. 본 교재는 회원의 나이를 19세 이상 80세 이하로 보고, 연간 구매액은 0보다 커야 한다고 정한다.

3.2 between과 결측치

Series.between(a, b)는 a <= 값 <= b이면 True이다. 경계값을 포함하는 것이 기본값(inclusive="both")이다. 결측치는 비교할 수 없으므로 False가 된다.

# [예제 9]
cond = df["age"].between(19, 80)
print((~cond).sum(), df["age"].isna().sum())
a = df[df["age"].between(19, 80)]
b = df[(df["age"].between(19, 80)) | (df["age"].isna())]
print(len(df), len(a), len(b))
107 97
3030 2923 3020

조건이 False인 107행에는 불가능한 값 10개와 결측치 97개가 함께 들어 있다. 그래서 이 조건만으로 고른 a(2,923행)는 결측 행까지 잃는다. 결측치를 남기려면 조건에 | df["age"].isna()를 더한다(b, 3,020행). 결측치는 범위 밖의 값이 아니므로, 가이드가 “범위 밖의 값을 제거한다”고만 하면 결측치를 남기는 것이 원칙이다.

  • 확인 6 출력이 107 97과 3030 2923 3020이다. b에서 지워진 행은 10개(3030 - 3020)로, 3.1절의 불가능한 나이 4 + 6과 같다.

경계의 포함 여부는 inclusive 인자로 바꾼다. 값은 "both"(기본값), "neither"(양 끝 제외), "left"(왼쪽만 포함), "right"(오른쪽만 포함)이다. 이 자료에는 정확히 19세인 회원이 116명이므로, inclusive="neither"로 쓰면 이 116명이 빠져 2,807행이 남는다. 시험의 가이드는 이상, 이하, 초과, 미만을 구분하여 쓰므로 그 낱말을 비교 연산자로 그대로 옮긴다.

가이드의 표현 비교 연산 between으로 쓸 때
a 이상 b 이하 (s >= a) & (s <= b) s.between(a, b)
a 초과 b 미만 (s > a) & (s < b) s.between(a, b, inclusive="neither")
a 이상 b 미만 (s >= a) & (s < b) s.between(a, b, inclusive="left")
a 초과 b 이하 (s > a) & (s <= b) s.between(a, b, inclusive="right")

3.3 조건으로 고르기와 인덱스로 지우기

조건에 맞지 않는 행을 제거하는 방법은 두 가지이다. 3.2절처럼 남길 행의 조건으로 고르는 방법과, 지울 행의 인덱스를 구하여 drop(index=...)로 지우는 방법이다. 예를 들어 bad = df[df["annual_spend"] <= 0].index 다음에 df.drop(index=bad)로 쓰면 구매액이 0 이하인 5행이 지워져 3,025행이 남는다. 가이드가 “~인 행을 삭제한다”고 하면 drop을, “~인 행만 남긴다”고 하면 조건 선택을 쓰면 읽기 쉽다. 어느 방법이든 처리 전후의 행 수를 출력하여 확인한다.

4. 사분위수 범위에 의한 이상치 제거

4.1 경계의 계산

2장의 상자그림에서 수염 밖에 점으로 표시된 값은 다음 경계를 벗어난 값이다.

  • 아래쪽 경계 = Q1 - 1.5 × IQR
  • 위쪽 경계 = Q3 + 1.5 × IQR
  • IQR = Q3 - Q1

quantile(q)는 0과 1 사이의 비율 q에 해당하는 분위수를 돌려준다. 제1사분위수는 quantile(0.25), 제3사분위수는 quantile(0.75)이다. 결측치는 빼고 계산한다.

# [예제 10]
q1 = df["visits_per_month"].quantile(0.25)
q3 = df["visits_per_month"].quantile(0.75)
iqr = q3 - q1
lower = q1 - 1.5 * iqr
upper = q3 + 1.5 * iqr
print(q1, q3, round(iqr, 2))
print(round(lower, 2), round(upper, 2))
7.2 14.3 7.1
-3.45 24.95

visits_per_month의 Q1은 7.2회, Q3은 14.3회이므로 회원의 가운데 절반은 한 달에 7.2회에서 14.3회 방문한다. 경계는 이 폭(IQR 7.1회)의 1.5배만큼 상자 바깥으로 넓힌 자리로, 아래쪽 -3.45, 위쪽 24.95이다. 방문 수는 음수가 될 수 없으므로 아래쪽 경계 밖의 값은 없다. 출력에 round를 쓴 것은 14.3 - 7.2를 2진수로 계산하면 7.1000000000000005처럼 끝자리가 남기 때문이다. 비교에는 반올림하지 않은 값을 쓴다.

  • 확인 7 출력이 7.2 14.3 7.1과 -3.45 24.95이다.

4.2 경계 밖의 행 제거

# [예제 11]
s = df["visits_per_month"]
print((s < lower).sum(), (s > upper).sum())
d = df[(s.between(lower, upper)) | (s.isna())]
print(len(df), len(d))
0 63
3030 2967

위쪽 경계를 넘는 63행이 제거되어 2,967행이 남는다. 3.2절과 마찬가지로 between은 결측치를 False로 판정하므로, 결측치를 남기려면 | s.isna()를 더한다. 경계값과 같은 값은 남는다. 제거 전후의 상자그림을 나란히 그려 처리의 효과를 확인한다. sharey=True는 두 칸의 y축 범위를 같게 맞춘다.

# [예제 12]
import matplotlib.pyplot as plt
import seaborn as sns

fig, axes = plt.subplots(1, 2, figsize=(8, 3.5), sharey=True)
sns.boxplot(data=df, y="visits_per_month", ax=axes[0])
sns.boxplot(data=d, y="visits_per_month", ax=axes[1])
axes[0].set_title("Before IQR filter")
axes[1].set_title("After IQR filter")
plt.tight_layout()
plt.show()

제거 후에도 상자그림에 점이 몇 개 보일 수 있다. 행을 지운 뒤의 자료로 사분위수를 다시 계산하면 경계가 조금 안쪽으로 옮겨지기 때문이다. IQR에 의한 제거는 가이드가 지시한 횟수(대개 한 번)만 적용한다.

4.3 경계는 그 시점의 자료로 정해진다

사분위수는 계산하는 시점의 자료에 따라 달라진다. 2장 4.2절에서 원본으로 계산한 avg_session_min의 경계는 4.4와 29.2였다. 중복 행과 불가능한 값을 먼저 제거한 뒤에 계산하면 Q1과 Q3이 달라져 경계도 달라진다. 그래서 IQR에 의한 제거는 가이드가 정한 순서에서 정확히 그 단계의 자료로 계산해야 한다. 또 IQR은 업무의 판단 없이 분포만으로 경계를 정하므로 실제로 가능한 값도 제거될 수 있다. 시험에서는 가이드가 배수와 대상 열을 지정한다.

4.4 사분위수의 손 계산과 quantile의 보간

사분위수의 자리가 두 값 사이에 떨어지면 두 값 사이의 어디를 고를지를 정해야 하는데, 이 방식을 보간(interpolation)이라 한다. pandas의 quantile은 기본값 interpolation="linear"를 쓴다. 값을 작은 것부터 0, 1, 2, …로 번호 매겼을 때 자리는 (n - 1) × q이고, 자리가 두 값 i와 j 사이에 놓이면 i + (j - i) * fraction으로 계산한다(fraction은 자리의 소수 부분). 열 개의 값 2, 4, 5, 7, 8, 9, 11, 12, 15, 40으로 계산한다.

단계 Q1 (q = 0.25) Q3 (q = 0.75)
자리 (n - 1) × q 9 × 0.25 = 2.25 9 × 0.75 = 6.75
자리를 둘러싼 두 값 2번 값 5, 3번 값 7 6번 값 11, 7번 값 12
i + (j - i) × fraction 5 + (7 - 5) × 0.25 = 5.5 11 + (12 - 11) × 0.75 = 11.75

IQR은 6.25, 아래쪽 경계는 5.5 - 9.375 = -3.875, 위쪽 경계는 11.75 + 9.375 = 21.125이며, 경계 밖의 값은 40 하나이다.

# [예제 13]
v = pd.Series([2, 4, 5, 7, 8, 9, 11, 12, 15, 40])
q1 = v.quantile(0.25)
q3 = v.quantile(0.75)
iqr = q3 - q1
print(q1, q3, iqr)
print(q1 - 1.5 * iqr, q3 + 1.5 * iqr)
print(v[(v < q1 - 1.5 * iqr) | (v > q3 + 1.5 * iqr)].tolist())
5.5 11.75 6.25
-3.875 21.125
[40]

고등학교 교과서에서 흔히 쓰는 방식은 자료를 아래 절반(2, 4, 5, 7, 8)과 위 절반(9, 11, 12, 15, 40)으로 나누어 각 절반의 중앙값을 Q1(5), Q3(12)으로 삼는다. 어느 쪽도 틀린 것이 아니라 정의가 다른 것이다. 시험과 이 과목의 답은 언제나 quantile의 기본값으로 계산한다.

4.5 이상치 제거와 결측치 대체의 순서

이상치 제거와 결측치 대체는 서로의 입력을 바꾼다. 원본 df의 avg_session_min으로 두 순서를 비교한다. 순서 A는 IQR로 이상치를 제거한 뒤 남은 자료의 중앙값을 대체값으로 구하고, 순서 B는 원본의 중앙값으로 먼저 채운 뒤 IQR로 제거한다.

# [예제 14]
s = df["avg_session_min"]
# 순서 A: 이상치 제거 → 결측치 대체
q1a = s.quantile(0.25)
q3a = s.quantile(0.75)
lo_a, up_a = q1a - 1.5 * (q3a - q1a), q3a + 1.5 * (q3a - q1a)
a = df[(s.between(lo_a, up_a)) | (s.isna())]
fill_a = a["avg_session_min"].median()
# 순서 B: 결측치 대체 → 이상치 제거
fill_b = s.median()
sb = s.fillna(fill_b)
q1b = sb.quantile(0.25)
q3b = sb.quantile(0.75)
lo_b, up_b = q1b - 1.5 * (q3b - q1b), q3b + 1.5 * (q3b - q1b)
b = df[sb.between(lo_b, up_b)]
print("A", round(lo_a, 2), round(up_a, 2), len(a), fill_a)
print("B", round(lo_b, 2), round(up_b, 2), len(b), fill_b)
A 4.4 29.2 2994 16.7
B 4.8 28.8 2989 16.7
  • 확인 8 두 줄이 A 4.4 29.2 2994 16.7과 B 4.8 28.8 2989 16.7이다(경계, 남은 행, 대체값).

순서 A는 결측 61개를 뺀 2,969개의 값으로, 순서 B는 채운 61개를 포함한 3,030개의 값으로 사분위수를 계산한다. 채운 값 16.7은 모두 분포의 가운데에 있으므로, 이 값들이 더해지면 가운데가 두터워져 Q1은 13.7에서 13.8로 올라가고 Q3은 19.9에서 19.8로 내려간다. 상자가 좁아지므로 경계도 안쪽으로 들어오고, 순서 A에서는 남았던 5개 행이 순서 B에서는 이상치로 제거된다. 대체값은 이 자료에서 우연히 16.7로 같았으나, 평균으로 채우는 경우에는 순서 B의 대체값이 300분 이상의 값에 끌려 18.558이 된다(2.5절).

[그림 자리: 정제 단계의 처리 순서 흐름 도식] 왼쪽에서 오른쪽으로 상자 일곱 개를 화살표로 잇는 도식. read_csv (3030 rows) → drop_duplicates (3000) → drop customer_id (16 cols) → dropna annual_spend (2988) → range filter age, annual_spend (2973) → IQR filter avg_session_min (2940) → fillna median/mode, reset_index (2940, 0 NaN). IQR 상자와 fillna 상자 사이에 “compute Q1, Q3 here”, “compute median here”라는 짧은 영문 주석을 단다. 그림 안의 글자는 영문으로 쓴다. 만들 곳: 도식 작성 도구.

중심 실습의 순서는 이 결과를 따른다. 행을 지우는 처리(중복, 목표 열의 결측, 불가능한 값, IQR)를 모두 마친 뒤에 대체한다. 그러면 대체값은 최종 자료의 중앙값이 되고, 사분위수는 채운 값이 섞이지 않은 자료로 계산된다. 시험에서는 가이드가 정한 순서를 지키는 것이 우선이다. 순서를 바꾸면 몇 행의 차이가 생기고, 그 차이가 뒤의 문항으로 이어진다.

5. 열 삭제, 중복 행 삭제, 인덱스 재설정

5.1 열 삭제: drop(columns=...)

drop(columns=[열, ...])은 지정한 열을 뺀 새 데이터프레임을 돌려준다. 모델은 입력 열의 값과 목표 값 사이의 규칙을 배우는데, customer_id 같은 식별자는 회원마다 다른 이름표여서 새 회원에게 쓸 규칙이 없다. 게다가 문자열이어서 4장의 인코딩에서 3,000개의 열을 만들거나 오류를 낸다. 그래서 식별자 열은 인코딩 전에 지운다(1장 3.6절에서 고유값의 수로 찾았다).

# [예제 15]
d = df.drop(columns=["customer_id"])
print(df.shape, d.shape)
(3030, 17) (3030, 16)

drop("customer_id", axis=1)로 써도 같다. axis=1을 빠뜨리면 pandas는 customer_id를 행의 인덱스에서 찾다가 KeyError: "['customer_id'] not found in axis"를 낸다. drop의 기본 방향(axis=0)이 행이기 때문이다. 없는 열 이름을 주어도 같은 꼴의 KeyError가 나므로, 메시지만으로는 방향과 철자 가운데 무엇이 잘못되었는지 구분할 수 없다. columns=로 쓰면 방향을 혼동할 일이 없다.

5.2 중복 행 삭제: drop_duplicates

drop_duplicates()는 1장의 duplicated()가 True로 표시한 행을 삭제한다.

인자 뜻 기본값
subset 중복을 판단할 열의 목록 모든 열
keep "first": 처음 나온 행을 남긴다. "last": 마지막 행을 남긴다. False: 중복된 행을 모두 삭제한다 "first" 
# [예제 16]
print(df.drop_duplicates().shape)
print(df.drop_duplicates(subset=["customer_id"]).shape)
print(df.drop_duplicates(subset=["customer_id"], keep="last").shape)
print(df.drop_duplicates(keep=False).shape)
(3000, 17)
(3000, 17)
(3000, 17)
(2970, 17)

모든 열을 기준으로 하든 customer_id만을 기준으로 하든 3,000행이 남는다. 이 자료의 중복 30개는 행 전체가 통째로 두 번 기록된 것이기 때문이다(1장 3.7절). keep="last"도 남는 행의 수는 같고 남는 행의 위치만 다르다. keep=False는 원본까지 지우므로 60행이 삭제되어 2,970행이 남는다. 중복의 원본은 정상인 기록이므로 keep=False는 쓰지 않는다. 중복을 지운 뒤에는 남은 중복이 0인지와 식별자의 고유값 수가 행 수와 같은지(회원 한 명이 한 행인지)를 함께 확인한다.

이 자료에서는 식별자 열을 먼저 지우고 중복을 지워도 결과가 같다(3,000행). 그러나 다른 회원이 우연히 모든 열의 값이 같은 자료라면, 식별자를 먼저 지운 뒤 중복을 지우면 서로 다른 회원이 하나로 합쳐진다. 그래서 중심 실습은 중복을 먼저 지우고 식별자 열을 나중에 지운다.

5.3 인덱스 재설정: reset_index(drop=True)

행을 삭제해도 남은 행의 인덱스는 원래 번호를 유지한다. 그래서 행을 지운 뒤의 인덱스는 중간이 비어 있고 마지막 번호가 행 수보다 크다.

# [예제 17]
d = df.drop_duplicates().dropna(subset=["annual_spend"])
print(d.index[-3:].tolist())
print(d.reset_index().columns[:2].tolist())
d = d.reset_index(drop=True)
print(d.index[-3:].tolist())
[3027, 3028, 3029]
['index', 'customer_id']
[2985, 2986, 2987]

중복과 결측 행을 지운 뒤 2,988행이 남았지만 마지막 인덱스는 3029이다. reset_index()는 인덱스를 0부터 다시 매기는데, 기본값(drop=False)에서는 이전 인덱스를 index라는 열로 데이터프레임에 넣는다. 이 열이 남으면 모델의 입력에 섞이므로 drop=True로 버린다. 재설정은 “마지막 인덱스 = 행 수 - 1”(여기서는 2987)로 확인한다. 인덱스가 비어 있으면 5장 이후에 다른 데이터프레임과 열을 이어 붙일 때 행이 어긋나므로, 행을 지우는 처리를 마치면 인덱스를 재설정한다.

  • 확인 9 출력이 [3027, 3028, 3029], ['index', 'customer_id'], [2985, 2986, 2987]이다.

6. 원본의 보존과 결과의 변수 저장

6.1 처리 결과의 재할당

이 장에서 다룬 dropna, fillna, drop, drop_duplicates, reset_index는 모두 처리한 새 객체를 돌려줄 뿐 원래의 데이터프레임을 바꾸지 않는다. 결과를 변수에 저장하지 않으면 처리는 화면에만 나타나고 사라진다.

# [예제 18]
d = df.copy()
d.dropna(subset=["annual_spend"])
print(d.shape)
d = d.dropna(subset=["annual_spend"])
print(d.shape)
(3030, 17)
(3018, 17)

첫 줄의 d.dropna(...)는 결과를 저장하지 않았으므로 d는 3,030행 그대로이다. d = d.dropna(...)처럼 같은 이름에 다시 저장해야 반영된다. 이 실수는 오류가 나지 않고 값만 틀리게 하므로 찾기 어렵다. 처리한 뒤마다 shape를 출력하여 행 수가 바뀌었는지 확인한다.

  • 확인 10 출력이 (3030, 17)과 (3018, 17)이다. 첫 줄은 결과를 저장하지 않은 경우, 둘째 줄은 다시 저장한 경우이다.

6.2 원본의 보존: copy()

d = df는 데이터프레임을 복사하지 않는다. 같은 데이터프레임에 이름을 하나 더 붙일 뿐이다. 따라서 d의 열을 바꾸면 df도 바뀐다. 원본과 독립된 데이터프레임이 필요하면 df.copy()를 쓴다.

# [예제 19]
base = df.copy()
alias = base
alias["flag"] = 1
print(alias is base, "flag" in base.columns)
copied = base.copy()
copied["flag2"] = 1
print(copied is base, "flag2" in base.columns)
True True
False False

alias는 base와 같은 객체이므로 alias에 더한 열이 base에도 생겼고, 다른 객체인 copied에 더한 열은 base에 생기지 않았다. 시험의 가이드가 “원본을 유지하고 새 변수에 저장한다”고 하면 새 변수 = 원본.copy()로 시작한다. 앞 문항의 결과를 뒤 문항이 다시 쓸 수 있기 때문이다(1장 7.2절 규칙 4). pandas 3.0부터는 Copy-on-Write가 기본 동작이어서, 조건으로 고른 결과(df[조건])나 열 하나(df["열"])를 바꾸어도 원본에는 영향을 주지 않는다. 다만 d = df처럼 이름만 붙인 경우는 같은 객체이므로 위와 같이 원본이 바뀐다.

6.3 inplace를 쓰지 않는 이유

많은 메서드에 inplace=True 인자가 있다. 이 인자를 주면 새 객체를 돌려주는 대신 그 데이터프레임을 바꾸고 None을 돌려준다. 아래 셀의 앞부분은 이것을, 뒷부분은 열 하나를 골라 inplace로 채운 경우를 보인다.

# [예제 20]
d = df.copy()
result = d.dropna(subset=["annual_spend"], inplace=True)
print(result, d.shape)
d = df.copy()
d["age"].fillna(d["age"].median(), inplace=True)
print(d["age"].isna().sum())
None (3018, 17)
97

본 교재는 inplace를 쓰지 않고 결과를 변수에 다시 저장한다. 이유는 세 가지이다. 첫째, 재할당과 섞어 쓰면 변수가 None이 된다. d = d.dropna(..., inplace=True)로 쓰면 d가 None이 되어 다음 줄에서 AttributeError: 'NoneType' object has no attribute 'shape'가 난다. 둘째, 열 하나를 골라 inplace로 바꾸는 코드(df["열"].fillna(값, inplace=True))는 pandas 3.0부터 원본을 바꾸지 못한다. 고른 열이 원본과 분리된 객체이기 때문이며, 위 출력의 마지막 줄처럼 결측치 97개가 그대로 남는다. 셋째, pandas 3.1.0(2026-10-22)은 dropna, drop_duplicates, reset_index 등 실제로는 제자리에서 동작하지 않는 메서드의 inplace 인자를 폐지 예정으로 정하였다. 이 판에서 inplace=True를 쓰면 경고(Pandas4Warning)가 출력되며, 이후의 판에서 인자가 삭제될 예정이다.

6.4 실제 경고 메시지와 바른 쓰기

노트북에서 예제 20을 실행하면 경고가 분홍색 상자로 출력된다. 경고는 셀을 멈추지 않으므로, 상자가 보이면 내용을 읽고 코드를 고친다.

[그림 자리: 주피터에서 inplace 경고가 출력된 화면] d.dropna(subset=["annual_spend"], inplace=True)를 실행한 셀 아래에 분홍색 바탕의 경고 상자가 나온 화면. 상자의 첫 줄 Pandas4Warning: The inplace keyword in DataFrame.dropna is deprecated ...가 읽히게 찍는다. 찍을 곳: 학교 실습 환경의 주피터에서 예제 20을 실행한 화면.

Pandas4Warning의 첫 줄 The inplace keyword in DataFrame.dropna is deprecated and will be removed in a future version (PDEP-8).은 inplace가 지금은 동작하지만 이후의 판에서 삭제된다는 예고이다(PDEP-8은 pandas의 개선 제안 문서 번호). ChainedAssignmentError는 이름에 Error가 있지만 경고이며, 연쇄 할당으로 복사본에 값을 넣었으므로 원본은 바뀌지 않았다는 알림이다. 열을 골라 inplace로 채운 경우와, d[d["age"] > 80]["age"] = 80처럼 고른 결과의 열에 값을 넣은 경우에 나온다(아래 흔한 오류 표). 바른 쓰기는 두 가지이다. 열을 채울 때에는 결과를 열에 다시 저장하거나 데이터프레임의 fillna에 사전을 주고, 조건에 맞는 칸에 값을 넣을 때에는 loc[행 조건, 열 이름]으로 한 번에 지정한다.

# [예제 21]
d = df.copy()
d = d.fillna({"age": d["age"].median()})
d.loc[d["age"] > 80, "age"] = 80
print(d["age"].isna().sum(), d["age"].max())

둘째 줄은 3.4절의 상한 고정에 해당한다. 80세를 넘는 값(999세 6개)을 80으로 바꾸었으므로 최댓값이 80.0이 되었다. 중심 실습은 이 행들을 삭제하므로 이 처리를 쓰지 않는다.

주제 기억할 것
결측치의 집계 열별 isna().sum(), 행별 isna().sum(axis=1), 결측 행의 수 isna().any(axis=1).sum()
결측 행의 삭제 dropna(subset=[열]). how="any"(기본값)와 "all", thresh는 남길 값의 수
대체 수치형은 mean()·median(), 범주형은 mode()[0]. 결과를 그 열에 다시 저장한다
대체의 영향 평균 대체는 평균을 유지하고 표준편차를 줄인다. 극단값이 있으면 평균이 대체값을 끌어올린다
조건에 의한 제거 between(a, b)는 경계를 포함하고 결측을 False로 판정한다. 결측을 남기려면 | isna()
IQR q1 = quantile(0.25), q3 = quantile(0.75), 경계 q1 - 1.5*iqr, q3 + 1.5*iqr. 그 단계의 자료로 계산한다. 자리는 (n - 1) × q의 선형 보간
열과 중복, 인덱스 drop(columns=[...]), drop_duplicates(subset=..., keep="first"), 행을 지운 뒤 reset_index(drop=True)
재할당과 복사 df = df.처리(), 원본 보존은 df.copy(). inplace를 쓰지 않는다. ChainedAssignmentError는 원본에 반영되지 않았다는 경고
처리 순서 중복 → 식별자 열 → 목표 열의 결측 → 불가능한 값 → IQR → 대체 → 인덱스 재설정
