[11주차] 응시 전략과 답안 규칙

비즈니스빅데이터분석

11주차

응시 전략과 답안 규칙

2027학년도 「비즈니스빅데이터분석」의 준비 중인 교재입니다. 편집 상태를 검토하기 위해 미리 공개한 것으로, 수업 전에 내용과 순서가 바뀔 수 있습니다.

학사 13주차 · 교재 11 · 4부 응시 전략 · 출제 분야: 전 분야(시험 형식과 응시 규정)

1~10장은 시험지의 문항을 하나씩 떼어 연습하였다. 실제 시험은 표 데이터 한 건과 14문항을 90분 안에 푸는 형식이고, 100점 만점에 80점 이상이어야 합격한다. 문항별 배점은 공개되어 있지 않으나, 잃을 수 있는 점수가 20점뿐이므로 배점이 큰 AI 모델링 문항을 두세 개 놓치면 불합격이 된다. 또 앞 문항의 결과가 뒤 문항의 대상이 되므로, 시간 배분이나 답안 규칙의 실수 하나가 여러 문항의 점수를 잃게 만든다.

본 장은 새로운 함수를 다루지 않고 시간 배분, 선행 문항의 실패 처리, 답안 규칙, 커널 재시작 시의 복구, 공식 문서의 검색, 감독 환경과 금지 행위를 정리한다. 이어서 실제 시험과 같은 조건으로 종합 모의 1(회귀 문제, 14문항 90분)을 치르고, 시간 기록표와 오답 원인표를 작성한다. 14주차와 15주차에는 같은 형식의 종합 모의 2와 3을 치른다.

학습 목표

  1. 90분을 출제 분야별로 나누어 문항당 시간의 상한을 정하고, 상한을 넘은 문항을 건너뛰는 기준을 적용한다.
  2. 선행 문항의 실패가 후속 문항에 미치는 경로를 설명하고, 실패한 문항이 뒤 문항을 막지 않도록 처리한다.
  3. 답안 셀, 변수 이름, 파일 이름의 규칙을 위반하지 않고 답안을 제출한다.
  4. 커널이 재시작되었을 때 정해진 순서로 작업 상태를 복구한다.
  5. 허용된 일곱 곳의 공식 문서에서 필요한 쪽을 빨리 찾고, 온라인 감독 환경의 금지 행위를 지킨다.
  6. 종합 모의를 시간 안에 수행하고, 시간 기록표와 오답 원인표로 자신의 약점을 찾는다.

준비 사항

항목 내용
종합 모의 1 문제지 노트북과 자료는 수업 시간에 배부한다. 회귀 문제, 14문항, 90분
양식 시간 기록표와 오답 원인표(7.3절, 7.4절). 종이에 인쇄하여 배부한다
참고 부록 B(시험 규정 카드), 부록 C(함수 카드)
앞 장과의 연계 1~10장 전체. 특히 1장 7절(문항의 네 가지 형식과 답안 규칙)과 각 장의 시간 제한 문항
실습 환경 접속과 설치는 부록 A를 따른다

학기 말의 일정

학사 주차 본 과목 AICE 2027년 제4회
13 11장, 종합 모의 1(회귀) 접수 시작(11.22)
14 종합 모의 1의 해설, 종합 모의 2(이진 분류)
15 종합 모의 3(다중 분류, 실전 조건), 응시 준비 접수 마감(12.10). 사전 환경점검(12.10~12.16)
16 기말고사(14문항 90분) 시험(12.17~12.18)

13~15주차의 종합 모의, 채점 결과의 확인, 오답 원인표의 작성은 모두 수업 시간 안에 마치며 수업 밖의 과제는 없다. 같은 시기에 「프로젝트실습Ⅱ」의 졸업 프로젝트를 완성하고 발표하기 때문이다. 시험 일정은 AICE의 2027년 일정 공지의 값이며 변경될 수 있으므로 접수 전에 공식 사이트에서 다시 확인한다.

1. 분야별 시간 배분

1.1 시험의 구성

출제 분야 본 과목의 장 문항 수 배점 문항당 점수(추산)
데이터 분석 1~2 5~6 30 5~6점
데이터 전처리 3~5 4~5 30 6~7.5점
AI 모델링 6~10 4~5 40 8~10점

문항별 배점은 공개되어 있지 않으므로 마지막 열은 분야 배점을 문항 수로 나눈 추산이다. AI 모델링 한 문항은 데이터 분석 한 문항의 1.5배 이상이다. 반면 데이터 분석의 문항은 점수가 작아도 시험지의 앞에 있어 뒤 문항이 모두 그 결과를 쓴다(2절).

1.2 시간 배분의 기준

90분을 배점에 비례하여 나누면 데이터 분석 27분, 데이터 전처리 27분, AI 모델링 36분이다. 본 과목은 이 비례 배분을 조정하여 다음을 기준으로 연습한다.

구간 시간 누적 조정한 이유
데이터 분석 20분 20분 짧은 코드가 많다
데이터 전처리 25분 45분 결과의 크기를 확인하는 시간이 든다
AI 모델링 35분 80분 격자 탐색과 신경망 학습의 실행을 기다린다
검토 10분 90분 처음부터 다시 실행하여 확인한다(4절)

이 값은 출발점이며 종합 모의의 기록에 맞추어 각자 고친다. 분야 시간을 문항 수로 나누면 문항당 기준 시간이 된다(데이터 분석 5문항이면 4분, AI 모델링 5문항이면 7분).

1.3 건너뛰기의 기준

  1. 한 문항에 기준 시간의 두 배를 쓰고도 끝나지 않으면 건너뛴다.
  2. 건너뛰기 전에 그 문항의 답안 셀에 지금까지의 코드를 남기고, 맨 위 줄에 주석으로 표시한다(# 미완: 인자 확인 필요처럼).
  3. 뒤 문항이 그 문항의 결과를 쓰면 2절의 차단 방법을 먼저 적용한다.
  4. 누적 80분이 되면 새 문항을 시작하지 않고 검토로 넘어간다.
  5. 검토 시간에 남는 시간이 있으면 표시한 문항으로 되돌아간다. 점수가 큰 AI 모델링 문항부터 되돌아간다.

막혔을 때의 순서는 “오류 메시지의 마지막 줄 읽기 → 공식 문서에서 함수의 쪽 찾기(5절) → 그래도 안 되면 표시하고 건너뛰기 → 검토 시간에 되돌아오기”이다.

2. 선행 문항의 실패가 후속 문항에 미치는 영향

2.1 문항의 연쇄

AICE의 공개 샘플 문항에서는 한 문항의 결과 데이터프레임이 다음 문항의 대상이 된다. 본 과목의 공통 자료가 원본 → 정제본 → 인코딩본 → 훈련·검증 데이터 → 모델로 이어진 것과 같다.

실패한 문항 뒤 문항의 증상
라이브러리 불러오기, 파일 읽기 모든 문항에서 NameError
이상치·결측치 처리 행 수가 달라져 뒤의 모든 값이 기준과 다르다
인코딩 문자열 열이 남아 fit에서 ValueError
분할 X_train이 없어 NameError
모델 학습 예측에서 NotFittedError

뒤 문항이 받는 피해는 실행이 멈추는 것과, 실행은 되지만 값이 기준과 달라지는 것의 두 종류이다. 앞의 것은 눈에 보이지만 뒤의 것은 채점 결과를 보기 전까지 모른다.

2.2 차단 방법

방법 1. 원본을 보존하고 결과는 지정된 새 변수에 저장한다. 원본이 남아 있으면 앞 문항의 실수를 고쳐 다시 실행할 수 있다.

방법 2. 단계마다 결과의 크기를 출력한다. 처리 문항의 답안 셀 끝에 print(df_clean.shape)를 두면 행 수가 예상과 다를 때 곧바로 알 수 있다.

방법 3. 막힌 처리 문항은 뒤 문항이 실행될 수 있는 형태로 남긴다. 예를 들어 이상치 제거 문항을 끝내지 못하였다면, 가이드가 지정한 변수 이름으로 원본의 복사본이라도 만들어 둔다.

# 미완: 사분위수 경계 계산을 끝내지 못하였다. 뒤 문항을 위해 변수만 만든다.
df_clean = df.copy()
print(df_clean.shape)

이렇게 하면 뒤 문항의 코드는 실행되지만 값은 기준과 다를 수 있다. 시험이 부분 점수를 주는지, 뒤 문항을 위한 중간 데이터를 제공하는지는 공개되어 있지 않다. 방법 3은 실행이 멈추는 것을 막는 장치일 뿐이므로, 표시를 남기고 검토 시간에 돌아가 바로잡는다.

방법 4. 오래 걸리는 셀과 그 결과를 쓰는 셀을 나누어 생각한다. 셀은 오류가 난 줄의 바로 앞 줄까지 실행된 상태로 남는다. 8장의 시간 제한 문항 2에서는 gs_t2.fit이 실행된 뒤 예측에서 오류가 났으므로, 문항 3(변수 중요도)은 문항 2를 고치지 않아도 풀 수 있었다.

3. 답안 셀, 변수 이름, 파일 이름의 규칙

3.1 수험자 가이드의 응시 중 유의사항

AICE 수험자 가이드의 Associate 응시 중 유의사항과 지키는 방법은 다음과 같다(1장 7절).

유의사항 지키는 방법
답안은 하나의 셀에만 작성한다. 여러 셀로 제출하면 채점되지 않는다 작업용 셀은 제출 전에 지운다(3.2절)
문항 가이드의 파일명과 확장자 규칙을 그대로 따른다 대소문자, 밑줄, 확장자까지 같게 한다(3.4절)
패키지나 데이터를 처음에 불러오는 데 실패하면 뒤 문항에 연쇄적으로 영향을 미친다 첫 문항의 출력을 확인한다(2절)
문항 가이드를 따르지 않으면 커널이 재시작될 수 있다 설정값을 임의로 늘리지 않는다. 재시작되면 4절의 순서로 복구한다
복사와 붙여넣기는 시험지 안의 ‘복사 기능’ 목록으로만 수행한다 문서의 예제를 붙여 넣을 수 있다고 가정하지 않고 직접 입력한다

3.2 답안 셀

값을 확인하려고 추가한 작업용 셀은 확인이 끝나면 바로 지운다. 검토 시간에 한꺼번에 지우려고 하면 어느 셀이 답안 셀인지 헷갈리고 시간이 모자라 남기게 된다.

상황 올바른 처리
답안 셀의 코드가 길어졌다 한 셀 안에서 빈 줄과 주석으로 단계를 구분한다
그래프 문항 그리는 코드도 답안 셀 하나에 둔다. 여러 그래프는 plt.subplots로 한 그림에 나눈다(2장)
빈칸 채우기 문항 가이드가 지정하면 빈칸에 쓴 내용을 지정된 답 변수에도 기재한다

3.3 변수 이름과 답 변수의 자료형

변수 이름이 한 글자라도 다르면 값이 맞아도 채점에서 찾지 못한다. 답 변수의 값은 자료형까지 가이드에 맞춘다.

# 가이드: 결측치가 가장 많은 열의 이름을 ans3에 저장한다
ans3 = df.isna().sum().idxmax()      # 문자열 'visits_per_month'

# 잘못된 예
Ans3 = df.isna().sum().idxmax()      # 이름의 대소문자가 다르다
ans3 = df.isna().sum().max()         # 이름이 아니라 개수(숫자)이다
ans3 = "visits_per_month "           # 손으로 옮겨 적다가 공백이 들어갔다
가이드의 표현 답 변수의 형태 흔한 실수
“열의 이름” 문자열 max()로 값을 저장
“행 수” 정수 shape(튜플)를 저장
“소수 넷째 자리까지 반올림” round(값, 4) 출력만 반올림(print(round(x, 4)))
“최적 설정” 딕셔너리(best_params_) best_score_를 저장

모델을 저장하는 문항은 파일 이름과 확장자를 가이드가 정한다. 10장의 모델 저장처럼 확장자가 저장 형식을 결정하는 경우가 있다.

4. 커널 재시작 시의 복구 순서

4.1 재시작되면 무엇이 사라지는가

커널이 재시작되면 셀의 코드와 화면의 출력은 남지만, 변수, 불러온 라이브러리, 학습한 모델은 모두 사라진다. 출력이 남아 있어 상태가 그대로인 것처럼 보이는 것이 함정이다. 재시작 직후에 뒤 문항의 셀을 실행하면 NameError: name 'df' is not defined가 난다. 시험 환경의 자원은 CPU 2코어와 메모리 16G로 안내되어 있으므로, 가이드보다 큰 탐색 범위나 많은 에폭을 쓰지 않는다.

4.2 복구 순서

순서 할 일 확인
1 라이브러리를 불러오는 첫 셀을 실행한다 오류 없이 끝나는가
2 데이터를 읽는 셀을 실행한다 df.shape가 문제지의 크기와 같은가
3 데이터 분석과 전처리의 답안 셀을 위에서부터 차례로 실행한다 각 셀 끝의 크기 출력이 앞서 본 값과 같은가
4 분할과 스케일링의 셀을 실행한다 X_train.shape
5 모델 문항은 지금 풀고 있는 문항에 필요한 것만 실행한다 오래 걸리는 셀(격자 탐색, 신경망 학습)의 시간을 고려한다
6 중단된 문항으로 돌아가 이어서 푼다

셀은 Shift+Enter로 하나씩 실행하거나, 실행 메뉴에 “선택한 셀 위의 모든 셀 실행”이 있으면 그것을 쓴다. 이 순서가 통하려면 작업용 셀이 남아 있지 않아야 하고(변수를 덮어쓸 수 있다), 각 답안 셀이 위의 셀들만으로 실행되어야 한다.

4.3 같은 결과의 재현

다시 실행하여도 같은 값이 나오려면 분할, 나무 모델, 교차 검증의 섞기에 random_state를, 신경망에 tf.random.set_seed를 가이드의 값대로 고정한다. 신경망은 시드를 고정하여도 소수점 아래의 값이 조금 달라질 수 있다.

4.4 검토 시간의 전체 실행

검토 10분의 첫 일은 커널을 직접 재시작하고 처음부터 끝까지 실행하여 답 변수의 값을 확인하는 것이다. 신경망 학습처럼 오래 걸리는 셀이 있으면 검토를 일찍 시작한다.

5.3 함수의 쪽을 빨리 읽는 방법

  1. 인자의 철자와 기본값은 맨 위의 서명에서 본다.

함수 이름을 모르면 User Guide에서 주제를 찾고, 알면 API 쪽으로 바로 간다(1장 6절).

7.5 채점 결과를 읽는 방법

종합 모의는 답 변수와 결과 데이터프레임을 검사하는 스크립트로 채점하며, 문항별 정답 여부, 분야별 점수, 합계를 돌려준다. 다음 순서로 읽는다.

  1. 합계와 80점의 차이. 합격 기준까지 모자라거나 남는 점수를 확인한다.
  2. 분야별 득점률. 분야별 점수를 배점으로 나누어 가장 낮은 분야를 찾는다.
  3. 원인 기호의 집계. 가장 많은 원인을 찾는다(아래 표).
  4. 장의 집계. 같은 장이 두 번 이상 나오면 그 장의 중심 실습과 시간 제한 문항을 다시 푼다.
  5. 시간 기록표와의 대조. 오답 문항이 시간을 크게 넘긴 문항과 겹치면 지식보다 시간 관리가 문제이다.

재시작 import → 데이터 읽기 → 앞 답안 셀을 위에서부터 → 지금 문항. 시드를 고정하여 같은 결과를 재현한다
문서 검색 일곱 곳, 시험지 안의 링크로만. 함수 이름을 알면 API, 모르면 User Guide. 쪽 안에서는 Ctrl+F로 인자 이름
감독 시작 30분 전 입실, 다른 기기·이어폰·메모·생성형 AI 금지, 적발 시 0점. 사전 환경점검은 시험 7일 전부터 1일 전까지
종합 모의 시간 기록표(시작 시각만 적는다)와 오답 원인표(원인 기호 A~G)로 약점을 찾는다
