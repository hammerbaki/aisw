2027학년도 「컴퓨터활용」의 준비 중인 교재입니다. 편집 상태를 검토하기 위해 미리 공개한 것으로, 수업 전에 내용과 순서가 바뀔 수 있습니다.

「컴퓨터 활용」 교재 01~13의 공통 부록

본 부록은 각 장이 공통으로 참조하는 내용을 한곳에 모은 것이다. 프로그램, 실습 파일의 수령과 제출, 파이썬 실행 환경, AI 도구의 접속에 관한 안내는 각 장에 기재하지 않고 부록 A에만 기재한다. 접속 주소, 계정, 제출처와 같이 학기마다 달라지는 사항은 본 부록에 기재하지 않으며 담당 교수가 수업 시간에 안내한다.

C 함수 요약 3~6장, 11장

부록 A. 실습 환경

A-1. 사용하는 프로그램

프로그램 사용하는 장 비고
엑셀 1~6장, 11장 본 교재의 메뉴 이름은 한국어판 Microsoft 365를 기준으로 한다
파워포인트 7장 위와 같다
액세스 13장 위와 같다. 액세스는 Windows용 오피스에만 포함되어 있다
웹 브라우저 8~12장 실습 사이트와 AI 도구에 접속한다
메모장 12장 요구 명세서를 작성한다

사용 중인 오피스의 버전은 엑셀에서 [파일] 탭 → [계정]의 “제품 정보”로 확인한다. 버전에 따라 메뉴의 이름이나 위치가 다른 경우에는 본문에 버전에 따른 차이로 표시하였다. 본문의 메뉴가 화면에 없으면 리본 메뉴의 위쪽에 있는 검색 상자에 명령의 이름을 입력하여 찾는다.

A-2. 실습 폴더

모든 실습 파일은 [문서] 폴더의 컴퓨터활용 폴더에 둔다. 폴더는 1장에서 작성한다.

컴퓨터활용\
  자료\      배포받은 파일
  실습\      작업 파일
  출력\      PDF 출력물
폴더 내용 유의점
자료 월별 판매 파일 12개(판매_2026_01.xlsx ~ 판매_2026_12.xlsx), 실습 노트북(8~10장) 배포받은 파일은 수정하지 않는다. 수정이 필요하면 실습 폴더에 다른 이름으로 저장한 뒤 수정한다
실습 핵심 실습의 작업 파일, 따라 하기의 연습 파일 장마다 앞 장의 파일을 열어 새 이름으로 저장한다
출력 인쇄 형태의 PDF 2장, 5장, 7장에서 생성한다

실습실 PC에 저장한 파일은 다음 수업까지 보존되지 않을 수 있다. 수업을 마칠 때 컴퓨터활용 폴더 전체를 개인 저장 매체나 클라우드 저장소에 복사하여 보관하고, 다음 수업을 시작할 때 [문서] 폴더로 복사한다.

A-3. 실습 파일의 수령

배포 파일(월별 판매 파일 12개와 8~10장의 실습 노트북)의 수령 방법은 담당 교수가 수업 시간에 안내한다. 수령한 파일은 컴퓨터활용\자료 폴더에 둔다.

파일 내용 사용하는 장
판매_2026_01.xlsx 1월 판매 내역 20행. 1장에서 수강생이 직접 입력하는 자료와 같으며 기준 파일이라고 부른다 8~10장, 12~13장. 1장을 수행하지 못한 수강생의 대체 자료
판매_2026_02.xlsx 2월 판매 내역 19행 1~13장의 따라 하기와 연습 문제
판매_2026_03.xlsx 3월 판매 내역 25행 8~13장의 연습 문제
판매_2026_04.xlsx ~ 판매_2026_12.xlsx 4~12월 판매 내역 10장, 12장
Office_08장_실습_학생용.ipynb 등 3개 8~10장의 실습 노트북 8~10장

모든 상호, 품목, 수치는 실습을 위하여 작성한 가상의 값이다.

A-4. 파일 이름

“학번”의 자리에는 본인의 학번을 기재한다. 파일 이름에 공백을 넣지 않는다.

A-5. 제출

장마다 핵심 실습의 결과 파일을 제출한다. 제출처와 기한은 담당 교수가 수업 시간에 안내한다. 따라 하기의 연습 파일, 심화 실습과 연습 문제의 결과는 제출하지 않는다.

제출물은 완료 기준의 충족 여부로 판정한다. 완료 기준은 각 장의 핵심 실습과 부록 D에 있다. 제출하기 전에 파일을 닫는다. 열려 있는 파일은 올라가지 않거나 저장되지 않은 상태로 올라갈 수 있다.

A-6. 파이썬 실행 환경

8~10장과 12장은 학과 실습 사이트의 JupyterLab에서 수행한다. 프로그램을 설치하지 않으며 웹 브라우저로 접속한다.

  1. 담당 교수가 안내한 주소로 접속하여 안내받은 계정으로 로그인한다. 최초 접속 시 비밀번호의 변경을 요구받으면 본인만 아는 비밀번호로 변경한다. 계정과 비밀번호를 다른 사람과 공유하지 않는다.
  2. JupyterLab의 파일 탐색기에서 컴퓨터활용 폴더를 작성하고 그 안에 자료 폴더를 작성한다(8장 2-2절).
  3. 자료 폴더에 월별 판매 파일 12개를 올리고, 컴퓨터활용 폴더에 실습 노트북을 올린다.
  4. 코드가 생성한 결과 파일은 컴퓨터활용/결과 폴더에 생성된다. 필요한 파일은 내려받아 수강생 PC의 컴퓨터활용\실습 폴더에 보관한다.
  5. 수업을 마칠 때 노트북을 저장하고 [File] → [Log Out]으로 로그아웃한다.
서버의 폴더 내용
컴퓨터활용/ 실습 노트북(실습_08_학번.ipynb 등)
컴퓨터활용/자료/ 월별 판매 파일 12개. 다른 파일을 두지 않는다
컴퓨터활용/결과/ 9~10장의 코드가 생성한 결과 파일
컴퓨터활용/결과_AI/ 12장에서 AI가 작성한 코드가 생성한 결과 파일

코드는 서버에서 실행되므로 수강생 PC의 파일을 직접 읽지 못한다. 읽을 파일은 서버에 올려야 하고, 결과 파일은 내려받아야 수강생의 PC에서 열 수 있다.

A-7. 생성형 AI 도구

11~12장은 웹 기반의 대화형 AI 도구를 사용한다. 사용할 도구와 접속 방법은 담당 교수가 수업 시간에 안내한다. 도구에 따라 화면의 구성과 응답의 문구가 다르나, 본 교재의 절차는 지시문을 입력하고 응답을 받는 기능만을 사용하므로 도구에 관계없이 수행할 수 있다.

AI 도구에는 다음의 정보를 입력하지 않는다.

  • 이름, 학번, 연락처, 주소 등 본인과 타인의 개인정보
  • 실습 사이트와 그 밖의 서비스의 계정과 비밀번호
  • 외부에 공개되지 않은 자료

본 과목의 판매 자료는 가상의 값이므로 입력하여도 된다. 시험에서는 AI 도구를 사용하지 않는다.

A-8. 프로그램을 여는 방법과 링크

본 과목의 실습은 실습실 PC에 설치된 엑셀, 파워포인트, 액세스로 수행한다. 프로그램은 다음의 방법으로 연다.

방법 조작 비고
시작 메뉴 Windows 키를 누르고 프로그램의 이름(엑셀, PowerPoint, Access)을 입력하여 선택한다 새 문서로 시작할 때 사용한다
파일 열기 파일 탐색기에서 실습 파일을 두 번 누른다 확장자에 연결된 프로그램이 열린다. .xlsx는 엑셀, .pptx는 파워포인트, .accdb는 액세스이다
웹용 프로그램 웹 브라우저에서 https://www.microsoft365.com/launch/excel(엑셀) 또는 https://www.microsoft365.com/launch/powerpoint(파워포인트)에 접속한다 프로그램이 설치되지 않은 PC에서 복습할 때 사용할 수 있다. Microsoft 계정의 로그인이 필요할 수 있다. 메뉴의 구성이 설치형과 다르며, 본 교재의 절차는 설치형을 기준으로 한다. 액세스에는 웹용 프로그램이 없다

부록 F. 후속 과목의 학습 내용

본 과목은 후속 과목인 사무자동화 과목의 선수 과목이다. 후속 과목은 사무자동화산업기사의 실기시험 수준의 기능과 문제 풀이를 다룬다. 실기시험은 표 계산(엑셀), 자료 처리(액세스), 시상(파워포인트)의 세 작업으로 구성되며 출력물로 채점한다. 본 과목에서 익힌 내용과 후속 과목에서 새로 학습할 내용은 다음과 같다.

도구 본 과목에서 익힌 내용 후속 과목에서 학습할 내용
공통 폴더와 파일 이름, 저장 형식, 인쇄 미리 보기, 여백, 한 쪽 맞춤 시험의 출력 규칙과 시간 관리

후속 과목의 학습에서 본 과목의 내용이 전제되는 지점은 다음과 같다.

  • 수식의 복사와 참조. 후속 과목의 함수는 모두 수식을 작성하여 복사하는 것을 전제로 한다. 3장의 상대 참조와 절대 참조가 그 바탕이다.
  • 함수의 일반 형식. 함수의 종류는 늘어나나 이름, 괄호, 인수, 범위의 형식은 4장에서 익힌 것과 같다.
  • 자료 범위의 선택. 차트와 피벗 테이블의 작성은 5~6장에서 익힌 범위의 선택에서 시작한다.
  • 저장과 인쇄. 시험은 지정된 폴더와 파일 이름으로 저장하고 출력물을 제출한다. 1~2장의 파일 관리와 인쇄 설정이 그대로 사용된다.
  • 테이블과 쿼리의 개념. 후속 과목의 조회 화면과 보고서는 13장의 테이블과 쿼리 위에 작성된다.

3부(파이썬)와 4부(생성형 AI의 활용)는 자격시험의 범위가 아니며, 이후의 데이터 분석 교과목과 연계된다.
