[8주차] 파이썬 실행 환경과 엑셀 파일 읽기

8주차

파이썬 실행 환경과 엑셀 파일 읽기

2027학년도 「컴퓨터활용」의 준비 중인 교재입니다. 편집 상태를 검토하기 위해 미리 공개한 것으로, 수업 전에 내용과 순서가 바뀔 수 있습니다.

학사 10주차 · 교재 08 · 3부 파이썬

본 장부터 세 장에 걸쳐 파이썬을 다룬다. 3부의 목적은 파이썬의 문법을 습득하는 것이 아니라, 1부에서 엑셀로 수행한 작업을 코드로 수행하는 방법을 경험하고 두 방식의 차이를 이해하는 것이다. 본 장에서는 실행 환경의 사용법을 익히고, 판매 자료 파일을 읽어 3장 「수식과 셀 참조」와 4장 「기본 함수」에서 엑셀로 산출한 금액과 통계 값을 코드로 다시 산출한다. 코드의 결과는 4장의 수작업 결과와 대조하여 검증한다.

본 과목에서는 코드를 처음부터 작성하지 않는다. 주어진 코드를 실행하고, 지정된 부분을 채우거나 변경하여 다시 실행하고, 결과를 수작업 결과와 비교하는 방식으로 진행한다. 수업은 실습 노트북을 위에서부터 실행하며 진행하고, 본 강의안은 노트북의 각 셀이 수행하는 일과 그 근거를 설명한다. 강의안의 절 번호는 노트북의 절 번호와 일치한다.

학습 목표

  1. 실습 사이트에 접속하여 노트북을 열고 셀을 실행할 수 있다.
    • 예시: 코드 셀을 Shift + Enter로 실행하고 실행 번호와 결과를 확인한다.
  2. 변수에 값을 저장하고 계산 결과를 출력할 수 있다.
    • 예시: 수량과 단가를 변수에 저장하여 금액을 계산하고 print로 출력한다.
  3. 주어진 코드를 실행하여 엑셀 파일을 표로 읽고 열의 계산으로 금액 열을 추가할 수 있다.
    • 예시: sales["금액"] = sales["수량"] * sales["단가"]가 수행하는 일을 엑셀의 수식과 대응하여 설명한다.
  4. 합계, 평균, 최댓값, 최솟값, 개수를 코드로 산출하여 수작업 결과와 대조할 수 있다.
    • 예시: 코드의 결과 6479000이 4장의 G25와 일치함을 확인한다.

준비 사항

항목 내용
실행 환경 학과 실습 사이트의 JupyterLab. 접속 방법은 부록 A를 따른다
자료 자료\판매_2026_01.xlsx ~ 판매_2026_12.xlsx(월별 파일 12개). 본 장에서는 1~3월 파일을 사용하나, 9장과 10장을 위하여 12개를 모두 올려 둔다
실습 노트북 Office_08주차_실습_학생용.ipynb. 수령 방법은 부록 A를 따른다
수작업 결과 4장에서 저장한 판매현황_04_학번.xlsx의 G25:G29(합계, 평균, 최댓값, 최솟값, 개수)와, 따라 하기에서 작성한 판매연습_04_학번.xlsx의 G24:G28

1. 엑셀과의 비교

1-1. 대응 관계

본 장에서 코드로 수행하는 작업은 3~4장에서 엑셀로 수행한 작업과 동일하다.

엑셀에서의 작업(3~4장) 파이썬에서의 작업(본 장)
통합 문서를 연다 엑셀 파일을 읽어 표로 저장한다
G4에 =E4*F4를 작성하여 20행에 복사한다 수량 열과 단가 열을 곱하여 금액 열을 추가한다
H4에 =G4/$G$25를 작성하여 복사한다 금액 열을 금액의 합계로 나누어 구성비 열을 추가한다
=SUM(G4:G23) 등 함수 5개를 작성한다 금액 열의 합계, 평균, 최댓값, 최솟값, 개수를 산출한다

1-2. 파이썬의 이점과 한계

구분 엑셀 파이썬
계산 절차의 기록 수식은 셀마다 흩어져 있으며, 마우스로 수행한 조작(정렬, 서식 등)은 기록되지 않는다 계산 절차 전체가 코드로 기록된다
재실행 동일한 작업을 반복하려면 조작을 다시 수행하여야 한다 코드를 다시 실행하면 동일한 결과가 산출된다
결과의 확인 값을 변경하면 결과가 즉시 다시 계산되어 화면에 표시된다 코드를 실행하여야 결과가 표시된다
표의 편집 화면에서 직접 입력하고 서식을 지정한다 직접 입력과 서식 지정에는 적합하지 않다
자료의 크기 행이 수만 개를 넘으면 조작이 느려진다 행의 수가 증가하여도 코드는 변하지 않는다

파이썬은 엑셀을 대체하는 도구가 아니다. 자료를 입력하고 눈으로 확인하는 작업은 엑셀이 적합하며, 동일한 계산을 반복하거나 다수의 파일을 처리하는 작업은 파이썬이 적합하다. 9장 「데이터 집계의 자동화」와 10장 「다중 파일의 일괄 처리」에서 그러한 작업을 다룬다.

1-3. 용어의 대응

두 도구는 같은 대상을 서로 다른 용어로 부르거나, 같은 용어로 서로 다른 대상을 부른다.

엑셀 파이썬(JupyterLab, pandas) 유의점
통합 문서(.xlsx) 노트북(.ipynb) 노트북에는 자료가 아니라 코드와 설명이 저장된다
셀(값이나 수식을 담는 칸) 셀(설명이나 코드를 담는 구획) 명칭은 같으나 의미가 다르다
시트의 표 표(DataFrame) 표는 변수에 저장되어 이름으로 참조된다
열 머리글 열의 이름 코드에서는 열 문자(G)가 아니라 열의 이름("금액")으로 열을 가리킨다
수식 코드의 한 줄 수식은 값이 변경되면 자동으로 다시 계산되나, 코드는 실행하여야 계산된다

2. 실행 환경과 셀의 실행

2-1. 화면의 구성

JupyterLab은 웹 브라우저에서 파이썬 코드를 실행하는 환경이다. 프로그램을 설치할 필요가 없으며, 코드는 실습 사이트의 서버에서 실행된다. 따라서 엑셀 파일은 수강생의 PC가 아닌 서버에 있어야 한다. 수강생의 PC에 있는 파일은 서버로 올린 뒤에 코드로 읽을 수 있으며, 코드가 만든 결과 파일은 서버에 생성되므로 내려받아야 수강생의 PC에서 열 수 있다.

영역 위치 용도
파일 탐색기 화면의 왼쪽 서버에 있는 폴더와 파일의 목록. 파일을 올리고 내려받는다
노트북 화면의 가운데 설명과 코드가 셀 단위로 배열된 문서. 확장자는 .ipynb이다
메뉴 화면의 위쪽 [File], [Edit], [Run], [Kernel] 등
도구 모음 노트북의 위쪽 저장, 셀의 추가와 삭제, 실행, 셀 종류의 선택

메뉴가 한국어로 표시되는 환경에서는 대응하는 항목을 선택한다.

그림 필요: (JupyterLab 화면에서 파일 탐색기, 노트북, 메뉴, 도구 모음의 위치)

2-2. 폴더의 구성과 파일의 준비

  1. 파일 탐색기의 위쪽에 있는 [New Folder] 단추로 컴퓨터활용 폴더를 생성하고, 폴더를 두 번 눌러 안으로 이동한다.
  2. 같은 방법으로 컴퓨터활용 폴더 안에 자료 폴더를 생성한다.
  3. 자료 폴더 안으로 이동하여 [Upload Files] 단추로 수강생 PC의 컴퓨터활용\자료 폴더에 있는 월별 파일 12개를 모두 올린다. 파일 선택 창에서 Ctrl + A로 12개를 한 번에 선택할 수 있다.
  4. 컴퓨터활용 폴더로 돌아와 실습 노트북 Office_08주차_실습_학생용.ipynb를 올린다.
  5. 올린 노트북을 마우스 오른쪽 단추로 눌러 [Rename]을 선택하고 이름을 실습_08_학번.ipynb로 변경한다.

완료된 폴더의 구성은 다음과 같다. 수강생 PC의 폴더 구성(1장 「파일 관리와 데이터 입력」)과 같은 이름을 사용한다.

컴퓨터활용/
  실습_08_학번.ipynb
  자료/
    판매_2026_01.xlsx
    …
    판매_2026_12.xlsx

2-3. 셀의 종류와 실행

노트북은 셀로 구성된다. 노트북의 셀은 설명 또는 코드를 담는 하나의 구획이다.

셀의 종류 내용 실행하였을 때
마크다운 셀 설명 글 서식이 적용된 글로 표시된다
코드 셀 파이썬 코드 코드가 실행되고 결과가 셀의 아래에 표시된다
  • 셀을 선택하고 Shift + Enter를 누르면 셀이 실행되고 다음 셀로 이동한다.
  • 코드 셀의 왼쪽에 있는 [ ]는 실행 순서를 나타낸다. 실행하면 [1], [2]와 같이 번호가 부여되고, 실행 중에는 [*]로 표시된다. 번호가 없는 셀은 아직 실행하지 않은 셀이다.
  • 셀은 위에서부터 순서대로 실행한다. 앞의 셀에서 만든 변수를 뒤의 셀이 사용하기 때문이다.
  • 코드 셀에 여러 줄이 있을 때에는 마지막 줄의 계산 결과만 셀의 아래에 표시된다. 중간 줄의 값을 표시하려면 print를 사용한다(3절).
  • 마크다운 셀을 두 번 누르면 편집 상태가 되어 원문이 표시된다. Shift + Enter를 누르면 다시 서식이 적용된 글로 표시된다. 설명 셀을 실수로 편집 상태로 만든 경우에 사용한다.

2-4. 커널과 저장

노트북의 코드를 실제로 실행하는 프로그램을 커널이라고 한다. 커널은 노트북을 연 동안 실행한 셀의 결과(변수)를 기억한다. 커널과 노트북 파일은 별개이므로 다음의 두 가지를 구분하여야 한다.

대상 저장되는 곳 사라지는 경우
셀의 내용(코드, 설명)과 화면에 표시된 결과 노트북 파일(.ipynb) 저장하지 않고 닫은 경우
변수에 저장된 값 커널의 기억 커널을 재시작하거나 실습 사이트에서 로그아웃한 경우

노트북을 다시 열면 이전의 결과가 화면에 남아 있으나 변수는 남아 있지 않다. 따라서 노트북을 다시 열었을 때에는 맨 위의 셀부터 다시 실행하여야 한다. [Kernel] → [Restart Kernel and Run All Cells...]는 커널을 재시작하고 모든 셀을 처음부터 차례로 실행한다. 노트북의 저장은 Ctrl + S로 한다.

따라 하기

실습 노트북의 2절에 있는 셀을 차례로 실행한다.

  1. 30 * 24000이 기재된 셀을 선택하고 Shift + Enter를 누른다. 셀의 아래에 720000이 표시된다.
  2. print가 기재된 셀을 실행한다.
  3. 2월 자료의 판매번호 1022는 토너 6개(단가 85,000원)이다. ____ * ____가 기재된 셀의 ____를 수량과 단가로 변경하여 실행한다.
    • 확인 1 셀의 아래에 510000이 표시되고, 셀의 왼쪽에 실행 번호가 부여되었다.

3. 변수와 출력

3-1. 변수

값에 이름을 부여한 것을 변수라고 한다. 엑셀에서는 값을 셀에 두고 셀 주소(E4)로 참조하였다. 파이썬에서는 값을 변수에 저장하고 변수의 이름(qty)으로 참조한다.

qty = 30          # 수량
price = 24000     # 단가
amount = qty * price
print(amount)
표기 의미
qty = 30 오른쪽의 값 30을 qty라는 이름에 저장한다. 등호는 “같다”가 아니라 “저장한다”를 의미한다
qty * price 곱하기. 연산자(+, -, *, /)는 엑셀의 수식과 같다
print(amount) 괄호 안의 값을 화면에 출력한다
# 수량 #의 뒤는 설명(주석)이며 실행되지 않는다

변수의 이름에는 다음의 규칙이 있다.

  • 영문자, 숫자, 밑줄(_)을 사용한다. 숫자로 시작할 수 없으며 공백을 포함할 수 없다.
  • 대문자와 소문자를 구분한다. qty와 Qty는 서로 다른 변수이다.
  • 이미 있는 이름에 값을 다시 저장하면 이전의 값은 사라진다.

엑셀은 셀의 값이 변경되면 그 셀을 참조하는 수식을 자동으로 다시 계산한다. 노트북은 그렇지 않다. qty의 값을 변경한 뒤에는 amount를 계산하는 줄을 다시 실행하여야 결과가 갱신된다.

3-2. 숫자와 문자

값에는 숫자와 문자가 있다. 문자는 큰따옴표로 감싼다. 큰따옴표가 없는 글자는 변수의 이름으로 해석된다.

표기 해석
24000 숫자. 계산에 사용할 수 있다. 쉼표를 넣지 않는다
"한빛상사" 문자
"02" 문자. 숫자 2가 아니다. 파일 이름의 월과 같이 자릿수를 유지하여야 하는 값에 사용한다(9장)
한빛상사 변수의 이름으로 해석된다. 그러한 변수가 없으면 오류가 발생한다

엑셀에서도 숫자와 문자는 구분되었다. 1장에서 숫자는 셀의 오른쪽에, 문자는 왼쪽에 맞추어 표시됨을 확인하였고, 4장의 IF 함수에서 문자 값 "달성"을 큰따옴표로 감쌌다.

3-3. 출력

print의 괄호 안에 쉼표로 구분하여 여러 값을 기재하면 한 줄에 차례로 출력된다. 값과 값의 사이에는 공백이 하나 들어간다.

customer = "한빛상사"
print(customer, "의 판매 금액:", amount)

round(값, 자릿수)는 값을 지정한 소수 자릿수까지 반올림한다. 자릿수를 생략하면 정수로 반올림한다. 엑셀의 [자릿수 늘림]과 [자릿수 줄임]은 표시만 변경하였으나, round는 반올림한 값을 새로 만든다.

4. 엑셀 파일 읽기

4-1. 라이브러리

파이썬에는 특정한 작업에 필요한 기능을 모아 둔 라이브러리가 있다. 표 형태의 자료를 다루는 라이브러리는 pandas이며, 다음과 같이 불러온 뒤에 사용한다. pd는 pandas를 짧게 부르기 위한 이름이다. 이 셀은 실행하여도 아무것도 표시되지 않으며, 커널을 재시작하면 다시 실행하여야 한다.

import pandas as pd

4-2. 파일 읽기

sales = pd.read_excel("자료/판매_2026_01.xlsx")
sales.head()
표기 의미
pd.read_excel(…) 엑셀 파일을 읽어 표로 반환한다
"자료/판매_2026_01.xlsx" 파일의 위치. 노트북이 있는 폴더를 기준으로 자료 폴더 안의 파일을 가리킨다. 폴더의 구분은 /로 표기한다
sales = … 읽은 표를 sales라는 변수에 저장한다

파일의 위치는 노트북이 있는 폴더를 기준으로 해석된다. 노트북이 컴퓨터활용 폴더에 있고 파일이 컴퓨터활용/자료에 있으므로 "자료/판매_2026_01.xlsx"로 기재한다. 노트북을 다른 폴더로 옮기면 같은 코드가 파일을 찾지 못한다. 파일 이름은 확장자를 포함하여 글자 하나까지 일치하여야 한다.

read_excel은 통합 문서의 첫 시트를 읽는다. 기준 파일에는 “판매내역” 시트 하나만 있다.

4-3. 표의 확인

읽은 표는 계산에 앞서 다음의 방법으로 확인한다. 엑셀에서는 파일을 열면 표가 화면에 표시되나, 코드에서는 표시하도록 지시하여야 보인다.

표기 결과 1월 자료
sales.head() 처음 5행. 괄호 안에 숫자를 기재하면 그 수만큼 표시한다 판매번호 1001~1005
sales.tail(3) 마지막 3행 판매번호 1018~1020
sales.shape 표의 크기 (행의 수, 열의 수) (20, 6)
list(sales.columns) 열의 이름의 목록 판매번호, 판매일, 거래처, 품목, 수량, 단가

표의 맨 왼쪽에 표시되는 0, 1, 2, …는 pandas가 부여한 행 번호이며 자료의 일부가 아니다. 엑셀의 행 번호와 달리 0부터 시작한다. shape의 행의 수에는 머리글 행이 포함되지 않는다. 엑셀에서 자료가 2행부터 21행까지 20행이었던 것과 같다.

4-4. 기준 파일을 사용하는 이유

코드가 읽는 파일은 수강생이 작성한 판매현황_04_학번.xlsx가 아니라 기준 파일 판매_2026_01.xlsx이다. 수강생의 통합 문서에는 1행에 제목, 2행에 빈 행, 25행 이하에 요약 행이 있다. read_excel은 첫 행이 머리글이고 그 아래가 모두 자료인 표를 전제로 하므로, 제목과 요약 행이 포함된 시트를 그대로 읽으면 제목이 열의 이름이 되고 요약 행이 자료로 취급된다. 사람이 읽기 위한 표와 프로그램이 읽기 위한 표는 형태가 다르다는 점은 13장 「액세스 입문: 테이블과 쿼리」에서 다시 다룬다.

5. 열의 계산

5-1. 열의 선택

대괄호 안에 열의 이름을 기재하면 해당 열 전체가 선택된다. 열의 이름은 문자이므로 큰따옴표로 감싼다. 대괄호를 두 겹으로 하여 이름을 쉼표로 나열하면 여러 열을 함께 선택한다.

표기 결과
sales["수량"] 수량 열
sales[["거래처", "품목", "금액"]] 세 열로 구성된 표
sales["수량"].sum() 수량 열의 합계. 1월 자료는 493이며 1장에서 상태 표시줄로 검산한 값과 같다

5-2. 열과 열의 계산

열과 열을 계산하면 같은 행의 값끼리 계산된다.

sales["금액"] = sales["수량"] * sales["단가"]
엑셀 파이썬
G4에 =E4*F4를 작성하고 채우기 핸들로 G23까지 복사한다 열 전체를 한 줄로 계산한다
행이 추가되면 수식을 다시 복사하여야 한다 행의 수와 무관하게 동일한 코드를 사용한다
수식을 복사하지 않은 행이 있으면 그 행만 값이 비어 있어 발견하기 어렵다 모든 행에 동일한 계산이 적용된다

등호의 왼쪽에 존재하지 않는 열의 이름("금액")을 기재하면 계산 결과가 새로운 열로 추가된다. 이미 있는 이름을 기재하면 그 열의 값이 교체된다.

구성비도 동일한 방법으로 산출한다. sales["금액"].sum()은 값 하나이므로 모든 행이 같은 값으로 나누어진다. 3장에서 필요하였던 절대 참조($G$25)에 해당하는 지정은 필요하지 않다.

sales["구성비"] = sales["금액"] / sales["금액"].sum()

5-3. 원본 파일과의 관계

코드로 추가한 열은 변수 sales에 저장된 표에만 존재한다. 서버의 파일 판매_2026_01.xlsx는 변경되지 않는다. 엑셀에서 통합 문서를 열어 열을 추가하고 저장하면 파일이 변경되는 것과 다르다. 계산 결과를 파일로 남기려면 별도의 저장 명령이 필요하며 9장에서 다룬다. 이 성질 때문에 코드는 원본을 훼손할 위험 없이 여러 번 실행할 수 있다.

대조표에 False가 있는 경우에는 다음의 순서로 원인을 좁힌다. 코드는 기준 파일을 읽으므로 코드의 결과는 모든 수강생에게서 동일하다. 따라서 원인은 기재한 수작업 결과에 있다. 먼저 기재한 값에 오타가 없는지 확인하고, 오타가 아니면 4장의 파일에서 해당 셀의 수식과 범위를 확인한다. 4장의 값 자체가 기준 값과 다르면 1장의 입력 값에 오류가 있는 것이다.

빈번한 오류와 해결

오류가 발생하면 셀의 아래에 붉은색의 오류 내용이 표시된다. 오류 내용은 여러 줄이나, 맨 마지막 줄에 오류의 종류와 원인이 기재되어 있으므로 마지막 줄을 먼저 확인한다. 그 위에는 오류가 발생한 줄이 화살표(---->)로 표시된다.

오류의 마지막 줄 원인 해결
FileNotFoundError: … No such file or directory 파일이 해당 위치에 없다. 자료 폴더의 이름이 다르거나, 파일을 다른 폴더에 올렸거나, 노트북이 컴퓨터활용 폴더에 있지 않다 파일 탐색기에서 2-2절의 폴더 구성과 대조한다
NameError: name 'sales' is not defined 변수를 만드는 셀을 실행하지 않았다. 노트북을 다시 열었거나 커널을 재시작한 뒤에 중간의 셀부터 실행한 경우이다 위의 셀부터 순서대로 다시 실행한다
NameError: name 'pd' is not defined import pandas as pd의 셀을 실행하지 않았다 해당 셀을 실행한다
KeyError: '____', AttributeError: … '____', NameError: name '____' is not defined ____를 채우지 않고 실행하였다 ____를 지시된 값으로 변경한다
KeyError: '수 량' 등 열의 이름이 표의 머리글과 일치하지 않는다. 띄어쓰기와 오타를 포함한다 list(sales.columns)의 결과와 동일하게 기재한다
SyntaxError: unterminated string literal 큰따옴표를 닫지 않았다 문자의 앞뒤에 큰따옴표가 모두 있는지 확인한다
NameError: name '한빛상사' is not defined 문자 값을 큰따옴표로 감싸지 않았다 "한빛상사"로 기재한다
ModuleNotFoundError: No module named 'openpyxl' 엑셀 파일을 읽는 데 필요한 라이브러리가 설치되어 있지 않다 담당 교수에게 알린다
셀이 [*]인 채로 종료되지 않는다 실행이 진행 중이거나 중단되었다 [Kernel] → [Restart Kernel...]을 실행한 뒤 처음부터 다시 실행한다
“일치” 열에 False가 표시된다 기재한 수작업 결과가 코드의 결과와 다르다 완료 기준 아래의 순서로 원인을 좁힌다

심화 실습

핵심 실습을 완료한 수강생은 4장의 목표 달성 건수를 코드로 산출한다.

  1. 노트북의 “심화 실습” 절에 있는 셀에서 target의 값으로 500000을 기재하여 실행한다. 결과를 4장에서 센 달성 건수(5건)와 대조한다.
  2. target을 300000으로 변경하여 다시 실행한다.
  3. 엑셀에서 기준 금액을 300,000원으로 변경하려면 어떠한 조작이 필요한지 정리하여 코드의 경우와 비교한다.

sales["금액"] >= target은 행마다 조건의 충족 여부를 참(True) 또는 거짓(False)으로 판정하며, sum()은 참의 개수를 센다. 4장의 IF 함수가 행마다 “달성” 또는 “미달”을 표시한 것과 같은 판정이다.

연습 문제

3월 자료(자료/판매_2026_03.xlsx)를 사용한다. 노트북의 “연습 문제” 절에 있는 빈 셀에 코드를 작성한다. 절차는 제시하지 않는다.

  1. 3월 파일을 읽어 mar에 저장하고 표의 크기를 확인한다. 기준 값은 (25, 6)이다.
  2. mar에 금액 열을 추가하고 금액의 합계와 평균을 출력한다. 기준 값은 합계 8687000, 평균 347480.0이다.
  3. 3월의 수량 합계와, 금액이 500,000원 이상인 판매 건의 수를 출력한다. 기준 값은 수량 합계 536, 500,000원 이상 8건이다.

개념 점검

  1. 수강생의 PC에 있는 엑셀 파일을 코드로 읽으려면 먼저 무엇을 하여야 하는가. 그 이유는 무엇인가.
  2. 노트북을 닫았다가 다시 열어 7절의 셀만 실행하였더니 NameError가 발생하였다. 원인과 해결 방법을 기술하시오.
  3. qty = 30과 엑셀의 수식 =30에서 등호의 의미는 어떻게 다른가.
  4. sales["금액"] = sales["수량"] * sales["단가"]는 엑셀의 어떠한 조작에 해당하는가. 행이 20개에서 200개로 증가하였을 때 두 방식에서 필요한 작업을 비교하시오.
  5. 코드가 수강생의 판매현황_04_학번.xlsx가 아닌 기준 파일을 읽는 이유는 무엇인가.
