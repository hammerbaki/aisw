[7주차] 엑셀 자료를 활용한 슬라이드 작성

엑셀 자료를 활용한 슬라이드 작성

2027학년도 「컴퓨터활용」의 준비 중인 교재입니다. 편집 상태를 검토하기 위해 미리 공개한 것으로, 수업 전에 내용과 순서가 바뀔 수 있습니다.

학사 9주차 · 교재 07 · 2부 파워포인트

본 장부터 2부 파워포인트이다. 본 장은 1부에서 작성한 엑셀의 결과물을 보고 자료로 구성하는 장이다. 6장 「피벗 테이블」에서 작성한 거래처별 금액 합계의 피벗 테이블과 5장 「정렬, 필터, 차트」에서 작성한 한빛상사의 품목별 금액 차트를 슬라이드에 삽입하고, 도형으로 판매 업무의 흐름도를 작성하여 슬라이드 2매의 판매 현황 보고 자료를 완성한다. 본 장에서는 새로운 계산을 수행하지 않는다. 슬라이드에 기재하는 모든 수치는 엑셀에서 가져오며, 엑셀의 값과 일치하는지를 대조하는 것으로 실습을 마친다.

각 절의 끝에 있는 「따라 하기」는 교수의 시연을 연습용 파일에서 따라 수행하는 조작이다. 연습용 프레젠테이션(연습_07_학번.pptx)과 2월 자료로 작성한 연습용 통합 문서(판매연습_06_학번.xlsx)를 사용하며, 1월 자료를 사용하는 핵심 실습과는 도형의 구성과 수치가 다르다.

학습 목표

  1. 프레젠테이션, 슬라이드, 레이아웃, 개체 틀의 관계를 설명하고 슬라이드를 추가, 삭제, 이동한다.
  2. 도형과 글상자를 삽입하고 채우기, 윤곽선, 글꼴, 크기를 지정한다.
  3. 여러 도형을 맞춤과 배분으로 정렬하고 그룹으로 묶으며, 개체의 순서를 변경한다.
  4. 엑셀의 표와 차트를 슬라이드에 붙여 넣고, 붙여넣기 옵션에 따른 편집 가능 여부와 원본과의 연결 여부를 설명한다.
  5. 슬라이드에 기재한 수치를 엑셀의 값과 대조하여 검산한다.
  6. 슬라이드 2매를 유인물의 형태로 한 쪽에 출력하여 PDF로 저장한다.

준비 사항

항목 내용
선행 결과물 6장에서 저장한 컴퓨터활용\실습\판매현황_06_학번.xlsx
사용하는 자료 “피벗” 시트의 거래처별 피벗 테이블(A3:B9)과 “한빛상사” 시트의 차트
확인할 값 피벗 테이블의 총합계가 6,479,000이고 한빛상사가 1,756,000이다
작성하는 파일 컴퓨터활용\실습\판매보고_07_학번.pptx, 컴퓨터활용\출력\판매보고_07_학번.pdf
연습용 파일 컴퓨터활용\실습\판매연습_06_학번.xlsx(2월 자료. “피벗” 시트의 피벗 테이블 A3:B9와 “토너” 시트의 표 A1:E4, 차트가 있다). 따라 하기에서 컴퓨터활용\실습\연습_07_학번.pptx를 새로 작성한다. 연습용 파일은 제출하지 않는다
대체 자료 앞 장의 결과 파일이 없는 수강생은 교수가 제공하는 앞 장의 완성 파일로 시작한다

프로그램을 여는 방법과 웹용 프로그램의 주소는 부록 A-8에 있다.

1. 파워포인트의 화면과 슬라이드

1-1. 엑셀과의 연계

엑셀은 자료를 계산하고 집계하는 도구이고, 파워포인트는 그 결과를 다른 사람에게 전달하는 도구이다. 본 장에서 작성하는 슬라이드의 구성 요소와 그 원천은 다음과 같다.

슬라이드의 구성 요소 원천 작성한 장
거래처별 금액의 표 “피벗” 시트의 피벗 테이블 6장
품목별 금액의 차트 “한빛상사” 시트의 차트 5장
요약 문장의 수치 피벗 테이블의 총합계와 한빛상사의 값 4장, 6장
판매 업무 흐름도 엑셀의 자료가 아니다. 도형으로 직접 작성한다 본 장

슬라이드의 수치는 다시 계산하거나 기억에 의존하여 입력하지 않는다. 엑셀에서 검증을 마친 값을 복사하여 가져오고, 가져온 뒤에 엑셀의 값과 대조한다.

1-2. 프레젠테이션과 슬라이드

파워포인트의 파일을 프레젠테이션이라고 하며 확장자는 .pptx이다. 프레젠테이션은 여러 장의 슬라이드로 구성된다. 엑셀의 용어와 대응시키면 다음과 같다.

엑셀 파워포인트 차이
통합 문서(.xlsx) 프레젠테이션(.pptx) 파일의 단위이다
워크시트 슬라이드 시트에는 이름이 있으나 슬라이드에는 번호만 있다. 슬라이드의 내용은 제목으로 구별한다
셀 대응하는 요소가 없다 슬라이드에는 칸이 없으며 모든 내용이 개체로 놓인다
차트(셀 위에 놓이는 개체) 도형, 글상자, 표, 차트, 그림 슬라이드의 내용은 모두 개체이다

엑셀에서는 값이 셀이라는 고정된 칸에 들어가므로 행과 열이 자동으로 정돈된다. 파워포인트에는 칸이 없으며 모든 내용이 개체로서 임의의 위치에 놓인다. 따라서 개체의 위치를 정돈하는 기능(맞춤, 배분)을 별도로 사용하여야 한다.

1-3. 화면의 구성

파워포인트의 화면은 엑셀과 같이 위쪽에 리본 메뉴가 있으며, 그 아래의 작업 영역이 다르다.

화면의 요소 위치와 역할
슬라이드 축소판 창 화면 왼쪽의 영역. 슬라이드가 번호와 함께 작은 그림으로 나열된다. 슬라이드를 선택, 추가, 삭제, 이동하는 곳이며 엑셀의 시트 탭에 해당한다
슬라이드 창 화면 가운데의 영역. 축소판 창에서 선택한 슬라이드를 편집한다
상태 표시줄 화면 아래쪽. 현재 슬라이드의 번호와 전체 슬라이드의 수가 표시되고, 오른쪽에 확대/축소 슬라이더가 있다

그림 필요: 파워포인트의 화면에서 슬라이드 축소판 창, 슬라이드 창, 상태 표시줄의 슬라이드 번호 표시의 위치

조작의 대상이 어느 영역에 있는지에 따라 같은 키의 결과가 달라진다. 축소판 창에서 슬라이드를 선택한 상태의 Ctrl + C는 슬라이드 전체를 복사하고, 슬라이드 창에서 도형을 선택한 상태의 Ctrl + C는 그 도형을 복사한다.

1-4. 레이아웃과 개체 틀

개체 틀은 제목이나 내용을 입력하도록 슬라이드에 미리 준비된 영역이다. 점선의 테두리로 표시되며, 내용을 입력하기 전에는 안내 문구가 표시된다. 안내 문구는 입력을 시작하면 사라지며, 아무것도 입력하지 않은 개체 틀은 인쇄되지 않는다.

레이아웃은 슬라이드에 배치되어 있는 개체 틀의 구성이다. 레이아웃은 슬라이드마다 하나씩 지정되며 [홈] 탭 → [슬라이드] 그룹 → [레이아웃]에서 변경한다.

레이아웃 개체 틀 용도
제목 슬라이드 제목, 부제목 표지. 새 프레젠테이션의 첫 슬라이드에 적용되어 있다
제목 및 내용 제목, 내용 글머리 기호 목록, 또는 표나 차트 하나
제목만 제목 제목 아래에 도형, 표, 차트를 자유롭게 배치한다. 본 장에서 사용한다
빈 화면 없음 모든 내용을 직접 배치한다

본 장에서 [제목만]을 사용하는 이유는 두 가지이다. 첫째, 제목 개체 틀이 있으므로 모든 슬라이드에 제목이 같은 위치와 같은 서식으로 놓인다. 둘째, 내용 개체 틀이 없으므로 붙여 넣은 표와 차트가 개체 틀에 들어가 크기와 위치가 임의로 변하는 일이 없다.

그림 필요: [레이아웃] 목록에서 [제목 슬라이드], [제목 및 내용], [제목만], [빈 화면]의 위치와, [제목만]을 적용한 슬라이드의 제목 개체 틀

1-5. 슬라이드의 추가, 삭제, 순서 변경

슬라이드에 대한 조작은 슬라이드 축소판 창에서 수행한다.

조작 방법
추가 축소판 창에서 슬라이드를 선택하고 [홈] 탭 → [슬라이드] 그룹 → [새 슬라이드]의 화살표를 눌러 레이아웃을 선택한다. 새 슬라이드는 선택한 슬라이드의 바로 뒤에 추가된다
삭제 축소판 창에서 슬라이드를 마우스 오른쪽 단추로 누르고 [슬라이드 삭제]를 선택한다
복제 축소판 창에서 슬라이드를 마우스 오른쪽 단추로 누르고 [슬라이드 복제]를 선택한다. 사본이 원본의 바로 뒤에 추가된다
순서 변경 축소판 창에서 슬라이드를 원하는 위치로 끌어 놓는다. 슬라이드의 번호는 순서에 따라 다시 부여된다
여러 슬라이드의 선택 Ctrl을 누른 채 슬라이드를 차례로 누른다. 연속한 슬라이드는 첫 슬라이드를 누른 뒤 Shift를 누른 채 마지막 슬라이드를 누른다

삭제한 슬라이드에 놓여 있던 개체도 함께 삭제된다. 잘못 삭제한 경우에는 곧바로 Ctrl + Z로 되돌린다.

1-6. 가독성의 기준

보고 자료는 작성자가 아닌 사람이 읽는 문서이다. 본 장에서는 슬라이드를 꾸미는 방법을 다루지 않으며, 읽는 사람이 내용을 놓치지 않기 위한 최소한의 기준만을 적용한다.

기준 본 장에서의 적용 근거
한 슬라이드에는 하나의 내용만 싣는다 1매는 업무의 흐름, 2매는 1월 판매 현황이다. 2매의 표, 차트, 요약 문장은 모두 “1월의 판매 현황”이라는 하나의 내용을 뒷받침한다 한 슬라이드에 여러 내용이 있으면 읽는 사람이 무엇을 전달하려는 슬라이드인지 판단하여야 한다. 내용이 하나이면 제목이 그 내용을 대표할 수 있다
모든 슬라이드에 내용을 나타내는 제목을 둔다 제목 개체 틀에 “판매 업무 흐름”, “2026년 1월 판매 현황”을 입력한다 제목은 슬라이드를 구별하고 찾는 단서이다. Microsoft의 접근성 지침은 모든 슬라이드에 서로 다른 제목을 지정하도록 권고한다
글꼴 크기는 18 이상으로 한다 도형과 표의 문자는 18, 요약 문장은 20으로 지정한다 Microsoft의 접근성 지침은 18pt 이상의 글꼴을 권고한다. 발표 화면에 대해서는 30보다 작은 글꼴은 청중이 보기 어렵다고 안내한다
문자와 배경의 명암 차이를 확보한다 도형을 밝은 색으로 채우고 문자를 검정으로 지정한다 명암 차이가 작으면 화면과 인쇄물에서 문자를 읽기 어렵다
수치에는 단위와 기준을 표시한다 표의 머리글을 “금액(원)”으로 수정하고, 요약 문장에 “1월”과 “원”을 기재한다 단위와 기간이 없는 수치는 엑셀 파일을 보지 않은 사람이 해석할 수 없다

유인물로 인쇄하면 슬라이드가 축소되므로 문자도 함께 작아진다. 글꼴 크기가 적절한지는 인쇄 미리 보기와 PDF에서 표의 수치를 읽을 수 있는지로 최종 확인한다(5절).

  4. 슬라이드 축소판 창과 슬라이드 창을 확인한다. 첫 슬라이드에는 제목과 부제목의 개체 틀이 있다.
  • 확인 1 제목 표시줄에 연습_07_학번.pptx가 표시되고, 축소판 창에 슬라이드가 1개이며 슬라이드 창에 개체 틀이 2개 표시되었다.

(2) 레이아웃의 변경

  1. 축소판 창에서 첫 슬라이드를 선택한다.
  2. [홈] 탭 → [슬라이드] 그룹 → [레이아웃] → [제목만]을 선택한다.
  3. 제목 개체 틀의 안쪽을 누르고 처리 흐름을 입력한다.
  4. 슬라이드의 빈 곳을 눌러 개체 틀의 선택을 해제한다.
  • 확인 2 부제목 개체 틀이 사라지고 제목 개체 틀 하나에 처리 흐름이 표시되었다.

(3) 슬라이드의 추가, 순서 변경, 삭제

  1. [홈] 탭 → [슬라이드] 그룹 → [새 슬라이드]의 화살표를 누르고 [제목만]을 선택한다. 제목에 2월 판매 현황을 입력한다.
  2. 같은 방법으로 슬라이드를 하나 더 추가하고 제목에 삭제할 슬라이드를 입력한다. 슬라이드는 3개이다.
  3. 축소판 창에서 3번 슬라이드를 1번과 2번 슬라이드의 사이로 끌어 놓는다. “삭제할 슬라이드”의 번호가 2로 바뀌는지 확인한다.
  4. 2번 슬라이드(“삭제할 슬라이드”)를 마우스 오른쪽 단추로 누르고 [슬라이드 삭제]를 선택한다.
  5. Ctrl + S로 저장한다.
  • 확인 3 축소판 창에 슬라이드가 2개이고, 1번의 제목이 처리 흐름, 2번의 제목이 2월 판매 현황이다. 상태 표시줄에 표시된 전체 슬라이드의 수가 2이다.

2. 도형과 글상자

2-1. 도형의 삽입

도형은 [삽입] 탭 → [일러스트레이션] 그룹 → [도형]에서 종류를 선택한 뒤 슬라이드 위에서 끌어 그린다. 도형을 선택한 상태에서 문자를 입력하면 도형 안에 문자가 들어간다.

도형을 그리거나 옮길 때 Shift와 Ctrl을 함께 사용하면 조작이 제한되거나 복사가 수행된다.

조작 결과
Shift를 누른 채 끌어 그리기 가로와 세로의 길이가 같은 도형(정사각형, 원)이 그려진다. 선은 수평, 수직, 45도 방향으로 그려진다
도형을 끌기 도형이 이동한다
Shift를 누른 채 도형을 끌기 수평 또는 수직 방향으로만 이동한다
Ctrl을 누른 채 도형을 끌기 도형이 복사된다
Ctrl + Shift를 누른 채 도형을 끌기 수평 또는 수직 방향의 위치에 복사된다
Ctrl + D 선택한 도형이 복제되어 오른쪽 아래에 놓인다
Shift를 누른 채 모서리의 크기 조정 핸들을 끌기 가로와 세로의 비율을 유지한 채 크기가 변한다
Ctrl을 누른 채 크기 조정 핸들을 끌기 도형의 중심이 제자리에 있는 상태로 크기가 변한다

화살표는 [도형]의 [선] 범주에서 한쪽 끝에 화살촉이 있는 선을 선택하여 그린다. 화살표를 선택한 상태에서 마우스를 도형 위로 가져가면 도형의 테두리에 연결점이 표시된다. 한 도형의 연결점에서 다른 도형의 연결점까지 끌면 두 도형을 잇는 화살표가 그려지며, 양 끝이 연결점에 붙은 화살표는 도형을 이동하면 함께 이동한다. 연결점이 아닌 위치에서 끝난 선은 도형과 무관한 개체이므로 도형을 이동하여도 따라오지 않는다.

그림 필요: 화살표를 선택한 상태에서 직사각형 위에 마우스를 올렸을 때 네 변의 가운데에 표시되는 연결점과, 두 도형의 연결점을 이은 화살표

버전에 따른 차이: [선] 범주의 화살표는 마우스를 올렸을 때 [선 화살표] 또는 [화살표]라는 이름으로 표시된다. 연결점의 모양과 색도 버전에 따라 다르다.

2-2. 개체의 선택

선택 대상 조작
개체 하나 도형은 테두리를 누른다. 그림과 화살표는 개체 위를 누른다
여러 개체 Shift를 누른 채 개체를 차례로 누른다. 이미 선택된 개체를 Shift를 누른 채 다시 누르면 그 개체만 선택에서 제외된다
한 영역의 개체 슬라이드의 빈 곳에서 끌어 개체들을 둘러싼다. 영역에 완전히 포함된 개체만 선택된다
슬라이드의 모든 개체 Ctrl + A. 제목 개체 틀도 함께 선택된다
다른 개체에 가려진 개체 [홈] 탭 → [편집] 그룹 → [선택] → [선택 창]을 열어 목록에서 개체의 이름을 누른다

도형의 안쪽을 누르면 문자를 편집하는 상태가 되어 커서가 깜박인다. 이 상태에서 서식을 지정하면 선택한 문자에만 적용된다. 도형 전체에 서식을 적용할 때에는 도형의 테두리를 눌러 도형 자체를 선택한다. 두 상태는 테두리의 모양으로 구별할 수 있다. 문자를 편집하는 상태에서는 테두리가 점선으로, 도형 자체를 선택한 상태에서는 실선으로 표시된다.

끌어서 선택할 때에는 제목 개체 틀이 함께 선택되기 쉽다. 선택한 뒤에는 선택된 개체의 수가 의도와 같은지 확인하고, 불필요한 개체는 Shift를 누른 채 눌러 제외한다.

2-3. 도형 서식

도형을 선택하면 리본 메뉴에 [도형 서식] 탭이 나타난다. 이 탭은 도형, 글상자, 화살표가 선택되어 있는 동안에만 표시된다.

서식 경로 지정하는 내용
채우기 [도형 서식] 탭 → [도형 스타일] 그룹 → [도형 채우기] 도형 내부의 색
윤곽선 [도형 서식] 탭 → [도형 스타일] 그룹 → [도형 윤곽선] 테두리 선의 색과 두께. 화살표는 선 자체가 윤곽선이므로 색과 두께를 여기에서 지정한다
글꼴 [홈] 탭 → [글꼴] 그룹 도형 안 문자의 글꼴, 크기, 색

채우기 색과 글꼴 색은 서로 독립된 서식이다. 새로 그린 도형은 진한 색의 채우기에 흰색의 문자가 기본값이므로, 채우기를 밝은 색으로 변경하면 문자가 보이지 않게 된다. 채우기를 변경할 때에는 글꼴 색을 함께 지정한다.

같은 서식의 도형이 여러 개 필요할 때에는 도형 하나의 서식을 먼저 완성한 뒤 복제한다. 복제된 도형은 크기와 서식이 원본과 같으므로 문자만 수정하면 된다.

버전에 따른 차이: 이전 버전에서는 [도형 서식] 탭이 [그리기 도구] 아래의 [서식] 탭으로 표시된다.

2-4. 크기와 위치의 수치 지정

마우스로 끌어 정한 크기는 도형마다 조금씩 달라진다. 크기가 같아야 하는 도형은 수치로 지정한다.

지정하는 값 경로 비고
높이, 너비 [도형 서식] 탭 → [크기] 그룹의 높이 상자와 너비 상자 값을 입력하고 Enter를 누른다. 단위는 cm이다
위치 [크기] 그룹의 오른쪽 아래에 있는 작은 화살표(대화 상자 표시 아이콘)를 눌러 [도형 서식] 작업 창을 열고, [크기 및 속성]의 [위치]에서 가로 위치와 세로 위치를 입력한다 슬라이드의 왼쪽 위 모서리로부터 도형의 왼쪽 위 모서리까지의 거리이다

여러 도형을 선택한 상태에서 높이와 너비를 입력하면 선택한 도형 모두에 같은 값이 적용된다. 위치는 도형마다 달라야 하므로 수치로 하나씩 지정하기보다 3절의 맞춤과 배분으로 정한다. 위치의 수치는 맞춤의 결과를 확인하는 용도로 사용할 수 있다. 중간 맞춤을 실행한 도형들은 높이가 같다면 세로 위치의 값이 같다.

2-5. 글상자와 도형 안의 문자

글상자는 문자를 슬라이드의 임의의 위치에 놓기 위한 개체이다. 파워포인트의 메뉴에서는 [텍스트 상자]라는 이름으로 표시된다. [삽입] 탭 → [텍스트] 그룹 → [텍스트 상자]를 누르고 슬라이드 위에서 가로로 끌어 너비를 정한 뒤 문자를 입력한다. 글상자는 채우기와 윤곽선이 없는 도형과 같으며, 서식을 지정하는 방법도 도형과 같다.

문자를 놓는 방법은 개체 틀, 도형 안의 문자, 글상자의 세 가지이다.

구분 개체 틀 도형 안의 문자 글상자
위치 레이아웃이 정한다 도형의 안쪽 임의의 위치
도형과의 관계 없다 도형에 속한다. 도형을 이동하거나 복제하면 문자도 함께 이동하고 복제된다 다른 도형과 독립되어 있다. 도형을 이동하여도 글상자는 제자리에 있다
문자가 많아진 경우 글꼴 크기가 자동으로 줄어든다 도형의 크기는 변하지 않으며 문자가 도형의 밖으로 넘칠 수 있다 글상자의 높이가 문자의 양에 따라 늘어난다
본 장에서의 용도 슬라이드의 제목 흐름도의 각 단계 요약 문장

도형과 함께 움직여야 하는 문자(단계의 이름)는 도형 안에 입력하고, 어느 도형에도 속하지 않는 설명(요약 문장)은 글상자로 작성한다. 도형 위에 글상자를 따로 올려놓는 방법은 사용하지 않는다. 도형을 이동하거나 정렬할 때 문자가 따라오지 않기 때문이다.

따라 하기

연습용 프레젠테이션의 1번 슬라이드에 직사각형 3개와 글상자 1개를 작성한다.

(1) 첫 도형의 작성과 서식

  1. 축소판 창에서 1번 슬라이드(“처리 흐름”)를 선택한다.
  2. [삽입] 탭 → [일러스트레이션] 그룹 → [도형]에서 [사각형] 범주의 [직사각형]을 선택하고 슬라이드의 빈 곳에서 끌어 그린다.
  3. [도형 서식] 탭 → [크기] 그룹에서 높이에 2, 너비에 4를 입력한다.
  4. 도형이 선택된 상태에서 입력이라는 문자를 입력한다.
  5. 도형의 테두리를 눌러 도형 자체를 선택한다.
  6. [도형 채우기]에서 밝은 계열의 색을, [도형 윤곽선]에서 색 [검정, 텍스트 1]과 두께 1½pt를 지정한다.
  7. [홈] 탭 → [글꼴] 그룹에서 글꼴 색을 [검정, 텍스트 1], 글꼴 크기를 18로 지정한다.
  • 확인 4 도형을 선택하였을 때 [크기] 그룹에 높이 2cm, 너비 4cm가 표시되고, 도형 안에 검정색의 입력이 표시되었다.

(2) 도형의 복제

  1. 도형이 선택된 상태에서 Ctrl + D를 두 번 누른다. 도형이 3개가 된다.
  2. 세 도형을 끌어 왼쪽에서 오른쪽으로 나열한다. 높이와 간격은 맞추지 않는다.
  3. 둘째 도형의 안쪽을 눌러 문자를 계산으로, 셋째 도형의 문자를 출력으로 수정한다.
  • 확인 5 직사각형이 3개이고 문자가 왼쪽부터 입력, 계산, 출력이다. 어느 도형을 선택하여도 높이 2cm, 너비 4cm가 표시되었다.

(3) 글상자의 작성과 도형 안의 문자와의 비교

  1. [삽입] 탭 → [텍스트] 그룹 → [텍스트 상자]를 누르고 세 도형의 아래에서 가로로 끌어 글상자를 그린다.
  2. 자료의 처리 순서를 입력하고 슬라이드의 빈 곳을 누른다.
  3. 첫째 도형의 테두리를 끌어 위쪽으로 이동한다. 문자 입력이 도형과 함께 이동하고 글상자는 제자리에 있는지 확인한다.
  4. Ctrl + Z를 눌러 도형을 원래의 위치로 되돌린다.
  5. Ctrl + S로 저장한다.
  • 확인 6 도형을 이동하였을 때 도형 안의 문자는 함께 이동하고 글상자는 이동하지 않았다. 슬라이드에 직사각형 3개와 글상자 1개가 있다.

3. 맞춤, 배분, 그룹, 순서

3-1. 맞춤

맞춤은 선택한 개체들의 위치를 한 줄에 맞추는 기능이다. [도형 서식] 탭 → [정렬] 그룹 → [맞춤]에서 실행한다. [홈] 탭 → [그리기] 그룹 → [정렬] → [맞춤]에서도 같은 명령을 실행할 수 있으며, 표나 그림이 함께 선택된 경우에는 이 경로를 사용한다.

명령 맞추는 방향 결과 사용하는 경우
왼쪽 맞춤 가로 가장 왼쪽에 있는 개체의 왼쪽 변에 맞추어진다 위아래로 나열한 개체
가운데 맞춤 가로 개체들의 가로 가운데가 같은 세로선 위에 놓인다 위아래로 나열한 개체
오른쪽 맞춤 가로 가장 오른쪽에 있는 개체의 오른쪽 변에 맞추어진다 위아래로 나열한 개체
위쪽 맞춤 세로 가장 위에 있는 개체의 위쪽 변에 맞추어진다 좌우로 나열한 개체
중간 맞춤 세로 개체들의 세로 가운데가 같은 가로선 위에 놓인다 좌우로 나열한 개체
아래쪽 맞춤 세로 가장 아래에 있는 개체의 아래쪽 변에 맞추어진다 좌우로 나열한 개체

[가운데 맞춤]과 [중간 맞춤]은 이름이 유사하나 방향이 다르다. 좌우로 나열한 도형에 [가운데 맞춤]을 실행하면 모든 도형이 한 위치에 겹친다. 명령을 선택할 때에는 “도형을 어느 방향으로 움직여야 하는가”를 먼저 판단한다. 좌우로 나열한 도형은 위아래로 움직여야 한 줄이 되므로 세로 방향의 명령(위쪽, 중간, 아래쪽)을 사용한다.

그림 필요: [맞춤] 메뉴의 항목(맞춤 6개, 간격 2개, 기준 2개)과 좌우로 나열한 도형에 [중간 맞춤]을 실행하기 전과 후의 모습

3-2. 배분

배분은 선택한 개체들 사이의 간격을 같게 하는 기능이다. [맞춤] 메뉴의 [가로 간격을 동일하게]와 [세로 간격을 동일하게]로 실행한다. 양 끝의 두 개체는 이동하지 않고 그 사이의 개체들이 이동하므로, 개체를 3개 이상 선택하여야 한다.

좌우로 나열한 도형을 정렬하는 순서는 다음과 같다.

  1. 양 끝의 두 도형을 원하는 위치에 놓는다. 나머지 도형은 그 사이에 순서대로 놓는다.
  2. 모든 도형을 선택하고 [중간 맞춤]을 실행한다. 세로 위치가 맞추어진다.
  3. 선택을 유지한 채 [가로 간격을 동일하게]를 실행한다. 간격이 같아진다.

정렬이 완료되었는지는 같은 명령을 한 번 더 실행하여 확인한다. 이미 정렬된 도형은 명령을 다시 실행하여도 움직이지 않는다.

버전에 따른 차이: Microsoft의 지원 문서(한국어판)는 간격을 같게 하는 명령을 [가로로 분산], [세로로 분산]으로 표기하기도 한다. 메뉴에서는 맞춤 명령 6개의 아래에 있는 두 항목이다.

3-3. 맞춤과 배분의 기준

맞춤과 배분의 기준은 [맞춤] 메뉴의 아래쪽에 있는 두 항목으로 지정한다. 현재의 기준에는 선택 표시가 되어 있다.

기준 맞춤의 결과 배분의 결과
선택한 개체 맞춤 선택한 개체들끼리 맞추어진다 양 끝의 개체는 제자리에 있고 사이의 개체들의 간격이 같아진다
슬라이드에 맞춤 슬라이드의 가장자리 또는 가운데에 맞추어진다. [왼쪽 맞춤]은 개체를 슬라이드의 왼쪽 가장자리로 옮긴다 개체들이 슬라이드의 한쪽 끝에서 반대쪽 끝까지 같은 간격으로 벌어진다

개체를 하나만 선택한 경우에는 [선택한 개체 맞춤]을 사용할 수 없으며 슬라이드가 기준이 된다. 이 성질을 이용하면 개체 하나(또는 그룹 하나)를 슬라이드의 가로 가운데에 놓을 수 있다. 개체를 선택하고 [가운데 맞춤]을 실행하면 된다.

기준은 한 번 지정하면 다음에 변경할 때까지 유지된다. 여러 도형을 정렬하기 전에는 기준이 [선택한 개체 맞춤]인지 확인한다. 기준이 [슬라이드에 맞춤]인 상태에서 [가로 간격을 동일하게]를 실행하면 도형이 슬라이드의 양 끝까지 벌어진다.

3-4. 그룹

그룹은 여러 개체를 하나의 개체처럼 다루도록 묶는 기능이다. 개체들을 선택하고 [도형 서식] 탭 → [정렬] 그룹 → [그룹화] → [그룹]을 실행하거나 Ctrl + G를 누른다.

조작 방법 결과
그룹 개체를 2개 이상 선택하고 Ctrl + G 한 번 누르면 전체가 선택된다. 이동하거나 크기를 변경할 때 서로의 위치 관계가 유지된다
그룹 안의 개체 선택 그룹을 선택한 뒤 해당 개체를 한 번 더 누른다 그룹을 해제하지 않고 개체 하나의 문자나 서식을 수정할 수 있다
그룹 해제 그룹을 선택하고 [그룹화] → [그룹 해제] 또는 Ctrl + Shift + G 개체들이 다시 낱개로 선택된다

모든 개체를 그룹으로 묶을 수 있는 것은 아니다. 제목 개체 틀과 같은 개체 틀, 그리고 표는 그룹에 포함할 수 없다. 이러한 개체가 함께 선택되어 있으면 [그룹] 명령을 사용할 수 없다.

그룹은 맞춤의 관점에서 개체 하나로 취급된다. 흐름도를 구성하는 도형과 화살표를 먼저 정렬하고 그룹으로 묶은 뒤, 그룹을 슬라이드의 가운데에 맞추는 순서로 작업한다. 순서를 바꾸어 그룹을 먼저 묶으면 그룹 안의 도형들을 서로 맞추기가 번거롭다.

3-5. 순서

슬라이드의 개체는 작성한 순서대로 쌓이며, 나중에 작성한 개체가 먼저 작성한 개체의 위에 놓인다. 개체가 겹치면 위의 개체가 아래의 개체를 가린다. 순서는 [도형 서식] 탭 → [정렬] 그룹의 [앞으로 가져오기]와 [뒤로 보내기]로 변경한다.

명령 결과
앞으로 가져오기 한 단계 위로 올린다
맨 앞으로 가져오기 모든 개체의 위로 올린다
뒤로 보내기 한 단계 아래로 내린다
맨 뒤로 보내기 모든 개체의 아래로 내린다

개체가 쌓인 순서는 [선택 창]에서 확인할 수 있다. [홈] 탭 → [편집] 그룹 → [선택] → [선택 창]을 열면 슬라이드의 모든 개체가 목록으로 표시되며, 목록의 위쪽에 있는 개체일수록 앞에 놓인 개체이다. 다른 개체에 완전히 가려져 누를 수 없는 개체는 이 목록에서 이름을 눌러 선택한다.

따라 하기

2절의 따라 하기에서 작성한 직사각형 3개를 정렬하고, 화살표로 이은 뒤 그룹으로 묶는다.

(1) 맞춤과 배분

  1. 연습용 프레젠테이션의 1번 슬라이드에서 세 도형의 높이가 서로 어긋나 있도록 둘째 도형을 조금 아래로 끈다.
  2. 슬라이드의 빈 곳에서 끌어 세 도형을 둘러싸 선택한다. 제목 개체 틀과 글상자가 함께 선택되지 않도록 한다.
  3. [도형 서식] 탭 → [정렬] 그룹 → [맞춤]을 눌러 기준이 [선택한 개체 맞춤]인지 확인한다.
  4. [중간 맞춤]을 실행한다.
  5. 선택을 유지한 채 [맞춤] → [가로 간격을 동일하게]를 실행한다.
  6. 두 명령을 한 번씩 더 실행하여 도형이 움직이지 않는지 확인한다.
  • 확인 7 세 도형의 세로 위치가 같고 도형 사이의 두 간격이 같다. 명령을 다시 실행하여도 도형이 움직이지 않았다.

(2) 방향과 기준의 확인

  1. 세 도형이 선택된 상태에서 [맞춤] → [가운데 맞춤]을 실행한다. 세 도형이 한 위치에 겹치는지 확인한 뒤 Ctrl + Z로 되돌린다.
  2. [맞춤] → [슬라이드에 맞춤]을 선택하여 기준을 변경한다.
  3. [맞춤] → [가로 간격을 동일하게]를 실행한다. 양 끝의 도형이 슬라이드의 양쪽 가장자리로 이동하는지 확인한 뒤 Ctrl + Z로 되돌린다.
  4. [맞춤] → [선택한 개체 맞춤]을 선택하여 기준을 되돌린다.
  • 확인 8 [가운데 맞춤]에서는 도형이 겹치고, 기준이 [슬라이드에 맞춤]인 상태의 배분에서는 도형이 슬라이드의 양 끝까지 벌어졌다. 되돌린 뒤 도형의 배치가 확인 7의 상태와 같고 기준이 [선택한 개체 맞춤]이다.

(3) 화살표의 연결

  1. [삽입] 탭 → [일러스트레이션] 그룹 → [도형]에서 [선] 범주의 화살표를 선택한다.
  2. 마우스를 첫째 도형 위로 가져가 연결점이 표시되면, 오른쪽 변의 연결점에서 둘째 도형의 왼쪽 변의 연결점까지 끈다.
  3. 같은 방법으로 둘째 도형과 셋째 도형을 잇는 화살표를 그린다.
  4. Shift를 누른 채 화살표 2개를 눌러 선택하고 [도형 윤곽선]에서 색을 [검정, 텍스트 1], 두께를 2¼pt로 지정한다.
  5. 둘째 도형의 테두리를 끌어 아래로 이동한다. 화살표 2개의 끝이 도형을 따라오는지 확인한 뒤 Ctrl + Z로 되돌린다.
  • 확인 9 수평의 화살표 2개가 입력에서 계산으로, 계산에서 출력으로 향한다. 도형을 이동하였을 때 화살표의 끝이 함께 이동하였다.

(4) 그룹

  1. 슬라이드의 빈 곳에서 끌어 도형 3개와 화살표 2개를 선택한다.
  2. Ctrl + G를 눌러 그룹으로 묶는다.
  3. 그룹이 선택된 상태에서 [맞춤] → [가운데 맞춤]을 실행한다. 선택한 개체가 하나이므로 그룹이 슬라이드의 가로 가운데에 놓인다.
  4. 그룹 안의 계산 도형을 한 번 더 눌러 선택하고 [도형 채우기]에서 다른 밝은 색을 지정한다. 그룹을 해제하지 않아도 도형 하나의 서식이 변경되는지 확인한다.
  5. 그룹의 테두리를 눌러 그룹 전체를 선택하고 Ctrl + Shift + G를 눌러 그룹을 해제한다. 개체 5개가 낱개로 선택되는지 확인한 뒤, 그 상태에서 Ctrl + G를 눌러 다시 묶는다.
  • 확인 10 도형 하나를 한 번 누르면 도형 3개와 화살표 2개를 둘러싼 하나의 테두리가 표시되고, 그룹이 슬라이드의 가로 가운데에 놓여 있다.

(5) 순서

  1. 직사각형을 하나 더 그려 그룹 전체를 덮는다. 흐름도가 가려진다.
  2. 이 직사각형의 [도형 채우기]를 밝은 회색 계열의 색으로, [도형 윤곽선]을 [윤곽선 없음]으로 지정한다.
  3. [도형 서식] 탭 → [정렬] 그룹 → [뒤로 보내기]의 화살표를 누르고 [맨 뒤로 보내기]를 선택한다.
  4. [홈] 탭 → [편집] 그룹 → [선택] → [선택 창]을 열어 방금 그린 직사각형이 목록의 맨 아래에 있는지 확인하고 창을 닫는다.
  5. Ctrl + S로 저장한다.
  • 확인 11 회색 직사각형의 위에 흐름도가 표시되고, 선택 창의 목록에서 회색 직사각형이 맨 아래에 있다.

4. 엑셀 자료의 삽입

4-1. 복사와 붙여넣기

엑셀에서 범위나 차트를 선택하여 Ctrl + C로 복사하고, 파워포인트의 슬라이드에서 Ctrl + V로 붙여 넣는다. 붙여 넣은 직후 개체의 오른쪽 아래에 [붙여넣기 옵션] 단추가 표시되며, 이 단추에서 붙여 넣는 형태를 선택한다. [홈] 탭 → [클립보드] 그룹 → [붙여넣기]의 화살표를 눌러 붙여 넣기 전에 형태를 선택할 수도 있다. 옵션의 그림 위에 마우스를 올리면 옵션의 이름이 표시된다.

붙여 넣기 전에 슬라이드의 빈 곳을 한 번 눌러 개체 틀의 선택을 해제한다. 제목 개체 틀 안에 커서가 있는 상태에서 붙여 넣으면 표의 내용이 제목의 문자로 들어간다.

그림 필요: 표를 붙여 넣은 직후 표의 오른쪽 아래에 표시되는 [붙여넣기 옵션] 단추와 단추를 눌렀을 때 나열되는 옵션

4-2. 표의 붙여넣기 옵션

엑셀에서 복사한 셀 범위를 붙여 넣을 때의 옵션은 다음과 같다. 다섯 옵션은 모두 복사한 시점의 내용을 프레젠테이션 안에 넣는 방식이며, 엑셀 파일과 연결되지 않는다.

옵션 붙여 넣은 결과 슬라이드에서의 편집
대상 스타일 사용 파워포인트의 표. 프레젠테이션의 서식이 적용된다 셀의 문자와 서식을 수정할 수 있다
원본 서식 유지 파워포인트의 표. 엑셀에서의 서식이 유지된다 셀의 문자와 서식을 수정할 수 있다
포함 엑셀의 워크시트가 개체로 삽입된다 두 번 누르면 엑셀의 편집 화면이 열린다. 수정한 내용은 프레젠테이션 안의 사본에만 반영된다
그림 표의 모양이 그림으로 삽입된다 크기와 위치만 변경할 수 있다. 문자를 수정할 수 없다
텍스트만 유지 표의 형태가 없는 문자로 삽입된다 문자를 수정할 수 있다. 열의 구분이 사라진다

피벗 테이블의 범위를 복사하여 [원본 서식 유지]로 붙여 넣으면 값과 서식만 전달된다. 슬라이드의 표는 피벗 테이블이 아니며, 새로 고침이나 필드의 변경과 같은 피벗 테이블의 기능은 전달되지 않는다.

4-3. 차트의 붙여넣기 옵션

엑셀의 차트를 붙여 넣을 때의 옵션은 차트의 자료를 어디에 두는가에 따라 세 부류로 나뉜다.

옵션 붙여 넣은 결과 슬라이드에서의 편집 엑셀 파일과의 연결
대상 테마 사용 및 통합 문서 포함 차트. 서식이 프레젠테이션에 맞추어 변경된다 차트의 요소와 자료를 수정할 수 있다 연결되지 않는다. 자료의 사본이 프레젠테이션 파일 안에 저장된다
원본 서식 유지 및 통합 문서 포함 차트. 엑셀에서의 서식이 유지된다 위와 같다 위와 같다
대상 테마 사용 및 데이터 연결 차트. 서식이 프레젠테이션에 맞추어 변경된다 차트의 요소를 수정할 수 있다. 자료는 엑셀 파일에 있다 연결된다. 엑셀의 값이 변경되면 차트에 반영된다
원본 서식 유지 및 데이터 연결 차트. 엑셀에서의 서식이 유지된다 위와 같다 위와 같다
그림 차트의 모양이 그림으로 삽입된다 크기와 위치만 변경할 수 있다 연결되지 않는다

연결된 차트는 엑셀 파일의 위치나 이름이 변경되면 연결이 끊어진다. 또한 프레젠테이션 파일만 전달받은 사람은 차트의 자료를 갱신할 수 없다. 옵션을 선택하지 않고 Ctrl + V만 누르면 연결되는 형태로 붙여지는 경우가 있으므로, 차트를 붙여 넣은 뒤에는 옵션을 반드시 지정한다.

버전에 따른 차이: 데이터 연결에 해당하는 두 옵션의 이름은 버전과 문서에 따라 표기가 다르다. Microsoft의 지원 문서(한국어판)에는 [대상 테마 & 데이터 연결 사용], [데이터 연결 & 원본 서식 유지]로 표기되어 있다. 옵션의 그림 위에 마우스를 올려 표시되는 이름을 확인하고 선택한다.

4-4. 붙여넣기 옵션의 선택 기준

옵션은 두 가지 질문으로 선택한다. 첫째는 슬라이드에서 내용을 수정하여야 하는가이고, 둘째는 프레젠테이션 파일이 엑셀 파일 없이도 같은 내용을 표시하여야 하는가이다.

대상 본 과목에서의 선택 이유
표 [원본 서식 유지] 머리글(“행 레이블”, “합계 : 금액”)을 “거래처”, “금액(원)”으로 수정하고 글꼴 크기를 변경하여야 하므로 편집할 수 있는 표이어야 한다. 엑셀에서 지정한 표시 형식(쉼표)과 테두리가 유지된다
차트 [그림] 차트의 제목과 축 제목은 5장에서 이미 완성하였으므로 슬라이드에서 수정할 내용이 없다. 그림은 보고 시점의 모양이 고정되며, 프레젠테이션 파일 하나만 제출하여도 동일하게 표시된다

본 과목에서는 데이터 연결을 사용하지 않는다. 제출물이 프레젠테이션 파일과 PDF이고, 채점하는 사람의 PC에는 수강생의 엑셀 파일이 없기 때문이다.

4-5. 원본과의 관계

슬라이드에 붙여 넣은 표와 그림은 복사한 시점의 사본이다. 엑셀의 값이 변경되어도 슬라이드의 표는 자동으로 변하지 않는다.

대상 원본의 값을 변경하였을 때
엑셀의 수식(3~4장) 즉시 다시 계산된다
엑셀의 피벗 테이블(6장) 새로 고침을 실행하면 반영된다. [자동 새로 고침]이 켜져 있는 버전에서는 곧바로 반영된다(6장 「피벗 테이블」의 4절)
슬라이드에 붙여 넣은 표와 그림 반영되지 않는다. 엑셀에서 다시 복사하여 붙여 넣어야 한다
슬라이드의 요약 문장 반영되지 않는다. 사람이 입력한 문자이므로 어떤 붙여넣기 옵션을 사용하여도 자동으로 변하지 않는다

붙여 넣은 뒤에 엑셀의 값이 변경된 경우에는 다음의 순서로 처리한다.

  1. 엑셀에서 수정을 마치고 피벗 테이블을 새로 고친 뒤 총합계를 확인한다.
  2. 슬라이드의 표를 삭제하고 엑셀에서 다시 복사하여 붙여 넣는다. 머리글의 수정과 글꼴 크기의 지정을 다시 수행한다.
  3. 차트의 그림을 삭제하고 엑셀에서 차트를 다시 복사하여 붙여 넣는다.
  4. 요약 문장의 수치를 새 값으로 수정한다.
  5. 4-6의 검산을 다시 수행한다.

같은 작업을 반복하지 않으려면 엑셀에서의 작업과 검증을 모두 마친 뒤에 슬라이드에 붙여 넣는다.

4-6. 수치의 검산

슬라이드의 수치는 엑셀의 값과 대조하여 검산한다. 검산은 다음의 네 가지이다.

검산 방법 발견되는 오류
행별 대조 슬라이드의 표와 엑셀의 “피벗” 시트를 나란히 놓고 한 행씩 값을 대조한다 새로 고치지 않은 피벗 테이블을 복사한 경우, 다른 범위를 복사한 경우
합의 검산 엑셀에서 거래처 5개의 금액 셀을 선택하여 상태 표시줄의 합계를 읽고, 슬라이드의 총합계와 대조한다 총합계 행이 누락되었거나 거래처가 누락된 경우
문장과 표의 대조 요약 문장의 수치를 슬라이드의 표에서 찾아 자릿수까지 대조한다 수치를 직접 입력하면서 발생한 오타, 쉼표의 위치 오류
판단의 대조 “금액이 가장 큰 거래처”와 같은 판단을 표의 다섯 값을 비교하여 다시 확인한다 첫 행이나 마지막 행의 거래처를 가장 큰 거래처로 잘못 기재한 경우

피벗 테이블의 행은 거래처의 이름 순으로 나열되므로 금액이 가장 큰 거래처가 첫 행에 있지 않다. 1월 자료에서 가장 큰 거래처는 마지막 행의 한빛상사이고, 2월 자료에서는 첫 행의 대한사무기이다.

따라 하기

연습용 통합 문서(2월 자료)의 표와 차트를 연습용 프레젠테이션의 2번 슬라이드에 삽입한다.

(1) 엑셀 자료의 확인

  1. 엑셀에서 컴퓨터활용\실습\판매연습_06_학번.xlsx를 연다.
  2. “피벗” 시트에서 피벗 테이블 안의 셀을 선택하고 [피벗 테이블 분석] 탭 → [데이터] 그룹 → [새로 고침]을 실행한다.
  3. 총합계가 8,016,000인지 확인한다.
  4. 거래처 5개의 금액 셀(6장의 따라 하기와 같이 작성하였다면 B4:B8)을 선택하고 상태 표시줄의 합계를 읽는다.
  • 확인 12 피벗 테이블의 총합계가 8,016,000이고, 거래처 5개의 금액을 선택하였을 때 상태 표시줄의 합계도 8,016,000이다.

(2) 표의 붙여넣기

  1. 피벗 테이블의 머리글 행부터 총합계 행까지의 범위(A3:B9)를 끌어 선택하고 Ctrl + C를 누른다.
  2. 파워포인트의 연습용 프레젠테이션에서 2번 슬라이드(“2월 판매 현황”)를 선택한다.
  3. 슬라이드의 빈 곳을 한 번 누른 뒤 Ctrl + V를 누른다.
  4. [붙여넣기 옵션] 단추를 누르고 [원본 서식 유지]를 선택한다.
  5. 표의 테두리를 눌러 표 전체를 선택하고 글꼴 크기를 18로 지정한다.
  6. 표의 첫 행에서 “행 레이블”을 거래처로, “합계 : 금액”을 금액(원)으로 수정한다.
  7. 거래처나 금액이 두 줄로 나뉘어 표시되면 표의 열 경계선을 오른쪽으로 끌어 한 줄에 표시될 때까지 넓힌다. 붙여 넣은 표는 엑셀의 열 너비를 그대로 가져오므로 글꼴을 키우면 문자가 열에 들어가지 않는다.
  8. 표의 테두리를 끌어 슬라이드의 왼쪽 절반에 놓는다.
  • 확인 13 슬라이드에 7행 2열의 표가 있다. 머리글이 거래처, 금액(원)이고 대한사무기가 2,118,000, 총합계가 8,016,000이다. 셀을 누르면 커서가 표시되어 문자를 수정할 수 있다.

(3) 옵션의 비교

  1. 슬라이드의 빈 곳을 누르고 Ctrl + V를 한 번 더 누른다.
  2. [붙여넣기 옵션] 단추를 누르고 [그림]을 선택한다.
  3. 붙여진 그림 안의 숫자를 눌러 본다. 커서가 표시되지 않고 그림 전체가 선택되며, 리본 메뉴에 [그림 서식] 탭이 나타나는지 확인한다.
  4. 그림이 선택된 상태에서 Delete를 눌러 삭제한다.
  • 확인 14 그림으로 붙여 넣은 표는 문자를 수정할 수 없었다. 그림을 삭제한 뒤 슬라이드에 표가 하나만 있다.

(4) 차트의 붙여넣기

  1. 엑셀의 “토너” 시트에서 차트(“토너 거래처별 판매 금액”)의 테두리를 눌러 차트를 선택하고 Ctrl + C를 누른다.
  2. 파워포인트의 2번 슬라이드에서 빈 곳을 한 번 누른 뒤 Ctrl + V를 누른다.
  3. [붙여넣기 옵션] 단추를 누르고 [그림]을 선택한다.
  4. 그림의 모서리에 있는 크기 조정 핸들을 끌어 크기를 조정하고 슬라이드의 오른쪽 절반에 놓는다.
  5. Shift를 누른 채 표와 그림을 차례로 눌러 함께 선택하고 [홈] 탭 → [그리기] 그룹 → [정렬] → [맞춤] → [위쪽 맞춤]을 실행한다.
  • 확인 15 표의 오른쪽에 제목이 “토너 거래처별 판매 금액”이고 막대가 3개(한빛상사, 대한사무기, 서울오피스)인 차트의 그림이 있고, 표와 그림의 위쪽 변이 맞추어져 있으며 서로 겹치지 않는다.

(5) 요약 문장과 검산

  1. [삽입] 탭 → [텍스트] 그룹 → [텍스트 상자]를 누르고 표와 차트의 아래에서 가로로 끌어 글상자를 그린다.
  2. 다음 문장을 입력하고 글꼴 크기를 20으로 지정한다.
2월 판매 금액은 8,016,000원이며, 금액이 가장 큰 거래처는 대한사무기(2,118,000원)이다.
  1. 문장의 8,016,000을 표의 총합계와, 2,118,000을 표의 대한사무기의 값과 대조한다.
  2. 표의 다섯 값을 비교하여 2,118,000이 가장 큰 값인지 확인한다.
  3. Ctrl + S로 저장한다.
  • 확인 16 요약 문장의 두 수치가 표의 값과 자릿수까지 일치하고, 표의 다섯 거래처 가운데 대한사무기의 금액이 가장 크다.

(6) 원본을 변경한 경우의 확인

  1. 엑셀의 “판매내역” 시트에서 E4(판매번호 1021의 수량)를 33에서 34로 변경한다. G4가 792,000에서 816,000으로 즉시 변하는지 확인한다.
  2. “피벗” 시트에서 [새로 고침]을 실행한다. 동아문구가 920,000, 총합계가 8,040,000으로 변하는지 확인한다.
  3. 파워포인트의 2번 슬라이드를 확인한다. 표의 동아문구와 총합계가 변하였는지 살핀다.
  4. 엑셀의 “판매내역” 시트에서 E4를 33으로 되돌리고 “피벗” 시트에서 [새로 고침]을 실행한다.
  5. 총합계가 8,016,000인지 확인하고 엑셀 파일을 저장한다.
  • 확인 17 엑셀의 총합계가 8,040,000으로 변한 동안에도 슬라이드의 표는 동아문구 896,000, 총합계 8,016,000으로 남아 있었다. 원본을 되돌린 뒤 엑셀의 총합계가 8,016,000이다.

5. 유인물 인쇄와 PDF 저장

5-1. 인쇄 형태

파워포인트의 인쇄 형태는 한 쪽에 슬라이드 하나를 출력하는 전체 페이지 슬라이드와 한 쪽에 여러 슬라이드를 축소하여 출력하는 유인물로 구분된다. 기본값은 전체 페이지 슬라이드이다. [파일] 탭 → [인쇄]의 [설정]에서 [전체 페이지 슬라이드]를 누르면 인쇄 형태의 목록이 열리며, [유인물]에서 한 쪽에 넣을 슬라이드의 수를 선택한다.

유인물의 형태 한 쪽의 구성 용도
2슬라이드 세로 방향의 용지에 슬라이드 2매가 위아래로 놓인다 슬라이드의 문자를 읽을 수 있는 크기로 출력한다. 본 장에서 사용한다
3슬라이드 슬라이드 3매의 옆에 필기용 줄이 함께 인쇄된다 청중이 내용을 받아 적는 배포 자료
4슬라이드 이상 슬라이드가 두 줄 이상으로 놓인다 전체의 구성을 한눈에 확인한다. 슬라이드가 작아지므로 표의 수치는 읽기 어렵다

인쇄 화면의 오른쪽에는 미리 보기가 표시된다. 형태를 변경하면 미리 보기와 쪽 수가 즉시 달라지므로, 출력하기 전에 쪽 수가 의도와 같은지 확인한다. 슬라이드가 2매일 때 전체 페이지 슬라이드는 2쪽, 2슬라이드의 유인물은 1쪽이다.

그림 필요: [파일] 탭 → [인쇄] 화면의 [설정]에서 [전체 페이지 슬라이드]를 눌러 연 목록의 [유인물] 영역과, [2슬라이드]를 선택하였을 때의 미리 보기

5-2. PDF 저장의 두 가지 방법

프레젠테이션을 PDF로 저장하는 방법은 두 가지이며 결과가 다르다.

방법 경로 결과
인쇄에 의한 저장 [파일] 탭 → [인쇄]에서 프린터를 [Microsoft Print to PDF]로 지정하고 [인쇄]를 누른다. 저장 위치와 파일 이름을 묻는 대화 상자가 열린다 인쇄 설정에서 선택한 형태 그대로 저장된다. 유인물을 선택하였으면 유인물의 형태로 저장된다
내보내기에 의한 저장 [파일] 탭 → [내보내기] → [PDF/XPS 만들기]를 누르고 파일 이름을 지정한 뒤 [게시]를 누른다 별도로 지정하지 않으면 슬라이드 하나가 한 쪽이 된다. 출력 형태는 대화 상자의 [옵션]에서 변경한다

본 장의 출력물은 한 쪽에 슬라이드 2매가 있는 유인물이므로 인쇄에 의한 저장을 사용한다. 2장 「셀 서식과 인쇄 설정」에서와 같이, 출력한 뒤에는 PDF 파일을 열어 쪽 수를 확인한다.

따라 하기

연습용 프레젠테이션을 두 가지 방법으로 PDF로 저장하고 쪽 수를 비교한다.

(1) 유인물의 형태로 저장

  1. 연습용 프레젠테이션에서 Ctrl + S로 저장한 뒤 [파일] 탭 → [인쇄]를 선택한다.
  2. 프린터를 [Microsoft Print to PDF]로 지정한다.
  3. [설정]의 [전체 페이지 슬라이드]를 누르고 [유인물]의 [2슬라이드]를 선택한다.
  4. 미리 보기에서 한 쪽에 슬라이드 2매가 위아래로 표시되고 쪽 수가 1인지 확인한다.
  5. [인쇄]를 누르고 저장 위치를 컴퓨터활용\출력 폴더로, 파일 이름을 연습_07_학번으로 지정하여 저장한다.
  • 확인 18 출력 폴더의 연습_07_학번.pdf를 열었을 때 1쪽에 슬라이드 2매가 있고, 표의 총합계 8,016,000을 읽을 수 있다.

(2) 내보내기에 의한 저장과의 비교

  1. [파일] 탭 → [내보내기] → [PDF/XPS 만들기]를 누른다.
  2. 저장 위치를 컴퓨터활용\출력 폴더로, 파일 이름을 연습_07_학번_슬라이드로 지정하고 [게시]를 누른다.
  3. 저장된 PDF를 열어 쪽 수를 확인한다.
  • 확인 19 연습_07_학번_슬라이드.pdf는 2쪽이고 한 쪽에 슬라이드가 하나씩 있다.

6. 핵심 실습: 판매 현황 보고 슬라이드의 작성

슬라이드 2매를 작성한다. 1매는 도형으로 작성한 판매 업무 흐름도이고, 2매는 엑셀의 표와 차트를 삽입한 1월 판매 현황의 요약이다. 핵심 실습은 1월 자료로 작성한 판매현황_06_학번.xlsx를 사용한다. 연습용 통합 문서와 연습용 프레젠테이션은 닫고 시작한다.

절차

단계 1. 파일의 준비

  1. 파워포인트를 실행하고 [새 프레젠테이션]을 선택한다.
  2. [파일] 탭 → [다른 이름으로 저장]에서 컴퓨터활용\실습 폴더에 판매보고_07_학번.pptx로 저장한다.
  3. 엑셀에서 컴퓨터활용\실습\판매현황_06_학번.xlsx를 연다. “피벗” 시트의 피벗 테이블 안의 셀을 선택하고 [피벗 테이블 분석] 탭 → [데이터] 그룹 → [새로 고침]을 실행한 뒤, 총합계가 6,479,000인지 확인한다.
  • 확인 20 파워포인트의 제목 표시줄에 판매보고_07_학번.pptx가 표시되고, 엑셀의 “피벗” 시트의 총합계가 6,479,000이다.

단계 2. 1매: 제목과 첫 도형

  1. 파워포인트에서 첫 슬라이드를 선택하고 [홈] 탭 → [슬라이드] 그룹 → [레이아웃] → [제목만]을 선택한다.
  2. 제목 개체 틀을 누르고 판매 업무 흐름을 입력한다.
  3. [삽입] 탭 → [일러스트레이션] 그룹 → [도형]에서 [사각형] 범주의 [직사각형]을 선택하고 슬라이드의 빈 곳에서 끌어 그린다.
  4. [도형 서식] 탭 → [크기] 그룹에서 높이를 2.5cm, 너비를 4.5cm로 지정한다.
  5. 도형이 선택된 상태에서 주문 접수를 입력한다.
  6. 도형의 테두리를 눌러 도형을 선택하고 다음의 서식을 지정한다.
서식 지정하는 값
도형 채우기 테마 색에서 밝은 계열의 색 하나
도형 윤곽선 색은 [검정, 텍스트 1], 두께는 1½pt
글꼴 색 [검정, 텍스트 1]
글꼴 크기 18
  • 확인 21 1매의 제목이 판매 업무 흐름이고, 높이 2.5cm, 너비 4.5cm의 직사각형에 검정색의 주문 접수가 표시되었다.

단계 3. 1매: 도형의 복제와 정렬

  1. 도형이 선택된 상태에서 Ctrl + D를 네 번 눌러 도형을 5개로 만든다.
  2. 다섯 도형을 끌어 왼쪽에서 오른쪽으로 나열한다. 첫째 도형은 슬라이드의 왼쪽 가장자리 가까이, 다섯째 도형은 오른쪽 가장자리 가까이에 놓는다. 높이와 간격은 맞추지 않아도 된다.
  3. 둘째부터 다섯째 도형의 문자를 왼쪽부터 재고 확인, 출고, 대금 청구, 입금 확인으로 수정한다.
  4. 슬라이드의 빈 곳에서 끌어 다섯 도형을 둘러싸 모두 선택한다. 제목 개체 틀이 함께 선택되지 않도록 한다.
  5. [도형 서식] 탭 → [정렬] 그룹 → [맞춤] → [중간 맞춤]을 실행한다. 다섯 도형의 세로 위치가 맞추어진다.
  6. 선택을 유지한 채 [맞춤] → [가로 간격을 동일하게]를 실행한다. 도형 사이의 간격이 같아진다.
  7. 선택을 유지한 채 5와 6의 명령을 한 번씩 더 실행하여 도형이 움직이지 않는지 확인한다. 움직이지 않으면 정렬된 상태이다.
  • 확인 22 직사각형 5개의 문자가 왼쪽부터 주문 접수, 재고 확인, 출고, 대금 청구, 입금 확인이고, 두 명령을 다시 실행하여도 도형이 움직이지 않았다.

단계 4. 1매: 화살표, 그룹, 순서

  1. [삽입] 탭 → [일러스트레이션] 그룹 → [도형]에서 [선] 범주의 화살표를 선택한다.
  2. 마우스를 첫째 도형 위로 가져가 연결점이 표시되면, 오른쪽 변의 연결점에서 둘째 도형의 왼쪽 변의 연결점까지 끈다.
  3. 같은 방법으로 둘째와 셋째, 셋째와 넷째, 넷째와 다섯째 도형을 잇는 화살표를 그린다. 화살표는 모두 4개이다.
  4. Shift를 누른 채 화살표 4개를 차례로 눌러 선택하고 [도형 서식] 탭 → [도형 스타일] 그룹 → [도형 윤곽선]에서 색을 [검정, 텍스트 1], 두께를 2¼pt로 지정한다.
  5. 슬라이드의 빈 곳에서 끌어 도형 5개와 화살표 4개를 모두 선택하고 Ctrl + G를 눌러 그룹으로 묶는다.
  6. 그룹이 선택된 상태에서 [맞춤] → [가운데 맞춤]을 실행한다. 선택한 개체가 하나이므로 슬라이드를 기준으로 맞추어져 흐름도가 슬라이드의 가로 가운데에 놓인다.
  7. 직사각형을 하나 더 그려 흐름도 전체를 덮는다. 나중에 작성한 도형이 위에 놓이므로 흐름도가 가려진다.
  8. 이 직사각형의 [도형 채우기]를 밝은 회색 계열의 색으로, [도형 윤곽선]을 [윤곽선 없음]으로 지정한다.
  9. [도형 서식] 탭 → [정렬] 그룹 → [뒤로 보내기]의 화살표를 누르고 [맨 뒤로 보내기]를 선택한다. 흐름도가 직사각형의 위에 다시 표시된다.
  • 확인 23 흐름도의 도형 하나를 한 번 누르면 도형 5개와 화살표 4개를 둘러싼 하나의 테두리가 표시되고, 회색 직사각형의 위에 흐름도가 표시되었다.

단계 5. 2매: 표의 삽입

  1. [홈] 탭 → [슬라이드] 그룹 → [새 슬라이드]의 화살표를 누르고 [제목만]을 선택한다.
  2. 제목 개체 틀에 2026년 1월 판매 현황을 입력한다.
  3. 엑셀의 “피벗” 시트에서 A3:B9를 끌어 선택하고 Ctrl + C를 누른다.
  4. 파워포인트의 2매에서 슬라이드의 빈 곳을 한 번 누른 뒤 Ctrl + V를 누른다.
  5. 붙여 넣은 표의 오른쪽 아래에 표시된 [붙여넣기 옵션] 단추를 누르고 [원본 서식 유지]를 선택한다.
  6. 표의 테두리를 눌러 표 전체를 선택하고 [홈] 탭 → [글꼴] 그룹에서 글꼴 크기를 18로 지정한다.
  7. 표의 첫 행에서 “행 레이블”을 거래처로, “합계 : 금액”을 금액(원)으로 수정한다.
  8. 금액 열의 셀을 끌어 선택하고 [홈] 탭 → [단락] 그룹 → [오른쪽 맞춤]을 누른다.
  9. 거래처나 금액이 두 줄로 나뉘어 표시되면 열 경계선을 오른쪽으로 끌어 모든 문자가 한 줄에 표시될 때까지 넓힌다. 열 하나의 너비는 4~5cm가 적당하다.
  10. 표의 테두리를 끌어 슬라이드의 왼쪽 절반에 놓는다.
  • 확인 24 2매의 제목이 2026년 1월 판매 현황이고, 7행 2열의 표에 머리글 거래처, 금액(원)과 총합계 6,479,000이 표시되었다.

단계 6. 2매: 차트의 삽입과 요약 문장

  1. 엑셀의 “한빛상사” 시트에서 차트의 테두리를 눌러 차트를 선택하고 Ctrl + C를 누른다.
  2. 파워포인트의 2매에서 슬라이드의 빈 곳을 한 번 누른 뒤 Ctrl + V를 누른다.
  3. [붙여넣기 옵션] 단추를 누르고 [그림]을 선택한다.
  4. 그림의 모서리에 있는 크기 조정 핸들을 끌어 크기를 조정하고 슬라이드의 오른쪽 절반에 놓는다. 표와 겹치지 않아야 한다.
  5. Shift를 누른 채 표와 그림을 차례로 눌러 함께 선택하고 [홈] 탭 → [그리기] 그룹 → [정렬] → [맞춤] → [위쪽 맞춤]을 실행한다.
  6. [삽입] 탭 → [텍스트] 그룹 → [텍스트 상자]를 누르고 표와 차트의 아래에서 가로로 끌어 글상자를 그린다.
  7. 글상자에 다음 문장을 입력하고 글꼴 크기를 20으로 지정한다.
1월 판매 금액은 6,479,000원이며, 금액이 가장 큰 거래처는 한빛상사(1,756,000원)이다.
  • 확인 25 2매에 표, 막대가 5개인 “한빛상사 품목별 판매 금액” 차트의 그림, 요약 문장의 글상자가 서로 겹치지 않게 놓여 있다.

단계 7. 수치의 대조

  1. 슬라이드의 표에 있는 6개의 값을 엑셀의 “피벗” 시트와 행별로 대조한다.
  2. 엑셀의 “피벗” 시트에서 B4:B8을 선택하여 상태 표시줄의 합계가 슬라이드의 총합계와 같은지 확인한다.
  3. 요약 문장의 6,479,000이 표의 총합계와, 1,756,000이 표의 한빛상사의 값과 일치하는지 확인한다.
  4. 표의 다섯 거래처 가운데 한빛상사의 금액이 가장 큰지 확인한다.
  • 확인 26 슬라이드의 표의 6개 값이 엑셀의 피벗 테이블과 일치하고, 요약 문장의 두 수치가 표의 값과 자릿수까지 일치하였다.

단계 8. 유인물 인쇄와 저장

  1. Ctrl + S로 저장한다.
  2. [파일] 탭 → [인쇄]에서 프린터를 [Microsoft Print to PDF]로 지정한다.
  3. [설정]의 [전체 페이지 슬라이드]를 누르고 [유인물]의 [2슬라이드]를 선택한다. 미리 보기에서 한 쪽에 슬라이드 2매가 위아래로 표시되는지 확인한다.

빈번한 오류와 해결

증상 원인 해결
도형에 입력한 문자가 보이지 않는다 채우기 색을 밝은 색으로 변경하였으나 글꼴 색이 흰색으로 남아 있다 도형의 테두리를 눌러 선택하고 글꼴 색을 [검정, 텍스트 1]로 지정한다
서식이 도형의 일부 문자에만 적용된다 도형의 안쪽을 눌러 문자를 편집하는 상태에서 서식을 지정하였다 도형의 테두리를 눌러 도형 자체를 선택한 뒤 다시 지정한다
붙여 넣은 표에서 “대한사무기”, “1,272,000”이 두 줄로 나뉜다 붙여 넣은 표가 엑셀의 열 너비를 그대로 가져왔고, 글꼴을 18로 키워 문자가 열에 들어가지 않는다 표의 열 경계선을 끌어 열을 넓힌다(실습 PC의 Microsoft 365에서 확인하였다)
도형 안의 문자가 도형의 밖으로 넘친다 문자의 양에 비하여 도형이 좁다. 도형은 문자에 맞추어 커지지 않는다 도형의 너비를 수치로 늘리거나 글꼴 크기를 줄인다. 글꼴 크기는 18보다 작게 하지 않는다
다섯 도형이 한 위치에 겹쳤다 [중간 맞춤]이 아닌 [가운데 맞춤]을 실행하였다 Ctrl + Z로 되돌리고 [중간 맞춤]을 실행한다
[가로 간격을 동일하게]를 실행하자 도형이 슬라이드의 양 끝까지 벌어졌다 맞춤의 기준이 [슬라이드에 맞춤]으로 지정되어 있다 Ctrl + Z로 되돌리고 [맞춤] 메뉴에서 [선택한 개체 맞춤]을 선택한 뒤 다시 실행한다
[가로 간격을 동일하게]가 실행되지 않거나 실행하여도 변화가 없다 도형이 2개 이하로 선택되어 있다 다섯 도형을 모두 선택한 뒤 다시 실행한다
도형을 이동하면 화살표가 따라오지 않는다 화살표의 끝이 연결점에 붙지 않았다 화살표의 끝점을 도형의 연결점까지 끌어 붙인다
[그룹] 명령을 사용할 수 없다 개체가 하나만 선택되었거나 제목 개체 틀 또는 표가 함께 선택되었다. 개체 틀과 표는 그룹으로 묶을 수 없다 도형 5개와 화살표 4개만 다시 선택한다
흐름도가 회색 직사각형에 가려져 있다 직사각형의 순서를 변경하지 않았다 직사각형을 선택하고 [맨 뒤로 보내기]를 실행한다
회색 직사각형의 뒤에 있는 개체를 누를 수 없다 순서를 잘못 변경하여 개체가 가려졌다 [선택 창]의 목록에서 개체의 이름을 눌러 선택하고 [맨 앞으로 가져오기]를 실행한다
표의 내용이 제목의 자리에 문자로 들어갔다 제목 개체 틀 안에 커서가 있는 상태에서 붙여 넣었다 Ctrl + Z로 되돌리고 슬라이드의 빈 곳을 누른 뒤 다시 붙여 넣는다
[붙여넣기 옵션] 단추가 사라졌다 붙여 넣은 뒤 다른 조작을 수행하였다 붙여 넣은 개체를 삭제하고 [홈] 탭 → [클립보드] 그룹 → [붙여넣기]의 화살표에서 옵션을 선택하여 다시 붙여 넣는다
붙여 넣은 차트를 누르면 [차트 디자인] 탭이 나타난다 옵션을 지정하지 않아 그림이 아닌 차트로 붙여졌다. 엑셀 파일과 연결되어 있을 수 있다 차트를 삭제하고 다시 붙여 넣은 뒤 [그림]을 선택한다
슬라이드의 총합계가 6,479,000이 아니다 엑셀의 원본이 변경된 상태이거나 피벗 테이블을 새로 고치지 않았다 엑셀에서 6장의 완료 기준을 다시 확인한 뒤 표를 다시 복사하여 붙여 넣는다
요약 문장의 수치가 표와 다르다 수치를 직접 입력하는 과정에서 오타가 발생하였다 표의 값을 보고 다시 입력한다
PDF가 2쪽이다 인쇄 형태가 [전체 페이지 슬라이드]인 상태로 출력하였거나 내보내기로 저장하였다 [파일] 탭 → [인쇄]에서 [유인물]의 [2슬라이드]를 선택한 뒤 다시 출력한다
화면 오른쪽에 디자인을 제안하는 작업 창이 열린다 그림을 삽입하면 자동으로 열리는 기능이다 작업 창을 닫는다. 제안된 디자인을 적용하지 않는다

심화 실습

핵심 실습을 완료한 수강생은 슬라이드 번호와 바닥글을 추가한다.

  1. [삽입] 탭 → [텍스트] 그룹 → [머리글/바닥글]을 누른다.
  2. 대화 상자의 [슬라이드] 탭에서 [슬라이드 번호]를 선택한다.
  3. [바닥글]을 선택하고 입력란에 본인의 학번과 이름을 입력한다.
  4. [모두 적용]을 누른다. [적용]을 누르면 현재의 슬라이드에만 적용된다.
  5. 두 슬라이드의 아래쪽에 학번과 이름, 슬라이드 번호가 표시되는지 확인한다.
  6. 출력물에 반영하려면 핵심 실습의 단계 8을 다시 수행하여 PDF를 같은 이름으로 저장한다.

그룹과 위치 도형 4개와 화살표 3개가 하나의 그룹이고, 그룹이 슬라이드의 가로 가운데에 있다
