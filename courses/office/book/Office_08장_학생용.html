파이썬 실행 환경과 엑셀 파일 읽기

2027학년도 「컴퓨터활용」의 준비 중인 교재입니다. 편집 상태를 검토하기 위해 미리 공개한 것으로, 수업 전에 내용과 순서가 바뀔 수 있습니다.

학사 10주차 · 교재 08 · 3부 파이썬

본 장부터 세 장에 걸쳐 파이썬을 다룬다. 3부의 목적은 파이썬의 문법을 습득하는 것이 아니라, 1부에서 엑셀로 수행한 작업을 코드로 수행하는 방법을 경험하고 두 방식의 차이를 이해하는 것이다. 본 장에서는 실행 환경의 사용법을 익히고, 판매 자료 파일을 읽어 3장 「수식과 셀 참조」와 4장 「기본 함수」에서 엑셀로 산출한 금액과 통계 값을 코드로 다시 산출한다. 코드의 결과는 4장의 수작업 결과와 대조하여 검증한다.

본 과목에서는 코드를 처음부터 작성하지 않는다. 주어진 코드를 실행하고, 지정된 부분을 채우거나 변경하여 다시 실행하고, 결과를 수작업 결과와 비교하는 방식으로 진행한다. 수업은 실습 노트북을 위에서부터 실행하며 진행하고, 본 강의안은 노트북의 각 절이 무엇을 하는지, 출력을 어떻게 읽는지, 엑셀의 어느 조작과 대응하는지를 설명한다. 강의안의 절 번호와 [확인 N]의 번호는 노트북과 일치한다.

노트북의 코드 셀은 세 종류이다. 첫 줄의 주석이 # [시연]인 셀은 교수가 1월 자료로 먼저 실행하여 보이는 셀이고, # [따라 하기]인 셀은 수강생이 2월 또는 3월 자료로 빈칸(____)을 채워 실행하는 셀이며, # [오류 확인]인 셀은 오류를 일부러 내어 오류 메시지를 읽는 연습을 하는 셀이다. 어느 셀이든 실행하기 전에 바로 위 설명의 예상을 읽고 결과를 짐작한 뒤 실행한다. 예상과 실제의 차이가 곧 배울 내용이다.

수업 시간의 범위. 150분 수업에서는 번호를 붙인 절의 설명과 따라 하기, 핵심 실습까지 한다. 심화 실습, 남은 연습 문제는 시간이 남을 때나 수업 뒤에 한다.

학습 목표

  1. 실습 사이트에 접속하여 노트북을 열고 셀을 실행할 수 있다.
    • 예시: 코드 셀을 Shift + Enter로 실행하고 실행 번호와 결과를 확인한다.
  2. 변수에 값을 저장하고 계산 결과를 출력할 수 있다.
    • 예시: 수량과 단가를 변수에 저장하여 금액을 계산하고 print로 출력한다.
  3. 주어진 코드를 실행하여 엑셀 파일을 표로 읽고 열의 계산으로 금액 열을 추가할 수 있다.
    • 예시: sales["금액"] = sales["수량"] * sales["단가"]가 수행하는 일을 엑셀의 수식과 대응하여 설명한다.
  4. 합계, 평균, 최댓값, 최솟값, 개수를 코드로 산출하여 수작업 결과와 대조할 수 있다.
    • 예시: 코드의 결과 6479000이 4장의 G25와 일치함을 확인한다.
  5. 코드 셀의 출력과 오류 메시지를 읽을 수 있다.
    • 예시: np.int64(6479000)에서 값을 읽고, KeyError: '수 량'에서 원인을 찾는다.

1-2. 파이썬의 이점과 한계

구분 엑셀 파이썬
계산 절차의 기록 수식은 셀마다 흩어져 있으며, 마우스로 수행한 조작(정렬, 서식 등)은 기록되지 않는다 계산 절차 전체가 코드로 기록된다
재실행 동일한 작업을 반복하려면 조작을 다시 수행하여야 한다 코드를 다시 실행하면 동일한 결과가 산출된다
결과의 확인 값을 변경하면 결과가 즉시 다시 계산되어 화면에 표시된다 코드를 실행하여야 결과가 표시된다
표의 편집 화면에서 직접 입력하고 서식을 지정한다 직접 입력과 서식 지정에는 적합하지 않다
자료의 크기 행이 수만 개를 넘으면 조작이 느려진다 행의 수가 증가하여도 코드는 변하지 않는다

파이썬은 엑셀을 대체하는 도구가 아니다. 자료를 입력하고 눈으로 확인하는 작업은 엑셀이 적합하며, 동일한 계산을 반복하거나 다수의 파일을 처리하는 작업은 파이썬이 적합하다. 9장 「데이터 집계의 자동화」와 10장 「다중 파일의 일괄 처리」에서 그러한 작업을 다룬다.

2. 실행 환경과 셀의 실행

2-1. 화면의 구성

JupyterLab은 웹 브라우저에서 파이썬 코드를 실행하는 환경이다. 프로그램을 설치할 필요가 없으며, 코드는 실습 사이트의 서버에서 실행된다. 따라서 엑셀 파일은 수강생의 PC가 아닌 서버에 있어야 한다. 수강생의 PC에 있는 파일은 서버로 올린 뒤에 코드로 읽을 수 있으며, 코드가 만든 결과 파일은 서버에 생성되므로 내려받아야 수강생의 PC에서 열 수 있다.

영역 위치 용도
파일 탐색기 화면의 왼쪽 서버에 있는 폴더와 파일의 목록. 파일을 올리고 내려받는다
노트북 화면의 가운데 설명과 코드가 셀 단위로 배열된 문서. 확장자는 .ipynb이다
메뉴 화면의 위쪽 [File], [Edit], [Run], [Kernel] 등
도구 모음 노트북의 위쪽 저장, 셀의 추가와 삭제, 실행, 셀 종류의 선택
커널 상태 노트북의 오른쪽 위 커널의 이름과 상태. 실행 중이면 원이 채워진 모양으로 바뀐다

메뉴가 한국어로 표시되는 환경에서는 대응하는 항목을 선택한다.

대상 저장되는 곳 사라지는 경우

변수에 저장된 값 커널의 기억 커널을 재시작하거나 실습 사이트에서 로그아웃한 경우

2-5. 출력 읽기

코드 셀의 출력은 엑셀의 셀 표시와 모양이 다르다. 2절의 셀들은 그 차이를 하나씩 보인다.

값만 표시된다. 30 * 24000을 실행하면 셀의 아래에 다음이 표시된다.

720000

엑셀의 ₩720,000에 있던 쉼표와 원화 기호는 표시 형식(2장)이 붙인 것이다. 코드의 출력에는 값만 나타나므로, 수작업 결과와 대조할 때에는 엑셀 쪽의 쉼표와 기호를 떼고 읽는다.

마지막 줄만 표시된다. 코드 셀의 줄은 모두 실행되지만 셀의 아래에는 마지막 줄의 결과만 표시된다. 노트북의 셋째 코드 셀은 30 * 24000과 50 * 6000의 두 줄이며 출력은 300000 하나이다. 중간의 값까지 보려면 print를 사용한다. print("판매번호 1001의 금액:", 30 * 24000)의 출력은 판매번호 1001의 금액: 720000이다. print는 쉼표로 구분한 값을 공백 하나를 사이에 두고 한 줄에 출력한다.

숫자 안의 쉼표는 다른 뜻이 된다. 엑셀에서는 24,000을 입력하여도 숫자로 인식되었으나(1장), 파이썬에서 쉼표는 값과 값을 구분하는 기호이다. 30 * 24,000의 출력은 다음과 같다.

(720, 0)

파이썬은 이 줄을 30 * 24와 000의 두 값으로 읽고 괄호로 묶어 표시하였다. 오류 없이 엉뚱한 값이 나오는 경우는 오류보다 발견하기 어렵다. 출력이 괄호로 묶인 여러 값이면 숫자에 쉼표가 들어갔는지 먼저 확인한다.

나누기의 결과에는 소수점이 붙는다. 6479000 / 20(4장의 =AVERAGE(G4:G23))의 출력은 323950.0이다. .0은 값이 실수로 계산되었다는 표시이며 크기는 323950과 같다.

2-6. 오류 메시지 읽기

코드가 실행되지 못하면 셀의 아래에 붉은 바탕의 여러 줄이 표시된다. 이 출력을 트레이스백이라고 한다. 파이썬 공식 자습서는 오류 메시지의 마지막 줄이 무슨 일이 일어났는지를 나타내며, 오류의 종류(예외의 이름)가 그 줄에 함께 인쇄된다고 설명한다. 그 앞부분은 오류가 일어난 맥락을 보여 준다. 따라서 오류가 나면 다음의 순서로 읽는다.

  1. 마지막 줄의 콜론 앞을 읽는다. 오류의 종류이다(NameError, KeyError, FileNotFoundError 등).
  2. 마지막 줄의 콜론 뒤를 읽는다. 원인의 설명이며, 따옴표 안에 문제가 된 이름이나 파일이 들어 있다.
  3. 위쪽에서 화살표(----> 또는 ^)가 가리키는 줄을 찾는다. 오류가 발견된 줄이다. 문법 오류에서는 화살표의 위치가 고쳐야 할 곳과 다를 수 있다.
  4. 마지막 줄을 본 장의 「빈번한 오류와 해결」 표와 대조한다.

노트북의 2절 끝에 있는 [오류 확인] 셀은 빈칸을 채우지 않고 ____ * 85000을 실행한 경우이다. 실제 출력의 마지막 줄은 다음과 같다.

NameError: name '____' is not defined

NameError는 “그런 이름이 없다”는 오류이다. 파이썬은 ____를 변수의 이름으로 읽었다. 따라 하기의 셀에서 이 오류가 나면 빈칸을 채우지 않은 것이다.

3. 변수와 출력

3-1. 변수

값에 이름을 부여한 것을 변수라고 한다. 엑셀에서는 값을 셀에 두고 셀 주소(E4)로 참조하였다. 파이썬에서는 값을 변수에 저장하고 변수의 이름(qty)으로 참조한다.

qty = 30               # 수량. 엑셀의 E4에 해당한다
price = 24000          # 단가. 엑셀의 F4에 해당한다
amount = qty * price   # 금액. 엑셀의 G4(=E4*F4)에 해당한다
print(amount)
표기 의미
qty = 30 오른쪽의 값 30을 qty라는 이름에 저장한다. 등호는 “같다”가 아니라 “저장한다”를 의미한다
qty * price 곱하기. 연산자(+, -, *, /)는 엑셀의 수식과 같다
print(amount) 괄호 안의 값을 화면에 출력한다
# 수량 #의 뒤는 설명(주석)이며 실행되지 않는다

변수의 이름에는 다음의 규칙이 있다.

  • 영문자, 숫자, 밑줄(_)을 사용한다. 숫자로 시작할 수 없으며 공백을 포함할 수 없다.
  • 대문자와 소문자를 구분한다. qty와 Qty는 서로 다른 변수이다.
  • 이미 있는 이름에 값을 다시 저장하면 이전의 값은 사라진다.

3-2. 엑셀의 자동 재계산과의 차이

엑셀은 셀의 값이 변경되면 그 셀을 참조하는 수식을 자동으로 다시 계산한다. 노트북은 그렇지 않다. 노트북의 3절은 이 차이를 세 셀로 보인다.

셀 코드 출력
1 qty = 31, amount = qty * price, print(amount) 744000
2 qty = 40, print(amount) 744000
3 amount = qty * price, print(amount) 960000

엑셀이라면 E4를 40으로 바꾸는 순간 G4가 960,000으로 바뀐다. 노트북의 둘째 셀은 744000을 출력한다. amount에는 마지막으로 계산한 시점의 값이 저장되어 있을 뿐 qty와 연결되어 있지 않기 때문이다. 계산하는 줄을 다시 실행하여야(셋째 셀) 960000이 된다. 엑셀의 수식은 참조한 셀과 연결된 채로 남지만, 코드의 변수는 실행한 시점의 값을 담는다. 셀을 위에서부터 순서대로 실행하여야 하는 까닭이 여기에 있다.

3-3. 숫자와 문자

값에는 숫자와 문자가 있다. 문자는 큰따옴표로 감싼다. 큰따옴표가 없는 글자는 변수의 이름으로 해석된다.

표기 해석
24000 숫자. 계산에 사용할 수 있다. 쉼표를 넣지 않는다
"한빛상사" 문자
"02" 문자. 숫자 2가 아니다. 파일 이름의 월과 같이 자릿수를 유지하여야 하는 값에 사용한다(9장)
한빛상사 변수의 이름으로 해석된다. 그러한 변수가 없으면 오류가 발생한다

노트북의 3절에 있는 [오류 확인] 셀은 customer = 한빛상사를 실행한다. 마지막 줄은 다음과 같다.

NameError: name '한빛상사' is not defined

2절의 오류와 종류가 같다. 4장의 IF 함수에서 "달성"을 큰따옴표로 감싸지 않으면 #NAME? 오류가 표시된 것과 같은 원인이다.

3-4. 출력과 반올림

print의 괄호 안에 쉼표로 구분하여 여러 값을 기재하면 한 줄에 차례로 출력된다. 값과 값의 사이에는 공백이 하나 들어간다.

customer = "한빛상사"
print(customer, "의 판매 금액:", amount)

이 셀은 3-2절의 셋째 셀 다음에 실행되므로 출력은 한빛상사 의 판매 금액: 960000이다. 의 앞의 공백은 print가 넣은 것이다.

round(값, 자릿수)는 값을 지정한 소수 자릿수까지 반올림하며, 자릿수를 생략하면 정수로 반올림한다. 엑셀의 [자릿수 줄임]은 표시만 변경하였으나 round는 반올림한 값을 새로 만든다. 3절의 따라 하기는 판매번호 1022의 구성비를 세 가지 꼴로 출력한다.

코드 출력 엑셀의 대응
amount / total 0.06362275449101797 H5에 저장된 값
round(amount / total, 3) 0.064 소수 셋째 자리까지 표시한 모양
round(amount / total * 100, 1) 6.4 백분율 형식으로 6.4%가 표시된 모양

4-3. 표의 확인

엑셀에서는 파일을 열면 표가 보이나, 코드에서는 표시하도록 지시하여야 보인다. 위의 셀의 출력은 다음과 같다.

   판매번호        판매일    거래처       품목  수량     단가
0  1001 2026-01-02   한빛상사  A4 복사용지  30  24000
1  1002 2026-01-05   동아문구       볼펜  50   6000

4-4. 자료형

sales.dtypes는 열마다 값이 어떤 종류(자료형)로 읽혔는지를 표시한다. 출력은 다음과 같다.

판매번호             int64
판매일     datetime64[us]
거래처                str
품목                 str
수량               int64
단가               int64
dtype: object
표시 뜻 엑셀의 대응(1장)
int64 정수(64비트) 일반, 쉼표, 통화 형식의 숫자
datetime64[us] 날짜와 시각. [us]는 마이크로초 단위까지 담는다는 뜻이다 날짜 형식으로 입력한 값
str 문자 셀의 왼쪽에 맞추어 표시되던 문자

마지막 줄의 dtype: object는 이 목록 자체의 종류이므로 읽지 않아도 된다. pandas의 자료형은 모양이 아니라 값의 종류를 기록하므로, 쉼표 형식의 수량과 통화 형식의 단가가 모두 int64로 읽힌다.

pandas 3.0의 변경 사항 문서에 따르면 3.0부터 문자 열에 전용 문자 자료형이 기본으로 쓰이며(이전에는 object), 날짜를 읽을 때의 기본 단위도 나노초(ns)에서 값에 맞는 단위(예: 마이크로초 us)로 바뀌었다. 실습 사이트의 pandas가 2.x이면 거래처와 품목은 object, 판매일은 datetime64[ns]로 표시되며, 계산 결과는 같다.

수량이나 단가가 int64가 아니라 str 또는 object로 표시되면 엑셀에서 숫자가 문자로 입력된 것이며 5절의 곱하기가 올바르게 수행되지 않는다. 판매일이 datetime64가 아니면 10장의 월 추출이 실패한다. 파일을 읽은 직후에 dtypes를 한 번 본다.

5. 열의 계산

5-1. 열의 선택

대괄호 안에 열의 이름을 기재하면 해당 열 전체가 선택된다. 엑셀에서 열 머리글 E를 눌러 열 전체를 선택하는 조작에 해당한다. 열의 이름은 문자이므로 큰따옴표로 감싼다. sales["수량"].head()의 출력은 다음과 같다.

0    30
1    50
2     4
3    40
4     8
Name: 수량, dtype: int64

표가 아니라 값의 목록이 표시되었다. 왼쪽은 행 번호, 오른쪽은 값이며, 맨 아래 줄은 이 목록의 이름이 수량이고 값이 정수라는 뜻이다. pandas는 이런 값의 목록을 Series라고 부른다. 대괄호를 두 겹으로 하여 이름을 쉼표로 나열하면 여러 열을 표로 선택한다. 엑셀에서 Ctrl을 누른 채 열 머리글을 여러 개 선택하는 것과 같다.

표기 결과

5-2. 열과 열의 계산

열과 열을 계산하면 같은 행의 값끼리 계산된다.

sales["금액"] = sales["수량"] * sales["단가"]   # 엑셀: G4에 =E4*F4를 입력하고 G23까지 복사한다
sales.head()

표의 오른쪽 끝에 금액 열이 생긴다. 출력은 다음과 같다.

   판매번호        판매일    거래처       품목  수량     단가      금액
0  1001 2026-01-02   한빛상사  A4 복사용지  30  24000  720000
1  1002 2026-01-05   동아문구       볼펜  50   6000  300000
2  1003 2026-01-06  서울오피스       토너   4  85000  340000
3  1004 2026-01-07   미래유통    파일 폴더  40   9000  360000
4  1005 2026-01-08   한빛상사       토너   8  85000  680000
엑셀 파이썬
G4에 =E4*F4를 작성하고 채우기 핸들로 G23까지 복사한다 열 전체를 한 줄로 계산한다
행이 추가되면 수식을 다시 복사하여야 한다 행의 수와 무관하게 동일한 코드를 사용한다
수식을 복사하지 않은 행이 있으면 그 행만 값이 비어 있어 발견하기 어렵다 모든 행에 동일한 계산이 적용된다

등호의 왼쪽에 존재하지 않는 열의 이름("금액")을 기재하면 계산 결과가 새로운 열로 추가된다. 이미 있는 이름을 기재하면 그 열의 값이 교체된다.

5-3. 구성비와 소수의 표시

구성비도 동일한 방법으로 산출한다. sales["금액"].sum()은 값 하나이므로 모든 행이 같은 값으로 나누어진다. 3장에서 필요하였던 절대 참조($G$25)에 해당하는 지정은 필요하지 않다.

sales["구성비"] = sales["금액"] / sales["금액"].sum()   # 엑셀: H4에 =G4/$G$25를 입력하고 복사한다
print(sales["구성비"].sum())                          # 엑셀: H25의 =SUM(H4:H23)
sales.head()

출력의 첫 줄은 1.0이고, 그 아래 표의 구성비 열은 다음과 같이 표시된다.

         금액       구성비
0    720000  0.111128
1    300000  0.046303
2    340000  0.052477

(실제 표에는 판매번호부터 단가까지의 열도 함께 표시된다. 위는 두 열만 옮긴 것이다.)

구성비 열은 표시할 때 소수 여섯째 자리에서 반올림될 뿐, 저장된 값은 그보다 길다. 0.111128은 3장에서 백분율 형식으로 표시한 11.1%와 같은 값이고, 구성비의 합계 1.0은 3장의 H25(100%)에 해당한다.

5-4. 원본 파일과의 관계

코드로 추가한 열은 변수 sales에 저장된 표에만 존재하며 서버의 판매_2026_01.xlsx는 변경되지 않는다. 계산 결과를 파일로 남기려면 별도의 저장 명령이 필요하며 9장에서 다룬다. 이 성질 때문에 코드는 원본을 훼손할 위험 없이 여러 번 실행할 수 있다.

6. 기초 통계

6-1. 함수의 대응

열을 선택한 뒤 점(.)과 함수의 이름을 기재하여 통계 값을 산출한다.

엑셀(4장) 파이썬 1월 자료의 결과 엑셀의 셀
=SUM(G4:G23) sales["금액"].sum() 6479000 G25
=AVERAGE(G4:G23) sales["금액"].mean() 323950.0 G26
=MAX(G4:G23) sales["금액"].max() 720000 G27
=MIN(G4:G23) sales["금액"].min() 108000 G28
=COUNT(G4:G23) sales["금액"].count() 20 G29

엑셀의 함수는 범위(G4:G23)를 인수로 지정하나 파이썬에서는 열의 이름으로 지정한다. 행이 20개에서 200개로 증가하여도 코드는 변경되지 않으며, 4장에서와 같이 합계 범위에 요약 행이 포함되는 오류가 생기지 않는다. 평균에 소수점이 붙는 까닭은 2-5절과 같다.

6-2. print 없이 표시한 값

같은 계산을 print 없이 셀의 마지막 줄에 두면 다음과 같이 표시된다.

np.int64(6479000)
np.float64(323950.0)

괄호 안이 값이고, 앞의 np.int64(64비트 정수)와 np.float64(64비트 실수)는 값의 종류를 나타내는 꼬리표이다. pandas는 계산에 NumPy라는 라이브러리를 사용하며, NumPy 2.0의 릴리스 노트는 값의 표현에 자료형의 정보를 넣도록 바꾸어 3.0 대신 np.float64(3.0)으로 표시한다고 설명한다. print로 출력하거나 NumPy가 2.0보다 오래된 판이면 꼬리표 없이 값만 나타난다. 대조할 때에는 괄호 안의 값만 읽는다.

6-3. 표시와 값의 대조

2월 자료의 금액 평균은 다음과 같이 출력된다.

평균  : 421894.7368421053
평균(반올림): 421895

엑셀에서 통화 형식으로 표시한 ₩421,895는 표시만 반올림한 것이고 셀의 값은 421894.7368…이다(3-4절). 화면에 보이는 421895를 코드의 평균과 그대로 비교하면 일치하지 않으므로, 노트북 6절의 대조 셀은 코드 쪽의 평균을 round로 반올림한 뒤 비교한다. 수작업 결과가 “표시된 값”인지 “저장된 값”인지를 먼저 정하고 코드의 결과도 같은 꼴로 맞춘다. 1월 자료의 평균은 나누어떨어지므로 핵심 실습에서는 이 문제가 생기지 않는다.

대조 셀의 출력은 다음과 같다.

      수작업 결과   코드의 결과    일치
합계   8016000  8016000  True
평균    421895   421895  True
최댓값   912000   912000  True
최솟값   104000   104000  True
개수        19       19  True

“일치” 열의 True는 두 값이 같다는 뜻이다. False가 나타나면 그 행의 두 값을 비교한다. 코드는 모든 수강생에게서 같은 결과를 내므로 대개는 기재한 수작업 결과에 오타가 있다.

심화 실습 [선택]

핵심 실습을 완료한 수강생은 4장의 목표 달성 건수를 코드로 산출한다.

  1. 노트북의 “심화 실습” 절에 있는 셀에서 target의 값으로 500000을 기재하여 실행한다. 결과를 4장에서 센 달성 건수(5건)와 대조한다.
  2. target을 300000으로 변경하여 다시 실행한다.
  3. 엑셀에서 기준 금액을 300,000원으로 변경하려면 어떠한 조작이 필요한지 정리하여 코드의 경우와 비교한다.

sales["금액"] >= target은 행마다 조건의 충족 여부를 참(True) 또는 거짓(False)으로 판정하며, sum()은 참의 개수를 센다. 참은 1, 거짓은 0으로 더해지기 때문이다. 4장의 IF 함수가 행마다 “달성” 또는 “미달”을 표시한 것과 같은 판정이다.

연습 문제

3월 자료(자료/판매_2026_03.xlsx)를 사용한다. 노트북의 “연습 문제” 절에 있는 셀에 코드를 작성한다. 셀에는 해야 할 일이 주석으로 적혀 있다. 절차는 제시하지 않는다. 변수의 이름은 sales나 feb가 아닌 새 이름(mar)을 사용한다.

  1. 3월 파일을 읽어 mar에 저장하고 표의 크기를 확인한다. 기준 값은 (25, 6)이다. 실마리: 4절의 따라 하기.
  2. mar에 금액 열을 추가하고 금액의 합계와 평균을 출력한다. 기준 값은 합계 8687000, 평균 347480.0이다. 실마리: 5절과 6절의 따라 하기.
  3. 3월의 수량 합계와, 금액이 500,000원 이상인 판매 건의 수를 출력한다. 기준 값은 수량 합계 536, 500,000원 이상 8건이다. 실마리: 5절의 수량 합계와 심화 실습의 셀.

개념 점검

  1. 수강생의 PC에 있는 엑셀 파일을 코드로 읽으려면 먼저 무엇을 하여야 하는가. 그 이유는 무엇인가.
  2. 노트북을 닫았다가 다시 열어 7절의 셀만 실행하였더니 NameError가 발생하였다. 원인과 해결 방법을 기술하시오.
  3. qty = 30과 엑셀의 수식 =30에서 등호의 의미는 어떻게 다른가.
  4. sales["금액"] = sales["수량"] * sales["단가"]는 엑셀의 어떠한 조작에 해당하는가. 행이 20개에서 200개로 증가하였을 때 두 방식에서 필요한 작업을 비교하시오.
  5. 코드가 수강생의 판매현황_04_학번.xlsx가 아닌 기준 파일을 읽는 이유는 무엇인가.
  6. sales["금액"].sum()의 표시 np.int64(6479000)에서 값은 무엇이며, np.int64는 무엇을 나타내는가.
  7. 2월의 평균을 엑셀의 화면에 보이는 421895와 비교하면 False가 나온다. 그 까닭과 대조하는 방법을 기술하시오.
