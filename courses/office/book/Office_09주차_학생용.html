데이터 집계의 자동화

2027학년도 「컴퓨터활용」의 준비 중인 교재입니다. 편집 상태를 검토하기 위해 미리 공개한 것으로, 수업 전에 내용과 순서가 바뀔 수 있습니다.

학사 11주차 · 교재 09 · 3부 파이썬

본 장은 5장 「정렬, 필터, 차트」의 정렬과 필터, 6장 「피벗 테이블」의 집계를 코드로 수행한다. 8장에서 읽은 판매 자료에서 조건에 해당하는 행을 선택하고, 거래처별 금액 합계표를 산출하여 엑셀 파일로 저장한다. 산출한 합계표는 6장의 피벗 테이블과 대조하여 검증한다. 이어서 동일한 코드를 2월 자료에 다시 실행한다. 엑셀에서는 자료가 교체되면 금액 열과 피벗 테이블을 다시 작성하여야 하나, 코드에서는 값 하나를 변경하여 재실행하는 것으로 집계가 완료된다. 본 장의 제목이 가리키는 자동화는 이 재실행을 의미한다.

수업은 실습 노트북을 위에서부터 실행하며 진행한다. 강의안의 절 번호는 노트북의 절 번호와 일치한다.

학습 목표

  1. 주어진 코드를 실행하여 표를 정렬하고 조건에 해당하는 행을 선택할 수 있다.
    • 예시: sales[sales["수량"] >= 30]의 결과가 5장의 필터 결과(8행)와 같음을 확인한다.
  2. pivot_table의 지정 항목을 엑셀 피벗 테이블의 영역과 대응하여 설명할 수 있다.
    • 예시: index="거래처"가 필드 목록의 행 영역에 거래처를 배치한 조작에 해당함을 설명한다.
  3. 거래처별 금액 합계표를 산출하여 엑셀 파일로 저장하고 6장의 수작업 결과와 대조할 수 있다.
    • 예시: 코드의 총합계 6479000이 피벗 테이블의 총합계와 일치함을 확인한다.
  4. 코드의 값을 변경하여 다른 월의 자료에 동일한 집계를 재실행할 수 있다.
    • 예시: month를 "02"로 변경하여 2월의 집계표와 결과 파일을 얻는다.

준비 사항

항목 내용
실행 환경 8장에서 구성한 실습 사이트의 컴퓨터활용 폴더와 자료 폴더(월별 파일 12개)
실습 노트북 Office_09주차_실습_학생용.ipynb를 컴퓨터활용 폴더에 올리고 이름을 실습_09_학번.ipynb로 변경한다
수작업 결과 6장에서 저장한 판매현황_06_학번.xlsx의 “피벗” 시트(거래처별 금액 합계와 총합계)와, 따라 하기에서 작성한 판매연습_06_학번.xlsx의 “피벗” 시트

1. 엑셀과의 비교

1-1. 대응 관계

엑셀에서의 작업(5~6장) 파이썬에서의 작업(본 장)
[데이터] 탭 → [정렬]로 금액 기준 내림차순 정렬 sort_values("금액", ascending=False)
필터에서 수량이 30 이상인 행을 선별 sales[sales["수량"] >= 30]
필터에서 거래처가 한빛상사인 행을 선별 sales[sales["거래처"] == "한빛상사"]
선별한 뒤 상태 표시줄에서 합계를 읽음 sales[sales["거래처"] == "한빛상사"]["금액"].sum()
피벗 테이블(행: 거래처, 값: 합계 : 금액) pivot_table(index="거래처", values="금액", aggfunc="sum")
[다른 이름으로 저장] to_excel("파일 이름")

1-2. 파이썬의 이점

6장에서 1월 자료의 피벗 테이블을 작성하였다. 2월 자료에 대하여 동일한 집계표가 필요하다고 할 때 두 방식의 작업은 다음과 같다.

단계 엑셀 파이썬
1 2월 파일을 연다 코드의 month를 "02"로 변경한다
2 금액 열을 추가하고 수식을 작성하여 복사한다 셀을 실행한다
3 피벗 테이블을 삽입하고 필드를 배치한다
4 결과를 다른 이름으로 저장한다

수강생은 1~6장의 따라 하기에서 2월 자료에 대하여 위의 엑셀 작업을 실제로 수행하였다. 월이 12개이면 엑셀에서는 위의 네 단계를 12회 반복하여야 한다. 코드에서는 변경할 값이 하나이며, 10장 「다중 파일의 일괄 처리」에서는 이 변경조차 필요하지 않도록 12개의 파일을 한 번에 처리한다.

코드에 의한 집계에는 절차가 기록된다는 이점도 있다. 피벗 테이블은 결과만 남으며 어떤 필드를 어디에 배치하였는지는 필드 목록을 열어 확인하여야 한다. 필터는 해제하면 조건이 남지 않는다. 코드는 정렬의 기준, 선택의 조건, 집계의 지정이 모두 문장으로 남으므로 다른 사람이 결과의 산출 과정을 확인할 수 있다.

1-3. 차이점

구분 엑셀 파이썬
정렬의 효과 시트의 행 순서가 실제로 변경된다. 되돌리려면 일련번호 열로 다시 정렬한다(5장) 정렬된 결과가 표시될 뿐 원래의 표는 변경되지 않는다
선별의 효과 조건에 맞지 않는 행이 숨겨진다. 필터를 해제하여야 전체가 다시 보인다 조건에 맞는 행으로 이루어진 새로운 표가 산출된다. 원래의 표는 그대로이다
집계표의 갱신 원본을 수정한 뒤 [새로 고침]을 하여야 한다(6장) 코드를 다시 실행한다

2. 자료의 준비

8장과 동일한 방법으로 기준 파일을 읽고 금액 열을 추가한다.

import pandas as pd

sales = pd.read_excel("자료/판매_2026_01.xlsx")
sales["금액"] = sales["수량"] * sales["단가"]

8장의 노트북에서 만든 변수는 본 장의 노트북에서 사용할 수 없다. 노트북마다 커널이 따로 실행되기 때문이다. 따라서 본 장의 노트북도 라이브러리를 불러오고 파일을 읽는 것에서 시작한다. 이 두 줄은 9장 이후의 모든 노트북의 첫머리에 놓인다.

따라 하기

실습 노트북의 2절까지 실행하여 자료를 준비한다. 1월 자료는 sales에, 2월 자료는 feb에 저장한다.

  1. import pandas as pd를 포함한 셀을 실행한다. sales.shape의 결과는 (20, 7)이다. 원본의 6개 열에 금액 열이 추가되었다.
  2. 2월 자료를 읽는 셀에서 ____ 2곳에 금액을 계산하는 두 열의 이름을 기재하여 실행한다.
    • 확인 1 feb.shape의 결과가 (19, 7)이다.

3. 정렬

3-1. 정렬의 표기

sales.sort_values("금액", ascending=False).head(3)
표기 의미
sort_values("금액") 금액 열을 기준으로 행을 정렬한다
ascending=False 내림차순. 생략하거나 True로 지정하면 오름차순이다
.head(3) 정렬한 결과의 처음 3행을 표시한다
.tail(1) 마지막 1행을 표시한다

결과의 첫 행은 판매번호 1001(720,000원), 마지막 행은 판매번호 1015(108,000원)이며 5장의 정렬 결과와 같다. 점(.)으로 여러 처리를 이어 기재하면 왼쪽부터 차례로 수행된다. 위의 코드는 “금액 기준 내림차순으로 정렬한 뒤 처음 3행을 표시한다”로 읽는다.

True와 False는 참과 거짓을 나타내는 값이며 첫 글자를 대문자로 기재한다. 큰따옴표로 감싸지 않는다.

3-2. 정렬의 기준과 결과

정렬의 기준은 숫자 열에 한정되지 않는다. 문자 열은 가나다순으로, 날짜 열은 날짜순으로 정렬된다. 엑셀의 정렬과 같다.

정렬된 결과에서 맨 왼쪽의 행 번호는 정렬 전의 번호를 유지한다. 1월 자료를 금액 기준 내림차순으로 정렬하면 행 번호가 0, 4, 5, …의 순으로 표시된다. 판매번호 1001이 원래 0번 행, 1005가 4번 행이었기 때문이다. 이 번호로 원래의 위치를 알 수 있다.

엑셀의 정렬은 시트의 행 순서를 실제로 변경한다. 5장에서 정렬 후에 판매번호 기준으로 되돌린 것은 이 때문이다. sort_values는 정렬된 결과를 화면에 표시할 뿐 sales의 순서를 변경하지 않으므로 되돌리는 절차가 필요하지 않다.

따라 하기

실습 노트북의 3절에 있는 셀을 차례로 실행한다.

  1. 1월 자료를 금액 기준 내림차순으로 정렬하는 셀 2개와 거래처 기준으로 정렬하는 셀을 실행한다.
  2. 2월 자료를 금액 기준 내림차순으로 정렬하는 셀에서 ____에 기준 열의 이름과 내림차순의 지정 값을 기재하여 실행한다.
    • 확인 2 첫 행은 판매번호 1036(금액 912000)이다.
  3. 다음 셀도 같은 값으로 채워 실행한다.
    • 확인 3 마지막 행은 판매번호 1033(금액 104000)이다. 5장의 따라 하기에서 연습용 통합 문서를 정렬한 결과와 같다.

4. 조건에 의한 선택

4-1. 선택의 표기

대괄호 안에 조건을 기재하면 조건을 충족하는 행만 선택된다.

sales[sales["수량"] >= 30]

안쪽의 sales["수량"] >= 30은 행마다 조건의 충족 여부를 참 또는 거짓으로 판정하고, 바깥쪽의 sales[…]는 참인 행만 남긴다. 결과는 8행이며 5장의 필터 결과(판매번호 1001, 1002, 1004, 1007, 1009, 1012, 1013, 1020)와 같다. 행의 수는 len(…)으로 센다. 5장에서는 상태 표시줄의 레코드 수로 확인하였다.

4-2. 비교 연산자

비교에 사용하는 연산자는 4장의 IF 함수에서 사용한 것과 대부분 같다.

의미 엑셀(IF의 조건) 파이썬
이상, 초과 >=, > >=, >
이하, 미만 <=, < <=, <
같다 = ==
같지 않다 <> !=

“같다”를 등호 두 개(==)로 표기하는 점이 다르다. 파이썬에서 등호 하나(=)는 변수에 값을 저장하는 기호이기 때문이다(8장). 문자 값은 큰따옴표로 감싸며, 자료의 표기와 글자 하나까지 일치하여야 한다. "한빛 상사"와 같이 공백이 들어가면 일치하는 행이 없어 결과가 0행이 된다. 오류가 발생하지 않으므로 행의 수를 확인하지 않으면 발견하기 어렵다.

sales[sales["거래처"] == "한빛상사"]

결과는 5행이며 5장에서 “한빛상사” 시트에 붙여 넣은 표와 같다.

4-3. 선택한 결과의 계산

선택한 결과는 하나의 표이므로 8장의 열 선택과 통계 함수를 이어서 적용할 수 있다.

sales[sales["거래처"] == "한빛상사"]["금액"].sum()

“거래처가 한빛상사인 행을 선택하고, 그 금액 열의 합계를 산출한다”로 읽는다. 결과는 1756000이며 6장의 피벗 테이블에서 한빛상사의 값과 같다. 엑셀의 기본 함수 6개로는 이 값을 수식 하나로 산출할 수 없었으며, 필터로 선별한 뒤 상태 표시줄을 읽거나 피벗 테이블을 작성하여야 하였다.

선택한 결과를 변수에 저장하면 이후의 줄에서 다시 사용할 수 있다.

toner = feb[feb["품목"] == "토너"]
print(len(toner))
print(toner["금액"].sum())

따라 하기

실습 노트북의 4절에 있는 셀을 차례로 실행한다.

5. 항목별 집계와 저장

5-1. 피벗 테이블

summary = sales.pivot_table(index="거래처", values="금액", aggfunc="sum",
                            margins=True, margins_name="총합계")

괄호 안의 지정은 엑셀의 피벗 테이블 필드 목록에서 수행한 조작과 대응한다.

엑셀의 피벗 테이블 pivot_table의 지정
행 영역에 거래처를 배치한다 index="거래처"
값 영역에 금액을 배치한다 values="금액"
값 요약 기준을 합계로 한다 aggfunc="sum"
값 요약 기준을 개수로 한다 aggfunc="count"
총합계 행을 표시한다 margins=True, margins_name="총합계"

괄호 안의 지정이 길어지면 쉼표의 뒤에서 줄을 바꾸어 기재할 수 있다. 지정의 순서는 결과에 영향을 주지 않는다. 결과는 다음과 같으며 6장의 피벗 테이블과 행의 순서까지 같다. 행은 거래처의 가나다순으로 배열된다.

거래처 금액
대한사무기 1272000
동아문구 1050000
미래유통 1353000
서울오피스 1048000
한빛상사 1756000
총합계 6479000

index에 지정한 열의 값 가운데 자료에 존재하는 것만 행으로 나타난다. 2월 자료에는 볼펜의 판매 건이 없으므로 2월의 품목별 합계표는 행이 4개이다. 엑셀의 피벗 테이블에서도 같다.

5-2. 엑셀 파일로의 저장

import os

os.makedirs("결과", exist_ok=True)
summary.to_excel("결과/거래처별합계_2026_01.xlsx")
표기 의미
os.makedirs("결과", exist_ok=True) 결과 폴더를 생성한다. 이미 있으면 아무 일도 일어나지 않는다
summary.to_excel(…) 표를 엑셀 파일로 저장한다. 같은 이름의 파일이 있으면 경고 없이 덮어쓴다

저장한 파일은 파일 탐색기의 결과 폴더에 나타난다. 폴더가 보이지 않으면 파일 탐색기의 위쪽에 있는 [Refresh File List] 단추를 누른다. 내려받아 엑셀로 열면 집계표가 값으로 들어 있다. 테두리와 표시 형식은 적용되어 있지 않으므로 보고 자료로 사용할 때에는 2장 「셀 서식과 인쇄 설정」의 방법으로 서식을 적용한다. 값으로 저장되므로 피벗 테이블과 달리 원본과 연결되어 있지 않다.

입력 파일을 자료 폴더에, 결과 파일을 결과 폴더에 분리하여 두는 것은 원본과 산출물을 혼동하지 않기 위한 것이다. 10장에서 자료 폴더의 파일을 한 번에 읽을 때 결과 파일이 섞여 들어가는 것도 방지한다.

5-3. 파일 이름에 변수 사용

핵심 실습의 코드는 파일 이름에 변수를 사용한다. 따옴표의 앞에 f를 붙이면 중괄호 안의 변수가 그 값으로 치환된다.

month = "03"
print(f"자료/판매_2026_{month}.xlsx")     # 자료/판매_2026_03.xlsx

month의 값을 변경하면 읽는 파일과 저장하는 파일의 이름이 함께 변경된다. month의 값은 "03"과 같이 큰따옴표로 감싼 두 자리의 문자이어야 한다. 숫자 3으로 지정하면 파일 이름이 판매_2026_3.xlsx가 되어 파일을 찾지 못한다.

개념 점검

  1. 엑셀에서 금액 기준으로 정렬한 뒤에는 판매번호 기준으로 되돌렸다. sort_values를 사용한 뒤에는 되돌릴 필요가 없는 이유는 무엇인가.
  2. sales[sales["거래처"] = "한빛상사"]를 실행하면 오류가 발생한다. 원인과 올바른 표기를 기술하시오.
  3. 조건에 의한 선택의 결과가 0행이었으나 오류는 발생하지 않았다. 가능한 원인과 이를 발견하는 방법을 기술하시오.
  4. pivot_table의 index, values, aggfunc는 엑셀 피벗 테이블의 무엇에 각각 대응하는가.
  5. 3월 자료의 거래처별 합계표를 얻기 위하여 엑셀에서 수행하여야 하는 작업과 본 장의 코드에서 변경하여야 하는 부분을 비교하시오.
