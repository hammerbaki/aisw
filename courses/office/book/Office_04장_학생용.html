[4장] 기본 함수

컴퓨터활용

4장

기본 함수

2027학년도 「컴퓨터활용」의 준비 중인 교재입니다. 편집 상태를 검토하기 위해 미리 공개한 것으로, 수업 전에 내용과 순서가 바뀔 수 있습니다.

학사 5주차 · 교재 04 · 1부 엑셀

본 장은 엑셀의 함수를 다룬다. 3장에서 자동 합계 단추가 입력한 =SUM(G4:G23)을 출발점으로 함수의 일반 형식(이름, 괄호, 인수, 범위)을 살펴보고, 같은 형식으로 평균, 최댓값, 최솟값, 개수를 산출한 뒤 조건에 따라 값을 둘로 구분하는 IF 함수를 작성한다. 다루는 함수는 SUM, AVERAGE, MAX, MIN, COUNT, IF의 6개이며, 목표는 모든 함수에 공통된 형식을 정확히 읽고 작성하는 것이다.

1~5절의 따라 하기는 연습용 통합 문서(2월 자료)에서 수행하고, 6절의 핵심 실습에서는 판매 현황 통합 문서(1월 자료)에 요약 행과 목표 달성 열을 작성하여 제출한다. 요약 함수의 결과는 숫자 하나이므로, 평균 = 합계 ÷ 개수의 관계와 요약 값 사이의 대소 관계로 검산한다.

수업 시간의 범위. 150분 수업에서는 번호를 붙인 절의 설명과 따라 하기, 핵심 실습까지 한다. 심화 실습, 연습 문제, 개념 점검은 시간이 남을 때나 수업 뒤에 한다.

학습 목표

  1. 함수의 일반 형식을 구성하는 요소(함수 이름, 괄호, 인수, 범위)를 설명하고, 쉼표와 콜론의 의미를 구분한다.
  2. 함수를 직접 입력, [함수 삽입] 대화 상자, [자동 합계] 목록의 세 가지 방법으로 입력하고, [함수 인수] 대화 상자에 미리 표시되는 결과로 범위를 점검한다.
  3. SUM, AVERAGE, MAX, MIN, COUNT로 금액 열의 요약 값을 산출하고, 빈 셀, 문자 셀, 0이 든 셀이 각 함수의 결과에 미치는 영향을 설명한다.
  4. 평균 = 합계 ÷ 개수의 관계로 요약 값을 검산하고, 범위를 잘못 지정한 경우의 결과를 읽어 원인을 찾는다.
  5. 비교 연산자로 조건을 작성하고, 경곗값의 포함 여부를 판단하여 단일 조건의 IF 함수로 목표 달성 여부를 표시한다.
  6. 기준 값을 별도의 셀에 두고 절대 참조로 참조하는 IF 수식을 작성한다.

1. 함수의 형식

1-1. 함수의 구성 요소

함수는 자주 사용하는 계산을 엑셀이 미리 정의하여 이름을 붙여 둔 것이다. 금액 20개의 합계는 =G4+G5+…+G23 대신 =SUM(G4:G23)으로 작성한다.

구성 요소 설명 예
등호 수식의 시작을 나타낸다. 함수도 수식이다 =
함수 이름 수행할 계산의 종류 SUM
괄호 함수 이름의 바로 뒤에 붙어 인수를 둘러싼다. 여는 괄호와 닫는 괄호가 짝을 이룬다 (, )
인수 함수에 전달하는 값. 계산의 대상이다 G4:G23 
=함수이름(인수1, 인수2, …)

인수가 둘 이상이면 쉼표로 구분하며, 인수의 개수와 의미는 함수마다 정해져 있다. 함수 이름은 대문자와 소문자를 구분하지 않는다. =sum(g4:g23)으로 입력하여도 엑셀이 대문자로 바꾸어 저장한다.

그림 1. 함수의 구성 요소. 함수의 종류가 달라져도 이름, 괄호, 인수의 형식은 같다.

지원 문서 「Excel에서 수식 손상을 방지하는 방법」은 등호로 시작하기, 괄호의 짝 맞추기, 필요한 인수 넣기, 숫자를 구분 기호 없이 입력하기, 텍스트를 따옴표로 묶기를 규칙으로 든다. 본 장의 오류 대부분은 이 가운데 하나를 어긴 것이다. 인수의 구분 기호는 한국어 설정의 실습실 PC에서 쉼표이다.

1-2. 범위의 표기

연속된 셀의 묶음인 범위는 시작 셀과 끝 셀을 콜론(:)으로 연결하여 표기한다. 쉼표는 셀이나 인수를 나열하는 기호이다.

표기 의미 셀의 수
G4:G23 G4부터 G23까지의 범위 20개
G4,G23 G4와 G23의 두 셀 2개
E4:F23 E4부터 F23까지의 직사각형 범위 40개

범위에 든 셀의 수는 끝 행 번호 - 시작 행 번호 + 1이다(G4:G23은 23 - 4 + 1 = 20). 범위의 셀이 20개이면 COUNT의 결과는 20을 넘을 수 없다.

1-3. 인수의 구분

인수의 자리에는 범위, 셀 하나, 숫자가 올 수 있으며, 엑셀은 쉼표를 만날 때마다 인수가 하나 끝난 것으로 해석한다.

수식 인수의 수 인수의 내용 결과
=SUM(G4:G23) 1 범위 하나 6,479,000
=SUM(G4:G13,G14:G23) 2 범위 둘. 앞의 10행과 뒤의 10행 6,479,000
=SUM(G4,G23) 2 셀 둘 848,000
=SUM(G4:G23,100000) 2 범위 하나와 숫자 하나 6,579,000

함수는 이름으로 계산의 종류를, 쉼표의 수로 인수의 수를, 인수마다의 콜론의 유무로 범위인지 셀 하나인지를 읽는다. 숫자 인수에 천 단위 쉼표를 넣으면 쉼표가 인수의 구분으로 해석된다. =SUM(G4:G23,100,000)은 범위, 100, 0의 세 인수가 되어 6,479,100을 표시하며, 오류 값이 나타나지 않으므로 결과만으로는 발견하기 어렵다.

2. 함수의 입력 방법

함수를 입력하는 방법은 세 가지이며, 어느 방법을 사용하여도 셀에 저장되는 수식은 같다.

2-1. 직접 입력과 수식 자동 완성

결과를 표시할 셀에 =와 함수 이름의 앞 글자를 입력하면(=AV) 그 글자로 시작하는 함수의 목록이 표시된다. 이를 수식 자동 완성이라고 한다. 목록에서 방향키로 함수를 고르고 Tab을 누르면 함수 이름과 여는 괄호가 입력된다. 이어서 범위를 마우스로 끌고, 닫는 괄호를 입력한 뒤 Enter를 누른다.

여는 괄호를 입력하면 셀 아래에 AVERAGE(number1, [number2], ...)와 같이 인수의 형식이 표시되며, 대괄호로 둘러싸인 인수는 생략할 수 있다. 목록에서 선택하면 함수 이름의 오타가 생기지 않는다. 목록이 표시되지 않으면 등호를 입력하지 않았거나 한글 입력 상태인 것이다.

[그림 자리: 수식 자동 완성 목록과 인수의 형식] 셀에 =AV를 입력하였을 때 표시되는 수식 자동 완성 목록과, 여는 괄호를 입력한 뒤 셀 아래에 AVERAGE(number1, [number2], ...)가 표시된 모습. 찍을 곳: Microsoft 365 엑셀, 연습용 통합 문서의 G25.

2-2. 함수 삽입 대화 상자

함수의 이름이나 인수의 순서가 기억나지 않으면 [함수 삽입] 대화 상자를 사용한다. 수식 입력줄 왼쪽의 [함수 삽입] 단추(fx), Shift + F3, [수식] 탭 [함수 라이브러리] 그룹의 [함수 삽입]이 같은 대화 상자를 연다. [함수 검색]이나 [범주 선택]으로 함수를 고르고 [확인]을 누르면 [함수 인수] 대화 상자가 열린다. 이 대화 상자는 인수마다 입력란과 설명을 제시하고 괄호와 쉼표를 대신 기재한다. 입력란에 엑셀이 추정한 범위가 미리 기재되어 있으면, 의도와 다를 때 지우고 시트에서 다시 끈다.

버전에 따른 차이: [함수 삽입] 단추를 눌렀을 때 열리는 대화 상자의 제목이 [함수 마법사]로 표시되는 버전이 있다. 구성과 조작은 같다.

2-3. 결과 미리 보기의 읽기

지원 문서 「Excel 수식에서 함수 및 중첩된 함수 사용」에 따르면 [함수 인수] 대화 상자는 함수의 현재 결과와 수식 전체의 현재 결과를 표시한다. 그러므로 [확인]을 누르기 전에 범위를 점검할 수 있다. 입력란의 시작 셀과 끝 셀이 자료의 첫 행과 마지막 행인지 읽고, 미리 표시된 결과가 예상의 범위 안에 있는지 본다. 최댓값은 금액 열의 어느 값보다 클 수 없고, 평균은 최솟값과 최댓값의 사이에 있으며, 개수는 범위의 셀 수를 넘을 수 없다. 벗어나면 [확인]을 누르지 않고 범위를 다시 끈다.

예를 들어 2월 자료의 G26(최댓값)에서 입력란에 바로 위의 요약 값 G24:G25가 제시되어 있으면 미리 보기는 합계 8,016,000을 최댓값으로 표시한다. 금액 한 건이 월 매출 전체와 같을 수는 없으므로 범위가 틀렸음을 알 수 있다.

입력란 G24:G25   →  미리 보기 8016000   (요약 행이 범위로 제시되었다)
입력란 G4:G22    →  미리 보기 912000    (판매번호 1036의 금액)

[그림 자리: 함수 인수 대화 상자의 결과 미리 보기] MAX 함수의 [함수 인수] 대화 상자. 첫째 입력란에 G4:G22가 기재되고, 입력란 옆과 대화 상자 아래쪽에 계산 결과 912000이 표시된 모습. 찍을 곳: Microsoft 365 엑셀, 연습용 통합 문서의 G26에서 [함수 삽입].

2-4. 자동 합계 목록

[홈] 탭 → [편집] 그룹 → [자동 합계] 옆의 화살표를 누르면 [평균], [숫자 개수], [최대값], [최소값]이 있는 목록이 열린다. 3장의 자동 합계와 같이 엑셀이 추정한 범위가 점선으로 표시되고 Enter로 확정된다. 둘째 요약 행부터는 바로 위의 요약 값이 범위로 제시되기 쉬우므로, 점선의 범위가 자료와 다르면 Enter를 누르기 전에 다시 끈다. 본 교재는 본문에서 “최댓값”, “최솟값”으로 쓰고 메뉴를 가리킬 때에만 화면의 표기(“최대값”, “최소값”)를 따른다.

2-5. 범위를 지정하는 방법

범위는 마우스로 끌거나 주소를 입력하여 지정한다. 끄는 방법은 주소의 오타가 없으나 한 행을 더 끌거나 덜 끌기 쉽고, 입력하는 방법은 범위가 화면을 벗어나도 정확하나 콜론이나 열 문자를 잘못 입력하기 쉽다. 어느 방법이든 입력을 마친 뒤에는 수식 입력줄에서 시작 셀과 끝 셀을 읽거나, 셀에서 F2를 눌러 색 테두리가 자료의 범위와 일치하는지 본다.

3. 요약 함수

3-1. SUM, AVERAGE, MAX, MIN, COUNT

다섯 함수는 이름만 다르고 형식이 같으며, 범위 하나를 전달하면 그 범위의 숫자를 대상으로 계산한다.

함수 산출하는 값 수식 결과
SUM 합계 =SUM(G4:G23) 6,479,000
AVERAGE 평균(합계를 개수로 나눈 값) =AVERAGE(G4:G23) 323,950
MAX 최댓값 =MAX(G4:G23) 720,000
MIN 최솟값 =MIN(G4:G23) 108,000
COUNT 개수(숫자가 들어 있는 셀의 수) =COUNT(G4:G23) 20

상태 표시줄의 평균과 합계는 선택을 해제하면 사라지지만, 함수의 결과는 셀에 남아 다른 수식에서 참조할 수 있다. 지원 문서 「Excel 상태 표시줄 옵션」에 따르면 상태 표시줄의 [개수]는 값이 있는 셀의 수이고 숫자 셀만 세는 것은 기본으로 꺼져 있는 [숫자 개수]이다. 거래처 열(C4:C22)을 선택하면 [개수]는 19이지만 =COUNT(C4:C22)는 0이다.

3-2. 숫자가 아닌 셀의 처리

다섯 함수는 범위 안의 숫자만을 계산의 대상으로 한다. 지원 문서 「COUNT 함수」는 범위 안의 빈 셀, 논리값, 텍스트, 오류 값을 세지 않는다고 설명한다.

수식 결과 이유
=COUNT(A4:A23) 20 판매번호는 숫자이다
=COUNT(B4:B23) 20 날짜는 숫자로 저장된다(2장)
=COUNT(C4:C23) 0 거래처는 문자이다
=COUNT(A3:A23) 20 머리글 A3은 문자이므로 제외된다
=COUNT(G4:G24) 20 빈 셀 G24는 제외된다

COUNT는 행의 수가 아니라 숫자가 든 셀의 수를 세므로, 금액 열의 개수가 20이 아니면 금액 열에 숫자가 아닌 값이 있다. 빈 셀과 0은 다르게 처리된다. 지원 문서 「AVERAGE 함수」에 따르면 텍스트와 빈 셀은 무시되지만 0은 평균에 포함된다. 문자 셀은 빈 셀과 같이 처리되므로 함수의 결과만으로는 빈 셀과 문자를 구별할 수 없다. 수량 열에서 판매번호 1002의 수량(E5, 50)을 바꾼 결과는 다음과 같다.

E5의 상태 =SUM(E4:E23) =COUNT(E4:E23) =AVERAGE(E4:E23)
50(원래의 값) 493 20 24.65
빈 셀 또는 50개 443 19 23.32
0 443 20 22.15

숫자가 하나도 없는 범위에서 SUM, MAX, MIN, COUNT는 0을, AVERAGE는 #DIV/0!를 표시한다(실습 PC 확인). 사칙 수식은 문자를 건너뛰지 않으므로 =C4+C5는 #VALUE!, =SUM(C4:C5)는 0이다. 범위에 오류 값이 있으면 COUNT를 뺀 네 함수가 같은 오류 값을 표시한다.

3-3. 결과의 예상: 빈 셀, 문자 셀, 0

3-2의 규칙을 거꾸로 읽으면 결과에서 자료의 상태를 추론할 수 있다. 지운 값이 평균보다 작았으면 평균은 커지고, 최댓값이나 최솟값이었으면 MAX, MIN은 다음 값으로 바뀐다. 0을 넣으면 MIN이 0이 된다. 금액 열은 수식이므로 한 단계가 더 있다. 수량 셀을 지우면 금액 수식이 0을 돌려주어 금액 열에 0이 생기고, 수량 셀에 문자를 넣으면 금액 수식이 #VALUE!가 되어 요약 함수에 오류가 전달된다. 2월 자료의 판매번호 1022(E5 6, G5 510,000)를 바꾸고 요약 행을 읽은 결과는 다음과 같다(실습 PC의 엑셀에서 확인).

조작 G5 합계 G24 평균 G25 최솟값 G27 개수 G28
원래의 상태 510,000 8,016,000 421,894.7 104,000 19
E5를 Delete 0 7,506,000 395,052.6 0 19
E5에 6개 #VALUE! #VALUE! #VALUE! #VALUE! 18
G5를 Delete(수식을 지움) 빈 셀 7,506,000 417,000 104,000 18
G5에 0을 입력 0 7,506,000 395,052.6 0 19

최솟값이 0이면 금액이 0인 행(대개 수량이 빈 행)이 있고, 개수가 행의 수보다 작으면 금액 열에 비었거나 숫자가 아닌 셀이 있으며, 다른 요약 값이 모두 오류인데 개수만 숫자이면 금액 열의 어느 셀이 오류 값이다. 요약 행은 표를 요약하는 동시에 표의 상태를 진단한다.

3-4. 평균의 검산

평균은 합계를 개수로 나눈 값이므로 같은 범위로 구한 세 요약 값 사이에는 “평균 = 합계 ÷ 개수”가 성립한다. 빈 셀에 =G25/G29를 입력하여 G26의 평균과 같은지를 보면 세 함수의 범위가 일치하는지를 한 번에 검산할 수 있다. 두 값이 다르면 계산이 아니라 범위가 다른 것이다.

G25 합계      =SUM(G4:G23)       6479000
G29 개수      =COUNT(G4:G23)     20
검산          =G25/G29           323950
G26 평균      =AVERAGE(G4:G23)   323950     (검산과 같으면 세 범위가 일치한다)

음수가 없는 자료에서는 다음의 관계도 언제나 성립한다. 하나라도 어긋나면 범위나 자료에 문제가 있다.

관계 1월 자료의 값 어긋날 때 의심할 것
최솟값 ≤ 평균 ≤ 최댓값 108,000 ≤ 323,950 ≤ 720,000 평균과 최솟값·최댓값의 범위가 서로 다르다
최댓값 ≤ 합계 720,000 ≤ 6,479,000 최댓값의 범위에 합계 등 요약 값이 들어갔다
개수 ≤ 범위의 셀 수 20 ≤ 20(G4:G23) 개수의 범위가 자료보다 넓다
합계 = 평균 × 개수 323,950 × 20 = 6,479,000 세 함수의 범위가 서로 다르다

세 함수가 똑같이 한 행을 빠뜨린 범위(G4:G22)를 쓰면 관계는 성립하지만 값은 틀린다. 관계의 점검은 기준 값과의 대조를 대신하지 않고, 그 전에 큰 오류를 걸러 내는 단계이다.

2월 자료의 평균 8,016,000 ÷ 19 = 421,894.7368…은 통화 형식에서 ₩421,895로 표시되지만, 참조하는 수식은 저장된 값으로 계산한다(3장 4-6과 같은 원리). [자릿수 늘림]을 누르면 표시되는 소수 자릿수가 늘어난다.

3-5. 범위 오류의 결과 읽기

함수는 전달된 범위를 그대로 계산할 뿐 범위가 의도와 맞는지는 판단하지 않는다. 요약 행 다섯 개를 완성한 뒤 범위에 요약 행이 들어간 경우를 1월 자료로 확인하면 다음과 같다.

수식 결과 결과에서 읽을 것
=AVERAGE(G4:G25) 617,048 합계 G25가 섞인 21개 값의 평균이다
=COUNT(G4:G29) 25 자료 20개에 요약 값 5개가 더해졌다. 빈 행 24는 세지 않는다
=MIN(G4:G29) 20 최솟값이 개수 셀의 값이 되었다. 금액이 20원일 수는 없다
=MAX(G4:G29) 6,479,000 최댓값이 합계와 같다
=AVERAGE(G4:G29) 564,398.8 최솟값과 최댓값 사이에 있으나 정상 평균(323,950)의 1.7배이다

개수가 행의 수보다 크거나, 최댓값이 합계와 같거나, 최솟값이 개수와 같으면 요약 행이 범위에 들어간 것이다. 평균 ≠ 합계 ÷ 개수이면 세 함수의 범위가 서로 다르다(3-4).

합계 수식을 채우기 핸들로 복사하면 상대 참조인 범위가 밀려 G26은 =SUM(G5:G24)(첫 행이 빠진 5,759,000)가 되므로, 요약 행의 함수는 각각 입력한다. 범위에 그 셀 자신이 들어가면 3장 5-5의 순환 참조가 된다. 실습 PC에서 2월 자료의 G25에 =AVERAGE(G4:G25)를 넣자 값은 0이었고 순환 참조로 보고되었다.

4. IF 함수

4-1. 비교 연산자와 조건

두 값의 크기를 비교하는 식을 조건이라고 하며, 결과는 참(TRUE) 또는 거짓(FALSE)이다(지원 문서 「Excel의 계산 연산자 및 우선 순위」). G4가 720,000일 때의 결과는 다음과 같다.

연산자 의미 조건 결과
>= 이상(크거나 같다) G4>=500000 TRUE
> 초과(크다) G4>500000 TRUE
< 미만(작다) G4<500000 FALSE
<= 이하(작거나 같다) G4<=500000 FALSE
= 같다 G4=720000 TRUE
<> 같지 않다 G4<>720000 FALSE
  • 조건도 수식이다. 빈 셀에 =G4>=500000을 입력하면 TRUE가 표시된다.
  • 두 글자의 연산자는 순서를 지킨다. =>나 ><로 입력하면 수식이 입력되지 않는다.
  • 비교 연산자는 사칙 연산자보다 나중에 계산된다. =E4*F4>=500000은 곱한 결과를 500,000과 비교한다.
  • 빈 셀은 0으로 간주된다. 빈 셀에 대한 >=500000은 거짓이고 >=0은 참이다.

4-2. 경곗값과 비교 연산자별 결과

“이상”과 “초과”는 경곗값에서 결과가 달라진다. =IF(금액 연산자 500000,"달성","미달")의 꼴에서 금액이 499,999, 500,000, 500,001일 때의 결과를 실습 PC의 엑셀에서 확인하면 다음과 같다.

연산자 499,999 500,000 500,001 500,000을 “달성”에 포함하는가
>= 미달 달성 달성 포함한다(이상)
> 미달 미달 달성 포함하지 않는다(초과)
< 달성 미달 미달 포함하지 않는다(미만)
<= 달성 달성 미달 포함한다(이하)
= 미달 달성 미달 경계 하나만 달성이다
<> 달성 미달 달성 경계 하나만 미달이다

결과가 갈리는 것은 가운데 열뿐이다. 1월 자료에는 금액이 정확히 500,000원인 행이 없어 핵심 실습에서는 >=와 >의 달성 건수가 5건으로 같으나, 결과가 같다고 조건이 맞는 것은 아니다(2월 자료의 사례는 5-4). “이상”, “이하”는 경계를 포함하고 “초과”, “미만”은 포함하지 않으므로, 경곗값을 하나 넣어 보아 원하는 결과가 나오는 연산자를 고른다.

4-3. IF의 형식

IF는 조건의 결과에 따라 두 값 중 하나를 표시하는 함수이며 인수는 3개이다.

=IF(조건, 참일 때의 값, 거짓일 때의 값)

=IF(G4>=500000,"달성","미달")은 “G4가 500,000 이상이면 달성을, 그렇지 않으면 미달을 표시한다”로 읽는다. 엑셀은 조건을 먼저 계산하고 그 결과에 따라 둘째 또는 셋째 인수를 표시한다(지원 문서 「IF 함수」). 4행(720,000)은 조건이 TRUE이므로 달성, 5행(300,000)은 FALSE이므로 미달이다. 요약 함수와 다른 점은 인수가 범위가 아니라 조건과 값이라는 것뿐이다.

flowchart LR
    S["=IF(G4>=500000, #quot;달성#quot;, #quot;미달#quot;)"] --> Q{"첫째 인수(조건)<br/>G4>=500000"}
    Q -->|"참"| T["둘째 인수의 값<br/>#quot;달성#quot;을 표시"]
    Q -->|"거짓"| F["셋째 인수의 값<br/>#quot;미달#quot;을 표시"]

그림 2. IF 함수의 흐름. 조건이 참이면 둘째 인수의 값이, 거짓이면 셋째 인수의 값이 셀에 표시된다.

4-4. 문자 값과 숫자 값의 표기

수식 안의 문자 값은 큰따옴표로 둘러싼다(지원 문서 「IF 함수」). 큰따옴표가 없는 문자는 함수 이름이나 셀 이름으로 해석된다. 숫자는 큰따옴표 없이, 천 단위 쉼표 없이 기재한다.

표기 엑셀의 해석
"달성" 문자 값 달성
달성 정의되지 않은 이름. #NAME? 오류가 발생한다
500000 숫자 500,000
500,000 숫자 500과 0의 두 인수. 인수의 수가 맞지 않아 수식이 입력되지 않는다
"500000" 문자 값. 숫자와의 크기 비교에 사용할 수 없다

IF의 결과가 문자이면 셀의 왼쪽에 맞추어지며, COUNT로 셀 수 없다. 실습 PC의 엑셀에서 =COUNT(I4:I22)는 0이었다.

4-5. IF 수식의 복사

IF 수식의 셀 주소도 상대 참조이다. I4의 수식을 아래로 복사하면 조건의 주소가 한 행씩 이동하고(I5는 =IF(G5>=500000,"달성","미달"), I23은 G23), 직접 기재한 상수(500000, “달성”, “미달”)는 변하지 않는다. 본 과목에서는 조건이 하나인 IF만 다루며, 조건의 결합이나 값을 셋 이상으로 구분하는 방법은 다루지 않는다.

4-6. #NAME? 오류

#NAME?는 수식 안의 글자를 엑셀이 함수 이름으로도 셀 주소로도 인식하지 못하였을 때 표시되며, 본 장에서 가장 자주 발생하는 오류 값이다.

원인 예 해결
함수 이름의 오타 =AVERGE(G4:G23) 이름을 수정한다. 수식 자동 완성의 목록에서 선택하면 발생하지 않는다
문자 값의 큰따옴표 누락 =IF(G4>=500000,달성,미달) 문자 값을 "달성", "미달"과 같이 큰따옴표로 둘러싼다
범위의 콜론 누락 =SUM(G4G23) G4:G23으로 수정한다
한글 입력 상태에서의 입력 =녀ㅡ(G4:G23) 한/영 키로 영문 입력 상태로 전환한 뒤 다시 입력한다

#NAME?가 표시된 셀에서 F2를 누르면 엑셀이 인식한 셀 주소에 색이 표시되므로, 함수 이름, 색이 있는 주소, 큰따옴표 안의 문자, 숫자의 어느 것도 아닌 글자를 찾는다.

5. IF 함수와 절대 참조

본 절은 연습용 통합 문서에서만 다루며, 셀 주소와 값은 2월 자료의 것이다. 핵심 실습의 수식은 4절과 같이 기준 금액을 상수로 기재한다.

5-1. 상수로 기재한 기준의 한계

=IF(G4>=500000,"달성","미달")은 기준 금액을 수식에 직접 기재하였으므로, 3장의 =30*24000과 같은 한계가 있다. 기준을 바꾸려면 첫 행의 수식을 고쳐 전체 행에 다시 복사하여야 하고, 수식을 열어 보기 전에는 기준이 얼마인지 알 수 없으며, 여러 열이 같은 기준을 쓰면 일부를 빠뜨리기 쉽다. 기준 금액을 표 바깥의 셀에 두고 수식이 그 셀을 참조하게 하면, 셀의 값 하나를 바꾸는 것으로 모든 행이 다시 계산된다.

5-2. 기준 값 셀의 참조

K2에 기준 금액을, K3에 500000을 입력하고 I4의 조건을 G4>=K3으로 작성하였다고 하자. 첫 행은 정확하나, 아래로 복사하면 3장의 구성비와 같은 문제가 생긴다.

셀 복사된 수식 비교하는 대상 결과
I4 =IF(G4>=K3,"달성","미달") 792,000과 500,000 달성(정상)
I5 =IF(G5>=K4,"달성","미달") 510,000과 빈 셀 달성
I6 =IF(G6>=K5,"달성","미달") 288,000과 빈 셀 달성(오류)

기준 금액의 주소가 한 행씩 내려가 빈 셀을 가리키고, 빈 셀은 0으로 간주되므로 19행이 모두 “달성”이 된다. 구성비의 #DIV/0!와 달리 오류 값이 표시되지 않으므로 건수를 기준 값과 대조하지 않으면 발견되지 않는다. 실습 PC의 엑셀에서 기준 금액을 0으로 두었을 때의 달성 건수도 19건이었다. 기준 금액의 주소를 절대 참조로 지정하면(=IF(G4>=$K$3,"달성","미달")) I6은 미달이 된다.

5-3. 판별 기준의 적용

3장의 판별 기준(“복사한 모든 행이 그 주소에서 같은 셀을 참조하여야 하는가”)을 적용하면, 행마다 자기 행의 금액을 비교하는 G4는 상대 참조, 하나의 셀에만 있는 기준 금액 K3은 절대 참조이다. 금액까지 $G$4로 지정하면 모든 행이 첫 행의 금액을 비교하여 19행의 결과가 모두 같아진다. 기준 값의 셀은 표와 떨어진 곳에 둔다. 표에 붙은 J 열에 값을 넣으면 5장의 정렬과 필터가 그 열까지를 자료 범위로 인식하므로, J 열을 비우고 K 열을 사용한다.

5-4. 기준 값의 변경과 재계산

기준 금액을 셀로 분리하면 K3만 바꾸어 여러 기준의 결과를 확인할 수 있다. 2월 자료에서 K3을 바꾸어 가며 센 달성 건수는 다음과 같다(실습 PC의 엑셀에서 확인).

K3의 값 달성 건수 달성한 판매번호

500,000 7건 1021, 1022, 1030, 1032, 1036, 1037, 1039

개념 점검

  1. =SUM(G4:G22)와 =SUM(G4,G22)는 인수의 수와 계산하는 셀의 수가 각각 몇 개인지 쓰고, 두 수식의 차이를 콜론과 쉼표의 의미로 설명하라.
  2. 판매 내역 표에서 =COUNT(D4:D23)(품목 열)의 결과를 쓰고 그 이유를 설명하라.

  4. =IF(E4>=30,"대량","소량")에서 E4의 값이 30일 때의 결과를 쓰고, 연산자를 >로 변경하면 결과가 어떻게 되는지 쓰라.
  5. 요약 행을 완성한 뒤 어떤 수강생의 최솟값이 20, 개수가 25로 나왔다. 수식을 보지 않고 결과만으로 범위가 어떻게 잘못되었는지 추론하고, 그렇게 판단한 근거를 두 가지 쓰라.

정리

용어 의미
함수 엑셀이 미리 정의한 계산. =함수이름(인수1, 인수2, …)의 형식으로 작성한다
인수 함수에 전달하는 값. 괄호 안에 기재하고 둘 이상이면 쉼표로 구분한다
범위 시작 셀과 끝 셀을 콜론으로 연결한 표기(G4:G23)
SUM, AVERAGE, MAX, MIN 범위 안의 숫자의 합계, 평균, 최댓값, 최솟값. 숫자가 없으면 AVERAGE는 #DIV/0!이다
COUNT 범위 안에서 숫자가 들어 있는 셀의 수. 빈 셀, 문자 셀, 오류 값은 세지 않는다
평균의 검산 평균 = 합계 ÷ 개수. 세 함수의 범위가 일치하는지 확인한다
조건, 비교 연산자 비교 연산자(>=, >, <, <=, =, <>)로 작성한 식. 결과는 TRUE 또는 FALSE이다
경곗값 기준과 정확히 같은 값. 이상(>=)과 초과(>)의 결과가 갈린다
IF 조건이 참이면 둘째 인수를, 거짓이면 셋째 인수를 표시하는 함수

본 장에서 산출한 금액의 합계 6,479,000, 평균 323,950, 최댓값 720,000, 최솟값 108,000은 8장에서 파이썬 코드의 결과를 검증하는 수작업 결과로 다시 사용한다. 5장 「정렬, 필터, 차트」에서는 본 장까지 작성한 표를 금액 기준으로 정렬하고 조건에 해당하는 행을 필터로 선별하며, 선별한 결과를 차트로 표현한다. 정렬한 결과의 첫 행과 마지막 행은 본 장의 최댓값과 최솟값으로 검산한다.
