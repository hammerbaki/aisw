[4장] 기본 함수

컴퓨터활용

4장

기본 함수

2027학년도 「컴퓨터활용」의 준비 중인 교재입니다. 편집 상태를 검토하기 위해 미리 공개한 것으로, 수업 전에 내용과 순서가 바뀔 수 있습니다.

학사 5주차 · 교재 04 · 1부 엑셀

본 장은 엑셀의 함수를 다룬다. 3장에서 자동 합계 단추가 입력한 =SUM(G4:G23)을 출발점으로 하여 함수의 일반 형식(이름, 괄호, 인수, 범위)을 살펴보고, 같은 형식으로 평균, 최댓값, 최솟값, 개수를 산출한다. 이어서 조건에 따라 값을 둘로 구분하는 IF 함수를 작성한다. 본 장에서 다루는 함수는 SUM, AVERAGE, MAX, MIN, COUNT, IF의 6개이다. 함수의 종류를 많이 아는 것이 아니라 함수의 형식을 정확히 읽고 작성하는 것이 본 장의 목표이며, 이 형식은 엑셀의 모든 함수에 동일하게 적용된다.

수업은 3장과 같이 두 개의 통합 문서로 진행한다. 1~5절에서는 절마다 설명에 이어 「따라 하기」를 연습용 통합 문서(2월 자료)에서 수행하고, 6절의 핵심 실습에서는 본인의 판매 현황 통합 문서(1월 자료)에 요약 행과 목표 달성 열을 작성하여 제출한다. 각 단계의 끝에 있는 [확인]은 그 단계를 마쳤을 때 화면에서 관찰되어야 하는 상태이다.

3장과 같이 따라 하기와 핵심 실습은 예상, 실행, 결과 읽기의 순서로 진행한다. 함수는 범위 안의 값을 하나로 요약하므로, 결과 하나만 보아서는 그 값이 맞는지 판단하기 어렵다. 함수를 입력하기 전에 “결과가 대략 얼마쯤이어야 하는가”, “빈 셀이나 문자 셀이 섞이면 결과가 커지는가 작아지는가”를 먼저 예상해 두면, 범위를 잘못 지정하였을 때 결과가 예상에서 크게 벗어나므로 즉시 알아차릴 수 있다. 본 장에서는 특히 평균 = 합계 ÷ 개수의 관계로 세 함수의 결과를 서로 검산하는 방법을 되풀이한다.

수업 시간의 범위. 150분 수업에서는 번호를 붙인 절의 설명과 따라 하기, 핵심 실습까지 한다. 제목에 [선택]이 붙은 곳(3절의 따라 하기(상태 표시줄과 요약 행의 대조), 4-7 숫자를 돌려주는 IF, 4절의 따라 하기(숫자를 돌려주는 IF))과 심화 실습, 남은 연습 문제는 시간이 남을 때나 수업 뒤에 한다.

학습 목표

  1. 함수의 일반 형식을 구성하는 요소(함수 이름, 괄호, 인수, 범위)를 설명하고, 쉼표와 콜론의 의미를 구분한다.
  2. 함수를 직접 입력, [함수 삽입] 대화 상자, [자동 합계] 목록의 세 가지 방법으로 입력하고, [함수 인수] 대화 상자에 미리 표시되는 결과로 범위를 점검한다.
  3. SUM, AVERAGE, MAX, MIN, COUNT로 금액 열의 요약 값을 산출하고, 빈 셀, 문자 셀, 0이 든 셀이 각 함수의 결과에 미치는 영향을 예상하고 확인한다.
  4. 평균 = 합계 ÷ 개수의 관계로 요약 값을 검산하고, 범위를 잘못 지정한 경우의 결과를 읽어 원인을 찾는다.
  5. 비교 연산자로 조건을 작성하고, 경곗값의 포함 여부를 판단하여 단일 조건의 IF 함수로 목표 달성 여부를 표시한다.
  6. 기준 값을 별도의 셀에 두고 절대 참조로 참조하는 IF 수식을 작성한다.

1. 함수의 형식

1-1. 함수의 구성 요소

함수는 자주 사용하는 계산을 엑셀이 미리 정의하여 이름을 붙여 둔 것이다. 금액 20개의 합계를 =G4+G5+G6+…+G23과 같이 작성할 수도 있으나, 함수를 사용하면 =SUM(G4:G23)으로 작성할 수 있다. 3장에서 자동 합계 단추가 G25에 입력한 수식이 이것이다.

=SUM(G4:G23)은 다음의 요소로 구성된다.

구성 요소 설명 예
등호 수식의 시작을 나타낸다. 함수도 수식이므로 등호로 시작한다 =
함수 이름 수행할 계산의 종류를 나타낸다 SUM
괄호 함수 이름의 바로 뒤에 붙으며 인수를 둘러싼다. 여는 괄호와 닫는 괄호가 짝을 이룬다 (, )
인수 함수에 전달하는 값이다. 계산의 대상이 된다 G4:G23

함수의 일반 형식은 다음과 같다.

=함수이름(인수1, 인수2, …)

인수가 둘 이상이면 쉼표로 구분한다. 인수의 개수와 의미는 함수마다 정해져 있다. 함수 이름은 대문자와 소문자를 구분하지 않으며, =sum(g4:g23)으로 입력하여도 엑셀이 대문자로 바꾸어 저장한다.

그림 1. 함수의 구성 요소. 함수의 종류가 달라져도 이름, 괄호, 인수의 형식은 같다.

Microsoft의 지원 문서 「Excel에서 수식 손상을 방지하는 방법」은 함수를 작성할 때 지킬 규칙으로 함수를 등호로 시작할 것, 여는 괄호와 닫는 괄호의 짝을 맞출 것, 필요한 인수를 모두 넣을 것, 숫자를 천 단위 구분 기호나 통화 기호 없이 입력할 것, 수식 안의 텍스트를 따옴표로 묶을 것을 든다. 본 장의 오류 대부분은 이 다섯 규칙 가운데 하나를 어긴 것이다. 같은 문서는 인수를 구분하는 기호가 운영 체제의 지역 설정과 엑셀의 설정에 따라 쉼표 또는 세미콜론일 수 있다고 적는다. 한국어 설정의 실습실 PC에서는 쉼표이다.

1-2. 범위의 표기

연속된 셀의 묶음인 범위는 시작 셀과 끝 셀을 콜론(:)으로 연결하여 표기한다. 콜론과 쉼표는 의미가 다르다.

표기 의미 셀의 수
G4:G23 G4부터 G23까지의 범위 20개
G4,G23 G4와 G23의 두 셀 2개
E4:F23 E4부터 F23까지의 직사각형 범위 40개

=SUM(G4:G23)은 인수가 하나(범위 하나)인 함수이고, =SUM(G4,G23)은 인수가 둘(셀 둘)인 함수이다. 앞의 결과는 6,479,000이고 뒤의 결과는 G4와 G23만을 더한 848,000이다.

범위에 든 셀의 수는 끝 행 번호에서 시작 행 번호를 빼고 1을 더하여 구한다. G4:G23은 23 - 4 + 1 = 20개이다. 이 계산은 뒤에서 COUNT의 결과를 예상할 때 그대로 쓰인다. 범위에 든 셀이 20개이면 COUNT의 결과는 20을 넘을 수 없다.

1-3. 인수의 구분

인수의 자리에는 범위, 셀 하나, 숫자가 올 수 있고, 서로 다른 종류를 쉼표로 이어 여러 개 전달할 수 있다. 엑셀은 쉼표를 만날 때마다 인수가 하나 끝난 것으로 해석한다.

수식 인수의 수 인수의 내용 결과
=SUM(G4:G23) 1 범위 하나 6,479,000
=SUM(G4:G13,G14:G23) 2 범위 둘. 앞의 10행과 뒤의 10행 6,479,000
=SUM(G4,G23) 2 셀 둘 848,000
=SUM(G4:G23,100000) 2 범위 하나와 숫자 하나 6,579,000

함수를 읽을 때에는 다음의 순서를 따른다.

  1. 함수 이름으로 계산의 종류를 확인한다.
  2. 괄호 안의 쉼표를 세어 인수의 수를 확인한다. 쉼표가 없으면 인수는 하나이다.
  3. 인수마다 콜론이 있는지를 확인한다. 콜론이 있으면 범위이고 없으면 셀 하나 또는 값이다.

숫자를 인수로 기재할 때 천 단위 쉼표를 넣으면 엑셀은 그 쉼표를 인수의 구분으로 해석한다. =SUM(G4:G23,100,000)은 범위, 100, 0의 세 인수가 되어 결과가 6,479,100이 된다. 오류 값이 표시되지 않으므로 결과만으로는 발견하기 어렵다.

2. 함수의 입력 방법

함수를 셀에 입력하는 방법은 세 가지이다. 어느 방법을 사용하여도 셀에 저장되는 수식은 같다.

2-1. 직접 입력과 수식 자동 완성

함수는 다음의 절차로 직접 입력한다.

  1. 결과를 표시할 셀을 선택하고 =와 함수 이름의 앞 글자를 입력한다. =AV까지 입력하면 해당 글자로 시작하는 함수의 목록이 표시된다. 이 목록을 수식 자동 완성이라고 한다.
  2. 목록에서 방향키로 함수를 선택하고 Tab을 누른다. 함수 이름과 여는 괄호가 입력된다. 함수 이름과 여는 괄호를 직접 입력하여도 된다.
  3. 범위의 첫 셀부터 마지막 셀까지 마우스로 끈다. 범위가 수식에 기재된다.
  4. 닫는 괄호를 입력하고 Enter를 누른다.

여는 괄호를 입력하면 셀의 아래에 AVERAGE(number1, [number2], ...)와 같이 인수의 형식이 표시된다. 대괄호로 둘러싸인 인수는 생략할 수 있는 인수이다. 수식 자동 완성의 목록에서 함수를 선택하면 이름의 오타가 발생하지 않는다. 목록이 표시되지 않으면 등호를 입력하지 않았거나 한글 입력 상태인 것이다.

[그림 자리: 수식 자동 완성 목록과 인수의 형식] 셀에 =AV를 입력하였을 때 표시되는 수식 자동 완성 목록과, 여는 괄호를 입력한 뒤 셀 아래에 AVERAGE(number1, [number2], ...)가 표시된 모습. 찍을 곳: Microsoft 365 엑셀, 연습용 통합 문서의 G25.

2-2. 함수 삽입 대화 상자

함수의 이름이나 인수의 순서가 기억나지 않을 때에는 [함수 삽입] 대화 상자를 사용한다. 수식 입력줄의 왼쪽에 있는 [함수 삽입] 단추(fx)를 누르거나 Shift + F3을 누르면 열린다. [수식] 탭의 [함수 라이브러리] 그룹에 있는 [함수 삽입]도 같은 대화 상자를 연다.

  1. 결과를 표시할 셀을 선택하고 [함수 삽입] 단추를 누른다.
  2. [함수 검색] 상자에 함수 이름을 입력하여 찾거나 [범주 선택] 상자에서 범주를 선택한 뒤, 목록에서 함수를 선택하고 [확인]을 누른다.
  3. [함수 인수] 대화 상자가 열린다. 인수의 입력란에 범위를 직접 입력하거나, 입력란을 누른 뒤 시트에서 범위를 끌어 지정한다.
  4. [확인]을 누른다.

[함수 인수] 대화 상자는 인수마다 입력란을 따로 제시하고, 선택한 인수의 설명을 함께 표시한다. 괄호와 쉼표는 엑셀이 대신 기재하므로 입력하지 않는다. 다만 입력란에는 엑셀이 추정한 범위가 미리 기재되어 있을 수 있으므로, 그 범위가 의도와 일치하는지 반드시 확인하고 다르면 지운 뒤 다시 지정한다.

버전에 따른 차이: [함수 삽입] 단추를 눌렀을 때 열리는 대화 상자의 제목이 [함수 마법사]로 표시되는 버전이 있다. 구성과 조작은 같다.

2-3. 결과 미리 보기의 읽기

[함수 인수] 대화 상자의 쓸모는 인수를 칸마다 나누어 입력하게 하는 데만 있지 않다. 지원 문서 「Excel 수식에서 함수 및 중첩된 함수 사용」은 이 대화 상자가 함수의 현재 결과와 수식 전체의 현재 결과를 표시한다고 설명한다. 즉 [확인]을 누르기 전에 결과를 미리 볼 수 있다. 이 미리 보기는 범위를 잘못 지정하였는지를 확정하기 전에 알려 주는 검산 도구가 된다.

미리 보기를 읽는 순서는 다음과 같다.

  1. 입력란의 범위를 읽는다. 시작 셀과 끝 셀이 자료의 첫 행과 마지막 행인지 확인한다(2월 자료는 G4:G22).
  2. 미리 표시된 결과를 예상과 비교한다. 금액의 최댓값은 금액 열의 어느 값보다도 클 수 없고, 평균은 최솟값과 최댓값의 사이에 있어야 하며, 개수는 범위의 셀 수(19)를 넘을 수 없다.
  3. 예상에서 벗어나면 [확인]을 누르지 않는다. 입력란의 내용을 지우고 범위를 다시 끈 뒤, 미리 보기가 바뀌는 것을 확인하고 [확인]을 누른다.

예를 들어 2월 자료의 G26(최댓값)에서 대화 상자를 열었을 때 입력란에 바로 위의 요약 값인 G24:G25가 제시되어 있다면, 미리 보기에는 합계 8,016,000이 최댓값으로 표시된다. 금액 한 건이 월 매출 전체와 같을 수는 없으므로 범위가 틀렸다는 것을 [확인]을 누르기 전에 알 수 있다. 범위를 G4:G22로 다시 지정하면 미리 보기가 912,000으로 바뀐다.

입력란 G24:G25   →  미리 보기 8016000   (요약 행이 범위로 제시되었다)
입력란 G4:G22    →  미리 보기 912000    (판매번호 1036의 금액)

[그림 자리: 함수 인수 대화 상자의 결과 미리 보기] MAX 함수의 [함수 인수] 대화 상자. 첫째 입력란에 G4:G22가 기재되고, 입력란 옆과 대화 상자 아래쪽에 계산 결과 912000이 표시된 모습. 찍을 곳: Microsoft 365 엑셀, 연습용 통합 문서의 G26에서 [함수 삽입].

2-4. 자동 합계 목록

[홈] 탭 → [편집] 그룹 → [자동 합계] 단추의 옆에 있는 화살표를 누르면 목록이 열린다. 목록에서 [평균], [최대값], [최소값]을 선택하면 해당 함수가 셀에 입력되며, 개수를 산출하는 항목은 같은 목록의 [숫자 개수]이다. 입력되는 방식은 3장의 자동 합계와 같다. 엑셀이 추정한 범위가 점선으로 표시되고 Enter를 누르면 확정된다.

이 방법은 가장 빠르지만 범위를 엑셀이 추정한다는 점에 유의하여야 한다. 요약 행은 자료의 아래쪽에 빈 행을 두고 차례로 놓이므로, 둘째 요약 행부터는 바로 위의 요약 값(합계, 평균 등)이 범위로 제시되기 쉽다. 점선의 범위가 자료의 범위와 다르면 Enter를 누르기 전에 자료의 첫 셀부터 마지막 셀까지 끌어 다시 지정한다.

엑셀의 메뉴와 지원 문서는 “최대값”, “최소값”으로 표기한다. 본 교재는 본문에서 “최댓값”, “최솟값”으로 쓰고, 메뉴의 이름을 가리킬 때에만 화면의 표기를 따른다.

2-5. 범위를 지정하는 방법

함수의 인수인 범위는 마우스로 끌어 지정하거나 주소를 직접 입력하여 지정한다.

방법 조작 장점 유의점
마우스로 끈다 여는 괄호를 입력한 뒤 범위의 첫 셀에서 마지막 셀까지 끈다 주소의 오타가 없다. 선택한 범위가 점선으로 표시되어 눈으로 확인된다 한 행을 더 끌거나 덜 끌기 쉽다. 끈 뒤 수식의 행 번호를 읽는다
주소를 입력한다 G4:G22와 같이 시작 셀, 콜론, 끝 셀을 입력한다 범위가 화면을 벗어날 만큼 길어도 정확하다 콜론을 빠뜨리거나 열 문자를 잘못 입력하기 쉽다

어느 방법으로 지정하였든 입력을 마친 뒤에는 수식 입력줄에서 범위의 시작 셀과 끝 셀을 읽어 자료의 첫 행과 마지막 행인지를 확인한다. 셀에서 F2를 눌러 색 테두리가 자료의 범위와 일치하는지를 보는 방법도 같은 확인이다.

3. 요약 함수

3-1. SUM, AVERAGE, MAX, MIN, COUNT

다수의 값을 하나의 값으로 요약하는 함수 5개를 다룬다. 다섯 함수는 이름만 다르고 형식이 같다. 인수로 범위 하나를 전달하면 그 범위의 숫자를 대상으로 계산한다.

함수 산출하는 값 수식 결과
SUM 합계 =SUM(G4:G23) 6,479,000
AVERAGE 평균(합계를 개수로 나눈 값) =AVERAGE(G4:G23) 323,950
MAX 최댓값(가장 큰 값) =MAX(G4:G23) 720,000
MIN 최솟값(가장 작은 값) =MIN(G4:G23) 108,000
COUNT 개수(숫자가 들어 있는 셀의 수) =COUNT(G4:G23) 20

범위를 선택하였을 때 상태 표시줄에 표시되는 평균과 합계는 위의 함수와 같은 값이다. 상태 표시줄의 값은 선택을 해제하면 사라지지만 함수의 결과는 셀에 남아 다른 수식에서 참조할 수 있다.

상태 표시줄의 [개수]는 COUNT와 같지 않을 수 있다. 지원 문서 「Excel 상태 표시줄 옵션」에 따르면 상태 표시줄의 [개수]는 선택한 셀의 수를 표시하고, 숫자 값이 들어 있는 셀만 세는 항목은 [숫자 개수]로 따로 있으며 이 항목은 기본으로 꺼져 있다. 같은 문서는 [최소]와 [최대]도 기본으로 꺼져 있는 항목으로 적는다. 금액 열처럼 모든 셀이 숫자인 범위에서는 두 값이 같지만, 거래처 열(C4:C22)을 선택하면 상태 표시줄의 [개수]는 19를 표시하는 반면 =COUNT(C4:C22)의 결과는 0이다. 상태 표시줄의 [개수]로 COUNT를 검산할 때에는 범위가 모두 숫자인지를 먼저 확인한다.

3-2. 숫자가 아닌 셀의 처리

다섯 함수는 범위 안의 숫자만을 계산의 대상으로 한다. 빈 셀과 문자가 들어 있는 셀은 제외된다. COUNT로 여러 열의 개수를 산출하면 이 규칙을 확인할 수 있다.

수식 결과 이유
=COUNT(A4:A23) 20 판매번호는 숫자이다
=COUNT(B4:B23) 20 날짜는 숫자로 저장된다(2장)
=COUNT(C4:C23) 0 거래처는 문자이다
=COUNT(A3:A23) 20 머리글 A3은 문자이므로 제외된다
=COUNT(G4:G24) 20 빈 셀 G24는 제외된다

지원 문서 「COUNT 함수」는 인수가 범위(참조)인 경우 그 안의 숫자만 세며 빈 셀, 논리값, 텍스트, 오류 값은 세지 않는다고 설명한다. COUNT는 “행의 수”가 아니라 “숫자가 들어 있는 셀의 수”를 센다. 금액 열의 개수가 20이 아니라면 금액 열에 숫자가 아닌 값이 들어 있는 것이다. 따라서 COUNT의 결과는 그 자체로 자료의 점검 수단이 된다.

빈 셀과 값이 0인 셀은 다르게 처리된다. 지원 문서 「AVERAGE 함수」는 범위에 텍스트, 논리값, 빈 셀이 있으면 무시되지만 값이 0인 셀은 평균에 포함된다고 설명한다. 합계에서는 두 경우의 결과가 같으나 평균과 개수에서는 달라진다. 수량 열(E4:E23)에서 판매번호 1002의 수량(E5, 50)을 지운 경우와 0으로 변경한 경우를 비교하면 다음과 같다.

E5의 상태 =SUM(E4:E23) =COUNT(E4:E23) =AVERAGE(E4:E23)
50(원래의 값) 493 20 24.65
빈 셀 443 19 23.32
0 443 20 22.15

문자 셀은 빈 셀과 같이 처리된다. E5에 50개를 입력하면 수량 열의 SUM, COUNT, AVERAGE는 빈 셀일 때와 같은 443, 19, 23.32이다. 함수의 결과만으로는 그 셀이 비었는지 문자인지 구별되지 않는다.

문자만 있는 범위를 전달하면 계산할 숫자가 없으므로 SUM, MAX, MIN은 0을 표시한다. =MAX(C4:C23)은 오류 값이 아니라 0이다. 그러나 AVERAGE는 다르다. 숫자가 하나도 없으면 합계를 개수 0으로 나누게 되므로 #DIV/0!가 표시된다. 실습 PC의 엑셀에서 빈 셀 세 개의 범위에 다섯 함수를 적용한 결과는 다음과 같았다.

=SUM(빈 범위)       0
=MAX(빈 범위)       0
=COUNT(빈 범위)     0
=AVERAGE(빈 범위)   #DIV/0!

한편 3장의 사칙 수식은 문자를 만나면 #VALUE!를 표시한다. =C4+C5는 #VALUE!이고 =SUM(C4:C5)는 0이다. 함수는 범위 안의 문자를 건너뛰고 연산자는 건너뛰지 않는다는 차이이다.

범위에 오류 값이 있는 셀이 포함되면 SUM, AVERAGE, MAX, MIN은 같은 오류 값을 표시한다. 3장에서 금액의 한 셀이 #VALUE!일 때 합계가 #VALUE!가 된 것이 이 규칙이다. COUNT만은 오류 값을 세지 않을 뿐 오류를 전달하지 않으므로, 다른 네 요약 값이 모두 #VALUE!일 때 COUNT는 오류 셀을 뺀 개수를 표시한다.

3-3. 결과의 예상: 빈 셀, 문자 셀, 0

함수를 쓰기 전에 다음의 표로 결과를 예상해 두면, 자료에 섞인 빈 셀이나 문자를 결과에서 거꾸로 읽어 낼 수 있다. 표는 범위 안의 한 셀이 원래 숫자였다가 빈 셀, 문자, 0으로 바뀐 경우에 각 함수의 결과가 원래보다 어떻게 되는지를 정리한 것이다.

바뀐 셀 SUM COUNT AVERAGE MAX, MIN
빈 셀 그 값만큼 작아진다 1 작아진다 남은 값의 평균. 지운 값이 평균보다 작았으면 커지고 컸으면 작아진다 지운 값이 최댓값이나 최솟값이었으면 다음 값으로 바뀐다
문자 빈 셀과 같다 빈 셀과 같다 빈 셀과 같다 빈 셀과 같다
0 그 값만큼 작아진다 변하지 않는다 0이 포함되므로 빈 셀일 때보다 작다 MIN이 0이 된다(음수가 없는 자료)

금액 열(G 열)은 수식이므로 상황이 한 단계 더 복잡하다. 수량 셀을 지우면 금액 수식은 빈 셀을 0으로 계산하여 0을 돌려주므로, 금액 열에서는 “빈 셀”이 아니라 “0”이 생긴다. 수량 셀에 문자를 넣으면 금액 수식이 #VALUE!가 되어 요약 함수에 오류가 전달된다. 2월 자료의 판매번호 1022(E5 6, G5 510,000)에 차례로 조작을 가하고 요약 행(G24:G28)을 읽은 결과는 다음과 같다. 실습 PC의 엑셀에서 확인한 값이다.

조작 G5 합계 G24 평균 G25 최솟값 G27 개수 G28
원래의 상태 510,000 8,016,000 421,894.7 104,000 19
E5를 Delete 0 7,506,000 395,052.6 0 19
E5에 6개 #VALUE! #VALUE! #VALUE! #VALUE! 18
G5를 Delete(수식을 지움) 빈 셀 7,506,000 417,000 104,000 18
G5에 0을 입력 0 7,506,000 395,052.6 0 19

이 표에서 읽을 것은 세 가지이다. 첫째, 최솟값이 0이면 금액이 0인 행(대개 수량이 빈 행)이 있다. 둘째, 개수가 행의 수보다 작으면 금액 열에 비었거나 숫자가 아닌 셀이 있다. 셋째, 다른 요약 값이 모두 오류인데 개수만 숫자이면 금액 열의 어느 셀이 오류 값이다. 요약 행은 표를 요약하는 동시에 표의 상태를 진단하는 도구이다.

3-4. 평균의 검산

평균은 합계를 개수로 나눈 값이므로 세 요약 값 사이에는 “평균 = 합계 ÷ 개수”의 관계가 성립한다. 1월 자료에서는 6,479,000 ÷ 20 = 323,950이다. 요약 행을 작성한 뒤 빈 셀에 =G25/G29를 입력하여 G26의 평균과 같은지를 확인하면, 세 함수의 범위가 서로 일치하는지를 한 번에 검산할 수 있다. 두 값이 다르면 세 함수 가운데 범위가 다른 것이 있다.

G25 합계      =SUM(G4:G23)       6479000
G29 개수      =COUNT(G4:G23)     20
검산          =G25/G29           323950
G26 평균      =AVERAGE(G4:G23)   323950     (검산과 같으면 세 범위가 일치한다)

검산이 맞는 까닭은 AVERAGE의 정의 자체에 있다. AVERAGE는 범위의 숫자를 모두 더한 뒤 숫자가 든 셀의 수로 나눈다. 같은 범위에서 SUM과 COUNT를 따로 구하여 나누면 같은 계산을 두 단계로 나누어 한 것이 된다. 그러므로 검산이 어긋난다면 계산이 아니라 범위가 다르다고 판단할 수 있다.

평균 = 합계 ÷ 개수 외에도, 같은 범위로 구한 다섯 요약 값 사이에는 언제나 성립하는 관계가 있다. 금액처럼 음수가 없는 자료라면 다음의 네 관계가 모두 성립하여야 하며, 하나라도 어긋나면 범위나 자료에 문제가 있다. 이 관계는 함수의 정의에서 바로 나오는 것이므로 자료가 바뀌어도 그대로 쓸 수 있다.

관계 1월 자료의 값 어긋날 때 의심할 것
최솟값 ≤ 평균 ≤ 최댓값 108,000 ≤ 323,950 ≤ 720,000 평균과 최솟값·최댓값의 범위가 서로 다르다
최댓값 ≤ 합계 720,000 ≤ 6,479,000 최댓값의 범위에 합계보다 큰 값(다른 달의 합계 등)이 들어갔다
개수 ≤ 범위의 셀 수 20 ≤ 20(G4:G23) 개수의 범위가 자료보다 넓다
합계 = 평균 × 개수 323,950 × 20 = 6,479,000 세 함수의 범위가 서로 다르다(3-4의 검산과 같다)

요약 행을 작성한 직후 이 네 관계를 눈으로 훑으면 몇 초 안에 끝난다. 특히 첫째 관계는 암산이 필요 없으므로, 평균이 최솟값보다 작거나 최댓값보다 크게 나오면 즉시 범위를 확인한다. 반대로 네 관계가 모두 성립한다고 해서 값이 맞는 것은 아니다. 세 함수가 똑같이 틀린 범위(예: 한 행을 빠뜨린 G4:G22)를 쓰면 관계는 모두 성립하지만 값은 기준 값과 다르다. 관계의 점검은 기준 값과의 대조를 대신하지 않고, 대조하기 전에 큰 오류를 먼저 걸러 내는 단계이다.

평균은 나누어떨어지지 않는 경우가 많다. 2월 자료의 평균은 8,016,000 ÷ 19 = 421,894.7368…이다. 이 셀에 통화 형식을 적용하면 ₩421,895로 표시되지만 저장된 값은 변하지 않는다. 표시 형식은 표시할 자릿수에서 반올림한 모습을 보여 줄 뿐이며, 이 셀을 참조하는 수식은 저장된 값 421,894.7368…로 계산한다. 3장 4-6의 구성비 합계와 같은 원리이다. [홈] 탭 → [표시 형식] 그룹 → [자릿수 늘림]을 누르면 표시되는 소수 자릿수가 하나씩 늘어난다.

3-5. 범위 오류의 결과 읽기

함수는 전달된 범위를 그대로 계산하며, 범위가 의도와 일치하는지는 판단하지 않는다. 범위에 합계 셀이 포함되면 오류 표시 없이 잘못된 값이 산출된다.

수식 결과 내용
=AVERAGE(G4:G23) 323,950 정상
=AVERAGE(G4:G25) 617,048 합계 G25를 포함한 21개 값의 평균이다
=MAX(G4:G25) 6,479,000 합계가 최댓값으로 산출된다
=COUNT(G4:G25) 21 합계 셀이 개수에 포함된다

요약 행 전체가 범위에 들어가면 결과는 더 이상해진다. 요약 행 다섯 개를 완성한 뒤 범위를 G4:G29로 잘못 지정한 경우를 1월 자료로 확인하면 다음과 같다.

수식 결과 결과에서 읽을 것
=COUNT(G4:G29) 25 자료 20개에 요약 값 5개(합계, 평균, 최댓값, 최솟값, 개수)가 더해졌다. 빈 행 24는 세지 않는다
=MIN(G4:G29) 20 최솟값이 개수 셀의 값 20이 되었다. 금액이 20원일 수는 없다
=MAX(G4:G29) 6,479,000 최댓값이 합계와 같다
=AVERAGE(G4:G29) 564,398.8 최댓값(720,000)과 최솟값(108,000)의 사이에 있기는 하지만 정상 평균(323,950)의 1.7배이다

이런 오류는 결과만 보아서도 판정할 수 있다. 읽는 기준은 다음과 같다.

  • 개수가 행의 수보다 크다. 범위에 자료가 아닌 숫자(요약 값)가 들어갔다.
  • 최댓값이 합계와 같거나, 최솟값이 개수와 같다. 요약 행이 범위에 들어갔다.
  • 평균이 최솟값보다 작거나 최댓값보다 크다. 서로 다른 범위로 구한 값을 비교하고 있다.
  • 평균 ≠ 합계 ÷ 개수이다. 세 함수의 범위가 서로 다르다(3-4).

G25의 합계 수식을 채우기 핸들로 아래로 복사하는 것도 같은 종류의 오류를 발생시킨다. 범위 G4:G23은 상대 참조이므로 G26으로 복사하면 =SUM(G5:G24)가 되어 첫 행이 제외된 5,759,000이 산출된다. 같은 방식으로 다른 함수를 한 행씩 밀린 범위로 작성하면 평균 303,105.3, 최댓값 680,000, 개수 19가 되어, 판매번호 1001의 금액 720,000이 빠진 결과가 된다. 요약 행의 함수는 복사하지 않고 각각 입력하며, 입력한 뒤에는 수식 입력줄에서 범위가 G4:G23인지 확인한다.

범위에 함수가 있는 셀 자신이 들어가면 3장 5-5의 순환 참조가 된다. G26에 =AVERAGE(G4:G26)을 입력하는 경우이다. 실습 PC의 엑셀에서 같은 꼴의 수식(2월 자료의 G25에 =AVERAGE(G4:G25))을 넣었을 때 셀의 값은 0이었고, 그 셀이 순환 참조로 보고되었다. 평균이 0으로 보이면 범위의 끝 셀이 그 셀 자신인지를 먼저 확인한다.

따라 하기

연습용 통합 문서에서 COUNT를 여러 열에 적용하여 숫자만 센다는 규칙을 확인하고, 평균을 검산하며, 빈 셀·문자 셀·0의 차이와 범위 오류를 재현한다. K 열에 입력한 내용은 마지막에 지운다.

예상. 판매번호(A), 판매일(B), 거래처(C) 열과, 머리글을 포함한 판매번호 열에 COUNT를 적용하면 각각 얼마인가. 2월 자료는 19행이다.

  1. K4에 =COUNT(A4:A22), K5에 =COUNT(B4:B22), K6에 =COUNT(C4:C22), K7에 =COUNT(A3:A22)를 입력한다.
  2. C4:C22를 선택하여 상태 표시줄의 [개수]를 읽는다.
  • 확인 9 K4:K7의 값이 차례로 19, 19, 0, 19이다. 판매번호와 판매일은 세어지고 거래처와 머리글은 세어지지 않았다. C4:C22를 선택한 상태 표시줄의 [개수]는 19였다.
  1. K8에 =G24/G28을 입력하여 G25의 값과 비교한다.
  2. G24를 선택하고 [홈] 탭 → [클립보드] 그룹 → [서식 복사]를 누른 뒤 G25:G27을 끈다.
  3. G25를 선택하고 [홈] 탭 → [표시 형식] 그룹 → [자릿수 늘림]을 한 번 누른다. 표시를 읽은 뒤 Ctrl + Z를 누른다.

4. IF 함수

4-1. 비교 연산자와 조건

두 값의 크기를 비교하는 식을 조건이라고 하며, 조건의 결과는 참(TRUE) 또는 거짓(FALSE)의 둘 중 하나이다. 지원 문서 「Excel의 계산 연산자 및 우선 순위」는 비교 연산자로 두 값을 비교한 결과가 TRUE 또는 FALSE의 논리값이 된다고 설명한다. 조건은 비교 연산자로 작성한다. G4의 값이 720,000일 때의 결과는 다음과 같다.

연산자 의미 조건 결과
>= 이상(크거나 같다) G4>=500000 TRUE
> 초과(크다) G4>500000 TRUE
< 미만(작다) G4<500000 FALSE
<= 이하(작거나 같다) G4<=500000 FALSE
= 같다 G4=720000 TRUE
<> 같지 않다 G4<>720000 FALSE
  • 빈 셀에 =G4>=500000을 입력하면 셀에 TRUE가 표시된다. 조건도 수식이다.
  • 두 글자로 된 연산자는 순서를 지켜 입력한다. >=를 =>로, <>를 ><로 입력하면 수식이 입력되지 않는다.
  • 비교 연산자는 사칙 연산자보다 나중에 계산된다. 같은 지원 문서의 우선순위 표에서 비교 연산자는 맨 아래에 있다. =E4*F4>=500000은 곱하기를 먼저 계산한 뒤 그 결과를 500,000과 비교한다.
  • 비교의 대상이 빈 셀이면 빈 셀은 0으로 간주된다. 빈 셀에 대한 >=500000은 거짓이고 >=0은 참이다.

4-2. 경곗값과 비교 연산자별 결과

“이상”과 “초과”는 경계 값에서 결과가 달라진다. 목표 금액 500,000원을 기준으로, 금액이 경계의 바로 아래(499,999), 경계(500,000), 경계의 바로 위(500,001)인 세 경우에 연산자마다 IF의 결과가 어떻게 되는지를 정리하면 다음과 같다. 수식은 =IF(금액 연산자 500000,"달성","미달")의 꼴이며, 실습 PC의 엑셀에서 세 값을 셀에 넣고 확인한 결과이다.

연산자 499,999 500,000 500,001 500,000을 “달성”에 포함하는가
>= 미달 달성 달성 포함한다(이상)
> 미달 미달 달성 포함하지 않는다(초과)
< 달성 미달 미달 포함하지 않는다(미만)
<= 달성 달성 미달 포함한다(이하)
= 미달 달성 미달 경계 하나만 달성이다
<> 달성 미달 달성 경계 하나만 미달이다

표의 가운데 열(500,000)만 연산자에 따라 결과가 갈린다. >=와 >는 경계 아래와 위에서는 같은 결과를 내므로, 자료에 경곗값과 정확히 같은 금액이 없으면 두 연산자의 차이가 결과에 드러나지 않는다. 1월 자료에는 금액이 정확히 500,000원인 행이 없으므로 핵심 실습에서는 >=로 쓰든 >로 쓰든 달성 건수가 5건으로 같다. 그러나 2월 자료에서 기준을 720,000원으로 하면 금액이 정확히 720,000원인 판매번호 1030의 결과가 연산자에 따라 달라진다(5-4). 결과가 같다고 해서 조건이 맞는 것은 아니다.

문장으로 주어진 기준을 조건으로 옮길 때에는 다음의 순서를 따른다.

  1. 기준의 말을 찾는다. “이상”, “이하”는 경계를 포함하고, “초과”, “미만”은 포함하지 않는다.
  2. 경곗값을 하나 골라 넣어 본다. “500,000원 이상이면 달성”에서 금액이 500,000원이면 달성이어야 한다.
  3. 2의 결과가 나오는 연산자를 위의 표에서 고른다(>=).

4-3. IF의 형식

IF는 조건의 결과에 따라 두 값 중 하나를 표시하는 함수이다. 인수는 3개이며 쉼표로 구분한다.

=IF(조건, 참일 때의 값, 거짓일 때의 값)
인수 내용 예
첫째 인수 조건 G4>=500000
둘째 인수 조건이 참일 때 표시할 값 "달성"
셋째 인수 조건이 거짓일 때 표시할 값 "미달"

=IF(G4>=500000,"달성","미달")은 “G4의 값이 500,000 이상이면 달성을, 그렇지 않으면 미달을 표시한다”로 읽는다. 엑셀은 조건을 먼저 계산하고, 그 결과에 따라 둘째 인수 또는 셋째 인수를 셀에 표시한다. 지원 문서 「IF 함수」도 첫 번째 결과는 비교가 참인 경우, 두 번째 결과는 비교가 거짓인 경우라고 설명한다.

행 금액 조건의 결과 표시되는 값
4(판매번호 1001) 720,000 TRUE 달성
5(판매번호 1002) 300,000 FALSE 미달

IF도 1절의 일반 형식을 따른다. 함수 이름, 괄호, 쉼표로 구분된 인수로 구성되며, 요약 함수와 다른 점은 인수가 범위가 아니라 조건과 값이라는 것뿐이다. 1-3의 순서로 읽으면 쉼표가 둘이므로 인수는 셋이다.

flowchart LR
    S["=IF(G4>=500000, #quot;달성#quot;, #quot;미달#quot;)"] --> Q{"첫째 인수(조건)<br/>G4>=500000"}
    Q -->|"참"| T["둘째 인수의 값<br/>#quot;달성#quot;을 표시"]
    Q -->|"거짓"| F["셋째 인수의 값<br/>#quot;미달#quot;을 표시"]

그림 2. IF 함수의 흐름. 조건이 참이면 둘째 인수의 값이, 거짓이면 셋째 인수의 값이 셀에 표시된다.

IF의 결과를 예상할 때에는 조건만 따로 떼어 계산한다. =IF(G4>=500000,"달성","미달")의 결과를 알고 싶으면 먼저 G4>=500000이 참인지 거짓인지를 정하고, 참이면 둘째 인수, 거짓이면 셋째 인수를 고른다. 따라 하기에서 조건을 먼저 셀에 입력해 보는 까닭이다.

4-4. 문자 값과 숫자 값의 표기

수식 안에서 문자 값은 큰따옴표로 둘러싼다. 지원 문서 「IF 함수」는 수식에 텍스트를 쓰려면 따옴표로 묶어야 한다고 적는다. 큰따옴표가 없는 문자는 엑셀이 함수 이름이나 셀 이름으로 해석하여 오류가 발생한다. 숫자 값은 큰따옴표 없이 기재하며 천 단위 쉼표를 넣지 않는다. 쉼표는 인수를 구분하는 기호이기 때문이다.

표기 엑셀의 해석
"달성" 문자 값 달성
달성 정의되지 않은 이름. #NAME? 오류가 발생한다
500000 숫자 500,000
500,000 숫자 500과 숫자 0의 두 인수. 인수의 수가 맞지 않아 수식이 입력되지 않는다
"500000" 문자 값. 숫자와의 크기 비교에 사용할 수 없다

IF의 결과가 문자이면 셀의 왼쪽에 맞추어 표시된다. 2장에서 다룬 기본 맞춤의 규칙이 수식의 결과에도 적용된 것이다. 결과가 문자이므로 IF가 표시한 “달성”은 COUNT로 셀 수 없다. 실습 PC의 엑셀에서 =COUNT(I4:I22)의 결과는 0이었다. 달성 건수를 세는 방법은 6절의 완료 기준에 적었다.

4-5. IF 수식의 복사

IF 수식 안의 셀 주소도 상대 참조이다. I4의 수식을 아래로 복사하면 조건의 셀 주소가 한 행씩 이동하고, 수식에 직접 기재한 상수(500000, “달성”, “미달”)는 변하지 않는다.

셀 복사된 수식
I4 =IF(G4>=500000,"달성","미달")
I5 =IF(G5>=500000,"달성","미달")
I23 =IF(G23>=500000,"달성","미달")

본 과목에서는 조건이 하나인 IF만을 다룬다. 두 개 이상의 조건을 결합하거나 값을 셋 이상으로 구분하는 방법은 다루지 않는다.

4-6. #NAME? 오류

#NAME?는 수식 안의 글자를 엑셀이 함수 이름으로도 셀 주소로도 인식하지 못하였을 때 표시된다. 함수를 입력하는 본 장에서 가장 자주 발생하는 오류 값이며 원인은 다음의 네 가지이다.

원인 예 해결
함수 이름의 오타 =AVERGE(G4:G23) 이름을 수정한다. 수식 자동 완성의 목록에서 선택하면 발생하지 않는다
문자 값의 큰따옴표 누락 =IF(G4>=500000,달성,미달) 문자 값을 "달성", "미달"과 같이 큰따옴표로 둘러싼다
범위의 콜론 누락 =SUM(G4G23) G4:G23으로 수정한다
한글 입력 상태에서의 입력 =녀ㅡ(G4:G23) 한/영 키로 영문 입력 상태로 전환한 뒤 다시 입력한다

#NAME?가 표시된 셀을 선택하고 F2를 누르면 수식이 편집 상태로 표시된다. 수식의 글자를 함수 이름, 셀 주소, 큰따옴표 안의 문자, 숫자로 하나씩 구분하여 읽고, 어느 것에도 해당하지 않는 글자를 찾는다. 엑셀이 인식한 셀 주소에는 색이 표시되므로 색이 없는 주소는 엑셀이 주소로 인식하지 못한 것이다.

따라 하기

연습용 통합 문서의 표에 목표 달성 열을 작성한다. 조건만을 먼저 입력하여 결과가 참 또는 거짓임을 확인하고, 경곗값에서 연산자별 결과를 확인한 뒤 IF로 감싼다.

예상. G4(792,000)와 G6(288,000)이 500,000 이상인지를 각각 판정한다.

  1. K4에 =G4>=500000, K5에 =G6>=500000을 입력한다.
  • 확인 15 K4에 TRUE, K5에 FALSE가 표시되었다. G4는 792,000, G6은 288,000이다.

예상. 4-2의 표를 가리고, 금액이 정확히 500,000일 때 >=와 >의 결과를 각각 적는다.

  1. K7에 500000을 입력한다.
  2. L7에 =IF(K7>=500000,"달성","미달"), M7에 =IF(K7>500000,"달성","미달")을 입력한다.
  3. K7을 499999, 500001로 차례로 바꾸며 L7과 M7을 읽는다.

결과 읽기. 두 연산자의 결과가 갈리는 것은 K7이 정확히 500,000일 때뿐이다.

4-7. [선택] 숫자를 돌려주는 IF

IF의 둘째 인수와 셋째 인수에는 문자 값만이 아니라 숫자나 수식도 올 수 있다. 지원 문서 「IF 함수」의 설명대로 IF는 조건이 참이면 하나의 값을, 거짓이면 다른 값을 돌려줄 뿐이며, 그 값이 문자인지 숫자인지는 가리지 않는다. 결과가 숫자이면 요약 함수로 다시 계산할 수 있다는 점이 문자 결과와 다르다.

수식(4행) 의미 결과의 종류 요약에 쓰는 법
=IF(G4>=500000,"달성","미달") 달성 여부를 글자로 표시한다 문자 눈으로 센다. COUNT는 0이다
=IF(G4>=500000,1,0) 달성이면 1, 미달이면 0 숫자 SUM이 달성 건수가 된다
=IF(G4>=500000,G4*1%,0) 달성이면 금액의 1%를 장려금으로, 미달이면 0 숫자 SUM이 장려금의 합계가 된다

둘째 수식의 열을 SUM으로 더하면 1인 행만 더해지므로 결과가 달성 건수와 같다. 함수를 새로 배우지 않고 6개 함수만으로 건수를 검산하는 방법이다. 1월 자료에서는 5, 2월 자료에서는 7이 된다. 셋째 수식은 조건에 따라 계산 자체를 바꾸는 예이다. 2월 자료의 달성 7건의 금액 합계는 5,198,000이므로 장려금의 합계는 그 1%인 51,980이다. 핵심 실습의 목표 달성 열은 문자 결과로 작성하며, 숫자를 돌려주는 IF는 아래의 [선택] 따라 하기에서만 다룬다.

따라 하기 [선택]: 숫자를 돌려주는 IF

예상. 2월 자료에서 =IF(G4>=500000,1,0)을 19행에 복사하고 SUM으로 더하면 얼마인가. 4절 따라 하기에서 센 달성 건수와 비교한다.

  1. K4에 =IF(G4>=500000,1,0), L4에 =IF(G4>=500000,G4*1%,0)을 입력한다.
  2. K4:L4를 선택하고 채우기 핸들을 L22까지 끈다.
  3. K24에 =SUM(K4:K22), L24에 =SUM(L4:L22)를 입력한다.

결과 읽기.

K24   =SUM(K4:K22)   7       (I 열의 "달성" 7건과 같다)
L24   =SUM(L4:L22)   51980   (달성 7건의 금액 5,198,000의 1%)
  • 확인 19 K24가 7, L24가 51,980이었다.
  1. K4:L24를 선택하고 Delete를 누른다.

5. IF 함수와 절대 참조

본 절의 내용은 연습용 통합 문서에서만 다룬다. 셀 주소와 값은 2월 자료의 것이다. 핵심 실습의 수식은 4절과 같이 기준 금액을 상수로 기재한다.

5-1. 상수로 기재한 기준의 한계

=IF(G4>=500000,"달성","미달")은 기준 금액 500,000을 수식 안에 직접 기재하였다. 3장에서 값을 직접 기재한 수식(=30*24000)이 자료의 변경을 반영하지 못하였던 것과 같은 한계가 있다.

  • 기준 금액을 700,000으로 변경하려면 첫 행의 수식을 수정한 뒤 전체 행에 다시 복사하여야 한다.
  • 시트를 보는 사람은 수식을 열어 보기 전에는 기준 금액이 얼마인지 알 수 없다.
  • 같은 기준을 여러 열의 수식이 사용하면 수정할 때 일부를 빠뜨리기 쉽다.

기준 금액을 표 바깥의 셀에 입력해 두고 수식이 그 셀을 참조하게 하면, 셀의 값 하나를 변경하는 것으로 모든 행의 결과가 다시 계산된다.

5-2. 기준 값 셀의 참조

K2에 기준 금액이라는 이름표를, K3에 500000을 입력하였다고 하자. I4의 조건을 G4>=K3으로 작성하면 첫 행의 결과는 정확하다. 그러나 이 수식을 아래로 복사하면 3장의 구성비와 같은 문제가 발생한다.

셀 복사된 수식 비교하는 대상 결과
I4 =IF(G4>=K3,"달성","미달") 792,000과 500,000 달성(정상)
I5 =IF(G5>=K4,"달성","미달") 510,000과 빈 셀 달성
I6 =IF(G6>=K5,"달성","미달") 288,000과 빈 셀 달성(오류)

기준 금액의 주소가 한 행씩 아래로 이동하여 빈 셀을 가리키게 되었다. 비교에서 빈 셀은 0으로 간주되므로 모든 금액이 “0 이상”이 되어 19행이 모두 “달성”으로 표시된다. 구성비에서는 #DIV/0!가 표시되어 오류가 드러났으나, 이 경우에는 오류 값이 표시되지 않는다. 결과가 그럴듯한 문자로 표시되므로 건수를 기준 값과 대조하지 않으면 발견되지 않는다. 실습 PC의 엑셀에서 기준 금액을 0으로 두었을 때의 달성 건수도 19건이었다. 빈 셀을 참조한 결과와 같다.

기준 금액의 주소를 절대 참조로 지정하면 해결된다.

셀 복사된 수식 결과
I4 =IF(G4>=$K$3,"달성","미달") 달성
I5 =IF(G5>=$K$3,"달성","미달") 달성
I6 =IF(G6>=$K$3,"달성","미달") 미달

5-3. 판별 기준의 적용

3장의 판별 기준은 “수식을 복사한 모든 행이 그 주소에서 하나의 같은 셀을 참조하여야 하는가”였다. IF의 조건에 있는 두 주소에 이 기준을 적용하면 다음과 같다.

주소 모든 행이 같은 셀을 참조하는가 참조 방식
G4(금액) 아니다. 행마다 자기 행의 금액을 비교한다 상대 참조
K3(기준 금액) 그렇다. 기준 금액은 하나의 셀에만 있다 절대 참조

반대로 금액의 주소에 절대 참조를 지정하여 =IF($G$4>=$K$3,"달성","미달")로 작성하면 모든 행이 첫 행의 금액을 비교하므로 19행의 결과가 모두 첫 행과 같아진다.

기준 값을 두는 셀은 표와 떨어진 위치로 정한다. 표에 붙은 열(J)에 값을 입력하면 5장의 정렬과 필터가 그 열까지를 자료 범위로 인식한다. 본 절에서는 J 열을 비워 두고 K 열을 사용한다.

5-4. 기준 값의 변경과 재계산

기준 금액을 셀로 분리하면 K3의 값만 변경하여 여러 기준의 결과를 차례로 확인할 수 있다. 2월 자료에서 기준 금액에 따른 달성 건수는 다음과 같다. 실습 PC의 엑셀에서 K3을 바꾸어 가며 센 값이다.

K3의 값 달성 건수 달성한 판매번호
300,000 10건 1021, 1022, 1024, 1030, 1032, 1035, 1036, 1037, 1038, 1039
500,000 7건 1021, 1022, 1030, 1032, 1036, 1037, 1039
700,000 5건 1021, 1030, 1036, 1037, 1039
720,000 5건 위와 같다. 판매번호 1030의 금액이 정확히 720,000이므로 >=에서는 달성이다
912,000 1건 1036. 최댓값과 같은 기준이다
912,001 0건 최댓값보다 큰 기준이다

720,000의 행은 4-2에서 다룬 경계 값의 사례이다. 조건의 연산자가 >이면 판매번호 1030이 미달로 바뀌어 4건이 된다. 912,000과 912,001의 두 행은 결과를 미리 예상하는 기준이 된다. 기준을 최댓값(G26)과 같게 하면 달성은 최댓값을 가진 행만 남고, 최댓값보다 크게 하면 0건이 된다. 요약 행의 최댓값과 IF의 결과가 서로 맞물린다는 것을 확인하는 방법이다.

따라 하기

  2. I4를 선택하고 F2를 눌러 수식의 500000을 지운 뒤 그 자리에 K3을 입력하고 Enter를 누른다. 수식은 =IF(G4>=K3,"달성","미달")이다.

  1. G25를 선택하여 수식 입력줄의 수식이 =SUM(G4:G23)인지, 셀의 값이 6,479,000인지 확인한다.
  2. 수식에서 함수 이름, 괄호, 인수를 각각 식별한다. 수식 입력줄에서 수식을 누르면 인수인 범위 G4:G23이 시트에 색 테두리로 표시된다. 확인한 뒤 Esc를 누른다.

단계 3. 요약 행의 작성

예상. 1월 자료의 합계 6,479,000과 건수 20으로 평균을 암산한다. 최댓값과 최솟값은 3장의 기준 값 표에서 찾는다(판매번호 1001과 1015). 네 값을 적은 뒤 입력한다.

  1. A26에 평균, A27에 최댓값, A28에 최솟값, A29에 개수를 입력한다.
  2. G26을 선택하고 =AVERAGE(를 입력한 뒤 G4부터 G23까지 끌고, )를 입력하고 Enter를 누른다. 수식 입력줄의 수식은 =AVERAGE(G4:G23)이다.
  3. 같은 방법으로 G27에 =MAX(G4:G23), G28에 =MIN(G4:G23), G29에 =COUNT(G4:G23)을 입력한다. 수식을 복사하지 않고 각각 입력한다.
  4. G26:G29의 셀을 하나씩 선택하여 범위가 모두 G4:G23인지 확인한다.

결과 읽기.

단계 4. 목표 달성 열의 작성

예상. 3장의 기준 값 표에서 금액이 500,000 이상인 판매번호를 먼저 찾아 건수를 적는다. 금액이 정확히 500,000인 행이 있는지도 확인한다(있다면 >=와 >의 결과가 갈린다).

  1. I3에 목표 달성을 입력한다.
  2. I4를 선택하고 =IF(G4>=500000,"달성","미달")을 입력한 뒤 Enter를 누른다. G4는 마우스로 선택하여 기재하여도 된다. 셀에 “달성”이 표시되는지 확인한다.
  3. I4를 선택하고 채우기 핸들을 두 번 눌러 I23까지 수식을 복사한다.
  4. I10을 선택하여 수식 입력줄의 수식이 =IF(G10>=500000,"달성","미달")인지 확인한다.
  5. I4:I23에서 “달성”이 표시된 셀을 눈으로 세어 5건인지 확인한다. 해당하는 행은 4, 8, 9, 14, 17행이다.
  • 확인 27 I10의 수식이 =IF(G10>=500000,"달성","미달")이고, “달성”이 4, 8, 9, 14, 17행의 5건이다.

단계 5. 서식의 적용

  1. A1을 선택하고 [홈] 탭 → [맞춤] 그룹 → [병합하고 가운데 맞춤]을 눌러 제목의 병합을 해제한다. 이어서 A1:I1을 선택하고 같은 단추를 눌러 다시 병합한다.
  2. H3을 선택하고 [홈] 탭 → [클립보드] 그룹 → [서식 복사]를 누른 뒤 I3을 누른다.
  3. I4:I23을 선택하고 [홈] 탭 → [글꼴] 그룹 → [테두리]의 목록 단추에서 [모든 테두리]를 선택한 뒤 [가운데 맞춤]을 누른다.
  4. G25를 선택하고 [서식 복사]를 누른 뒤 G26:G29를 끌어 합계와 같은 서식을 적용한다. 네 셀이 모두 통화 형식으로 표시된다.
  5. G29를 선택하고 [홈] 탭 → [표시 형식] 그룹의 표시 형식 목록에서 [일반]을 선택한다. 개수는 금액이 아니므로 통화 기호 없이 20으로 표시한다. 표시 형식만 변경하였으므로 셀의 값은 변하지 않는다.
  6. ####로 표시되는 셀이 있으면 열 머리글의 경계선을 두 번 눌러 너비를 맞춘다.
  • 확인 28 제목이 A1:I1의 가운데에 표시되었다. G26은 ₩323,950, G27은 ₩720,000, G28은 ₩108,000, G29는 20으로 표시되고 ####로 표시된 셀이 없다.

단계 6. 확인과 저장

예상. E4(판매번호 1001의 수량 30)를 10으로 바꾸면 G4는 240,000이 된다. 이때 I4, 최댓값 G27, 합계 G25, 평균 G26은 각각 어떻게 되는가. 1001이 최댓값을 가진 행이었으므로 새 최댓값은 두 번째로 큰 금액(판매번호 1005)이 된다.

  2. E4의 값을 10으로 변경한다. G4가 240,000으로, I4가 “미달”로, G27의 최댓값이 680,000으로 변하는지 확인한 뒤 Ctrl + Z로 되돌린다.

  4. Ctrl + S로 저장한다.

빈번한 오류와 해결

증상 원인 해결
#NAME?가 표시된다 함수 이름에 오타가 있거나(AVERGE 등), 문자 값에 큰따옴표를 붙이지 않았거나, 범위의 콜론이 빠졌다. 엑셀은 그 글자를 이름으로 찾다가 찾지 못한다 함수 이름과 범위를 수정한다. 문자 값을 "달성", "미달"과 같이 큰따옴표로 둘러싼다
수식에 문제가 있다는 안내가 표시되고 입력되지 않는다 닫는 괄호나 쉼표가 누락되었거나, 연산자를 =>로 입력하였다. 엑셀은 문법에 맞지 않는 수식을 저장하지 않는다 괄호의 짝과 쉼표 2개를 확인하고 연산자를 >=로 수정한다
인수가 너무 많다는 안내가 표시된다 기준 금액을 500,000으로 입력하였다. 쉼표가 인수의 구분으로 해석되어 IF의 인수가 4개가 되었다 쉼표 없이 500000으로 입력한다
평균이 617,048로 산출된다 범위에 합계 셀이 포함되었다(G4:G25) 범위를 G4:G23으로 수정한다
최댓값이 6,479,000이거나 개수가 21이다 위와 같다 범위를 G4:G23으로 수정한다
최솟값이 20이고 개수가 25이다 요약 행 다섯 개가 모두 범위에 들어갔다(G4:G29). 개수 셀의 값 20이 가장 작은 숫자가 되었다 범위를 G4:G23으로 수정한다
요약 값이 0이고 순환 참조 경고가 표시된다 범위에 함수가 있는 셀 자신이 들어갔다(G26에 =AVERAGE(G4:G26)) 범위를 G4:G23으로 수정한다
요약 값이 기준 값과 조금씩 다르고 범위가 G5:G24 등으로 되어 있다 합계 수식을 채우기 핸들로 복사하였다. 범위는 상대 참조이므로 한 행씩 밀렸다 복사한 수식을 지우고 함수를 각각 입력한다
평균, 최댓값 등의 범위가 G25:G26과 같이 요약 행을 가리킨다 [자동 합계] 목록이나 [함수 인수] 대화 상자가 제시한 범위를 확인하지 않고 확정하였다 수식의 범위를 G4:G23으로 수정한다. 대화 상자에서는 결과 미리 보기를 읽은 뒤 [확인]을 누른다
요약 값이 2월 자료의 값(8,016,000 등)이거나 범위가 G4:G22이다 연습용 통합 문서에서 작업하였거나 따라 하기의 주소를 그대로 사용하였다 제목 표시줄의 파일 이름을 확인하고 범위를 G4:G23으로 수정한다
평균 ≠ 합계 ÷ 개수이다 세 함수의 범위가 서로 다르다 세 수식의 범위를 수식 입력줄에서 읽어 G4:G23으로 맞춘다
평균이 #DIV/0!이다 범위에 숫자가 하나도 없다. 빈 열이나 문자 열을 범위로 지정하였다 범위의 열 문자가 G인지 확인한다
최솟값이 0이다 금액 열에 0인 셀이 있다. 대개 수량이나 단가를 지운 행이다 그 행의 수량과 단가를 다시 입력한다
개수가 ₩20으로 표시된다 통화 형식이 적용되었다 표시 형식을 [일반]으로 변경한다. 값은 20으로 정상이다
개수가 20보다 작다 금액 열에 수식이 아닌 문자가 입력되었거나 빈 셀이 있다 Ctrl + ~로 금액 열을 점검하고 해당 셀에 3장의 수식을 다시 작성한다
합계·평균·최댓값·최솟값이 모두 #VALUE!인데 개수만 숫자이다 금액 열의 어느 셀이 #VALUE!이다. COUNT는 오류 값을 세지 않을 뿐 전달하지 않는다 3장 5-7의 방법으로 원인 셀(수량이나 단가에 섞인 문자)을 찾는다
모든 행이 “달성”으로 표시된다 조건의 G4를 절대 참조($G$4)로 지정하여 모든 행이 G4를 비교한다. 기준 금액 셀을 참조하는 수식에서는 기준 금액의 주소를 절대 참조로 지정하지 않아 빈 셀(0으로 간주)과 비교하였다 $를 제거하여 G4로 수정하고 다시 복사한다. 기준 금액의 주소는 $K$3으로 수정한다
“달성”과 “미달”이 반대로 표시된다 연산자의 방향이 반대이거나 둘째 인수와 셋째 인수의 순서가 바뀌었다 조건을 G4>=500000으로, 인수의 순서를 “달성”, “미달”로 수정한다
달성 건수가 5건이 아니다 3장의 금액에 오류가 있거나 기준 금액의 자릿수가 다르다(50000, 5000000) 금액의 합계가 6,479,000인지 확인하고 수식의 기준 금액을 점검한다
연산자를 >로 썼는데 결과가 같다 1월 자료에 금액이 정확히 500,000인 행이 없어 차이가 드러나지 않았다(4-2) 기준이 “이상”이므로 >=로 고친다
함수 이름을 입력하여도 목록이 표시되지 않는다 등호를 입력하지 않았거나 한글 입력 상태이다 Esc로 취소하고 한/영 키를 누른 뒤 등호부터 다시 입력한다
채우기 핸들을 두 번 눌러도 I23까지 복사되지 않는다 왼쪽의 H 열에 빈 셀이 있다 채우기 핸들을 I23까지 직접 끈다. H 열의 구성비 수식을 점검한다
제목이 가운데에 오지 않는다 병합 범위가 A1:F1로 남아 있다 A1의 병합을 해제하고 A1:I1을 다시 병합한다

개념 점검

  1. =SUM(G4:G22)와 =SUM(G4,G22)는 인수의 수와 계산하는 셀의 수가 각각 몇 개인지 쓰고, 두 수식의 차이를 콜론과 쉼표의 의미로 설명하라.
  2. 판매 내역 표에서 =COUNT(D4:D23)(품목 열)의 결과를 쓰고 그 이유를 설명하라.

  4. =IF(E4>=30,"대량","소량")에서 E4의 값이 30일 때의 결과를 쓰고, 연산자를 >로 변경하면 결과가 어떻게 되는지 쓰라.
  5. 요약 행을 완성한 뒤 어떤 수강생의 최솟값이 20, 개수가 25로 나왔다. 수식을 보지 않고 결과만으로 범위가 어떻게 잘못되었는지 추론하고, 그렇게 판단한 근거를 두 가지 쓰라.

용어 의미
함수 엑셀이 미리 정의한 계산. =함수이름(인수1, 인수2, …)의 형식으로 작성한다
인수 함수에 전달하는 값. 괄호 안에 기재하고 둘 이상이면 쉼표로 구분한다
범위 시작 셀과 끝 셀을 콜론으로 연결한 표기(G4:G23)
수식 자동 완성 등호와 함수 이름의 앞 글자를 입력하면 표시되는 함수의 목록. Tab으로 선택한다
[함수 삽입] 대화 상자 함수를 검색하여 선택하고 [함수 인수] 대화 상자에서 인수를 지정하는 입력 방법. 확정하기 전에 결과를 미리 볼 수 있다
SUM, AVERAGE 범위 안의 숫자의 합계와 평균. 숫자가 하나도 없으면 AVERAGE는 #DIV/0!이다
MAX, MIN 범위 안의 숫자의 최댓값과 최솟값
COUNT 범위 안에서 숫자가 들어 있는 셀의 수. 빈 셀, 문자 셀, 오류 값은 세지 않는다
평균의 검산 평균 = 합계 ÷ 개수. 같은 범위로 구한 세 값 사이에 성립하므로 범위의 일치를 확인한다
조건 비교 연산자로 작성한 식. 결과는 TRUE 또는 FALSE이다
비교 연산자 >=, >, <, <=, =, <>
경곗값 기준과 정확히 같은 값. 이상(>=)과 초과(>)의 결과가 갈리는 값이다
IF 조건이 참이면 둘째 인수를, 거짓이면 셋째 인수를 표시하는 함수
큰따옴표 수식 안에서 문자 값을 나타내는 기호("달성")
