1장

파일 관리와 데이터 입력

2027학년도 「컴퓨터활용」의 준비 중인 교재입니다. 편집 상태를 검토하기 위해 미리 공개한 것으로, 수업 전에 내용과 순서가 바뀔 수 있습니다.

학사 2주차 · 교재 01 · 1부 엑셀

「컴퓨터 활용」은 엑셀에서 작성한 하나의 판매 자료를 서식, 수식, 함수, 차트, 피벗 테이블로 확장하고, 같은 자료를 파워포인트, 파이썬, 생성형 AI, 액세스에서 다시 사용하는 과목이다. 본 장은 그 출발점으로서, 이후의 모든 장이 사용하는 판매 자료 20행을 직접 입력하여 지정된 위치에 지정된 이름으로 저장한다.

본 장의 수업은 두 종류의 자료로 진행한다. 1~5절은 설명과 시연이며, 각 절의 끝에 있는 「따라 하기」에서 배포받은 2월 자료를 사용하여 시연한 조작을 직접 수행한다. 6절의 핵심 실습에서는 1월 자료 20행을 빈 통합 문서에 직접 입력한다. 완료 여부는 핵심 실습의 완료 기준에 제시된 값으로 판정한다. 서식의 적용과 인쇄 설정은 2장 「셀 서식과 인쇄 설정」에서 다루므로, 본 장에서는 값의 입력과 저장만을 수행한다.

수업 시간의 범위. 150분 수업에서는 번호를 붙인 절의 설명과 따라 하기, 핵심 실습까지 한다. 제목에 [선택]이 붙은 곳(2절의 따라 하기(CSV로 저장한 결과의 확인))과 심화 실습, 남은 연습 문제는 시간이 남을 때나 수업 뒤에 한다.

학습 목표

  • 파일을 지정된 폴더에 지정된 이름과 형식으로 저장할 수 있다.
    • 예시: 컴퓨터활용 폴더의 실습 폴더에 판매현황_01_학번.xlsx라는 이름의 Excel 통합 문서로 저장한다.
    • 활용: 결과물을 지정된 위치와 이름으로 저장하는 일은 이 과목의 모든 장과 후속 과목의 실기에서 공통으로 요구된다.
  • 셀과 범위를 선택하고 문자, 숫자, 날짜 자료를 구분하여 입력할 수 있다.
    • 예시: B2부터 F21까지의 범위에 판매일, 거래처, 품목, 수량, 단가를 입력하고, 입력 직후의 맞춤 위치로 자료의 종류를 판별한다.
    • 활용: 자료의 종류가 올바르게 입력되어야 이후의 장에서 수식, 정렬, 집계의 결과가 올바르게 산출된다.
  • 채우기 핸들로 연속된 값을 입력하고, 상태 표시줄의 값으로 입력 결과를 검산할 수 있다.
    • 예시: 판매번호 1001부터 1020까지를 채우기 핸들로 입력하고, 수량의 합계가 493인지 확인한다.
    • 활용: 입력을 마친 자료는 눈으로 훑어보는 것이 아니라 기준 값과 대조하여 검증한다. 이 절차는 이 과목의 모든 실습에 적용된다.

1. 실습 폴더의 구성

1-1. 폴더와 경로

파일(file)은 자료가 저장되는 단위이고, 폴더(folder)는 파일과 다른 폴더를 담는 단위이다. 경로(path)는 드라이브에서 출발하여 해당 파일에 이르기까지의 폴더를 순서대로 기재한 것이며, 폴더와 폴더 사이는 역슬래시(\)로 구분한다. 한글 글꼴에서는 역슬래시가 원화 기호(₩)로 표시되기도 한다.

C:\Users\사용자이름\Documents\컴퓨터활용\실습\판매현황_01_2027000.xlsx

위의 경로는 C 드라이브의 Users, 사용자이름, Documents(문서), 컴퓨터활용, 실습 폴더를 차례로 거쳐 판매현황_01_2027000.xlsx 파일에 이른다는 뜻이다. 파일을 저장할 때에는 파일 이름과 함께 이 경로가 의도한 위치인지를 확인하여야 한다.

파일 탐색기의 주소 표시줄은 같은 경로를 두 가지 모습으로 보여 준다. 평소에는 폴더 이름을 > 기호로 이어 놓은 모습(이동 경로)으로 표시되고, 주소 표시줄의 빈 곳을 클릭하면 드라이브 문자부터 시작하는 문자열로 바뀐다. 두 모습은 같은 위치를 가리키지만 표기가 다르다. 이동 경로에는 [문서]처럼 한국어 이름이 표시되고, 문자열에는 Documents처럼 실제 폴더 이름이 표시된다.

이동 경로로 표시될 때     … > 문서 > 컴퓨터활용 > 실습
클릭하여 문자열로 바꿀 때  C:\Users\사용자이름\Documents\컴퓨터활용\실습

이동 경로의 앞부분(…로 줄인 곳)에 무엇이 표시되는지는 Windows의 버전에 따라 다르다. 판단에 쓰는 것은 뒷부분이다.

경로는 오른쪽 끝에서부터 읽는다. 오른쪽 끝의 이름이 지금 열려 있는 폴더이고, 그 왼쪽이 그 폴더를 담고 있는 상위 폴더이다. 위의 경우 지금 열린 폴더는 실습이며, 실습은 컴퓨터활용 안에 있다. 저장한 파일을 찾지 못하는 경우의 대부분은 저장할 때 이 오른쪽 끝을 읽지 않은 것이 원인이다.

Windows에는 [문서] 폴더를 클라우드 저장소(OneDrive)에 백업하는 설정이 있다. 이 설정을 켠 PC에서는 [문서] 폴더의 파일이 OneDrive에도 보관되어 다른 장치에서 쓸 수 있게 되며, 2-3에서 설명하는 자동 저장이 동작할 수 있다. 실습을 시작하기 전에 주소 표시줄을 문자열로 바꾸어 [문서] 폴더의 실제 위치를 한 번 확인하고, 문자열이 C:\Users\사용자이름\Documents의 모양으로 시작하지 않으면 교수에게 알린다.

1-2. 실습 폴더의 구조

이 과목의 파일은 모두 컴퓨터활용 폴더에 보관한다. 이 폴더를 실습 폴더라 하며, 그 아래에 용도가 다른 폴더 세 개를 둔다.

컴퓨터활용
├─ 자료
├─ 실습
└─ 출력
폴더 용도 규칙
자료 수업에서 배포하는 파일(판매_2026_01.xlsx 등)을 보관한다 내용을 수정하지 않는다. 수정이 필요하면 파일을 연 뒤 실습 폴더에 다른 이름으로 저장하여 사용한다
실습 수강생이 직접 작성하는 파일을 보관한다 장마다 결과 파일을 새 이름으로 저장한다
출력 PDF로 출력한 파일을 보관한다 다음 장부터 사용한다
  • 실습 폴더는 [문서] 폴더에 둔다.
  • 폴더 이름과 파일 이름에는 공백을 넣지 않는다.
  • 수업을 마칠 때에는 실습 폴더 전체를 개인 저장 매체나 클라우드 저장소에 복사하여 보관한다.

자료 폴더와 실습 폴더를 구분하는 이유는 원본의 보존에 있다. 배포받은 파일을 직접 수정하면 기준 값과 대조할 원본이 없어진다. 원본을 한 곳에 수정하지 않은 상태로 두면 작업 파일에 오류가 발생하였을 때 언제든지 원본에서 다시 시작할 수 있다.

1-3. 파일 탐색기의 조작

폴더의 작성과 파일의 복사는 파일 탐색기에서 수행한다. 파일 탐색기의 창은 왼쪽의 탐색 창, 위쪽의 주소 표시줄, 가운데의 파일 목록으로 구성된다. 탐색 창에서 폴더를 선택하면 그 폴더의 내용이 파일 목록에 표시되고, 주소 표시줄에는 현재 폴더의 위치가 표시된다.

[그림 자리: 파일 탐색기 창의 구성] 컴퓨터활용 폴더를 연 파일 탐색기 창에 탐색 창(왼쪽), 주소 표시줄(위쪽), 파일 목록(가운데)의 세 곳을 번호로 표시하고, 주소 표시줄은 이동 경로의 모습과 클릭한 뒤의 문자열 모습을 나란히 보인다. 찍을 곳: Windows 11 파일 탐색기, [문서] → 컴퓨터활용 폴더.

작업 조작
파일 탐색기의 실행 Win + E
새 폴더의 작성 폴더를 작성할 위치를 연 상태에서 Ctrl + Shift + N을 누르고, 이름을 입력한 뒤 Enter를 누른다
이름의 변경 대상을 선택하고 F2를 누른다
복사 대상을 선택하고 Ctrl + C를 누른 뒤, 붙여 넣을 폴더를 열고 Ctrl + V를 누른다
이동 대상을 선택하고 Ctrl + X를 누른 뒤, 옮길 폴더를 열고 Ctrl + V를 누른다
삭제 대상을 선택하고 Delete를 누른다. 삭제한 항목은 휴지통으로 이동한다
직전 조작의 취소 Ctrl + Z
경로의 확인 주소 표시줄의 빈 곳을 클릭하거나 Alt + D를 누른다
상위 폴더로의 이동 Alt + ↑

복사는 원본을 그대로 둔 채 사본을 작성하고, 이동은 원본의 위치를 변경한다. 따라서 복사한 뒤에는 같은 파일이 두 곳에 존재하고, 이동한 뒤에는 한 곳에만 존재한다. 자료 폴더의 파일을 다른 곳에서 사용할 때에는 이동이 아니라 복사를 사용하여야 원본이 남는다.

여러 파일을 한꺼번에 다룰 때에는 먼저 대상을 모두 선택한다.

선택 대상 조작
폴더 안의 모든 항목 Ctrl + A
연속하여 나열된 항목 첫 항목을 클릭한 뒤 Shift를 누른 채 마지막 항목을 클릭한다
떨어져 있는 항목 Ctrl을 누른 채 항목을 하나씩 클릭한다

Delete로 삭제한 파일은 휴지통에 남아 있으므로 복원할 수 있다. Shift + Delete는 휴지통을 거치지 않고 영구적으로 삭제하므로 이 과목에서는 사용하지 않는다.

버전에 따른 차이: 파일 탐색기의 메뉴 구성은 Windows의 버전에 따라 다르다. 위 표의 단축키는 Windows 10과 Windows 11에서 동일하게 동작한다.

따라 하기

실습 폴더를 작성하고 배포받은 월별 파일 12개를 자료 폴더로 옮긴다. 이 따라 하기는 세 묶음(폴더의 작성, 이동, 복사)으로 되어 있으며, 묶음마다 조작하기 전에 결과를 먼저 예상하고 조작한 뒤 주소 표시줄과 파일 목록에서 결과를 읽는다.

예상. 단계 1~4를 마치면 컴퓨터활용 폴더 안에 빈 폴더 세 개가 생기고, 주소 표시줄의 문자열은 …\Documents\컴퓨터활용으로 끝난다. 폴더를 열지 않은 채 다음 폴더를 만들면 새 폴더가 [문서] 폴더에 생기므로, 단계 3에서 컴퓨터활용 폴더를 열었는지가 결과를 가른다.

  1. Win + E를 눌러 파일 탐색기를 실행하고 탐색 창에서 [문서] 폴더를 선택한다.
  2. Ctrl + Shift + N을 눌러 새 폴더를 작성하고 이름을 컴퓨터활용으로 입력한 뒤 Enter를 누른다.
  3. 작성한 폴더를 더블 클릭하여 열고, 같은 방법으로 자료, 실습, 출력 폴더를 작성한다.
  4. 주소 표시줄의 빈 곳을 클릭하여 경로를 확인한 뒤 Esc를 누른다.
  • 확인 1 컴퓨터활용 폴더에 자료, 실습, 출력 폴더 세 개가 있고, 주소 표시줄의 경로가 컴퓨터활용으로 끝났다.

세 폴더 가운데 하나가 [문서] 폴더에 생겼으면 그 폴더를 선택하고 Ctrl + X를 누른 뒤 컴퓨터활용 폴더를 열어 Ctrl + V로 옮긴다. 이름을 잘못 입력하였으면 F2로 고친다.

예상. 단계 5~7은 이동이다. 이동을 마치면 자료 폴더에 12개가 나타나고, 파일을 받았던 폴더에서는 12개가 사라진다. 개수는 파일 목록에서 판매_2026_01부터 판매_2026_12까지 월의 번호가 빠짐없이 이어지는지로 센다.

  1. 부록 A의 안내에 따라 받은 월별 파일 12개가 있는 폴더를 연다.
  2. 첫 파일을 클릭한 뒤 Shift를 누른 채 마지막 파일을 클릭하여 12개를 모두 선택하고 Ctrl + X를 누른다.
  3. 컴퓨터활용 폴더의 자료 폴더를 열고 Ctrl + V를 누른다.
  • 확인 2 자료 폴더에 판매_2026_01부터 판매_2026_12까지 12개의 파일이 있고, 파일을 받았던 폴더에는 이 파일들이 남아 있지 않다.

파일이 11개 이하이면 단계 6의 선택에서 첫 파일이나 마지막 파일이 빠진 것이다. 받았던 폴더에 남은 파일을 같은 방법으로 옮긴다. 받았던 폴더에도 12개가 그대로 있으면 Ctrl + X 대신 Ctrl + C를 누른 것이며, 결과에는 지장이 없으므로 받았던 폴더의 사본은 그대로 두거나 삭제한다.

예상. 단계 8~9는 복사이다. 복사를 마치면 같은 파일이 자료 폴더와 실습 폴더의 두 곳에 있게 된다. 이동과 복사의 차이는 원래의 폴더에 파일이 남는가로 판별한다.

  1. 자료 폴더에서 3월 파일(판매_2026_03)을 선택하고 Ctrl + C를 누른다.
  2. Alt + ↑를 눌러 컴퓨터활용 폴더로 이동하고, 실습 폴더를 열어 Ctrl + V를 누른다.
  • 확인 3 실습 폴더에 3월 파일의 사본이 1개 있고, 자료 폴더의 파일은 12개 그대로이다.

2. 파일 이름과 저장 형식

2-1. 파일 이름과 확장자

파일 이름은 이름.확장자의 형태이다. 확장자(extension)는 파일의 형식을 나타내며, Windows는 확장자에 따라 파일을 여는 프로그램을 결정한다. 엑셀 통합 문서의 확장자는 .xlsx이다.

파일 탐색기의 기본 설정에서는 확장자가 표시되지 않는다. 확장자가 표시되지 않으면 이름이 같고 형식이 다른 파일(예: 판매현황_02_학번.xlsx와 판매현황_02_학번.pdf)을 아이콘의 모양으로만 구분하여야 한다. 이 과목에서는 확장자가 표시되도록 설정하여 사용한다.

버전에 따른 차이: Windows 11에서는 파일 탐색기의 [보기] → [표시] → [파일 이름 확장명]을 선택한다. Windows 10에서는 [보기] → [옵션] → [폴더 및 검색 옵션 변경]을 선택하고, 대화 상자의 [보기] 탭에 있는 [고급 설정]에서 [알려진 파일 형식의 확장명 숨기기]의 선택을 해제한다.

파일 이름에는 \ / : * ? " < > |의 아홉 가지 문자를 사용할 수 없다. 확장자가 표시된 상태에서 이름을 변경할 때에는 확장자를 지우지 않도록 유의한다. 확장자를 지우거나 다른 것으로 바꾸면 Windows가 그 파일을 여는 프로그램을 찾지 못한다. 확장자를 바꾸어 적는 것만으로는 파일의 형식이 변환되지 않으며, 형식의 변환은 프로그램에서 [다른 이름으로 저장]으로 수행한다(2-4).

2-2. 파일 이름의 규칙

이 과목의 엑셀 결과 파일은 다음의 규칙으로 이름을 정한다.

판매현황_장 번호_학번.xlsx      핵심 실습의 통합 문서(제출한다)
판매연습_장 번호_학번.xlsx      연습용 통합 문서(제출하지 않는다)
  • 장 번호는 두 자리로 기재한다. 본 장의 파일은 판매현황_01, 판매연습_01로 시작한다.
  • 구분에는 밑줄(_)을 사용하고 공백을 넣지 않는다.
  • 예시: 학번이 2027000인 수강생의 본 장 결과 파일은 판매현황_01_2027000.xlsx이다.

장마다 앞 장의 파일을 열어 새 이름으로 저장하므로 장별 결과가 별도의 파일로 남는다. 오류가 발생하면 앞 장의 파일에서 다시 시작할 수 있다. 장 번호를 두 자리로 적는 이유는 파일 탐색기가 이름의 순서로 파일을 나열할 때 02가 10보다 앞에 놓이게 하기 위한 것이다.

2-3. 저장과 다른 이름으로 저장

명령 단축키 동작
저장 Ctrl + S 현재의 위치와 이름에 덮어쓴다. 한 번도 저장하지 않은 문서에서는 위치와 이름을 묻는다
다른 이름으로 저장 F12 [다른 이름으로 저장] 대화 상자를 열어 위치, 이름, 형식을 새로 지정한다
열기 Ctrl + O 저장된 통합 문서를 연다. 파일 탐색기에서 파일을 더블 클릭하여도 같다
닫기 Ctrl + W 현재의 통합 문서를 닫는다. 저장하지 않은 변경이 있으면 저장 여부를 묻는다

[저장]과 [다른 이름으로 저장]의 차이는 원본의 보존 여부이다. 자료 폴더의 파일을 열어 [저장]을 수행하면 원본이 변경된다. 열자마자 [다른 이름으로 저장]으로 실습 폴더에 새 이름을 부여하면 그 뒤의 [저장]은 새 파일에만 적용되고 원본은 그대로 남는다. 이 과목의 모든 장은 이 순서로 시작한다.

[다른 이름으로 저장] 대화 상자에서는 세 가지를 확인한다.

  1. 위쪽의 주소 표시줄에 표시된 폴더가 저장하려는 위치인가.
  2. [파일 이름]에 입력한 이름이 규칙과 일치하는가. 확장자는 입력하지 않아도 [파일 형식]에 따라 자동으로 부여된다.
  3. [파일 형식]이 Excel 통합 문서 (*.xlsx)인가.

[그림 자리: [다른 이름으로 저장] 대화 상자의 확인할 세 곳] 대화 상자의 위쪽 주소 표시줄(저장할 폴더), 아래쪽의 [파일 이름]과 [파일 형식]에 번호를 붙이고, 주소 표시줄이 자료 폴더를 가리키는 상태와 실습 폴더로 바꾼 상태를 나란히 보인다. 찍을 곳: Microsoft 365 엑셀, F12로 연 대화 상자.

저장이 완료되면 엑셀 창의 제목 표시줄에 파일 이름이 표시된다. 제목 표시줄은 저장이 의도대로 되었는지를 판정하는 첫 번째 근거이다. 저장하기 전과 후의 제목 표시줄은 다음과 같이 달라진다. 아래는 교수의 작업 PC(Microsoft 365, 확장명 표시 설정을 켠 상태)에서 엑셀 창의 제목을 읽은 형태를 이 과목의 파일 이름에 맞추어 적은 것이다(2026-11-15 확인).

2월 파일을 연 직후        판매_2026_02.xlsx - Excel
다른 이름으로 저장한 뒤    판매연습_01_학번.xlsx - Excel

제목 표시줄의 이름이 바뀌었다는 것은 지금 화면의 통합 문서가 새 파일이라는 뜻이다. 이때부터의 [저장]은 새 파일에만 적용된다. 이름이 바뀌지 않았으면 저장이 취소되었거나 대화 상자에서 [저장]을 누르지 않은 것이다. 제목 표시줄은 파일 이름만 보여 주고 폴더는 보여 주지 않으므로, 폴더는 파일 탐색기에서 따로 확인한다. 작업 중에는 Ctrl + S로 수시로 저장한다. 저장은 실행 취소의 대상이 아니므로, 잘못된 상태를 저장한 뒤에는 Ctrl + Z로 저장 이전의 파일로 되돌릴 수 없다.

인터넷에서 내려받은 파일을 열면 창의 위쪽에 노란색 메시지 표시줄이 나타나고 입력이 되지 않는 경우가 있다. 이 상태를 제한된 보기라 하며, 출처가 안전하지 않을 수 있는 파일을 읽기 전용으로 여는 보호 기능이다. 수업에서 배포한 파일과 같이 출처를 신뢰할 수 있는 파일이면 메시지 표시줄의 [편집 사용]을 선택하여 편집할 수 있는 상태로 전환한다.

버전에 따른 차이: 새 문서에서 Ctrl + S를 누르거나 [파일] 탭 → [다른 이름으로 저장]을 선택하였을 때 나타나는 화면은 오피스의 버전에 따라 다르며, 버전에 따라서는 클라우드 저장소가 기본 위치로 제시된다. F12는 버전과 관계없이 [다른 이름으로 저장] 대화 상자를 직접 연다. 노트북에서는 Fn 키와 함께 눌러야 하는 경우가 있다. 제목 표시줄의 왼쪽에 있는 [자동 저장] 스위치는 클라우드 저장소(OneDrive 등)에 저장된 파일에서만 동작한다. [문서] 폴더와 같은 PC의 폴더에 저장한 파일은 자동으로 저장되지 않으므로 직접 저장하여야 한다.

자동 저장과 다른 이름으로 저장의 관계. 자동 저장은 OneDrive, 비즈니스용 OneDrive, SharePoint Online에 저장된 파일에서 동작하며, 이 위치의 파일에서는 자동 저장의 기본값이 켜짐이다. 자동 저장이 켜진 파일에서는 고친 내용이 원본에 계속 저장된다. 따라서 클라우드 저장소에 있는 배포 파일을 열어 고치기 시작하면, [다른 이름으로 저장]을 하기 전에 이미 원본이 바뀐다. 이런 파일에서는 [파일] 탭에 [다른 이름으로 저장] 대신 [복사본 저장]이 표시되며, 원본을 남기려면 고치기 전에 [복사본 저장]을 먼저 수행하여야 한다. 반대로 C:\와 같은 PC의 폴더에 있는 파일에서는 자동 저장이 꺼져 있으므로 Ctrl + S를 누르기 전까지 원본이 바뀌지 않는다.

파일의 위치 자동 저장 고친 내용이 원본에 반영되는 시점 원본을 남기는 방법
PC의 폴더(C:\Users\…\Documents 등) 꺼짐 Ctrl + S를 누를 때 열자마자 F12로 다른 이름으로 저장한다
OneDrive, SharePoint Online 기본값은 켜짐 고치는 즉시(계속 저장된다) 고치기 전에 [복사본 저장]을 수행하거나 자동 저장을 끈다

이 과목의 실습 폴더를 PC의 [문서] 폴더에 두는 이유가 여기에 있다. 원본은 자료 폴더에 그대로 두고, 작업은 언제나 새 이름의 파일에서 시작한다는 규칙이 저장 위치와 관계없이 지켜지도록 하기 위한 것이다. 클라우드 저장소의 파일을 잘못 고친 경우에는 버전 기록에서 이전 버전을 복원할 수 있다.

2-4. 저장 형식

[다른 이름으로 저장] 대화 상자의 [파일 형식] 목록에는 여러 형식이 있다. 형식에 따라 파일에 저장되는 내용이 다르다.

형식 확장자 저장되는 내용 이 과목에서의 사용
Excel 통합 문서 .xlsx 모든 시트의 값, 수식, 서식, 차트, 인쇄 설정 엑셀의 기본 형식이다. 이 과목의 엑셀 파일은 모두 이 형식으로 저장한다
Excel 97-2003 통합 문서 .xls 구 버전의 형식이다. 새 버전의 일부 기능이 저장되지 않을 수 있다 사용하지 않는다
Excel 매크로 사용 통합 문서 .xlsm .xlsx의 내용과 매크로(자동 실행 코드) 사용하지 않는다
CSV(쉼표로 분리) .csv 현재 시트 하나의 값만 쉼표로 구분한 텍스트로 저장한다. 서식, 수식, 다른 시트는 저장되지 않는다 사용하지 않는다. 다른 프로그램과 자료를 주고받을 때 쓰이는 형식이다
PDF .pdf 인쇄되는 모습을 저장한다. 문서의 모양은 유지되나 엑셀에서 다시 계산하거나 수정할 수 없다 다음 장부터 출력물의 제출에 사용한다

.xlsx가 아닌 형식으로 저장하면 일부 서식, 자료, 기능이 저장되지 않을 수 있다. 예를 들어 서식을 적용한 표를 CSV로 저장한 뒤 다시 열면 테두리와 표시 형식이 모두 사라져 있다. 따라서 작업 중인 통합 문서는 항상 .xlsx로 저장하고, 다른 형식이 필요하면 .xlsx를 저장한 뒤에 사본을 그 형식으로 추가로 저장한다.

형식에 따라 남는 것. .xlsx는 엑셀의 기본 형식이며 XML을 바탕으로 한 파일 형식이다. 시트, 값, 수식, 서식이 모두 한 파일 안에 구조를 갖추어 저장된다. CSV는 이와 달리 글자만으로 된 텍스트 파일이다. 한 행이 한 줄이 되고 셀과 셀 사이에 쉼표가 들어가며, 저장되는 것은 셀에 표시된 값뿐이다. 다음은 2월 파일(판매_2026_02.xlsx)에 시트 하나를 더 추가한 통합 문서를 엑셀에서 CSV로 저장한 뒤, 그 파일의 처음 네 줄을 글자 그대로 읽은 것이다(교수의 작업 PC, 2026-11-15).

판매번호,판매일,거래처,품목,수량,단가
1021,2026-02-02,동아문구,A4 복사용지,33,24000
1022,2026-02-04,한빛상사,토너,6,85000
1023,2026-02-05,한빛상사,파일 폴더,32,9000

이 결과에서 세 가지를 읽을 수 있다.

  1. 파일은 머리글 1줄과 자료 19줄, 모두 20줄이었다. 추가한 두 번째 시트는 저장되지 않았다. CSV는 저장할 때 활성화된 시트 하나만 저장하기 때문이다.
  2. 판매일은 셀에 표시된 모습(2026-02-02)이 글자로 적혔다. 날짜의 표시 형식은 저장되지 않으므로, 이 CSV를 엑셀에서 다시 열었더니 판매일이 그 PC의 Windows 날짜 설정에 따른 모습으로 표시되었다.
  3. 다시 연 통합 문서에는 시트가 하나뿐이었고 시트의 이름은 파일 이름과 같았다.

[파일 형식] 목록에는 CSV가 두 가지 있다. [CSV(쉼표로 분리)]로 저장한 파일은 한국어를 Windows의 기본 문자 인코딩으로 적고, [CSV UTF-8(쉼표로 분리)]로 저장한 파일은 UTF-8 인코딩으로 적는다. 교수의 작업 PC에서 두 형식으로 저장한 파일의 내용은 같았으나, 앞의 것은 UTF-8로 읽으면 한국어가 깨졌고 뒤의 것은 UTF-8로 읽혔다. 한국어가 들어 있는 CSV를 다른 프로그램(8장 이후의 파이썬 등)에 넘길 때 글자가 깨지는 원인의 대부분이 이 인코딩의 차이이다. 이 과목에서는 CSV로 저장하지 않으며, 형식의 차이를 아는 것으로 그친다.

엑셀에서 통합 문서를 CSV로 저장하면 화면의 통합 문서가 CSV 파일로 바뀐다. 제목 표시줄의 이름이 ….csv로 바뀌고, 이후의 Ctrl + S는 CSV 파일에 저장된다. CSV로 저장한 뒤에 계속 작업하면 시트, 서식, 수식을 잃은 파일에 작업하게 되므로, 사본을 CSV로 저장한 뒤에는 그 창을 닫고 .xlsx 파일을 다시 연다.

따라 하기

파일 확장명을 표시하고, 2월 파일을 열어 연습용 통합 문서로 저장한다.

  1. 파일 탐색기에서 실습 폴더를 열고 파일 확장명이 표시되도록 설정한다(2-1).
  • 확인 4 실습 폴더의 파일 이름이 판매_2026_03.xlsx와 같이 확장자와 함께 표시되었다.
  1. 실습 폴더의 판매_2026_03.xlsx를 선택하고 F2를 누른다. 마침표와 xlsx는 남기고 이름을 이름변경연습으로 고친 뒤 Enter를 누른다.
  2. 이름변경연습.xlsx를 선택하고 Delete를 눌러 삭제한다.
  • 확인 5 실습 폴더가 비어 있고, 자료 폴더의 판매_2026_03.xlsx는 그대로 있다.

예상. 단계 4~8을 마치면 제목 표시줄의 이름이 판매_2026_02.xlsx에서 판매연습_01_학번.xlsx로 바뀌고, 파일은 실습 폴더에 하나 더 생긴다. 자료 폴더의 파일 수는 12개로 변하지 않는다. 단계 5에서 대화 상자가 처음 보여 주는 폴더는 방금 연 파일의 폴더, 곧 자료 폴더일 가능성이 크다.

  1. 자료 폴더의 판매_2026_02.xlsx를 더블 클릭하여 연다. 노란색 메시지 표시줄이 나타나면 [편집 사용]을 선택한다.
  2. F12를 눌러 [다른 이름으로 저장] 대화 상자를 열고, 주소 표시줄에 표시된 폴더를 확인한다. 자료 폴더가 제시되어 있으면 이 상태로 저장할 경우 자료 폴더에 저장된다.
  3. 컴퓨터활용 폴더의 실습 폴더로 이동한다.
  4. [파일 형식] 목록을 펼쳐 2-4의 형식들이 나열되어 있음을 확인하고 Excel 통합 문서 (*.xlsx)를 선택한다.
  5. [파일 이름]에 판매연습_01_학번을 입력하고 [저장]을 선택한다. 학번은 본인의 것으로 기재한다.
  • 확인 6 제목 표시줄에 판매연습_01_학번.xlsx가 표시되고, 실습 폴더에 같은 이름의 파일이 생성되었으며, 자료 폴더에는 판매_2026_02.xlsx가 그대로 있다.

실습 폴더에 파일이 없으면 자료 폴더를 연다. 판매연습_01_학번.xlsx가 그곳에 있으면 단계 5~6에서 폴더를 바꾸지 않고 저장한 것이다. 엑셀에서 F12를 다시 눌러 실습 폴더에 같은 이름으로 저장하고, 자료 폴더에 잘못 생긴 파일은 엑셀을 닫은 뒤 삭제한다. 제목 표시줄의 이름이 판매_2026_02.xlsx 그대로이면 대화 상자에서 [저장]을 누르지 않은 것이다.

따라 하기 [선택]: CSV로 저장한 결과의 확인

시간이 남는 수강생은 2-4에서 설명한 CSV의 결과를 직접 확인한다. 연습용 통합 문서를 고치지 않도록 사본을 만들어 수행하며, 끝나면 만든 파일을 모두 지운다.

예상. CSV로 저장하면 제목 표시줄의 이름이 .csv로 바뀐다. 다시 연 CSV에는 시트가 하나뿐이고 시트의 이름은 파일 이름과 같다. 판매일은 날짜로 인식되어 오른쪽에 놓이지만 모양은 Windows의 날짜 설정에 따른다.

  1. 판매연습_01_학번.xlsx가 열려 있는 상태에서 F12를 누르고, 실습 폴더에서 [파일 형식]을 [CSV(쉼표로 분리)]로 바꾼 뒤 [파일 이름]에 형식연습을 입력하여 저장한다. 일부 기능이 손실될 수 있다는 안내가 나타나면 읽고 저장을 계속한다.
  2. 제목 표시줄의 이름을 읽은 뒤 Ctrl + W로 창을 닫는다. 저장 여부를 물으면 [저장 안 함]을 선택한다.
  3. 엑셀에서 Ctrl + O를 눌러 실습 폴더의 형식연습.csv를 열고, 시트 탭의 이름과 판매일 열의 모양을 관찰한다. 판매일이 #으로 표시되면 열의 너비가 좁은 것이며 값에는 이상이 없다.
  4. Ctrl + W로 닫고, 파일 탐색기에서 형식연습.csv를 삭제한다. 판매연습_01_학번.xlsx를 다시 연다.
  • 확인 7 저장 직후 제목 표시줄은 형식연습.csv였고, 다시 연 CSV의 시트 탭은 형식연습 하나였다. 형식연습.csv를 삭제한 뒤 판매연습_01_학번.xlsx가 다시 열려 있다.

3. 엑셀 화면의 구성

3-1. 통합 문서, 워크시트, 셀

엑셀의 파일 하나를 통합 문서(workbook)라 한다. 통합 문서는 하나 이상의 워크시트(worksheet, 이하 시트)로 구성되고, 시트는 행(row)과 열(column)이 교차하는 셀(cell)로 구성된다.

  • 열은 A, B, C와 같은 영문자로, 행은 1, 2, 3과 같은 숫자로 구분한다. Z 열의 다음 열은 AA이다.
  • 셀의 주소는 열 문자와 행 번호를 이어 쓴다. B3은 B열과 3행이 교차하는 셀이다.
  • 하나의 셀에는 하나의 값을 입력한다.
  • 시트 하나는 1,048,576개의 행과 16,384개의 열로 구성된다. 화면에 보이는 부분은 시트의 왼쪽 위 일부이다.

3-2. 화면의 구성 요소

구성 요소 위치 기능

빠른 실행 도구 모음 제목 표시줄의 왼쪽 [저장], [실행 취소] 등 자주 사용하는 단추를 모아 둔 곳이다
리본 메뉴 제목 표시줄의 아래 명령을 탭과 그룹으로 분류하여 제시한다. 탭은 [파일], [홈], [삽입], [페이지 레이아웃], [수식], [데이터], [검토], [보기] 등이다

상태 표시줄 창의 맨 아래 왼쪽에는 셀의 입력 상태를, 오른쪽에는 선택한 범위의 평균, 개수, 합계를 표시한다
확대/축소 슬라이더 상태 표시줄의 오른쪽 끝 화면에 표시되는 크기를 조절한다. 인쇄되는 크기에는 영향을 주지 않는다

[그림 자리: 엑셀 화면의 구성 요소] 연습용 통합 문서를 연 엑셀 창에 위 표의 구성 요소 아홉 가지를 번호 ①~⑨로 표시한다. 이름 상자, 수식 입력줄, 상태 표시줄의 세 곳은 굵은 테두리로 강조한다. 찍을 곳: Microsoft 365 엑셀, 판매연습_01_학번.xlsx의 “판매내역” 시트에서 D2를 선택한 상태.

이름 상자, 수식 입력줄, 셀은 같은 셀을 서로 다른 관점에서 보여 준다. 이름 상자는 어디를, 수식 입력줄은 무엇이 저장되었는가를, 셀은 어떻게 보이는가를 보여 준다. 따라서 값을 확인할 때에는 셀만 보지 않고 세 곳을 함께 읽는다. 2월 파일의 B2를 선택하였을 때 세 곳은 다음과 같다.

이름 상자     B2
수식 입력줄   2026-02-02
셀의 표시     2026-02-02  (셀의 오른쪽에 놓인다)

2월 파일의 판매일 열에는 날짜의 표시 형식이 미리 지정되어 있으므로 셀의 모양이 2026-02-02로 일정하다. 빈 통합 문서에 날짜를 직접 입력하면 셀의 모양이 Windows의 날짜 설정에 따라 달라질 수 있다(5-1).

상태 표시줄의 왼쪽 끝에는 셀의 입력 상태가 표시된다. 셀을 선택만 한 상태에서는 [준비], 셀에 내용을 입력하는 중에는 [입력], 기존의 내용을 수정하는 중에는 [편집]으로 표시된다. 리본 메뉴의 명령이 선택되지 않을 때에는 이 표시가 [준비]인지를 먼저 확인한다.

3-3. 리본 메뉴의 표기와 표시

이 교재는 리본 메뉴의 명령을 [탭] 탭 → [그룹] 그룹 → [명령]의 순서로 표기한다. 예를 들어 [홈] 탭 → [편집] 그룹 → [지우기]는 [홈] 탭을 선택하고 [편집] 그룹에서 [지우기]를 선택한다는 뜻이다.

리본 메뉴는 접어 둘 수 있다. Ctrl + F1을 누르면 리본 메뉴가 숨겨져 탭의 이름만 남고, 다시 누르면 표시된다. 리본 메뉴의 단추가 보이지 않을 때에는 Ctrl + F1을 누르거나, 리본 메뉴의 오른쪽 끝에 있는 [리본 표시 옵션]에서 [항상 리본 표시]를 선택한다.

버전에 따른 차이: 리본 메뉴의 탭 구성과 단추의 모양은 오피스의 버전에 따라 다르다. 엑셀을 실행하였을 때 시작 화면이 나타나는 버전에서는 [새 통합 문서]를 선택하여야 빈 시트가 열린다.

3-4. 시트의 추가와 이름 변경

통합 문서에는 시트를 여러 개 둘 수 있다. 시트 탭의 오른쪽에 있는 [새 시트] 단추(더하기 모양)를 누르면 새 시트가 추가된다. 시트의 이름은 시트 탭을 더블 클릭하거나 마우스 오른쪽 단추로 클릭하여 [이름 바꾸기]를 선택한 뒤 입력한다. 시트를 제거할 때에는 시트 탭을 마우스 오른쪽 단추로 클릭하여 [삭제]를 선택한다. 이 과목에서는 자료가 있는 시트의 이름을 판매내역으로 통일하며, 이후의 장에서 시트를 추가할 때마다 교재가 이름을 지정한다.

4. 셀과 범위의 선택

엑셀의 명령은 선택된 셀을 대상으로 동작하므로, 조작의 순서는 항상 선택이 먼저이고 명령이 나중이다. 굵은 테두리로 표시된 셀 하나를 활성 셀(active cell)이라 하며, 입력한 내용은 활성 셀에 들어간다.

4-1. 셀의 이동

활성 셀은 마우스로 클릭하여 옮기거나 키로 옮긴다. 자료를 입력하는 중에는 손이 키보드에 있으므로 키에 의한 이동이 빠르다.

키 이동하는 위치
방향키 한 셀 위, 아래, 왼쪽, 오른쪽
Tab, Shift + Tab 한 셀 오른쪽, 한 셀 왼쪽
Enter, Shift + Enter 한 셀 아래, 한 셀 위
Home 현재 행의 첫 열(A열)
Ctrl + Home 시트의 첫 셀(A1)
Ctrl + End 시트에서 사용된 마지막 셀(사용된 가장 오른쪽 열과 가장 아래쪽 행이 만나는 셀)
Ctrl + 방향키 자료가 연속하여 입력된 영역의 가장자리
Page Down, Page Up 한 화면 아래, 한 화면 위

Ctrl + 방향키는 자료의 끝을 찾는 데 사용한다. 자료가 입력된 열에서 Ctrl + ↓를 누르면 그 열에서 자료가 끊기기 직전의 셀로 이동하므로, 이동한 셀의 행 번호로 자료의 행 수를 알 수 있다. Ctrl + End로 이동한 셀이 표의 오른쪽 아래 모서리가 아니면 표의 바깥에 내용이나 서식이 남아 있는 것이다.

4-2. 범위의 선택

범위(range)는 직사각형 모양으로 연속된 셀의 묶음이다. 범위는 왼쪽 위 셀의 주소와 오른쪽 아래 셀의 주소를 쌍점(:)으로 이어 표기한다. A2:F21은 A2부터 F21까지의 범위이며 20행, 6열, 120개의 셀로 구성된다.

선택 대상 조작
셀 하나 셀을 클릭한다. 또는 이름 상자에 주소를 입력하고 Enter를 누른다
연속된 범위 첫 셀에서 끝 셀까지 끈다. 또는 첫 셀을 클릭한 뒤 Shift를 누른 채 끝 셀을 클릭한다
주소를 아는 범위 이름 상자에 A2:F21과 같이 입력하고 Enter를 누른다
선택 영역의 확장 Shift + 방향키를 누르면 선택 영역이 한 셀씩 넓어진다
자료가 입력된 끝까지 첫 셀을 선택한 뒤 Ctrl + Shift + 방향키를 누른다
떨어져 있는 범위 첫 범위를 선택한 뒤 Ctrl을 누른 채 다음 범위를 선택한다
열 전체, 행 전체 열 머리글 또는 행 머리글을 클릭한다. 여러 열이나 행은 머리글을 끌어 선택한다
표 전체 표 안의 셀 하나를 선택하고 Ctrl + A를 누른다. 한 번 더 누르면 시트 전체가 선택된다

범위를 선택하는 방법은 범위의 크기에 따라 정한다. 화면 안에 들어오는 작은 범위는 끌어서 선택하고, 화면을 벗어나는 긴 범위는 이름 상자에 주소를 입력하거나 Ctrl + Shift + 방향키를 사용한다. 긴 범위를 끌어서 선택하면 화면이 빠르게 넘어가 끝 셀을 지나치기 쉽다.

4-3. 상태 표시줄에 의한 검산

숫자가 입력된 범위를 선택하면 상태 표시줄에 그 범위의 평균, 개수, 합계가 표시된다. 수식을 입력하지 않고도 값을 확인할 수 있으므로, 본 장에서는 상태 표시줄의 값을 입력 결과의 검산에 사용한다. 값이 표시되지 않으면 상태 표시줄을 마우스 오른쪽 단추로 클릭하여 [평균], [개수], [합계]를 선택한다.

[그림 자리: 상태 표시줄의 검산 값] 연습용 통합 문서에서 E2:E20을 선택한 상태의 엑셀 창 아래쪽을 확대하여, 상태 표시줄 오른쪽의 평균, 개수, 합계와 사용자 지정 목록(상태 표시줄을 마우스 오른쪽 단추로 클릭한 모습)을 함께 보인다. 찍을 곳: Microsoft 365 엑셀, 상태 표시줄.

상태 표시줄의 값은 아래와 같이 항목 이름과 값의 짝으로 읽는다. 아래는 연습용 통합 문서의 수량 열(E2:E20)을 선택하였을 때 읽어야 하는 값이다. 화면에서는 항목이 한 줄에 나란히 놓이며, 항목 사이의 간격과 순서는 버전에 따라 다를 수 있다.

선택한 범위   E2:E20
평균 28    개수 19    합계 532

[숫자 개수]를 켜 두면 이 줄에 항목 하나가 더 나타난다. 이 과목에서는 본 장의 따라 하기에서 [숫자 개수]를 켜고 그대로 둔다.

항목 표시되는 값 기본 설정
[평균] 선택한 셀 가운데 숫자가 입력된 셀의 평균 표시된다
[개수] 선택한 셀 가운데 내용이 있는 셀의 수. 문자가 입력된 셀도 센다 표시된다
[숫자 개수] 선택한 셀 가운데 숫자가 입력된 셀의 수 표시되지 않는다
[최소값], [최대값] 선택한 셀의 숫자 가운데 가장 작은 값과 가장 큰 값 표시되지 않는다
[합계] 선택한 셀의 숫자의 합 표시된다

[개수]와 [숫자 개수]는 세는 대상이 다르다. 2, 3, 문자, 4가 입력된 네 셀을 선택하면 [개수]는 4, [숫자 개수]는 3이다. 숫자를 입력하여야 하는 열에서 두 값이 다르면 문자로 입력된 셀이 있다는 뜻이다. 검산의 판단 기준은 다음과 같다.

관찰한 값 판단
[개수]가 기준 값보다 작다 빈 셀이 있다. 행이 누락되었거나 입력하지 않은 셀이 있다
[개수]는 맞고 [숫자 개수]가 작다 문자로 입력된 셀이 있다. 왼쪽에 맞추어진 셀을 찾는다
[개수]와 [숫자 개수]는 맞고 [합계]가 다르다 값을 잘못 입력한 셀이 있다. 범위를 나누어 합계를 대조하여 구간을 좁힌다

엑셀은 날짜를 숫자(일련번호)로 저장하므로 날짜가 입력된 셀은 [숫자 개수]에 포함된다. 2026년 1월 2일은 46024, 2026년 2월 2일은 46055라는 숫자로 저장되어 있다(2장 3-4에서 직접 확인한다). 이 성질 때문에 판매일 열에서도 같은 검산이 가능하다. 판매일 20개를 선택하였을 때 [숫자 개수]가 20이면 모든 판매일이 날짜로 입력된 것이고, 19이면 하나가 문자로 입력된 것이다. 다만 판매일 열의 [합계]와 [평균]은 일련번호를 더하고 나눈 값이므로 의미가 없다. 판매일 열에서는 [숫자 개수]만 읽는다.

열 읽는 항목 읽는 까닭
판매번호(A) [숫자 개수], 첫 값과 끝 값 번호가 모두 숫자로 들어갔는지, 빠진 번호가 없는지
판매일(B) [숫자 개수] 날짜가 문자로 들어간 셀을 찾는다. 합계는 의미가 없다
거래처, 품목(C, D) [개수] 문자 열이므로 [숫자 개수]는 0이 정상이다. 빈 셀만 찾는다
수량, 단가(E, F) [개수], [숫자 개수], [합계] 빈 셀, 문자 셀, 값의 오류를 차례로 찾는다

버전에 따른 차이: 숫자가 입력된 셀의 수를 표시하는 항목의 이름은 Microsoft의 지원 문서에 [숫자 개수]로 적혀 있다. 제품의 화면에는 [숫자 셀 수]와 같이 다른 이름으로 표시될 수 있으며, 목록에서 [개수]의 바로 아래에 있는 항목이다.

따라 하기

연습용 통합 문서의 판매내역 시트에서 키로 이동하고, 범위를 선택하여 상태 표시줄의 값을 읽는다.

예상. 2월 자료는 머리글 1행과 자료 19행이므로 자료의 마지막 행은 20행이고, 열은 A부터 F까지 여섯 개이다. 따라서 Ctrl + ↓는 A20에서, Ctrl + →는 F20에서 멈출 것이다. 수량 19개의 합계는 실습 자료 명세의 기준 값 532이다.

  1. Ctrl + Home을 눌러 A1로 이동한다.
  2. Ctrl + ↓를 누르고 이름 상자의 주소를 읽는다.
  3. Ctrl + →를 누르고 이름 상자의 주소를 읽는다.
  • 확인 11 Ctrl + ↓를 누른 뒤의 주소는 A20, Ctrl + →를 누른 뒤의 주소는 F20이다. 자료는 2행부터 20행까지 19행이다.
  1. 이름 상자에 E2:E20을 입력하고 Enter를 눌러 수량의 범위를 선택한다.
  2. 상태 표시줄의 평균, 개수, 합계를 읽는다.
  • 확인 12 상태 표시줄에 평균 28, 개수 19, 합계 532가 표시되었다.
  1. E2를 선택하고 Ctrl + Shift + ↓를 눌러 같은 범위가 선택되는지 확인한다.
  2. 이어서 Shift + →를 한 번 눌러 선택 영역을 E2:F20으로 넓힌다.
  • 확인 13 E2:F20을 선택한 상태에서 개수 38, 합계 464532가 표시되었다. 수량의 합계 532와 단가의 합계 464000을 더한 값이다.
  1. 열 머리글 E를 클릭하여 열 전체를 선택한다.
  2. 상태 표시줄을 마우스 오른쪽 단추로 클릭하여 [숫자 개수]를 선택하고 값을 읽는다.
  • 확인 14 E열 전체를 선택한 상태에서 개수는 20, 숫자 개수는 19이다. 머리글 수량이 문자이므로 두 값이 다르다.

예상. 판매일은 날짜이므로 숫자로 저장되어 있다. 판매일 19개를 선택하면 [숫자 개수]는 19일 것이고, 거래처 19개를 선택하면 [숫자 개수]는 0이거나 상태 표시줄에 나타나지 않을 것이다.

  1. 이름 상자에 B2:B20을 입력하고 Enter를 눌러 상태 표시줄의 개수와 숫자 개수를 읽는다.
  2. 이름 상자에 C2:C20을 입력하고 Enter를 눌러 같은 값을 읽는다.
  • 확인 15 B2:B20에서는 개수 19, 숫자 개수 19였고, C2:C20에서는 개수 19였으며 숫자 개수는 0으로 표시되거나 표시되지 않았다. 판매일은 날짜(숫자)로, 거래처는 문자로 저장되어 있다.
  1. E3을 클릭한 뒤 Ctrl을 누른 채 E13과 E19를 클릭한다. 세 셀은 품목이 토너인 판매 건의 수량이다.
  • 확인 16 떨어져 있는 세 셀을 선택한 상태에서 개수 3, 합계 18이 표시되었다.

5. 자료의 입력과 자동 채우기

5-1. 자료의 종류

엑셀은 입력된 내용을 문자, 숫자, 날짜로 구분하여 저장한다. 종류에 따라 계산과 정렬의 결과가 달라지므로 의도한 종류로 입력되었는지를 확인하여야 한다.

종류 예 기본 맞춤 입력할 때의 유의 사항
문자 한빛상사, A4 복사용지 왼쪽 앞뒤에 공백을 넣지 않는다
숫자 30, 24000 오른쪽 쉼표와 단위를 붙이지 않고 숫자만 입력한다
날짜 2026-01-02 오른쪽 연도, 월, 일을 붙임표(-)로 구분하여 연도까지 입력한다

엑셀이 인식한 종류는 입력을 확정한 직후의 맞춤 위치로 판별한다. 맞춤을 따로 지정하지 않은 셀에서 문자는 왼쪽에, 숫자와 날짜는 오른쪽에 놓인다. 숫자나 날짜를 입력하였는데 왼쪽에 맞추어지면 문자로 입력된 것이다. 이 판별은 가운데 맞춤과 같은 서식을 적용하기 전에만 유효하므로, 입력을 마친 직후에 수행한다.

입력한 내용 엑셀이 인식한 종류 판별의 근거와 결과
24000 숫자 오른쪽에 놓인다
24000원 문자 왼쪽에 놓인다. 계산에 사용할 수 없다
2026-02-02, 2026/2/2 날짜 오른쪽에 놓인다. 붙임표와 빗금은 모두 날짜의 구분 기호이다
2026.02.02 문자 왼쪽에 놓인다. 마침표는 날짜의 구분 기호가 아니다
2-2 날짜 오른쪽에 놓인다. 연도를 생략하면 입력하는 시점의 연도가 적용된다
010 숫자 10 오른쪽에 놓이고 앞의 0이 사라진다
'010 문자 010 왼쪽에 놓인다. 아포스트로피(')는 셀에 표시되지 않는다
  • 천 단위 쉼표와 통화 기호는 값에 포함하여 입력하지 않고, 다음 장에서 표시 형식으로 지정한다.
  • 엑셀은 날짜처럼 보이는 입력을 날짜로 자동 변환한다. 1-2나 1/2를 입력하면 1과 2가 아니라 1월 2일이 저장된다. 이 변환은 끌 수 없다.
  • 우편번호나 전화번호와 같이 0으로 시작하고 계산에 사용하지 않는 번호는 숫자가 아니라 문자로 입력하여야 앞의 0이 유지된다. 입력하는 내용의 앞에 아포스트로피를 붙이면 문자로 입력된다. 이렇게 입력한 셀의 왼쪽 위 모서리에는 작은 녹색 삼각형이 표시되기도 하며, 숫자가 문자로 저장되어 있음을 알리는 표시이다.
  • 본 과목의 판매번호는 계산과 정렬에 사용하는 일련번호이므로 숫자로 입력한다.

엑셀이 입력을 해석하는 방식. 엑셀은 셀에 입력된 글자를 확정하는 순간 그 글자가 숫자나 날짜로 읽힐 수 있는지를 검사하여, 읽히면 숫자로 저장하고 읽히지 않으면 입력된 글자 그대로 문자로 저장한다. 날짜로 읽힌 입력에는 날짜의 표시 형식이 자동으로 지정된다. 이때 지정되는 형식은 Windows 제어판의 기본 날짜 설정을 따른다. 그러므로 같은 2026-01-02를 입력하여도 PC의 날짜 설정에 따라 셀의 모양이 다를 수 있다. 셀의 모양이 달라도 오른쪽에 놓이면 날짜로 저장된 것이며, 표시 모양은 2장에서 표시 형식으로 통일한다.

아래는 교수의 작업 PC(Microsoft 365, 엑셀 16.0)에서 빈 통합 문서에 입력을 하나씩 확정하고 저장된 값을 읽은 결과이다(2026-11-15). 이 PC는 Windows의 간단한 날짜 형식이 기본값에서 바뀌어 있어 날짜가 02-02-26의 모양으로 표시되었으며, 셀의 모양은 실습실 PC와 다를 수 있다. 판단에 쓰는 것은 “저장된 종류”의 열이다.

24,000 숫자 24000 천 단위 쉼표(셀에는 24,000)

쉼표나 ₩를 붙여 입력하여도 숫자로 저장되기는 하지만, 표시 형식이 셀마다 제각각 지정되어 열의 모양이 고르지 않게 된다. 이 과목에서 숫자만 입력하게 하는 이유는 표시 형식을 2장에서 열 단위로 한 번에 지정하기 위한 것이다. 단위(개, 원)를 붙인 입력은 언제나 문자가 된다.

날짜와 숫자가 문자로 들어간 경우의 증상. 날짜나 숫자가 문자로 저장되면 화면에서는 값이 멀쩡해 보이므로 오류를 알아차리기 어렵다. 증상은 다음의 순서로 나타난다. 앞의 세 가지는 본 장에서, 나머지는 해당 장에서 드러난다.

증상 나타나는 곳 실습 PC에서 확인한 결과(2026-11-15)
셀의 왼쪽에 놓인다 입력 직후의 셀 2026.02.02, 24000원이 왼쪽에 놓였다
[숫자 개수]가 줄어든다 상태 표시줄 숫자 30과 문자 24000의 두 셀에서 숫자의 개수는 1, 내용이 있는 셀의 개수는 2였다

계산에서 오류 값이 나온다 3장의 수식 문자 2026.01.02에 1을 더하는 수식과 24000원에 2를 곱하는 수식은 모두 #VALUE!를 표시하였다

문자로 저장된 숫자가 언제나 계산에서 빠지는 것은 아니다. 위의 확인에서 문자 24000에 숫자 30을 곱하는 수식은 720000을 표시하였다. 곱셈과 같은 연산에서는 엑셀이 숫자처럼 읽히는 문자를 숫자로 바꾸어 계산하지만, 합계에서는 문자를 건너뛰기 때문이다. 같은 셀이 어떤 계산에는 들어가고 어떤 계산에서는 빠지므로, 문자로 저장된 숫자는 값이 맞아 보이는데 합계만 틀리는 원인이 된다. 입력 단계에서 [숫자 개수]로 걸러 내야 하는 까닭이 여기에 있다.

Microsoft의 지원 문서도 텍스트로 저장된 날짜는 셀의 오른쪽이 아닌 왼쪽에 맞추어지고, 텍스트로 저장된 숫자 옆에는 녹색 삼각형의 오류 표시가 나타나는 경우가 많다고 설명한다. 녹색 삼각형은 나타나지 않을 수도 있으므로 판별의 기준은 맞춤과 [숫자 개수]로 한다. 본 장에서는 문자로 들어간 셀을 찾으면 그 셀을 선택하여 올바른 모양으로 다시 입력하는 것으로 고친다.

5-2. 입력, 수정, 삭제, 실행 취소

셀을 선택하고 내용을 입력한 뒤 확정하여야 값이 셀에 들어간다. 입력 중에는 리본 메뉴의 명령 대부분이 동작하지 않으므로 입력을 확정하거나 취소한 뒤에 다음 조작을 수행한다.

키 동작
Enter 입력을 확정하고 아래의 셀로 이동한다
Tab 입력을 확정하고 오른쪽 셀로 이동한다
Esc 입력을 취소한다. 셀은 입력을 시작하기 전의 상태로 돌아간다
F2 선택한 셀의 내용을 수정한다. 커서가 내용의 끝에 놓인다. 셀을 더블 클릭하여도 같다
Delete 선택한 셀의 내용을 지운다. 범위를 선택하면 범위 전체의 내용을 지운다
Ctrl + Z 직전의 조작을 취소한다(실행 취소)
Ctrl + Y 취소한 조작을 다시 수행한다(다시 실행)

수정에는 두 가지 방법이 있다. 내용이 있는 셀을 선택하고 바로 입력하면 기존의 내용 전체가 새 내용으로 대체된다. F2를 누른 뒤 입력하면 기존의 내용을 유지한 채 일부만 고칠 수 있다. 값 전체가 틀렸으면 앞의 방법을, 한두 글자만 틀렸으면 뒤의 방법을 사용한다.

Delete는 셀의 내용만 지우고 셀에 적용된 서식은 남긴다. 날짜를 입력하였던 셀의 내용을 지우고 숫자를 입력하면 그 숫자가 날짜의 모습으로 표시되는 것은 이 때문이다. 서식까지 지우는 방법은 다음 장에서 다룬다.

Ctrl + Z는 누를 때마다 한 단계씩 이전의 상태로 되돌린다. 여러 단계를 되돌릴 수 있으나 파일의 저장은 되돌릴 수 없다. 조작의 결과가 예상과 다르면 다른 조작을 시도하기 전에 먼저 Ctrl + Z로 되돌린다.

5-3. 행 단위의 입력

표의 자료는 한 행씩 입력한다. Tab으로 오른쪽으로 이동하며 입력하고 행의 마지막 셀에서 Enter를 누르면, 활성 셀이 다음 행에서 입력을 시작한 열로 이동한다. 이 방법을 사용하면 마우스를 사용하지 않고 연속하여 입력할 수 있다. 입력 도중에 방향키나 마우스로 다른 셀을 선택하면 시작한 열의 기억이 사라지므로, 한 행의 입력을 마칠 때까지는 Tab만 사용한다.

5-4. 자동 완성

문자를 입력할 때 같은 열의 위쪽에 앞 글자가 같은 자료가 있으면 엑셀이 나머지 글자를 제시한다. 제시된 내용이 입력하려는 내용과 같으면 Enter 또는 Tab으로 확정하고, 다르면 무시하고 계속 입력한다. 자동 완성은 입력 시간을 줄이는 동시에 같은 상호를 서로 다르게 입력하는 오류를 줄인다. 다만 미래유통을 입력하려는데 앞 글자가 같은 다른 자료가 제시될 수 있으므로, 확정하기 전에 제시된 내용을 원본과 대조한다.

5-5. 화면의 표시와 실제 값

셀에 표시된 모양과 실제로 입력된 값은 다를 수 있다. 실제 값은 셀을 선택하였을 때 수식 입력줄에 표시되는 내용이다.

  • 문자가 열의 너비보다 길면 오른쪽 셀이 비어 있을 때에는 넘쳐서 표시되고, 오른쪽 셀에 내용이 있으면 잘려서 표시된다.
  • 숫자나 날짜가 열의 너비보다 길면 ####으로 표시된다.
  • 12자리 이상의 큰 숫자는 1.23E+11과 같은 지수의 모습으로 표시된다.

세 경우 모두 값은 정상적으로 입력되어 있다. 열의 너비는 다음 장에서 조정한다.

5-6. 채우기 핸들과 자동 채우기

채우기 핸들(fill handle)은 선택한 셀 또는 범위의 오른쪽 아래 모서리에 있는 작은 사각형이다. 마우스 포인터를 채우기 핸들에 올리면 포인터가 가는 십자 모양으로 바뀌며, 이 상태에서 끌면 선택한 내용을 바탕으로 끈 방향의 셀이 채워진다. 이 기능을 자동 채우기라 한다.

[그림 자리: 채우기 핸들과 마우스 포인터의 모양] C1:C2를 선택한 상태에서 범위의 오른쪽 아래 모서리의 작은 사각형(채우기 핸들)을 확대하고, 포인터를 올리기 전의 모양(굵은 십자)과 올린 뒤의 모양(가는 십자), 셀의 테두리에 올렸을 때의 모양(이동 화살표)을 세 칸으로 나란히 보인다. 찍을 곳: Microsoft 365 엑셀, “입력연습” 시트.

채워지는 내용은 선택한 자료에 따라 다르다.

선택한 자료 채우기 핸들을 끈 결과
숫자가 입력된 셀 하나 같은 숫자가 복사된다
숫자가 입력된 셀 둘(예: 1001, 1002) 두 값의 차이만큼 증가하는 값이 채워진다
숫자가 입력된 셀 둘(예: 10, 20) 10씩 증가하는 값(30, 40, …)이 채워진다
날짜가 입력된 셀 하나 하루씩 증가하는 날짜가 채워진다
날짜가 입력된 셀 둘(예: 7일 간격) 두 날짜의 간격만큼 증가하는 날짜가 채워진다
문자가 입력된 셀 하나 같은 문자가 복사된다
  • 숫자의 연속 번호는 처음 두 값을 입력하여 증가하는 규칙을 알려 주어야 한다. 아래쪽이나 오른쪽으로 끌면 값이 증가하고, 위쪽이나 왼쪽으로 끌면 값이 감소한다.
  • 채우기를 마치면 채워진 범위의 오른쪽 아래에 [자동 채우기 옵션] 단추가 나타난다. 이 단추에서 [셀 복사]와 [연속 데이터 채우기]를 선택하여 결과를 변경할 수 있다.
  • 자동 채우기로 입력한 번호는 입력한 시점의 값으로 고정된다. 중간의 행을 삭제하여도 번호가 다시 매겨지지 않는다.
  • 마우스 포인터가 가는 십자 모양이 아닌 상태에서 셀의 테두리를 끌면 셀의 내용이 이동한다. 의도하지 않게 이동하였으면 Ctrl + Z로 취소한다.
  • 채우기 핸들이 보이지 않으면 [파일] 탭 → [옵션] → [고급]의 [편집 옵션]에서 [채우기 핸들 및 셀 끌어서 놓기 사용]이 선택되어 있는지 확인한다.

따라 하기

연습용 통합 문서의 입력연습 시트에서 자료의 종류를 판별하고, 자동 채우기와 행 단위의 입력을 수행한다.

예상. 단계 2에서 입력하는 여섯 값 가운데 숫자나 날짜로 읽히는 것은 24000과 2026-02-02의 둘뿐이다. 나머지 넷은 단위(원), 마침표, 한글, 아포스트로피 때문에 문자가 된다. 문자가 된 셀은 왼쪽에 놓인다.

  1. 시트 탭 입력연습을 클릭한다.
  2. A1부터 아래로 24000, 24000원, 2026-02-02, 2026.02.02, 한빛상사, '010을 차례로 입력한다. 값마다 Enter를 누른다.
  3. A1:A6의 맞춤 위치를 관찰하고, A6을 선택하여 수식 입력줄을 읽는다.
  • 확인 17 A1과 A3은 오른쪽에, A2, A4, A5, A6은 왼쪽에 놓였다. A6의 셀에는 010이, 수식 입력줄에는 '010이 표시되었다.
  1. A2를 선택하고 F2를 누른 뒤 Backspace로 원을 지우고 Enter를 누른다.
  2. A4를 선택하고 2026-02-02를 입력한 뒤 Enter를 누른다. 기존의 내용이 대체된다.
  3. A5를 선택하고 Delete를 누른 뒤, Ctrl + Z를 눌러 지운 내용을 되살린다.
  • 확인 18 A2와 A4가 오른쪽으로 옮겨졌고, A5에는 한빛상사가 다시 표시되었다.

A2가 오른쪽으로 옮겨지지 않았으면 원의 앞이나 뒤에 공백이 남았는지 F2를 눌러 확인한다. A4가 왼쪽에 그대로 있으면 붙임표 대신 마침표를 다시 입력한 것이다.

예상. 이어서 문자로 저장된 셀이 상태 표시줄의 값에 어떻게 나타나는지 본다. A1:A6에는 숫자 24000이 두 개(A1, A2), 날짜가 두 개(A3, A4), 문자가 두 개(A5, A6) 있다. 따라서 [개수]는 6, [숫자 개수]는 4일 것이다.

  1. A1:A6을 선택하고 상태 표시줄의 개수와 숫자 개수를 읽는다.
  2. A1:A2를 선택하고 합계를 읽는다.
  • 확인 19 A1:A6에서 개수 6, 숫자 개수 4였고, A1:A2의 합계는 48000이다. 날짜 두 개는 숫자로 세어졌고 한빛상사와 '010은 세어지지 않았다.

예상. 단계 9~11의 세 열은 모두 19행까지 채워진다. 두 셀(1021, 1022)로 시작한 C열은 1씩 늘어 19번째 셀이 1021 + 18 = 1039가 된다. 날짜 하나로 시작한 D열은 하루씩 늘어 19번째 셀이 2월 2일에서 18일 뒤인 2월 20일이 된다. 숫자 하나로 시작한 E열은 처음에는 같은 값이 복사되고, 옵션을 바꾼 뒤에야 C열과 같아진다.

  1. C1에 1021, C2에 1022를 입력한다. C1:C2를 선택하고 채우기 핸들을 C19까지 끈다.
  2. D1에 2026-02-02를 입력한다. D1을 선택하고 채우기 핸들을 D19까지 끈다.
  3. E1에 1021을 입력한다. E1을 선택하고 채우기 핸들을 E19까지 끈 뒤, [자동 채우기 옵션] 단추에서 [연속 데이터 채우기]를 선택한다.
  • 확인 20 C19와 E19에 1039가, D19에 2026-02-20이 표시되었다. E19는 옵션을 선택하기 전에는 1021이었다.

C19가 1021이면 셀 하나만 선택하고 끈 것이다. Ctrl + Z로 되돌린 뒤 두 셀을 선택하여 다시 끈다. D19가 2026-02-20이 아니면 끈 끝의 행이 19행인지 행 번호로 확인한다. 날짜는 끈 셀의 수만큼 늘어나므로 끈 끝의 행이 하나 어긋나면 날짜도 하루 어긋난다.

절차

단계 1. 실습 폴더의 구성

1절과 2절의 따라 하기에서 구성한 실습 폴더를 점검한다. 구성하지 않은 항목은 이 단계에서 작성한다.

예상. 따라 하기를 모두 수행하였다면 이 단계에서 새로 만들 것은 없다. 실습 폴더에는 연습용 통합 문서 판매연습_01_학번.xlsx 하나가 있고, 자료 폴더에는 월별 파일 12개가 있다.

  1. Win + E를 눌러 파일 탐색기를 실행하고 [문서] 폴더를 연다.
  2. 컴퓨터활용 폴더가 없으면 Ctrl + Shift + N을 눌러 새 폴더를 작성하고 이름을 컴퓨터활용으로 입력한다.
  3. 컴퓨터활용 폴더를 열고, 자료, 실습, 출력 폴더 가운데 없는 것을 같은 방법으로 작성한다.
  4. 파일 확장명이 표시되도록 설정되어 있는지 확인한다(2-1).
  • 확인 22 [문서] 폴더에 컴퓨터활용 폴더가 있고 그 안에 자료, 실습, 출력 폴더가 있다.

결과 읽기. 주소 표시줄을 클릭하여 문자열이 …\Documents\컴퓨터활용으로 끝나는지 읽는다. 파일 이름에 .xlsx가 붙어 보이지 않으면 확장명 표시가 꺼진 것이므로 2-1의 방법으로 켠다. 확장명이 보이지 않아도 저장에는 지장이 없으나, 완료 기준 2번을 점검할 때 파일 이름을 끝까지 읽을 수 없다.

단계 2. 새 통합 문서의 저장

자료를 입력하기 전에 먼저 저장하여 위치와 이름을 확정한다. 입력을 모두 마친 뒤에 처음 저장하면, 저장 위치를 잘못 지정하였을 때 입력한 결과를 찾지 못하는 위험이 가장 커진다. 먼저 저장해 두면 이후의 Ctrl + S는 대화 상자 없이 같은 파일에 덮어쓴다.

예상. 저장하기 전의 제목 표시줄에는 통합 문서1과 같은 임시 이름이 표시되고, 저장한 뒤에는 판매현황_01_학번.xlsx로 바뀐다. 빈 통합 문서를 저장하는 것이므로 파일은 생기지만 내용은 비어 있다.

  1. 엑셀에서 Ctrl + N을 눌러 빈 통합 문서를 연다. 엑셀이 실행되어 있지 않으면 엑셀을 실행하여 빈 통합 문서를 연다.
  2. F12를 눌러 [다른 이름으로 저장] 대화 상자를 연다.
  3. 컴퓨터활용 폴더의 실습 폴더로 이동한다.
  4. [파일 이름]에 판매현황_01_학번을 입력한다. 학번은 본인의 것으로 기재한다.
  5. [파일 형식]이 Excel 통합 문서 (*.xlsx)인지 확인하고 [저장]을 선택한다.
  • 확인 23 제목 표시줄에 판매현황_01_학번.xlsx가 표시되고, 파일 탐색기의 실습 폴더에 같은 이름의 파일이 생성되었다.

결과 읽기. 이 확인은 제목 표시줄과 파일 탐색기의 두 곳에서 읽는다. 제목 표시줄은 이름만 알려 주고 폴더는 알려 주지 않기 때문이다. 파일 탐색기에서 실습 폴더에 판매연습_01_학번.xlsx와 판매현황_01_학번.xlsx의 두 파일이 보이면 정상이다. 이름의 학번 자리에 본인의 학번이 들어갔는지, 밑줄(_)이 두 곳에 있는지 읽는다.

단계 3. 시트 이름과 머리글의 입력

예상. 머리글 여섯 개를 Tab으로 입력하고 마지막에 Enter를 누르면, 활성 셀은 머리글을 시작한 열로 돌아와 A2에 놓인다. 머리글은 모두 문자이므로 여섯 셀 모두 왼쪽에 놓인다.

  1. 시트 탭의 Sheet1을 더블 클릭하고 판매내역을 입력한 뒤 Enter를 누른다.
  2. A1 셀을 선택한다.
  3. 판매번호, 판매일, 거래처, 품목, 수량, 단가를 차례로 입력한다. 항목 사이에서는 Tab을 누르고, 단가를 입력한 뒤에는 Enter를 누른다.
  • 확인 24 시트 탭에 판매내역이 표시되고 A1:F1에 머리글 여섯 개를 원본의 순서대로 입력하였다.

결과 읽기. 이름 상자에 A2가 표시되어 있으면 행 단위의 입력이 올바르게 끝난 것이다. A1:F1을 선택하면 상태 표시줄의 [개수]는 6이어야 한다. 머리글은 6장 「피벗 테이블」에서 필드의 이름으로 그대로 쓰이므로, 공백까지 원본과 같게 입력한다(예: 판매 일로 입력하지 않는다).

단계 4. 판매번호의 입력

판매번호는 1001부터 1020까지 1씩 증가하므로 채우기 핸들로 입력한다.

예상. 자료는 20행이므로 판매번호는 2행부터 21행까지 놓이고, 마지막 셀 A21은 1001 + 19 = 1020이 된다. 끈 끝이 한 행이라도 어긋나면 마지막 값이 1019나 1021이 된다.

  1. A2에 1001, A3에 1002를 입력한다.
  2. A2:A3을 선택한다.
  3. 채우기 핸들을 A21까지 끈다.
  • 확인 25 A21에 1020이 입력되었다.

결과 읽기. A2:A21을 선택하여 상태 표시줄을 읽는다. 아래와 같으면 판매번호 20개가 모두 숫자로 들어간 것이다. 합계 20210은 1001부터 1020까지의 합이다.

선택한 범위   A2:A21
평균 1010.5    개수 20    숫자 개수 20    합계 20210

단계 5. 판매일부터 단가까지의 입력

판매일, 거래처, 품목, 수량, 단가는 원본을 보고 한 행씩 입력한다. 입력할 셀은 B2:F21의 100개이며, 단계 4의 판매번호 20개와 합하여 자료 영역 A2:F21의 120개 셀이 모두 채워진다. 100개의 셀을 한 번에 입력하고 마지막에 한 번 검산하면, 합계가 틀렸을 때 100개 가운데 어디가 틀렸는지 찾기 어렵다. 그러므로 다섯 행(25개 셀)마다 멈추어 그 구간을 검산하고 저장한 뒤 다음 구간으로 넘어간다.

  1. B2 셀을 선택한다.
  2. 2026-01-02, 한빛상사, A4 복사용지, 30, 24000을 차례로 입력한다. 항목 사이에서는 Tab을 누르고, 단가를 입력한 뒤에는 Enter를 누른다. 활성 셀이 B3으로 이동한다.
  3. 같은 방법으로 6행(판매번호 1005)까지 입력한다.
  4. 아래의 「구간별 검산」의 첫 줄에 따라 검산하고 Ctrl + S로 저장한다.
  5. 같은 방법으로 7~11행, 12~16행, 17~21행을 입력하고, 구간을 마칠 때마다 검산하고 저장한다.

입력할 때에는 다음에 유의한다. 날짜는 연도까지 입력한다. 숫자에는 쉼표와 단위를 붙이지 않는다. 자동 완성으로 제시된 내용은 원본과 같은지 확인한 뒤 확정한다.

구간별 검산. 한 구간을 입력할 때마다 그 구간의 수량과 단가를 각각 선택하여 상태 표시줄을 읽는다. 기준 값은 1월 기준 파일(판매_2026_01.xlsx)에서 계산한 값이다. 같은 값을 누계로도 적었으므로, 구간 하나를 건너뛰었으면 E2부터 그 구간의 끝까지를 선택하여 누계로 대조할 수 있다.

구간(판매번호) 수량의 범위 평균 합계 누계(E2부터) 단가의 범위 합계 누계(F2부터)
1001~1005 E2:E6 26.4 132 132 F2:F6 209000 209000
1006~1010 E7:E11 31 155 287 F7:F11 64000 273000
1011~1015 E12:E16 23 115 402 F12:F16 131000 404000
1016~1020 E17:E21 18.2 91 493 F17:F21 128000 532000

예상. 첫 구간(1001~1005)을 마치면 수량 범위 E2:E6의 상태 표시줄은 다음과 같아야 한다. [개수]와 [숫자 개수]가 모두 5이면 다섯 셀이 모두 숫자로 들어간 것이고, 그 위에서 합계가 132이면 값도 맞는 것이다.

선택한 범위   E2:E6
평균 26.4    개수 5    숫자 개수 5    합계 132
  • 확인 26 첫 구간의 수량 E2:E6은 개수 5, 숫자 개수 5, 합계 132이고, 단가 F2:F6의 합계는 209000이다. Ctrl + S로 저장하였다.

한 구간의 값이 기준 값과 다르면 그 구간의 다섯 행만 원본과 한 행씩 대조한다. 다음 구간으로 넘어가기 전에 고치는 것이 원칙이다. 틀린 구간을 남긴 채 다음 구간을 입력하면 누계가 모두 어긋나 이후의 검산이 쓸모없어진다.

  • 확인 27 두 번째 구간까지 입력한 뒤 E2:E11의 합계(누계)가 287, F2:F11의 합계가 273000이다.

  • 확인 28 F21에 4000을 입력하였고, 22행 이하에는 입력한 내용이 없다. 네 구간의 합계가 모두 기준 값과 같고 Ctrl + S로 저장하였다.

결과 읽기. 마지막 구간을 마치면 Ctrl + End를 눌러 이름 상자를 읽는다. F21이면 자료가 A1:F21 안에만 있는 것이다. G 열이나 22행 이하의 셀로 이동하면 표의 바깥에 무엇인가 입력되어 있으므로, 그 셀을 찾아 Delete로 지운다. 표 바깥에 남은 내용은 2장의 인쇄 설정에서 출력물을 여러 쪽으로 나누는 원인이 된다.

단계 6. 자료 종류의 검산

입력한 값이 기준 값과 같더라도 종류가 다르면(날짜가 문자로 들어간 경우 등) 2장 이후의 서식과 수식에서 오류가 생긴다. 이 단계에서는 열마다 [숫자 개수]를 읽어 종류를 검산한다.

예상. 판매번호, 판매일, 수량, 단가의 네 열은 모두 숫자(날짜 포함)이므로 각 열의 [숫자 개수]는 20이다. 거래처와 품목의 두 열은 문자이므로 C2:D21의 [개수]는 40, [숫자 개수]는 0이다.

  1. 이름 상자에 B2:B21을 입력하고 Enter를 눌러 상태 표시줄의 [개수]와 [숫자 개수]를 읽는다.
  2. 같은 방법으로 C2:D21, E2:F21을 차례로 선택하여 읽는다.
  3. B열부터 F열까지를 훑어보며 셀의 맞춤을 관찰한다. 판매일, 수량, 단가는 오른쪽, 거래처와 품목은 왼쪽에 놓여야 한다.
B2:B21    개수 20    숫자 개수 20
C2:D21    개수 40    (숫자 개수 0 또는 표시되지 않음)
E2:F21    개수 40    숫자 개수 40    합계 532493

E2:F21의 합계 532493은 수량의 합계 493과 단가의 합계 532000을 더한 값으로, 의미는 없으나 두 열을 한 번에 검산하는 데 쓸 수 있다.

  • 확인 29 B2:B21의 숫자 개수가 20, E2:F21의 숫자 개수가 40이고, 판매일, 수량, 단가의 모든 셀이 오른쪽에 놓였다.

판매일의 [숫자 개수]가 19 이하이면 B열에서 왼쪽에 놓인 셀을 찾는다. 마침표로 구분하였거나(2026.01.02) 날짜 사이에 문자가 들어간 경우이다. 그 셀을 선택하여 2026-01-02의 모양으로 다시 입력하고, 다시 [숫자 개수]를 읽는다.

완료 기준

입력을 마치면 아래의 표에 따라 결과를 점검한다. 모든 항목이 기준 값과 일치하여야 실습이 완료된다. 점검 방법에서 범위를 선택하는 항목은 선택한 뒤 상태 표시줄의 값을 읽는다.

번호 점검 항목 점검 방법 기준 값
1 폴더의 구조 파일 탐색기에서 컴퓨터활용 폴더를 연다 하위 폴더 3개(자료, 실습, 출력)
2 파일의 위치와 이름 파일 탐색기에서 실습 폴더를 연다 판매현황_01_학번.xlsx
3 시트 이름 시트 탭을 확인한다 판매내역
4 머리글 A1:F1을 원본과 대조한다 판매번호, 판매일, 거래처, 품목, 수량, 단가
5 입력한 행의 수 A2:A21을 선택한다 개수 20
6 판매번호 A2와 A21의 값을 확인한다 1001, 1020
7 판매일 B2와 B21의 수식 입력줄과 맞춤을 확인하고, B2:B21을 선택한다 2026-01-02, 2026-01-29, 모두 오른쪽 맞춤, 숫자 개수 20
8 거래처와 품목 C2:D21을 선택하고 원본과 한 행씩 대조한다 개수 40, 원본과 동일
9 수량의 합계 E2:E21을 선택한다 개수 20, 합계 493
10 단가의 합계 F2:F21을 선택한다 개수 20, 합계 532000
  • 표시 형식을 지정하지 않았으므로 상태 표시줄의 합계는 쉼표 없이 표시된다.
  • 5번과 9번은 입력한 행의 수와 수량의 합계를 확인하는 항목으로, 본 장의 결과를 판정하는 기본 기준이다.

합계가 기준 값과 다르면 단계 5의 「구간별 검산」 표로 돌아가 오류가 있는 구간을 먼저 찾는다. 네 구간의 범위를 차례로 선택하여 상태 표시줄의 합계를 대조하고, 값이 다른 구간의 다섯 행만 원본과 대조한다.

개수가 20보다 작으면 빈 셀이 있는 것이다. 개수는 20인데 합계가 기준 값보다 작으면 문자로 입력된 셀이 있을 수 있다. 문자로 입력된 셀은 개수에는 포함되고 합계에는 포함되지 않기 때문이다. 이 경우에는 상태 표시줄의 [숫자 개수]가 20인지 확인하고(4-3), 수량과 단가의 열에서 왼쪽에 맞추어진 셀을 찾아 다시 입력한다.

오류 위치의 탐색

구간을 찾은 뒤에는 기준 값과의 차이를 계산하면 다섯 행 가운데 어느 셀이 틀렸는지를 더 좁힐 수 있다. 차이는 (읽은 합계) - (기준 값)이다. 차이의 모양에 따라 의심할 곳이 다르다.

차이의 모양 의심할 곳 예(1월 자료)
그 구간의 한 셀의 값과 같다 그 셀이 비었거나 두 번 들어갔다. [개수]가 4 또는 6인지 함께 본다 1001~1005의 수량 합계가 102이면 차이는 -30이며, 1001의 수량 30이 빠졌을 수 있다
9의 배수이다 두 자리의 순서가 바뀌었다(예: 45를 54로 입력). 두 자리를 맞바꾸면 차이는 언제나 9의 배수이다 1013의 수량 45를 54로 입력하면 1011~1015의 합계는 124, 차이는 +9이다
10, 100, 1000 등의 배수이다 한 자리의 숫자를 잘못 눌렀다(예: 35를 25로 입력하면 -10) 1009의 수량 35를 25로 입력하면 1006~1010의 합계는 145, 차이는 -10이다
단가의 합계에서 두 품목 단가의 차이와 같다 다른 품목의 단가를 입력하였다. 품목과 단가의 표와 대조한다 1002의 볼펜에 A4 복사용지의 단가 24000을 입력하면 차이는 +18000이다
단가의 합계에서 0이 하나 많거나 적다 0을 하나 더 눌렀거나 빠뜨렸다 1007의 단가 4000을 40000으로 입력하면 차이는 +36000이다
수량은 맞고 단가만 다르다, 또는 그 반대이다 차이가 난 열만 대조한다

차이가 없는데 원본과 다른 셀이 있을 수도 있다. 두 셀이 서로 반대 방향으로 틀리면 합계는 맞게 나온다. 합계에 의한 검산은 오류의 대부분을 찾아 주지만 모두를 찾아 주지는 않으므로, 거래처와 품목처럼 합계로 검산할 수 없는 문자 열은 원본과 한 행씩 대조한다(완료 기준 8번).

  • 확인 30 완료 기준 표의 열 개 항목이 모두 기준 값과 일치하였다.

제출

  1. Ctrl + S로 저장하고 엑셀을 종료한다.
  2. 실습 폴더의 판매현황_01_학번.xlsx를 부록 A에 안내된 경로로 제출한다. 연습용 통합 문서(판매연습_01_학번.xlsx)는 제출하지 않는다.
  3. 컴퓨터활용 폴더 전체를 개인 저장 매체나 클라우드 저장소에 복사하여 보관한다.
  • 확인 31 판매현황_01_학번.xlsx를 제출하고 컴퓨터활용 폴더의 사본을 보관하였다.

셀에 ####이 표시된다 열의 너비가 값보다 좁다 값은 정상이다. 열의 너비는 다음 장에서 조정한다

셀의 내용이 다른 위치로 옮겨졌다 채우기 핸들이 아닌 셀의 테두리를 끌었다 Ctrl + Z로 취소한다

합계는 다른데 개수는 기준 값과 같다 값을 잘못 입력하였거나 문자로 입력된 셀이 있다 [숫자 개수]를 확인하고, 구간별 합계를 대조하여 해당 행을 찾는다

클라우드 저장소의 파일을 열어 고쳤더니 원본이 바뀌었다 자동 저장이 켜진 파일은 고친 내용이 원본에 계속 저장된다 버전 기록에서 이전 버전을 복원한다. 이후에는 고치기 전에 [복사본 저장]을 수행한다
[파일] 탭에 [다른 이름으로 저장]이 없고 [복사본 저장]이 있다 클라우드 저장소(OneDrive 등)에 있는 파일을 열었다 수업의 파일은 PC의 컴퓨터활용 폴더에서 연다
CSV로 저장한 뒤 다시 열었더니 시트와 서식이 사라졌다 CSV는 활성 시트의 표시된 값만 텍스트로 저장한다 .xlsx 파일을 다시 연다. 작업 중인 통합 문서는 .xlsx로만 저장한다
다른 프로그램에서 CSV의 한국어가 깨진다 문자 인코딩이 다르다. [CSV(쉼표로 분리)]는 Windows의 기본 인코딩으로 저장된다 받는 쪽의 인코딩을 확인하거나 UTF-8의 CSV로 저장한다(이 과목에서는 사용하지 않는다)
합계는 맞는데 원본과 다른 셀이 있다 두 셀이 반대 방향으로 틀려 차이가 상쇄되었다 거래처와 품목처럼 수량과 단가도 구간 안에서 한 행씩 대조한다

심화 실습

핵심 실습을 완료한 수강생을 위한 선택 실습이며 제출하지 않는다.

입력 원본의 판매일은 2026년 1월 2일부터 1월 29일까지의 평일 20일이다. 이 날짜를 채우기 핸들로 채운다.

  1. Ctrl + N을 눌러 새 통합 문서를 연다.
  2. A1에 2026-01-02를 입력한다.
  3. A1을 선택하고 채우기 핸들을 A20까지 끈다. A20에 2026-01-21이 채워진다.
  4. [자동 채우기 옵션] 단추를 선택하고 [평일 단위 채우기]를 선택한다.
  5. A20의 값이 2026-01-29로 바뀌었는지 확인한다.
  6. 새 통합 문서는 저장하지 않고 닫는다.

연습 문제

연습용 통합 문서(판매연습_01_학번.xlsx)에서 수행한다. 절차는 제시하지 않으며, 본 장에서 다룬 조작만으로 해결할 수 있다. 결과가 기준 값과 일치하면 완료된 것이다.

문제 1. 판매내역 시트에서 판매번호 1030부터 1039까지 10건의 수량에 대하여 합계, 평균, 개수를 구한다.

  • 기준 값: 합계 272, 평균 27.2, 개수 10
  • 실마리: 판매번호가 놓인 행 번호를 먼저 찾는다(4-1의 Ctrl + 방향키, 4-2의 이름 상자).

문제 2. 판매내역 시트에서 거래처가 한빛상사인 판매 건의 수량만을 선택하여 개수와 합계를 구한다.

  • 기준 값: 개수 4, 합계 86
  • 실마리: 떨어져 있는 셀의 선택(4-2). 개수가 4가 아니면 C열을 다시 훑어 빠진 행을 찾는다.

문제 3. 입력연습 시트의 빈 열 두 개에 다음의 값을 채우기 핸들로 입력한다. (가) 5에서 시작하여 5씩 증가하는 수 10개. (나) 2026년 2월의 월요일에 해당하는 날짜 전부(첫 월요일은 2026-02-02이다).

  • 기준 값: (가) 마지막 값 50, 합계 275. (나) 날짜 4개, 마지막 값 2026-02-23
  • 실마리: 두 셀로 증가의 간격을 알려 주는 채우기(5-6). 날짜의 간격은 7일이다.

개념 점검

  1. 경로 C:\Users\사용자이름\Documents\컴퓨터활용\실습\판매연습_01_2027000.xlsx에서 파일이 들어 있는 폴더의 이름, 파일 이름, 확장자를 각각 적는다.
  2. 자료 폴더의 파일을 열어 작업할 때 [저장]보다 [다른 이름으로 저장]을 먼저 수행하여야 하는 이유를 설명한다.
  3. 단가를 입력하는 셀에 24000원을 입력하였다. 이 셀이 놓이는 위치(왼쪽 또는 오른쪽), 엑셀이 인식한 자료의 종류, 그로 인하여 발생하는 문제를 적는다.
  4. 수량 20개를 입력한 범위를 선택하였더니 상태 표시줄의 [개수]는 20, [숫자 개수]는 19였다. 이 범위에 어떤 오류가 있는지 설명한다.
  5. 1001이 입력된 셀 하나를 선택하여 채우기 핸들을 끈 결과와, 1001과 1002가 입력된 두 셀을 선택하여 끈 결과의 차이를 설명한다.
