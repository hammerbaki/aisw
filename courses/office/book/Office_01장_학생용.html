파일 관리와 데이터 입력

2027학년도 「컴퓨터활용」의 준비 중인 교재입니다. 편집 상태를 검토하기 위해 미리 공개한 것으로, 수업 전에 내용과 순서가 바뀔 수 있습니다.

학사 2주차 · 교재 01 · 1부 엑셀

「컴퓨터 활용」은 엑셀에서 작성한 하나의 판매 자료를 서식, 수식, 함수, 차트, 피벗 테이블로 확장하고, 같은 자료를 파워포인트, 파이썬, 생성형 AI, 액세스에서 다시 사용하는 과목이다. 본 장은 그 출발점으로서, 이후의 모든 장이 사용하는 판매 자료 20행을 직접 입력하여 지정된 위치에 지정된 이름으로 저장한다.

1~5절은 설명과 시연이며, 각 절 끝의 「따라 하기」에서 2월 자료로 같은 조작을 수행한다. 6절의 핵심 실습에서는 1월 자료 20행을 빈 통합 문서에 입력하고 완료 기준의 값으로 판정한다. 서식과 인쇄 설정은 2장 「셀 서식과 인쇄 설정」에서 다룬다.

수업 시간의 범위. 150분 수업에서는 번호를 붙인 절의 설명과 따라 하기, 핵심 실습까지 한다. 심화 실습, 연습 문제, 개념 점검은 시간이 남을 때나 수업 뒤에 한다.

학습 목표

  • 파일을 지정된 폴더에 지정된 이름과 형식으로 저장할 수 있다.
  • 셀과 범위를 선택하고 문자, 숫자, 날짜 자료를 구분하여 입력하며, 입력 직후의 맞춤 위치로 자료의 종류를 판별할 수 있다.
  • 채우기 핸들로 연속된 값을 입력하고, 상태 표시줄의 값으로 입력 결과를 검산할 수 있다.

1. 실습 폴더의 구성

1-1. 폴더와 경로

파일(file)은 자료가 저장되는 단위이고, 폴더(folder)는 파일과 다른 폴더를 담는 단위이다. 경로(path)는 드라이브에서 파일에 이르는 폴더를 순서대로 적은 것이며, 폴더 사이는 역슬래시(\, 한글 글꼴에서는 ₩)로 구분한다.

C:\Users\사용자이름\Documents\컴퓨터활용\실습\판매현황_01_2027000.xlsx

파일 탐색기의 주소 표시줄은 평소에는 폴더 이름을 >로 이은 이동 경로를, 빈 곳을 클릭하면 드라이브 문자로 시작하는 문자열을 표시한다. 이동 경로에는 [문서]처럼 한국어 이름이, 문자열에는 Documents처럼 실제 폴더 이름이 나타난다.

이동 경로로 표시될 때     … > 문서 > 컴퓨터활용 > 실습
클릭하여 문자열로 바꿀 때  C:\Users\사용자이름\Documents\컴퓨터활용\실습

경로는 오른쪽 끝에서부터 읽는다. 오른쪽 끝이 지금 열린 폴더이고 그 왼쪽이 상위 폴더이다. 저장한 파일을 찾지 못하는 경우의 대부분은 저장할 때 이 오른쪽 끝을 읽지 않은 것이 원인이다.

[문서] 폴더를 OneDrive에 백업하도록 설정한 PC에서는 2-3의 자동 저장이 동작할 수 있다. 실습 전에 주소 표시줄의 문자열이 C:\Users\사용자이름\Documents의 모양으로 시작하는지 확인하고, 아니면 교수에게 알린다.

1-2. 실습 폴더의 구조

이 과목의 파일은 모두 [문서] 폴더의 컴퓨터활용 폴더(실습 폴더)에 보관한다. 폴더와 파일 이름에는 공백을 넣지 않는다.

자료 폴더를 따로 두는 이유는 원본의 보존에 있다. 원본이 그대로 있으면 기준 값과 대조할 수 있고 오류가 생겼을 때 다시 시작할 수 있다. 수업을 마칠 때에는 실습 폴더 전체를 개인 저장 매체나 클라우드 저장소에 복사한다.

1-3. 파일 탐색기의 조작

파일 탐색기의 창은 왼쪽의 탐색 창, 위쪽의 주소 표시줄, 가운데의 파일 목록으로 구성된다.

[그림 자리: 파일 탐색기 창의 구성] 컴퓨터활용 폴더를 연 파일 탐색기 창에 탐색 창(왼쪽), 주소 표시줄(위쪽), 파일 목록(가운데)의 세 곳을 번호로 표시하고, 주소 표시줄은 이동 경로의 모습과 클릭한 뒤의 문자열 모습을 나란히 보인다. 찍을 곳: Windows 11 파일 탐색기, [문서] → 컴퓨터활용 폴더.

여러 항목의 선택 모두 Ctrl + A. 연속한 항목은 첫 항목을 클릭하고 Shift를 누른 채 마지막 항목을 클릭. 떨어진 항목은 Ctrl을 누른 채 클릭

복사는 원본을 둔 채 사본을 만들고, 이동은 원본의 위치를 바꾼다. 자료 폴더의 파일은 복사하여 써야 원본이 남는다. Shift + Delete는 휴지통을 거치지 않고 영구 삭제하므로 사용하지 않는다. 위 표의 단축키는 Windows 10과 11에서 같다.

따라 하기

실습 폴더를 작성하고 월별 파일 12개를 자료 폴더로 옮긴 뒤, 한 파일을 실습 폴더에 복사한다.

  1. Win + E를 눌러 파일 탐색기를 실행하고 탐색 창에서 [문서] 폴더를 선택한다.
  2. Ctrl + Shift + N을 눌러 새 폴더를 작성하고 이름을 컴퓨터활용으로 입력한 뒤 Enter를 누른다.
  3. 작성한 폴더를 더블 클릭하여 열고, 같은 방법으로 자료, 실습, 출력 폴더를 작성한다. 폴더를 열지 않은 채 작성하면 [문서] 폴더에 생긴다.
  4. 주소 표시줄의 빈 곳을 클릭하여 경로를 확인한 뒤 Esc를 누른다.
  5. 부록 A의 안내에 따라 받은 월별 파일 12개가 있는 폴더를 연다.
  6. 첫 파일을 클릭한 뒤 Shift를 누른 채 마지막 파일을 클릭하여 12개를 모두 선택하고 Ctrl + X를 누른다.
  7. 컴퓨터활용 폴더의 자료 폴더를 열고 Ctrl + V를 누른다.
  8. 자료 폴더에서 3월 파일(판매_2026_03)을 선택하고 Ctrl + C를 누른다.
  9. Alt + ↑를 눌러 컴퓨터활용 폴더로 이동하고, 실습 폴더를 열어 Ctrl + V를 누른다.
  • 확인 1 주소 표시줄의 경로가 컴퓨터활용으로 끝나는 폴더에 자료, 실습, 출력이 있다. 자료 폴더에는 판매_2026_01부터 판매_2026_12까지 12개가 있고 파일을 받았던 폴더에는 남아 있지 않으며, 실습 폴더에는 3월 파일의 사본이 1개 있다.

폴더가 [문서]에 잘못 생겼으면 Ctrl + X로 옮긴다. 자료 폴더의 파일이 11개 이하이면 단계 6의 선택에서 첫 파일이나 마지막 파일이 빠진 것이다.

2. 파일 이름과 저장 형식

2-1. 파일 이름과 확장자

파일 이름은 이름.확장자의 형태이다. 확장자(extension)는 파일의 형식을 나타내며, Windows는 확장자에 따라 파일을 여는 프로그램을 정한다. 엑셀 통합 문서의 확장자는 .xlsx이다. 기본 설정에서는 확장자가 표시되지 않아 판매현황_02_학번.xlsx와 판매현황_02_학번.pdf를 아이콘으로만 구분하여야 하므로, 이 과목에서는 확장자를 표시한다.

버전에 따른 차이: Windows 11에서는 파일 탐색기의 [보기] → [표시] → [파일 이름 확장명]을 선택한다. Windows 10에서는 [보기] → [옵션] → [폴더 및 검색 옵션 변경]을 선택하고, 대화 상자의 [보기] 탭에 있는 [고급 설정]에서 [알려진 파일 형식의 확장명 숨기기]의 선택을 해제한다.

파일 이름에는 \ / : * ? " < > |를 쓸 수 없다. 이름을 바꿀 때 확장자를 지우거나 바꾸면 Windows가 파일을 여는 프로그램을 찾지 못한다. 확장자를 바꾸어 적어도 형식은 변환되지 않으며, 형식의 변환은 [다른 이름으로 저장]으로 한다(2-4).

2-2. 파일 이름의 규칙

판매현황_장 번호_학번.xlsx      핵심 실습의 통합 문서(제출한다)
판매연습_장 번호_학번.xlsx      연습용 통합 문서(제출하지 않는다)

장 번호는 두 자리로 적고(이름 순으로 나열할 때 02가 10보다 앞에 놓인다), 구분에는 밑줄(_)을 쓰며 공백을 넣지 않는다. 학번이 2027000이면 본 장 결과 파일은 판매현황_01_2027000.xlsx이다.

2-3. 저장과 다른 이름으로 저장

[저장] (Ctrl + S)은 현재의 위치와 이름에 덮어쓰고, 처음 저장하는 문서에서는 위치와 이름을 묻는다. [다른 이름으로 저장] (F12)은 대화 상자에서 위치, 이름, 형식을 새로 지정한다. 열기는 Ctrl + O, 닫기는 Ctrl + W이다. 자료 폴더의 파일을 열어 [저장]하면 원본이 바뀐다. 열자마자 [다른 이름으로 저장]으로 실습 폴더에 새 이름을 부여하면 그 뒤의 [저장]은 새 파일에만 적용되어 원본이 보존된다. 이 과목의 모든 장은 이 순서로 시작한다. 대화 상자에서는 (1) 위쪽 주소 표시줄의 폴더, (2) [파일 이름]이 규칙과 일치하는가(확장자는 자동으로 붙는다), (3) [파일 형식]이 Excel 통합 문서 (*.xlsx)인가의 세 가지를 확인한다.

[그림 자리: [다른 이름으로 저장] 대화 상자의 확인할 세 곳] 대화 상자의 위쪽 주소 표시줄(저장할 폴더), 아래쪽의 [파일 이름]과 [파일 형식]에 번호를 붙이고, 주소 표시줄이 자료 폴더를 가리키는 상태와 실습 폴더로 바꾼 상태를 나란히 보인다. 찍을 곳: Microsoft 365 엑셀, F12로 연 대화 상자.

저장이 끝나면 제목 표시줄에 새 파일 이름이 표시된다. 아래는 교수의 작업 PC(Microsoft 365, 확장명 표시 설정을 켠 상태)에서 읽은 창의 제목을 이 과목의 파일 이름에 맞추어 적은 것이다(2026-11-15 확인).

인터넷에서 내려받은 파일을 열면 창 위쪽에 노란색 메시지 표시줄이 나타나고 입력이 되지 않을 수 있다. 출처가 불확실한 파일을 읽기 전용으로 여는 제한된 보기이며, 수업에서 배포한 파일이면 [편집 사용]을 선택한다.

버전에 따른 차이: 새 문서에서 Ctrl + S나 [파일] 탭 → [다른 이름으로 저장]을 선택하였을 때의 화면은 버전에 따라 다르며, 클라우드 저장소가 기본 위치로 제시되기도 한다. F12는 버전과 관계없이 대화 상자를 직접 연다(노트북에서는 Fn 키와 함께 누르기도 한다).

자동 저장. 제목 표시줄 왼쪽의 [자동 저장]은 OneDrive, SharePoint Online의 파일에서만 동작하며, 이런 파일에서는 [파일] 탭에 [다른 이름으로 저장] 대신 [복사본 저장]이 표시된다. 실습 폴더를 PC의 [문서] 폴더에 두는 이유가 여기에 있다.

3. 엑셀 화면의 구성

3-1. 통합 문서, 워크시트, 셀

엑셀의 파일 하나를 통합 문서(workbook)라 한다. 통합 문서는 하나 이상의 워크시트(worksheet, 이하 시트)로, 시트는 행(row)과 열(column)이 교차하는 셀(cell)로 구성된다. 열은 영문자(A, …, Z, AA)로, 행은 숫자로 구분하며, 셀의 주소는 열 문자와 행 번호를 이어 쓴다(B3). 하나의 셀에는 하나의 값을 입력한다. 시트 하나는 1,048,576행, 16,384열이다.

이름 상자     B2

3-3. 리본 메뉴의 표기와 표시

이 교재는 리본 메뉴의 명령을 [홈] 탭 → [편집] 그룹 → [지우기]와 같이 [탭] 탭 → [그룹] 그룹 → [명령]의 순서로 표기한다. 단추가 숨겨져 탭의 이름만 보이면 Ctrl + F1을 누르거나 [리본 표시 옵션]에서 [항상 리본 표시]를 선택한다.

버전에 따른 차이: 리본 메뉴의 탭 구성과 단추의 모양은 오피스의 버전에 따라 다르다. 엑셀을 실행하였을 때 시작 화면이 나타나는 버전에서는 [새 통합 문서]를 선택하여야 빈 시트가 열린다.

3-4. 시트의 추가와 이름 변경

시트 탭 오른쪽의 [새 시트] 단추(더하기 모양)를 누르면 시트가 추가된다. 이름은 시트 탭을 더블 클릭하거나 마우스 오른쪽 단추로 클릭하여 [이름 바꾸기]를 선택한 뒤 입력하고, 제거는 같은 메뉴의 [삭제]로 한다. 자료가 있는 시트의 이름은 판매내역으로 통일하며, 시트를 추가할 때마다 교재가 이름을 지정한다.

따라 하기

연습용 통합 문서(판매연습_01_학번.xlsx)에서 이름 상자와 수식 입력줄을 읽고 연습용 시트를 추가한다.

  1. D2 셀을 클릭하고 이름 상자와 수식 입력줄을 읽는다.
  2. B2 셀을 클릭하고 수식 입력줄을 읽는다.
  3. 이름 상자를 클릭하여 F20을 입력하고 Enter를 누른 뒤 수식 입력줄을 읽는다. 다른 셀이 선택되면 한/영 키로 영문 입력 상태로 바꾸어 다시 입력한다.

4. 셀과 범위의 선택

엑셀의 명령은 선택된 셀을 대상으로 동작하므로 조작은 항상 선택이 먼저이다. 굵은 테두리로 표시된 셀을 활성 셀(active cell)이라 하며, 입력한 내용은 활성 셀에 들어간다.

4-1. 셀의 이동

키 이동하는 위치

Tab, Shift + Tab 한 셀 오른쪽, 한 셀 왼쪽
Enter, Shift + Enter 한 셀 아래, 한 셀 위

4-2. 범위의 선택

범위(range)는 직사각형 모양으로 연속된 셀의 묶음이며, 왼쪽 위 셀과 오른쪽 아래 셀의 주소를 쌍점(:)으로 이어 표기한다. A2:F21은 20행, 6열, 120개의 셀이다.

선택 대상 조작
셀 하나 셀을 클릭하거나, 이름 상자에 주소를 입력하고 Enter
연속된 범위 첫 셀에서 끝 셀까지 끈다. 또는 첫 셀을 클릭하고 Shift를 누른 채 끝 셀을 클릭

4-3. 상태 표시줄에 의한 검산

숫자가 입력된 범위를 선택하면 상태 표시줄에 평균, 개수, 합계가 표시된다. 본 장에서는 이 값을 입력 결과의 검산에 사용한다. 표시할 항목은 상태 표시줄을 마우스 오른쪽 단추로 클릭하여 고른다.

[그림 자리: 상태 표시줄의 검산 값] 연습용 통합 문서에서 E2:E20을 선택한 상태의 엑셀 창 아래쪽을 확대하여, 상태 표시줄 오른쪽의 평균, 개수, 합계와 사용자 지정 목록(상태 표시줄을 마우스 오른쪽 단추로 클릭한 모습)을 함께 보인다. 찍을 곳: Microsoft 365 엑셀, 상태 표시줄.

아래는 연습용 통합 문서의 수량(E2:E20)을 선택하였을 때의 값이다. 항목의 간격과 순서는 버전에 따라 다를 수 있다.

선택한 범위   E2:E20
평균 28    개수 19    합계 532

[평균], [개수], [합계]는 기본으로 표시되고, [숫자 개수] (화면에 따라 [숫자 셀 수]. 목록에서 [개수]의 바로 아래), [최소값], [최대값]은 목록에서 골라야 표시된다. [개수]는 내용이 있는 셀(문자 포함)을, [숫자 개수]는 숫자가 든 셀만 센다. 2, 3, 문자, 4의 네 셀을 선택하면 [개수]는 4, [숫자 개수]는 3이다. 본 장의 따라 하기에서 [숫자 개수]를 켜고 그대로 둔다. 검산의 판단 기준은 다음과 같다.

5. 자료의 입력과 자동 채우기

5-1. 자료의 종류

엑셀은 입력을 확정하는 순간 그 글자가 숫자나 날짜로 읽히면 숫자로, 읽히지 않으면 글자 그대로 문자로 저장한다. 종류에 따라 계산과 정렬의 결과가 달라진다. 맞춤을 지정하지 않은 셀에서 문자는 왼쪽에, 숫자와 날짜는 오른쪽에 놓이므로 종류는 입력 직후의 맞춤 위치로 판별한다. 숫자는 쉼표와 단위 없이, 날짜는 2026-01-02처럼 붙임표로 구분하여 연도까지 입력한다. 날짜로 읽힌 입력에는 Windows의 기본 날짜 설정에 따른 표시 형식이 자동으로 지정되므로 PC마다 모양이 다를 수 있다.

Tab 입력을 확정하고 오른쪽 셀로 이동한다
Esc 입력을 취소한다

5-3. 행 단위의 입력

표의 자료는 한 행씩 입력한다. Tab으로 오른쪽으로 이동하며 입력하고 행의 끝에서 Enter를 누르면, 활성 셀이 다음 행의 입력을 시작한 열로 이동한다. 도중에 방향키나 마우스로 다른 셀을 선택하면 시작한 열의 기억이 사라지므로 한 행을 마칠 때까지 Tab만 쓴다.

5-4. 자동 완성

문자를 입력할 때 같은 열의 위쪽에 앞 글자가 같은 자료가 있으면 엑셀이 나머지 글자를 제시한다. 맞으면 Enter나 Tab으로 확정하고, 다르면 계속 입력한다. 앞 글자가 같은 다른 자료가 제시될 수 있으므로 확정하기 전에 원본과 대조한다.

5-5. 화면의 표시와 실제 값

셀의 모양과 실제 값은 다를 수 있으며, 실제 값은 수식 입력줄에 표시된다. 열의 너비보다 긴 문자는 오른쪽 셀이 비어 있으면 넘쳐서, 내용이 있으면 잘려서 표시된다. 너비보다 긴 숫자나 날짜는 ####으로, 12자리 이상의 숫자는 1.23E+11과 같은 지수로 표시된다. 어느 경우나 값은 정상이며 열의 너비는 다음 장에서 조정한다.

5-6. 채우기 핸들과 자동 채우기

채우기 핸들(fill handle)은 선택한 셀이나 범위의 오른쪽 아래 모서리에 있는 작은 사각형이다. 포인터가 가는 십자 모양일 때 끌면 선택한 내용을 바탕으로 끈 방향의 셀이 채워진다(자동 채우기).

[그림 자리: 채우기 핸들과 마우스 포인터의 모양] C1:C2를 선택한 상태에서 범위의 오른쪽 아래 모서리의 작은 사각형(채우기 핸들)을 확대하고, 포인터를 올리기 전의 모양(굵은 십자)과 올린 뒤의 모양(가는 십자), 셀의 테두리에 올렸을 때의 모양(이동 화살표)을 세 칸으로 나란히 보인다. 찍을 곳: Microsoft 365 엑셀, “입력연습” 시트.

선택한 자료 채우기 핸들을 끈 결과
숫자가 입력된 셀 하나 같은 숫자가 복사된다
숫자가 입력된 셀 둘(예: 1001, 1002 또는 10, 20) 두 값의 차이만큼 증가하는 값이 채워진다
날짜가 입력된 셀 하나 하루씩 증가하는 날짜가 채워진다
날짜가 입력된 셀 둘(예: 7일 간격) 두 날짜의 간격만큼 증가하는 날짜가 채워진다
문자가 입력된 셀 하나 같은 문자가 복사된다
  • 숫자의 연속 번호는 처음 두 값으로 증가의 규칙을 알려 준다. 위쪽이나 왼쪽으로 끌면 값이 감소한다.
  • 채우기를 마치면 나타나는 [자동 채우기 옵션] 단추에서 [셀 복사]와 [연속 데이터 채우기]로 결과를 바꿀 수 있다.
  • 채운 번호는 고정된 값이므로 중간의 행을 삭제하여도 다시 매겨지지 않는다.
  • 셀의 테두리를 끌면 내용이 이동한다. 의도하지 않았으면 Ctrl + Z로 취소한다.
  • 채우기 핸들이 보이지 않으면 [파일] 탭 → [옵션] → [고급]의 [채우기 핸들 및 셀 끌어서 놓기 사용]을 확인한다.

절차

단계 1. 실습 폴더의 구성

1절과 2절의 따라 하기에서 구성한 실습 폴더를 점검하고, 없는 항목을 작성한다.

  1. Win + E를 눌러 파일 탐색기를 실행하고 [문서] 폴더를 연다.
  2. 컴퓨터활용 폴더가 없으면 Ctrl + Shift + N을 눌러 새 폴더를 작성하고 이름을 컴퓨터활용으로 입력한다.
  3. 컴퓨터활용 폴더를 열고, 자료, 실습, 출력 폴더 가운데 없는 것을 같은 방법으로 작성한다.
  4. 파일 확장명이 표시되도록 설정되어 있는지 확인한다(2-1).

단계 2. 새 통합 문서의 저장

입력하기 전에 먼저 저장하여 위치와 이름을 확정한다. 그러면 이후의 Ctrl + S는 대화 상자 없이 같은 파일에 덮어쓴다.

  1. 엑셀에서 Ctrl + N을 눌러 빈 통합 문서를 연다. 엑셀이 실행되어 있지 않으면 엑셀을 실행하여 빈 통합 문서를 연다.
  2. F12를 눌러 [다른 이름으로 저장] 대화 상자를 연다.
  3. 컴퓨터활용 폴더의 실습 폴더로 이동한다.
  4. [파일 이름]에 판매현황_01_학번을 입력한다. 학번은 본인의 것으로 기재한다.
  5. [파일 형식]이 Excel 통합 문서 (*.xlsx)인지 확인하고 [저장]을 선택한다.
  • 확인 7 [문서] 폴더의 컴퓨터활용 폴더에 자료, 실습, 출력 폴더가 있다. 제목 표시줄에 판매현황_01_학번.xlsx가 표시되고, 파일 탐색기의 실습 폴더에 판매연습_01_학번.xlsx와 판매현황_01_학번.xlsx의 두 파일이 있다.

단계 3. 시트 이름과 머리글의 입력

  1. 시트 탭의 Sheet1을 더블 클릭하고 판매내역을 입력한 뒤 Enter를 누른다.
  2. A1 셀을 선택한다.
  3. 판매번호, 판매일, 거래처, 품목, 수량, 단가를 차례로 입력한다. 항목 사이에서는 Tab을 누르고, 단가를 입력한 뒤에는 Enter를 누른다.

입력을 마치면 활성 셀은 A2에 놓인다. 머리글은 6장 「피벗 테이블」에서 필드의 이름으로 쓰이므로 공백까지 원본과 같게 입력한다.

단계 4. 판매번호의 입력

판매번호는 1001부터 1020까지 1씩 증가하므로 채우기 핸들로 입력한다.

  1. A2에 1001, A3에 1002를 입력한다.
  2. A2:A3을 선택한다.
  3. 채우기 핸들을 A21까지 끈다.
  • 확인 8 시트 탭에 판매내역이 표시되고 A1:F1에 머리글 여섯 개가 원본의 순서대로 있다. A21에 1020이 입력되었고, A2:A21을 선택하면 상태 표시줄이 아래와 같다(20210은 1001부터 1020까지의 합).

단계 5. 판매일부터 단가까지의 입력

B2:F21의 100개 셀을 원본을 보고 한 행씩 입력한다. 마지막에 한 번 검산하면 틀린 곳을 찾기 어려우므로 다섯 행마다 그 구간을 검산하고 저장한다.

  2. 2026-01-02, 한빛상사, A4 복사용지, 30, 24000을 차례로 입력한다. 항목 사이에서는 Tab을 누르고, 단가를 입력한 뒤에는 Enter를 누른다. 활성 셀이 B3으로 이동한다.
  3. 같은 방법으로 6행(판매번호 1005)까지 입력한다.
  4. 아래의 「구간별 검산」의 첫 줄에 따라 검산하고 Ctrl + S로 저장한다.

단계 6. 자료 종류의 검산

값이 같더라도 날짜가 문자로 들어가면 2장 이후의 서식과 수식에서 오류가 생긴다. 열마다 [숫자 개수]를 읽어 종류를 검산한다.

  1. 이름 상자에 B2:B21을 입력하고 Enter를 눌러 상태 표시줄의 [개수]와 [숫자 개수]를 읽는다.
  2. 같은 방법으로 C2:D21, E2:F21을 차례로 선택하여 읽는다.
  3. B열부터 F열까지를 훑어보며 셀의 맞춤을 관찰한다. 판매일, 수량, 단가는 오른쪽, 거래처와 품목은 왼쪽에 놓여야 한다.
B2:B21    개수 20    숫자 개수 20
C2:D21    개수 40    (숫자 개수 0 또는 표시되지 않음)
E2:F21    개수 40    숫자 개수 40    합계 532493

E2:F21의 합계 532493은 수량의 합계 493과 단가의 합계 532000을 더한 값으로, 두 열을 한 번에 검산하는 데 쓴다.

  • 확인 11 B2:B21의 숫자 개수가 20, E2:F21의 숫자 개수가 40이고, 판매일, 수량, 단가의 모든 셀이 오른쪽에 놓였다.

판매일의 [숫자 개수]가 19 이하이면 B열에서 왼쪽에 놓인 셀을 찾아 2026-01-02의 모양으로 다시 입력한다.

심화 실습

핵심 실습을 완료한 수강생을 위한 선택 실습이며 제출하지 않는다.

입력 원본의 판매일(2026년 1월 2일~1월 29일의 평일 20일)을 채우기 핸들로 채운다.

  1. Ctrl + N을 눌러 새 통합 문서를 연다.
  2. A1에 2026-01-02를 입력한다.
  3. A1을 선택하고 채우기 핸들을 A20까지 끈다. A20에 2026-01-21이 채워진다.
  4. [자동 채우기 옵션] 단추를 선택하고 [평일 단위 채우기]를 선택한다.
  5. A20의 값이 2026-01-29로 바뀌었는지 확인한다.
  6. 새 통합 문서는 저장하지 않고 닫는다.

연습 문제

연습용 통합 문서에서 수행한다. 본 장에서 다룬 조작만으로 해결할 수 있다.

문제 1. 판매내역 시트에서 판매번호 1030부터 1039까지 10건의 수량에 대하여 합계, 평균, 개수를 구한다.

  • 기준 값: 합계 272, 평균 27.2, 개수 10
  • 실마리: 판매번호가 놓인 행 번호를 먼저 찾는다(4-1의 Ctrl + 방향키, 4-2의 이름 상자).

문제 2. 판매내역 시트에서 거래처가 한빛상사인 판매 건의 수량만을 선택하여 개수와 합계를 구한다.

  • 기준 값: 개수 4, 합계 86
  • 실마리: 떨어져 있는 셀의 선택(4-2).

문제 3. 입력연습 시트의 빈 열 두 개에 다음의 값을 채우기 핸들로 입력한다. (가) 5에서 시작하여 5씩 증가하는 수 10개. (나) 2026년 2월의 월요일에 해당하는 날짜 전부(첫 월요일은 2026-02-02이다).

  • 기준 값: (가) 마지막 값 50, 합계 275. (나) 날짜 4개, 마지막 값 2026-02-23
  • 실마리: 두 셀로 증가의 간격을 알려 주는 채우기(5-6). 날짜의 간격은 7일이다.

개념 점검

  1. 경로 C:\Users\사용자이름\Documents\컴퓨터활용\실습\판매연습_01_2027000.xlsx에서 파일이 들어 있는 폴더의 이름, 파일 이름, 확장자를 각각 적는다.
  2. 자료 폴더의 파일을 열어 작업할 때 [저장]보다 [다른 이름으로 저장]을 먼저 수행하여야 하는 이유를 설명한다.
  3. 단가를 입력하는 셀에 24000원을 입력하였다. 이 셀이 놓이는 위치(왼쪽 또는 오른쪽), 엑셀이 인식한 자료의 종류, 그로 인하여 발생하는 문제를 적는다.
  4. 수량 20개를 입력한 범위를 선택하였더니 상태 표시줄의 [개수]는 20, [숫자 개수]는 19였다. 이 범위에 어떤 오류가 있는지 설명한다.
  5. 1001이 입력된 셀 하나를 선택하여 채우기 핸들을 끈 결과와, 1001과 1002가 입력된 두 셀을 선택하여 끈 결과의 차이를 설명한다.
