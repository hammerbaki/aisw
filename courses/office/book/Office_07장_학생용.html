엑셀 자료를 활용한 슬라이드 작성

2027학년도 「컴퓨터활용」의 준비 중인 교재입니다. 편집 상태를 검토하기 위해 미리 공개한 것으로, 수업 전에 내용과 순서가 바뀔 수 있습니다.

학사 9주차 · 교재 07 · 2부 파워포인트

본 장부터 2부 파워포인트이다. 6장 「피벗 테이블」의 거래처별 금액 합계와 5장 「정렬, 필터, 차트」의 한빛상사 품목별 금액 차트를 슬라이드에 삽입하고, 도형으로 판매 업무의 흐름도를 작성하여 슬라이드 2매의 판매 현황 보고 자료를 완성한다. 새로운 계산은 하지 않으며, 슬라이드의 수치를 엑셀의 값과 대조하는 것으로 실습을 마친다.

각 절의 「따라 하기」는 연습용 프레젠테이션(연습_07_학번.pptx)과 2월 자료의 연습용 통합 문서(판매연습_06_학번.xlsx)로 수행한다. 1월 자료를 쓰는 핵심 실습과는 도형의 구성과 수치가 다르다.

수업 시간의 범위. 150분 수업에서는 번호를 붙인 절의 설명과 따라 하기, 핵심 실습까지 한다. 심화 실습과 연습 문제는 시간이 남을 때나 수업 뒤에 한다.

학습 목표

  1. 프레젠테이션, 슬라이드, 레이아웃, 개체 틀의 관계를 설명하고 슬라이드를 추가, 삭제, 이동한다.
  2. 도형과 글상자를 삽입하고 채우기, 윤곽선, 글꼴, 크기를 지정한다.
  3. 여러 도형을 맞춤과 배분으로 정렬하고 그룹으로 묶으며, 개체의 순서를 변경한다.
  4. 엑셀의 표와 차트를 슬라이드에 붙여 넣고, 붙여넣기 옵션에 따른 편집 가능 여부와 원본과의 연결 여부를 설명한다.
  5. 슬라이드에 기재한 수치를 엑셀의 값과 대조하여 검산한다.
  6. 슬라이드 2매를 유인물의 형태로 한 쪽에 출력하여 PDF로 저장한다.

1. 파워포인트의 화면과 슬라이드

1-1. 엑셀과의 연계

본 장의 슬라이드는 다음으로 구성된다.

슬라이드의 구성 요소 원천 작성한 장
거래처별 금액의 표 “피벗” 시트의 피벗 테이블 6장
품목별 금액의 차트 “한빛상사” 시트의 차트 5장
요약 문장의 수치 피벗 테이블의 총합계와 한빛상사의 값 4장, 6장
판매 업무 흐름도 도형으로 직접 작성한다 본 장

슬라이드의 수치는 다시 계산하거나 기억으로 입력하지 않고, 엑셀에서 검증한 값을 복사하여 가져온 뒤 대조한다.

1-2. 프레젠테이션과 슬라이드

파워포인트의 파일을 프레젠테이션(.pptx)이라 하며, 프레젠테이션은 여러 장의 슬라이드로 구성된다. 엑셀의 통합 문서와 워크시트에 대응하나 슬라이드에는 이름이 없어 제목으로 구별한다. 슬라이드에는 셀과 같은 칸이 없고 도형, 글상자, 표, 차트, 그림이 모두 개체로서 임의의 위치에 놓이므로, 위치를 정돈하는 기능(맞춤, 배분)을 따로 사용한다.

1-3. 화면의 구성

화면 왼쪽의 슬라이드 축소판 창에는 슬라이드가 번호와 함께 작은 그림으로 나열되며, 슬라이드를 선택, 추가, 삭제, 이동하는 곳으로 엑셀의 시트 탭에 해당한다. 가운데의 슬라이드 창에서는 선택한 슬라이드를 편집한다. 아래쪽의 상태 표시줄에는 현재 슬라이드의 번호와 전체 슬라이드의 수가 표시된다.

[그림 자리: 파워포인트의 화면 구성] 슬라이드 축소판 창, 슬라이드 창, 상태 표시줄의 슬라이드 번호 표시(“슬라이드 1/2”의 형태)에 이름을 붙인 화면. 찍을 곳: Microsoft 365 파워포인트, 슬라이드 2매의 프레젠테이션을 연 기본 보기 화면.

축소판 창에서 슬라이드를 선택한 상태의 Ctrl + C는 슬라이드 전체를, 슬라이드 창에서 도형을 선택한 상태의 Ctrl + C는 그 도형을 복사한다.

1-4. 레이아웃과 개체 틀

개체 틀은 제목이나 내용을 입력하도록 미리 준비된 영역으로, 점선의 테두리와 안내 문구로 표시되며 비어 있으면 인쇄되지 않는다. 레이아웃은 슬라이드에 배치된 개체 틀의 구성이며 [홈] 탭 → [슬라이드] 그룹 → [레이아웃]에서 변경한다.

레이아웃 개체 틀 용도
제목 슬라이드 제목, 부제목 표지. 새 프레젠테이션의 첫 슬라이드
제목 및 내용 제목, 내용 글머리 기호 목록, 또는 표나 차트 하나
제목만 제목 도형, 표, 차트를 자유롭게 배치한다. 본 장에서 사용한다
빈 화면 없음 모든 내용을 직접 배치한다

[제목만]을 쓰면 모든 슬라이드의 제목이 같은 위치와 서식으로 놓이고, 내용 개체 틀이 없으므로 붙여 넣은 표와 차트의 크기와 위치가 임의로 변하지 않는다.

[그림 자리: 레이아웃 목록과 제목만 레이아웃] [레이아웃] 목록에서 [제목 슬라이드], [제목 및 내용], [제목만], [빈 화면]의 위치와, [제목만]을 적용한 슬라이드에 제목 개체 틀 하나만 남은 모습. 찍을 곳: Microsoft 365 파워포인트, [홈] 탭 → [슬라이드] 그룹 → [레이아웃].

1-5. 슬라이드의 추가, 삭제, 순서 변경

슬라이드는 축소판 창에서 조작한다.

조작 방법
추가 [홈] 탭 → [슬라이드] 그룹 → [새 슬라이드]의 화살표에서 레이아웃을 고른다. 선택한 슬라이드의 뒤에 추가된다
삭제, 복제 슬라이드를 마우스 오른쪽 단추로 눌러 [슬라이드 삭제] 또는 [슬라이드 복제]를 선택한다
순서 변경 슬라이드를 원하는 위치로 끌어 놓는다. 번호는 다시 부여된다
여러 슬라이드의 선택 Ctrl을 누른 채 차례로 누른다. 연속한 슬라이드는 Shift로 처음과 끝을 누른다

1-6. 가독성의 기준

본 장은 슬라이드를 꾸미지 않고, 읽는 사람이 내용을 놓치지 않기 위한 최소한의 기준만 적용한다. 근거는 Microsoft의 접근성 지침(「장애가 있는 사용자가 액세스할 수 있도록 PowerPoint 프레젠테이션 만들기」)과 W3C의 WCAG 2.1이다(2026-11-15 확인).

기준 본 장에서의 적용 근거
한 슬라이드에 하나의 내용, 서로 다른 제목 1매 “판매 업무 흐름”, 2매 “2026년 1월 판매 현황” 제목이 내용을 대표한다. 화면 읽기 프로그램의 사용자는 제목의 목록으로 슬라이드를 찾는다
글꼴 크기 18 이상 도형과 표 18, 요약 문장 20 Microsoft의 지침은 18pt 이상을 권고하며, WCAG 2.1도 18pt 이상을 “큰 글자”로 정의한다
문자와 배경의 명암 차이 밝은 채우기에 검정 문자 WCAG 2.1은 일반 문자 4.5:1, 큰 글자 3:1 이상의 대비를 정한다
수치의 단위와 기간 머리글 “금액(원)”, 요약 문장의 “1월”과 “원” 단위와 기간이 없는 수치는 엑셀 파일을 보지 않은 사람이 해석할 수 없다

유인물로 인쇄하면 문자도 축소되므로, 글꼴 크기는 인쇄 미리 보기와 PDF에서 표의 수치를 읽을 수 있는지로 최종 확인한다(5절).

따라 하기

  1. 파워포인트에서 [새 프레젠테이션]을 선택하고, F12를 눌러 컴퓨터활용\실습 폴더에 연습_07_학번으로 저장한다.
  2. 첫 슬라이드의 레이아웃을 [홈] 탭 → [슬라이드] 그룹 → [레이아웃] → [제목만]으로 바꾸고, 제목에 처리 흐름을 입력한다.
  3. [새 슬라이드]의 화살표에서 [제목만]을 골라 제목이 2월 판매 현황인 슬라이드와 삭제할 슬라이드인 슬라이드를 차례로 추가한다.
  4. 축소판 창에서 3번 슬라이드를 1번과 2번 사이로 끌어 번호가 2로 바뀌는 것을 본 뒤, 그 슬라이드를 마우스 오른쪽 단추로 눌러 [슬라이드 삭제]를 선택하고 Ctrl + S로 저장한다.
  • 확인 1 제목 표시줄이 연습_07_학번.pptx이고 슬라이드가 2개(상태 표시줄의 전체 수 2)이다. 1번은 부제목 없이 제목 처리 흐름만 있고, 2번의 제목은 2월 판매 현황이다.

2. 도형과 글상자

2-1. 도형의 삽입

도형은 [삽입] 탭 → [일러스트레이션] 그룹 → [도형]에서 종류를 골라 슬라이드 위에서 끌어 그린다. 도형을 선택한 채 문자를 입력하면 도형 안에 들어간다.

조작 결과
Shift를 누른 채 끌어 그리기 정사각형, 원, 수평·수직·45도의 선이 그려진다
Shift를 누른 채 도형을 끌기 수평 또는 수직으로만 이동한다
Ctrl을 누른 채 도형을 끌기, Ctrl + D 도형이 복사된다. Ctrl + D의 사본은 오른쪽 아래에 놓인다

화살표는 [선] 범주에서 한쪽 끝에 화살촉이 있는 선을 골라 그린다. 화살표를 고른 채 도형 위로 마우스를 가져가면 테두리에 연결점이 표시되며, 연결점끼리 이은 화살표만 도형을 이동할 때 따라온다.

[그림 자리: 연결점과 연결된 화살표] 화살표를 선택한 상태에서 직사각형 위에 마우스를 올렸을 때 네 변의 가운데에 표시되는 연결점과, 두 도형의 연결점을 이은 화살표. 찍을 곳: Microsoft 365 파워포인트, [삽입] 탭 → [도형] → [선] 범주의 화살표를 고른 직후의 슬라이드 창.

버전에 따른 차이: [선] 범주의 화살표는 [선 화살표] 또는 [화살표]로 표시된다.

2-2. 개체의 선택

여러 개체는 Shift를 누른 채 차례로 누르거나 빈 곳에서 끌어 둘러싸 선택한다. 끌면 영역에 완전히 들어간 개체만 선택되며 제목 개체 틀이 함께 선택되기 쉬우므로, 선택된 개체를 확인하고 불필요한 것은 Shift를 누른 채 눌러 제외한다. 가려진 개체는 선택 창(3-7)에서 선택한다.

도형의 안쪽을 누르면 문자를 편집하는 상태(테두리가 점선)가 되어 서식이 선택한 문자에만 적용된다. 도형 전체에 서식을 줄 때에는 테두리를 눌러 도형 자체를 선택한다(테두리가 실선).

2-3. 도형 서식

[도형 서식] 탭의 [도형 스타일] 그룹에서 [도형 채우기](내부의 색)와 [도형 윤곽선](테두리 선의 색과 두께)을, [홈] 탭 → [글꼴] 그룹에서 문자의 크기와 색을 지정한다. 새 도형은 진한 채우기에 흰 문자가 기본값이므로 채우기를 밝게 하면 글꼴 색도 바꾼다. 같은 서식의 도형은 하나를 완성한 뒤 복제한다.

버전에 따른 차이: 이전 버전에서는 [도형 서식] 탭이 [그리기 도구] 아래의 [서식] 탭으로 표시된다.

2-4. 크기와 위치의 수치 지정

높이와 너비는 [도형 서식] 탭 → [크기] 그룹에 cm로 입력한다(여러 도형을 선택하면 모두에 적용된다). 위치는 [크기] 그룹의 대화 상자 표시 아이콘으로 연 작업 창의 [크기 및 속성] → [위치]에서 읽으며, 맞춤과 배분(3절)의 결과를 확인하는 데 쓴다.

  • 슬라이드의 크기. 새 프레젠테이션의 슬라이드는 33.87cm × 19.05cm(16:9)이다(실습 PC 확인).
  • 기준점. 위치 값은 슬라이드의 왼쪽 위 모서리에서 도형의 왼쪽 위 모서리까지의 거리이다. 너비 4cm, 가로 위치 2cm인 도형의 오른쪽 변은 6cm에 있다.
  • 반올림. 위치는 pt로 저장되어 cm로 환산되므로 같은 위치가 0.01cm 다르게 보일 수 있다. 이 차이는 무시한다.

2-5. 글상자와 도형 안의 문자

글상자(메뉴의 [텍스트 상자])는 문자를 임의의 위치에 놓는 개체이다. [삽입] 탭 → [텍스트] 그룹 → [텍스트 상자]를 누르고 가로로 끌어 그린다.

구분 개체 틀 도형 안의 문자 글상자
위치 레이아웃이 정한다 도형의 안쪽. 도형과 함께 이동하고 복제된다 임의의 위치. 도형을 이동하여도 제자리에 있다
문자가 많아지면 글꼴이 자동으로 줄어든다 도형 밖으로 넘칠 수 있다 높이가 늘어난다
본 장의 용도 제목 흐름도의 각 단계 요약 문장

도형 위에 글상자를 올려놓으면 정렬할 때 문자가 따라오지 않으므로 단계의 이름은 도형 안에 입력한다.

따라 하기

연습용 프레젠테이션의 1번 슬라이드에 직사각형 3개와 글상자 1개를 작성한다. 이 도형은 3절의 따라 하기에서 정렬한다.

  1. 1번 슬라이드(“처리 흐름”)에 [도형]의 [사각형] 범주에서 [직사각형]을 골라 그리고, [크기] 그룹에서 높이 2, 너비 4를 입력한 뒤 입력을 입력한다.
  2. 도형의 테두리를 눌러 [도형 채우기]에 밝은 계열의 색을, [도형 윤곽선]에 [검정, 텍스트 1]과 두께 1½pt를 지정하고, 글꼴 색을 [검정, 텍스트 1], 크기를 18로 지정한다.
  3. Ctrl + D를 두 번 눌러 3개로 만들고 왼쪽에서 오른쪽으로 대략 나열한 뒤(높이와 간격은 맞추지 않는다), 둘째와 셋째의 문자를 계산, 출력으로 고친다.
  4. 세 도형의 아래에 [텍스트 상자]로 글상자를 그려 자료의 처리 순서를 입력한다.
  5. 첫째 도형을 위로 끌어 문자는 따라오고 글상자는 제자리에 있는 것을 본 뒤, Ctrl + Z로 되돌리고 Ctrl + S로 저장한다.
  • 확인 2 직사각형 3개의 문자가 왼쪽부터 검정색의 입력, 계산, 출력이고, 어느 도형을 선택하여도 높이 2cm, 너비 4cm이다. 도형을 옮겼을 때 글상자는 이동하지 않았다.

3. 맞춤, 배분, 그룹, 순서

3-1. 맞춤

맞춤은 선택한 개체들의 위치를 한 줄에 맞추는 기능이다. [도형 서식] 탭 → [정렬] 그룹 → [맞춤]에서 실행하며, 표나 그림이 함께 선택되었으면 [홈] 탭 → [그리기] 그룹 → [정렬] → [맞춤]을 쓴다. 기준이 [선택한 개체 맞춤](3-3)일 때 각 명령이 기준으로 삼는 것은 다음과 같다.

명령 기준으로 삼는 것 바뀌는 값
왼쪽 맞춤, 오른쪽 맞춤 가장 왼쪽 개체의 왼쪽 변, 가장 오른쪽 개체의 오른쪽 변 가로 위치
가운데 맞춤 선택한 개체 전체를 둘러싼 범위의 가로 가운데 가로 위치
위쪽 맞춤, 아래쪽 맞춤 가장 위 개체의 위쪽 변, 가장 아래 개체의 아래쪽 변 세로 위치
중간 맞춤 선택한 개체 전체를 둘러싼 범위의 세로 가운데 세로 위치

[가운데 맞춤]과 [중간 맞춤]은 이름이 비슷하나 방향이 다르다. 좌우로 나열한 도형은 위아래로 움직여야 한 줄이 되므로 세로 위치를 바꾸는 명령을 쓴다. 여기에 [가운데 맞춤]을 실행하면 모든 도형이 겹친다.

[그림 자리: 맞춤 메뉴와 중간 맞춤의 전후] [맞춤] 메뉴의 항목(맞춤 6개, 간격 2개, 기준 2개)과, 좌우로 나열한 도형 3개에 [중간 맞춤]을 실행하기 전과 후의 모습. 찍을 곳: Microsoft 365 파워포인트, [도형 서식] 탭 → [정렬] 그룹 → [맞춤].

3-2. 배분

배분은 개체들 사이의 간격을 같게 하는 기능으로, [맞춤] 메뉴의 [가로 간격을 동일하게]와 [세로 간격을 동일하게]로 실행한다. 양 끝의 두 개체는 움직이지 않으므로 3개 이상을 선택한다. 좌우로 나열한 도형은 양 끝을 원하는 위치에 놓고 모두 선택하여 [중간 맞춤]과 [가로 간격을 동일하게]를 차례로 실행한다. 같은 명령을 다시 실행하여 도형이 움직이지 않으면 정렬이 끝난 것이다.

버전에 따른 차이: 지원 문서(한국어판)는 간격 명령을 [가로로 분산], [세로로 분산]으로 표기하기도 한다.

3-3. 맞춤과 배분의 기준

기준은 [맞춤] 메뉴 아래쪽의 두 항목으로 지정하며, 다시 바꿀 때까지 유지된다.

기준 맞춤의 결과 배분의 결과
선택한 개체 맞춤 선택한 개체들끼리 맞추어진다 양 끝의 개체는 제자리에 있고 사이의 간격이 같아진다
슬라이드에 맞춤 슬라이드의 가장자리나 가운데에 맞추어진다 개체들이 슬라이드의 폭 전체에 퍼진다. 실습 PC에서는 양 끝의 여백까지 간격과 같아졌다(3-6)

지원 문서는 슬라이드 기준의 배분을 “전체 슬라이드를 기준으로 간격을 균등하게 지정”한다고만 설명한다. 정렬 전에는 기준이 [선택한 개체 맞춤]인지 확인한다. 개체를 하나만 선택하면 슬라이드가 기준이 되므로, 개체 하나(또는 그룹 하나)에 [가운데 맞춤]을 실행하면 슬라이드의 가로 가운데에 놓인다.

3-4. 그룹

그룹은 여러 개체를 하나처럼 다루도록 묶는 기능이다. [도형 서식] 탭 → [정렬] 그룹 → [그룹화] → [그룹] 또는 Ctrl + G로 묶고, Ctrl + Shift + G로 푼다. 한 번 누르면 전체가, 한 번 더 누르면 안의 개체 하나가 선택된다. 개체 틀과 표는 넣을 수 없다. 그룹은 맞춤에서 개체 하나이므로, 흐름도는 먼저 정렬하고 묶은 뒤 슬라이드의 가운데에 맞춘다.

3-5. 순서

슬라이드의 개체는 작성한 순서대로 쌓여 나중에 작성한 개체가 위에 놓이고 아래의 개체를 가린다. 순서는 [정렬] 그룹의 [앞으로 가져오기], [맨 앞으로 가져오기], [뒤로 보내기], [맨 뒤로 보내기]로 바꾸며, 쌓인 순서는 선택 창(3-7)에서 확인한다.

  • 중간 맞춤. 범위 7.00~10.50cm(입력의 위쪽 변~계산의 아래쪽 변)의 가운데 8.75cm에서 높이의 절반을 빼면 7.75cm이다. 평균(약 7.67cm)이 아니다.
  • 가로 간격을 동일하게. 입력의 오른쪽 변 6.00cm와 출력의 왼쪽 변 19.00cm 사이에서 계산의 너비를 뺀 9.00cm를 둘로 나누면 간격 4.50cm, 계산의 위치 10.50cm이다.
  • 다른 명령. 같은 처음 위치에서 [가운데 맞춤]은 세 도형을 10.50cm에 겹치게 하고, [위쪽 맞춤]은 7.00cm, [아래쪽 맞춤]은 8.50cm로 맞춘다.

3-7. 선택 창 읽기

선택 창([홈] 탭 → [편집] 그룹 → [선택] → [선택 창])은 개체를 겹친 순서대로 나열하며, 위의 항목일수록 앞에 놓인다. 항목을 끌면 순서가 바뀌고, 눈 모양 아이콘은 개체를 숨기며(인쇄에서도 빠진다), 이름을 누르면 가려진 개체도 선택된다(지원 문서 「슬라이드에서 개별 개체 선택」). 그룹은 한 항목이며 펼치면 안의 개체가 들여 쓰여 나열된다. 이름은 자동으로 붙으므로 항목의 수와 위아래만 읽는다. 실습 PC에서 그룹 위에 새로 그린 직사각형은 목록의 맨 위에 놓였고, [맨 뒤로 보내기] 뒤에는 맨 아래로 옮겨졌으며 제목과 그룹의 순서는 바뀌지 않았다(2026-11-15 확인).

[그림 자리: 선택 창의 목록] 흐름도의 그룹을 펼친 선택 창. 그룹 아래에 직사각형과 화살표가 들여 쓰여 나열되고, 회색 직사각형이 목록의 맨 아래에 있는 모습. 찍을 곳: Microsoft 365 파워포인트, [홈] 탭 → [편집] 그룹 → [선택] → [선택 창].

따라 하기

2절의 직사각형 3개를 3-6의 처음 위치에 놓고 정렬한 뒤, 화살표로 잇고 그룹으로 묶어 순서를 바꾼다.

(1) 위치 값의 지정과 정렬

  1. 입력 도형을 선택하고 [크기] 그룹의 대화 상자 표시 아이콘으로 작업 창의 [크기 및 속성] → [위치]를 펼쳐 가로 2, 세로 7을 입력한다(값마다 Enter). 계산에는 9, 8.5를, 출력에는 19, 7.5를 입력한다.
  2. 3-6의 셈으로 [중간 맞춤] 뒤의 세로 위치와 [가로 간격을 동일하게] 뒤의 계산의 가로 위치를 적는다.
  3. 세 도형만 선택하고 기준이 [선택한 개체 맞춤]인지 확인한 뒤 [중간 맞춤], [가로 간격을 동일하게]를 실행한다.
  4. 위치 값을 2와 대조하고, 두 명령을 다시 실행하여 값이 변하지 않는지 본다. 세로 위치가 7.00이면 [위쪽 맞춤]을, 8.50이면 [아래쪽 맞춤]을 실행한 것이다.
  • 확인 3 정렬 뒤 세 도형의 세로 위치가 모두 7.75cm, 계산의 가로 위치가 10.50cm이며, 다시 실행하여도 변하지 않았다.

(2) 화살표, 그룹, 순서

  1. [선] 범주의 화살표로 첫째 도형의 오른쪽 변의 연결점에서 둘째 도형의 왼쪽 변의 연결점까지 끌고, 둘째와 셋째도 잇는다.
  2. 화살표 2개에 [도형 윤곽선]의 [검정, 텍스트 1], 두께 2¼pt를 지정한다. 둘째 도형을 끌어 화살표가 따라오는 것을 본 뒤 Ctrl + Z로 되돌린다.
  3. 도형 3개와 화살표 2개를 선택하여 Ctrl + G로 묶고, 그룹의 너비를 읽은 뒤 [가운데 맞춤]을 실행하여 가로 위치를 (33.87 − 너비) ÷ 2와 대조한다.
  4. 그룹 안의 계산을 한 번 더 눌러 채우기 색을 바꾼다. Ctrl + Shift + G로 해제하여 개체 5개가 낱개로 선택되는 것을 본 뒤 Ctrl + G로 다시 묶는다.
  5. 그룹 전체를 덮는 직사각형을 그려 채우기를 밝은 회색 계열로, 윤곽선을 [윤곽선 없음]으로 하고 [맨 뒤로 보내기]를 실행한 뒤 저장한다.

실습 PC에서 연결점끼리 그린 첫째 화살표는 가로 위치 6.00cm, 세로 위치 8.75cm, 너비 4.50cm, 높이 0cm(수평)였다(2026-11-15 확인).

  • 확인 4 수평의 화살표 2개가 입력 → 계산 → 출력으로 향하고 도형을 따라 움직였다. 도형 하나를 누르면 그룹 전체가 선택되고, 그룹의 너비가 21.00cm, 가로 위치가 6.43cm이다. 흐름도가 회색 직사각형의 위에 표시된다.

4. 엑셀 자료의 삽입

4-1. 복사와 붙여넣기

엑셀에서 Ctrl + C로 복사한 범위나 차트를 슬라이드에서 Ctrl + V로 붙이고, 직후에 개체의 오른쪽 아래에 나타나는 [붙여넣기 옵션] 단추에서 형태를 고른다([홈] 탭 → [클립보드] 그룹 → [붙여넣기]의 화살표로 미리 고를 수도 있다). 붙이기 전에는 빈 곳을 한 번 누른다. 제목 개체 틀에 커서가 있으면 표의 내용이 제목으로 들어간다.

[그림 자리: 붙여넣기 옵션 단추] 표를 붙여 넣은 직후 표의 오른쪽 아래에 표시되는 [붙여넣기 옵션] 단추와, 단추를 눌렀을 때 나열되는 옵션 다섯 개의 그림. 찍을 곳: Microsoft 365 파워포인트, 엑셀의 피벗 테이블 범위를 Ctrl + V로 붙여 넣은 직후의 슬라이드 창.

4-2. 표의 붙여넣기 옵션

셀 범위의 붙여넣기 옵션은 다섯 가지이며 모두 엑셀 파일과 연결되지 않는다. 실습 PC에서 6장 완성 파일의 “피벗” 시트 A3:B9(맑은 고딕 11pt, A열 약 2.42cm, B열 약 2.24cm)를 붙여 넣은 결과는 다음과 같다(2026-11-15 확인).

옵션 만들어진 개체 눌렀을 때와 편집
대상 스타일 사용 7행 2열의 표. 첫 행 “행 레이블”, “합계 : 금액”, 11pt, 열 너비 2.43cm, 2.26cm. 머리글 셀은 연한 회색 계열 셀에 커서가 표시되고 [테이블 디자인], [레이아웃] 탭이 나타난다. 문자와 서식을 고칠 수 있다
원본 서식 유지 위와 같은 표. 머리글 셀은 엑셀의 피벗 테이블 스타일의 연한 파랑 위와 같다
포함 엑셀 워크시트 개체(약 4.7cm × 4.2cm) 두 번 누르면 엑셀의 셀과 리본이 나타난다. 수정은 안의 사본에만 반영된다
그림 그림(약 4.7cm × 4.2cm) [그림 서식] 탭이 나타난다. 크기와 위치만 바꿀 수 있다
텍스트만 유지 글상자(18pt). 7개의 단락이며 두 값이 탭으로 구분된다 [도형 서식] 탭이 나타난다. 열의 구분이 없어 열 단위의 서식을 줄 수 없다

옵션 없이 붙인 표는 [대상 스타일 사용]과 같았다. 슬라이드의 표는 값과 서식만 옮겨진 표이며 새로 고침을 할 수 없다.

글꼴 크기와 열 너비. 붙인 표는 엑셀의 11pt와 열 너비를 가져오므로 글꼴만 18pt로 키우면 문자가 두 줄로 나뉜다. 실습 PC에서 [원본 서식 유지]의 표를 18pt로 키우자 행의 높이가 0.60cm에서 1.54cm로, 표의 높이가 4.20cm에서 10.79cm로 늘었고, 두 열을 4.5cm로 넓히자 행의 높이 0.78cm, 표 9.00cm × 5.46cm가 되었다(2026-11-15 확인).

4-3. 차트의 붙여넣기 옵션

옵션 결과 엑셀 파일과의 연결
대상 테마 사용 및 통합 문서 포함, 원본 서식 유지 및 통합 문서 포함 차트. 요소와 자료를 고칠 수 있다 없다. 자료의 사본이 안에 저장된다
대상 테마 사용 및 데이터 연결, 원본 서식 유지 및 데이터 연결 차트. 자료는 엑셀 파일에 있다 연결된다. 엑셀의 값이 바뀌면 차트에 반영된다
그림 차트의 모양이 그림으로 들어간다. 크기와 위치만 바꿀 수 있다 없다

연결된 차트는 엑셀 파일의 위치나 이름이 바뀌면 연결이 끊어지고, 프레젠테이션 파일만 받은 사람은 갱신할 수 없다. 큰 엑셀 파일을 포함하면 프레젠테이션이 크게 늘어난다(지원 문서 「PowerPoint에서 Excel 데이터 삽입 및 업데이트」).

옵션 없는 Ctrl + V는 연결되는 형태가 될 수 있다. 실습 PC에서 “토너” 차트를 옵션 없이 붙이자 엑셀 파일과 연결된 차트 개체가 만들어졌다. 엑셀에서 E3(대한사무기)을 680,000에서 900,000으로 바꾸자 엑셀의 차트는 즉시 바뀌었으나 슬라이드의 그림과 차트 개체는 680,000 그대로였다(2026-11-15 확인). 연결된 차트는 연결을 다시 읽을 때([링크 업데이트]) 바뀌므로 보고 시점의 수치를 고정할 수 없다. 차트를 붙인 뒤에는 옵션을 반드시 지정한다.

버전에 따른 차이: 지원 문서(한국어판)는 데이터 연결의 두 옵션을 [대상 테마 & 데이터 연결 사용], [데이터 연결 & 원본 서식 유지]로 표기한다. 옵션의 그림 위에 마우스를 올려 이름을 확인한다.

4-4. 붙여넣기 옵션의 선택 기준

옵션은 슬라이드에서 내용을 고쳐야 하는가, 엑셀 파일 없이도 같은 내용이 표시되어야 하는가로 고른다.

대상 선택 이유
표 [원본 서식 유지] 머리글과 글꼴을 고쳐야 하므로 편집할 수 있는 표이어야 하며, 엑셀의 쉼표와 테두리가 유지된다
차트 [그림] 고칠 내용이 없고(5장에서 완성), 보고 시점의 모양이 고정되어 파일 하나만으로 같게 표시된다

본 과목에서는 데이터 연결을 사용하지 않는다. 제출물이 프레젠테이션 파일과 PDF이고, 채점하는 사람의 PC에는 수강생의 엑셀 파일이 없기 때문이다.

4-5. 원본과의 관계

슬라이드에 붙인 표와 그림은 복사한 시점의 사본이므로 엑셀의 값이 바뀌어도 자동으로 변하지 않는다. 엑셀의 수식은 즉시, 피벗 테이블은 새로 고침을 실행할 때([자동 새로 고침]이 켜진 버전에서는 곧바로) 반영되나, 슬라이드의 표와 그림, 사람이 입력한 요약 문장은 반영되지 않는다. 엑셀의 값이 바뀌었으면 피벗 테이블을 새로 고친 뒤 표와 그림을 다시 붙이고(머리글과 글꼴도 다시 지정한다) 요약 문장을 고쳐 4-6의 검산을 다시 한다. 그러므로 엑셀의 작업과 검증을 모두 마친 뒤에 붙인다.

4-6. 수치의 검산

엑셀의 값은 4장과 6장에서 검증하였으므로, 슬라이드에서 새로 생기는 오류는 옮기는 과정의 오류이다. 이를 다음의 네 가지로 찾는다.

5. 유인물 인쇄와 PDF 저장

5-1. 인쇄 형태

인쇄 형태는 한 쪽에 슬라이드 하나를 출력하는 전체 페이지 슬라이드(기본값)와 여러 슬라이드를 축소하여 출력하는 유인물로 나뉜다. [파일] 탭 → [인쇄]의 [설정]에서 [전체 페이지 슬라이드]를 누르고 [유인물]에서 한 쪽의 슬라이드 수를 고른다. 본 장이 쓰는 2슬라이드는 세로 방향의 용지에 슬라이드 2매를 위아래로 놓는다. 3슬라이드는 옆에 필기용 줄이 인쇄되고, 4슬라이드 이상은 표의 수치를 읽기 어렵다. 슬라이드가 2매이면 전체 페이지 슬라이드는 2쪽, 2슬라이드 유인물은 1쪽이며, 형태를 바꾸면 미리 보기의 쪽 수가 즉시 달라진다.

[그림 자리: 인쇄 화면의 유인물 목록과 미리 보기] [설정]에서 [전체 페이지 슬라이드]를 눌러 연 목록의 [유인물] 영역과, [2슬라이드]를 선택하였을 때 세로 방향의 용지에 슬라이드 2매가 위아래로 놓인 미리 보기, 미리 보기 아래의 쪽 표시. 찍을 곳: Microsoft 365 파워포인트, [파일] 탭 → [인쇄].

5-2. PDF 저장의 두 가지 방법

5-3. 미리 보기와 PDF에서 읽을 것

미리 보기 아래의 쪽 표시에서 전체 쪽이 1인지(2이면 형태가 [전체 페이지 슬라이드]로 남아 있다), 용지가 세로 방향이고 위에서부터 1매(흐름도), 2매(1월 판매 현황)가 놓였는지, 확대하였을 때 표의 일곱 자리 숫자를 읽을 수 있는지를 본다. 저장한 뒤에는 출력 폴더의 PDF를 열어 쪽 표시가 1 / 1인지 확인한다. 미리 보기는 1쪽인데 PDF가 2쪽이면 내보내기로 저장한 것이다.

빈번한 오류와 해결

증상 원인 해결
도형의 문자가 보이지 않는다 채우기를 밝게 하였으나 글꼴 색이 흰색이다 글꼴 색을 [검정, 텍스트 1]로 지정한다
