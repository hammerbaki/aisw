셀 서식과 인쇄 설정

2027학년도 「컴퓨터활용」의 준비 중인 교재입니다. 편집 상태를 검토하기 위해 미리 공개한 것으로, 수업 전에 내용과 순서가 바뀔 수 있습니다.

학사 3주차 · 교재 02 · 1부 엑셀

본 장은 입력을 마친 표를 문서의 형태로 정돈하고 종이에 출력할 수 있는 상태로 만드는 방법을 다룬다. 1장 「파일 관리와 데이터 입력」에서 입력한 판매 내역 표의 위쪽에 제목을 두고, 글꼴, 테두리, 맞춤, 표시 형식을 적용한 뒤 인쇄 설정을 거쳐 한 쪽 분량의 PDF로 출력한다. 서식은 셀에 저장된 값을 변경하지 않고 표시되는 모습만 변경한다는 점을 이해하는 것이 본 장의 핵심이다. 본 장에서 확정하는 표의 위치(머리글 3행, 자료 4~23행)와 인쇄 설정은 3장 이후의 모든 장에서 그대로 사용한다.

1~4절은 설명과 시연이며, 각 절의 끝에 있는 「따라 하기」에서 연습용 통합 문서(2월 자료)에 시연한 조작을 직접 수행한다. 5절의 핵심 실습에서는 1장에서 입력한 통합 문서(1월 자료)에 같은 조작을 적용한다. 두 통합 문서는 자료의 행 수가 다르므로(2월 19행, 1월 20행) 셀 주소가 한 행씩 다르다.

수업 시간의 범위. 150분 수업에서는 번호를 붙인 절의 설명과 따라 하기, 핵심 실습까지 한다. 제목에 [선택]이 붙은 곳(4-5 페이지 나누기 미리 보기, 4-6 머리글과 바닥글)과 심화 실습, 남은 연습 문제는 시간이 남을 때나 수업 뒤에 한다.

학습 목표

  1. 행과 열을 삽입, 삭제하고 숨기며, 삽입에 따라 셀 주소가 변하는 규칙을 설명한다.
  2. 글꼴, 채우기, 테두리, 맞춤을 적용하고 [서식 복사]로 서식을 다른 셀에 적용하며, 내용 지우기와 서식 지우기를 구분한다.
  3. 표시 형식의 종류를 구분하여 날짜, 쉼표 스타일, 통화를 적용하고, 표시 형식이 셀의 값을 변경하지 않음을 확인한다.
  4. 용지 방향, 여백, 페이지 가운데 맞춤, [한 페이지에 시트 맞추기]를 설정하고 인쇄 미리 보기로 출력 형태를 확인한다.
  5. 시트를 PDF로 내보내어 지정된 폴더에 지정된 이름으로 저장한다.

1. 행과 열의 편집

1-1. 행과 열의 삽입

1장의 표는 1행에서 시작하므로 제목을 둘 자리가 없다. 표를 아래로 옮기지 않고 표의 위쪽에 빈 행을 삽입하여 자리를 확보한다. 행을 삽입하는 절차는 다음과 같다.

  1. 삽입할 위치의 행 머리글(시트 왼쪽의 행 번호)을 선택한다. 두 행을 삽입할 때에는 행 머리글 두 개를 끌어 선택한다.
  2. 선택한 행 머리글 위에서 마우스 오른쪽 단추를 누르고 [삽입]을 선택한다.

선택한 행의 수만큼 빈 행이 위쪽에 삽입되고 기존의 행은 아래로 이동한다. [홈] 탭 → [셀] 그룹 → [삽입] → [시트 행 삽입]으로도 같은 결과를 얻는다. 열의 삽입도 열 머리글을 선택하여 같은 방법으로 수행하며, 빈 열은 선택한 열의 왼쪽에 삽입된다.

삽입된 행이나 열은 인접한 행이나 열의 서식을 이어받는다. 서식이 적용된 표의 중간에 행을 삽입하면 새 행에도 테두리와 표시 형식이 적용되어 있는 것은 이 때문이다. 삽입 직후에 나타나는 [삽입 옵션] 단추에서 이어받을 서식을 변경할 수 있다.

1-2. 삽입에 따른 셀 주소의 변화

셀 주소는 값에 붙은 이름이 아니라 시트 위의 위치이다. 따라서 행을 삽입하면 같은 값이 다른 주소에 놓이게 된다. 1행과 2행의 자리에 두 행을 삽입하면 표의 위치는 다음과 같이 변한다.

내용 삽입 전 삽입 후
머리글 A1:F1 A3:F3
자료 20행 A2:F21 A4:F23
판매번호 1001의 수량 E2 E4
판매번호 1020의 단가 F21 F23

본 교재의 3장 이후에 기재된 셀 주소는 모두 삽입 후의 위치를 기준으로 한다. 삽입한 행의 수가 두 행이 아니면 이후의 장에서 교재의 주소와 실제 위치가 일치하지 않으므로, 삽입 직후에 머리글이 3행에 있는지 반드시 확인한다. 시트에 수식이 있는 경우에는 엑셀이 수식 안의 셀 주소를 삽입된 행의 수만큼 자동으로 조정한다.

1-3. 행과 열의 삭제

행이나 열을 제거할 때에는 머리글을 선택하고 마우스 오른쪽 단추를 눌러 [삭제]를 선택한다. [홈] 탭 → [셀] 그룹 → [삭제] → [시트 행 삭제] 또는 [시트 열 삭제]로도 같은 결과를 얻는다. 삭제하면 그 아래의 행이 위로, 오른쪽의 열이 왼쪽으로 이동하여 빈자리를 채우며, 삽입과 반대 방향으로 셀 주소가 변한다.

삭제는 Delete 키에 의한 지우기와 다르다.

조작 결과 셀 주소의 변화
행 머리글을 선택하고 Delete를 누른다 행의 내용만 지워지고 빈 행이 남는다 변하지 않는다
행 머리글을 선택하고 [삭제]를 선택한다 행 자체가 제거되고 아래의 행이 올라온다 아래쪽 셀의 주소가 한 행씩 줄어든다

삭제한 직후에는 Ctrl + Z로 되돌릴 수 있다. 자료가 있는 행을 삭제하면 그 자료는 사라지므로, 삭제하기 전에 선택한 행이 의도한 행인지를 행 번호로 확인한다.

1-4. 행과 열의 숨기기

숨기기는 행이나 열을 삭제하지 않고 화면에서 보이지 않게 하는 기능이다. 숨긴 행과 열의 값은 그대로 남아 있으며, 셀 주소도 변하지 않는다.

작업 조작
숨기기 열 머리글 또는 행 머리글을 선택하고 마우스 오른쪽 단추를 눌러 [숨기기]를 선택한다
숨기기 취소 숨긴 열의 양쪽에 있는 열 머리글을 함께 끌어 선택하고 마우스 오른쪽 단추를 눌러 [숨기기 취소]를 선택한다. 행도 같다

열 머리글의 문자가 A, C와 같이 건너뛰어 있거나 두 머리글 사이의 경계가 이중선으로 표시되면 그 사이에 숨긴 열이 있는 것이다. 받은 파일의 열 문자나 행 번호가 연속하지 않으면 숨긴 부분이 있는지 먼저 확인한다. 삭제와 숨기기는 다음의 기준으로 구분하여 사용한다. 필요 없는 자료는 삭제하고, 필요한 자료이지만 일시적으로 보이지 않게 할 때에는 숨긴다.

1-5. 열 너비와 행 높이

열의 너비는 열 머리글(시트 위쪽의 열 문자) 사이의 경계선을 끌어 조정한다. 경계선을 두 번 누르면 해당 열에서 가장 긴 내용에 맞추어 너비가 자동으로 조정된다. 여러 열의 머리글을 선택한 상태에서 그중 한 경계선을 두 번 누르면 선택한 열 전체가 각각의 내용에 맞추어진다. 행의 높이도 행 머리글의 아래쪽 경계선을 끌거나 두 번 눌러 같은 방법으로 조정한다.

너비와 높이를 수치로 지정할 때에는 열이나 행을 선택하고 [홈] 탭 → [셀] 그룹 → [서식]에서 [열 너비] 또는 [행 높이]를 선택한다. 같은 목록의 [열 너비 자동 맞춤]과 [행 높이 자동 맞춤]은 경계선을 두 번 누르는 것과 같다.

구분 단위 기본 값
열 너비 기본 글꼴의 문자 수 8.43
행 높이 포인트 15

숫자나 날짜가 들어 있는 셀이 ####로 표시되는 것은 열의 너비가 값을 표시하기에 부족하다는 의미이다. 값에는 이상이 없으며 열의 너비를 넓히면 정상적으로 표시된다. 문자는 너비가 부족하면 ####로 표시되지 않고 오른쪽 셀로 넘치거나 잘려서 표시된다. 글꼴 크기를 키우면 행 높이는 자동으로 늘어나지만 열 너비는 자동으로 늘어나지 않으므로, 서식을 적용한 뒤에는 열 너비를 다시 확인한다.

열 너비를 내용에 맞춘 결과는 [열 너비] 대화 상자의 값으로 읽을 수 있다. 교수의 작업 PC에서 핵심 실습의 완성 파일을 열어 A~F열의 너비를 읽었더니 8.08, 10.17, 9.83, 10.83, 4.42, 7.42였다(2026-11-15). 판매일(B열)과 품목(D열)이 넓고, 두 자리 수가 들어가는 수량(E열)이 가장 좁다. 자동 맞춤은 열마다 가장 긴 내용을 기준으로 하므로, 한 셀에만 긴 내용이 있어도 그 열 전체가 넓어진다. 수강생의 화면에서 값이 조금 달라도 #으로 표시되는 셀이 없으면 된다.

2. 글꼴, 테두리, 맞춤

2-1. 글꼴과 채우기

[홈] 탭 → [글꼴] 그룹의 단추로 선택한 셀의 글꼴을 변경한다.

단추 기능 본 장에서의 사용
[글꼴 크기] 글자의 크기를 지정한다 제목을 16으로 지정한다
[굵게] 글자를 굵게 표시한다. Ctrl + B로도 지정한다 제목과 머리글에 적용한다
[채우기 색] 셀의 배경색을 지정한다 머리글에 연한 회색을 적용한다
[글꼴 색] 글자의 색을 지정한다 사용하지 않는다

머리글에 굵은 글꼴과 채우기를 적용하는 이유는 머리글과 자료를 시각적으로 구분하기 위한 것이다. 색은 흑백으로 인쇄하여도 구분되는 연한 회색을 사용한다.

2-2. 테두리

시트에 보이는 옅은 회색의 선은 눈금선이며 셀의 경계를 화면에 나타낼 뿐 기본 설정에서는 인쇄되지 않는다. 인쇄물에 선이 나타나게 하려면 테두리를 적용하여야 한다. [홈] 탭 → [글꼴] 그룹 → [테두리]의 목록 단추를 누르면 테두리의 종류가 표시된다.

종류 적용되는 선
[모든 테두리] 선택한 범위 안의 모든 셀의 네 변
[테두리 없음] 선택한 범위의 테두리를 모두 제거한다

목록에는 범위의 바깥 둘레나 한쪽 변에만 선을 적용하는 종류도 있다. 본 장에서는 머리글과 자료를 포함한 범위 전체에 [모든 테두리]를 적용한다. 테두리는 범위를 먼저 선택한 뒤에 종류를 선택하며, 선택한 범위가 표보다 넓으면 빈 셀에도 선이 적용되어 인쇄된다.

[그림 자리: 눈금선과 테두리의 인쇄 결과] 같은 표의 인쇄 미리 보기 두 장을 나란히 놓는다. 왼쪽은 테두리를 적용하기 전(화면에는 눈금선이 보이나 미리 보기에는 선이 없다), 오른쪽은 [모든 테두리]를 적용한 뒤(미리 보기에 선이 있다)이다. 찍을 곳: Microsoft 365 엑셀, [파일] 탭 → [인쇄]의 미리 보기, 연습용 통합 문서의 “판매내역” 시트.

2-3. 맞춤

엑셀은 값의 종류에 따라 맞춤을 자동으로 정한다. 문자는 셀의 왼쪽에, 숫자와 날짜는 셀의 오른쪽에 맞추어진다. 값이 의도와 다른 쪽에 맞추어져 있으면 입력 값의 종류가 의도와 다르다는 신호이다. 숫자를 입력한 셀이 왼쪽에 맞추어져 있으면 문자로 입력된 것이다.

[홈] 탭 → [맞춤] 그룹에는 가로 방향의 [왼쪽 맞춤], [가운데 맞춤], [오른쪽 맞춤]이 있다. 본 장에서는 다음의 기준으로 맞춤을 지정한다.

대상 맞춤 이유
머리글 가운데 맞춤 열의 이름이므로 열의 중앙에 둔다
판매번호, 판매일 가운데 맞춤 자릿수가 일정한 식별 값이다
거래처, 품목 왼쪽 맞춤(변경하지 않는다) 문자의 기본 맞춤이다
수량, 단가 오른쪽 맞춤(변경하지 않는다) 자릿수를 맞추어야 크기를 비교할 수 있다

맞춤을 직접 지정한 셀은 값의 종류와 관계없이 지정한 쪽에 놓인다. 따라서 가운데 맞춤을 적용한 판매번호와 판매일은 맞춤 위치로 자료의 종류를 판별할 수 없다. 자료의 종류는 1장에서와 같이 맞춤을 지정하기 전에 점검한다.

2-4. 셀 병합

제목은 표의 너비 전체에 걸쳐 가운데에 배치한다. 여러 셀을 하나의 셀로 합치는 것을 셀 병합이라고 하며, [홈] 탭 → [맞춤] 그룹 → [병합하고 가운데 맞춤]은 선택한 범위를 병합하고 내용을 가운데에 맞춘다.

  • 병합할 범위에서 값은 왼쪽 위 셀에만 입력한다. 여러 셀에 값이 있는 범위를 병합하면 왼쪽 위 셀의 값만 남고 나머지 셀의 값은 삭제된다.
  • 병합된 셀의 주소는 왼쪽 위 셀의 주소이다. A1:F1을 병합한 셀의 주소는 A1이다.
  • 병합된 셀을 선택하고 같은 단추를 다시 누르거나, 단추의 목록에서 [셀 병합 해제]를 선택하면 병합이 해제된다.
  • 셀에 내용을 입력하는 중에는 병합할 수 없다. 입력을 확정한 뒤에 병합한다.

병합은 제목과 같이 계산에 사용하지 않는 셀에만 적용한다. 자료 범위 안의 셀을 병합하면 5장의 정렬과 필터가 정상적으로 동작하지 않는다. 같은 값이 여러 행에 반복된다는 이유로 자료의 셀을 세로로 병합하면 값이 첫 행에만 남고 나머지 행은 빈 셀이 되므로, 자료 범위에서는 반복되는 값도 행마다 입력한다.

2-5. 서식 복사

이미 적용한 서식을 다른 셀에 동일하게 적용할 때에는 서식을 다시 지정하지 않고 [서식 복사]를 사용한다. 서식 복사는 셀의 값은 그대로 두고 서식(글꼴, 채우기, 테두리, 맞춤, 표시 형식)만 복사한다.

  1. 서식이 적용된 셀을 선택한다.
  2. [홈] 탭 → [클립보드] 그룹 → [서식 복사]를 누른다. 마우스 포인터에 붓 모양이 함께 표시된다.
  3. 서식을 적용할 셀을 누르거나 범위를 끈다.

[서식 복사]를 한 번 누르면 한 차례만 적용되고 해제된다. 단추를 두 번 누르면 여러 곳에 연속하여 적용할 수 있으며 Esc를 눌러 해제한다. 서식 복사는 3장 이후에 열을 추가할 때마다 사용한다.

2-6. 서식 지우기와 내용 지우기

셀에는 내용(값)과 서식이 따로 저장되어 있으므로 지우는 대상도 구분된다. Delete 키는 내용만 지우고 서식은 남긴다. 서식을 지우려면 [홈] 탭 → [편집] 그룹 → [지우기]의 목록에서 항목을 선택한다.

조작 내용(값) 서식(글꼴, 채우기, 테두리, 표시 형식)
Delete 키 지운다 남긴다
[지우기] → [내용 지우기] 지운다 남긴다
[지우기] → [서식 지우기] 남긴다 지운다
[지우기] → [모두 지우기] 지운다 지운다

내용을 지운 셀에 서식이 남아 있으면 다음에 입력하는 값이 그 서식으로 표시된다. 날짜를 지운 자리에 숫자를 입력하였더니 날짜로 표시되는 경우와, 빈 셀로 보이는 곳에 채우기 색이나 테두리가 남아 인쇄되는 경우가 이에 해당한다. 서식을 잘못 적용한 범위는 값을 다시 입력하지 않고 [서식 지우기]로 서식만 제거한 뒤 다시 적용한다.

지우기는 셀을 빈 상태로 남기고, 1-3의 삭제는 셀 자체를 제거하여 주변의 셀을 이동시킨다. 표 안의 값 하나를 없앨 때에는 지우기를, 행이나 열 전체를 없앨 때에는 삭제를 사용한다.

따라 하기

연습용 통합 문서의 표에 제목을 작성하고 글꼴, 테두리, 맞춤을 적용한 뒤, 새 시트에서 지우기의 차이를 확인한다.

예상. 제목을 A1에 입력하면 글자가 오른쪽의 빈 셀로 넘쳐 보이지만 값은 A1에만 있다. A1:F1을 병합하면 여섯 셀이 하나가 되고, 그 셀의 주소는 왼쪽 위 셀인 A1이 된다.

  1. “판매내역” 시트의 A1에 2026년 2월 판매 내역을 입력한다.
  2. A1:F1을 선택하고 [홈] 탭 → [맞춤] 그룹 → [병합하고 가운데 맞춤]을 누른다.
  3. A1이 선택된 상태에서 [글꼴 크기]를 16으로 지정하고 [굵게]를 누른다.
  4. C1의 위치를 클릭하고 이름 상자의 주소를 읽는다.
  • 확인 6 제목이 A열부터 F열까지의 가운데에 굵게 표시되었고, 병합된 셀의 어느 곳을 클릭하여도 이름 상자에 A1이 표시되었다.

병합할 때 일부 값만 남는다는 안내가 나타나면 [취소]를 누른다. B1부터 F1 사이에 값이 들어간 셀이 있다는 뜻이다. 그 셀의 값을 Delete로 지운 뒤 다시 병합한다.

예상. 서식 복사는 서식만 옮기므로 B3:F3의 글자(판매일, 거래처 등)는 그대로이고 모양만 A3과 같아진다.

  1. A3을 선택하고 [굵게]를 누른다. [채우기 색]의 목록 단추를 눌러 연한 회색을 선택하고, [가운데 맞춤]을 누른다.
  2. A3이 선택된 상태에서 [홈] 탭 → [클립보드] 그룹 → [서식 복사]를 누른 뒤 B3:F3을 끈다.
  • 확인 7 머리글 여섯 개가 모두 굵은 글꼴, 연한 회색의 채우기, 가운데 맞춤으로 표시되었고, 머리글의 내용은 변하지 않았다.
  1. A3:F22를 선택하고 [홈] 탭 → [글꼴] 그룹 → [테두리]의 목록 단추를 눌러 [모든 테두리]를 선택한다.
  2. A4:B22를 선택하고 [가운데 맞춤]을 누른다.
  • 확인 8 A3:F22의 모든 셀에 테두리가 표시되었고, 판매번호와 판매일은 가운데에, 거래처와 품목은 왼쪽에, 수량과 단가는 오른쪽에 놓였다.

예상. Delete는 내용만 지우므로, 지운 셀에 다시 입력한 값은 남아 있던 굵은 글꼴과 채우기로 표시될 것이다. [서식 지우기]는 반대로 값을 남기고 서식만 없앤다.

  1. 시트 탭의 오른쪽에 있는 [새 시트] 단추를 눌러 시트를 추가하고 이름을 서식연습으로 변경한다.
  2. “서식연습” 시트의 C1에 연습을 입력한다. C1을 선택하여 [굵게]를 누르고 [채우기 색]에서 연한 회색을 선택한다.
  3. C1을 선택하고 Delete를 누른 뒤 1을 입력한다. 채우기와 굵은 글꼴이 남아 있는지 관찰한다.
  4. C1을 선택하고 [홈] 탭 → [편집] 그룹 → [지우기] → [서식 지우기]를 선택한다. 이어서 [지우기] → [모두 지우기]를 선택한다.
  5. “판매내역” 시트로 돌아와 Ctrl + S로 저장한다.
  • 확인 9 Delete를 누른 뒤에 입력한 1은 굵은 글꼴과 채우기로 표시되었다. [서식 지우기]를 선택한 뒤에는 1만 남고 서식이 사라졌으며, [모두 지우기]를 선택한 뒤에는 C1이 빈 셀이 되었다.

3. 표시 형식

3-1. 값과 표시의 구분

셀에는 저장된 값과 표시되는 모습이 따로 존재한다. 표시 형식은 저장된 값을 화면과 인쇄물에 나타내는 방법을 지정하는 서식이다. 표시 형식은 값을 변경하지 않고 표시 방법만 변경한다.

저장된 값 표시 형식 표시되는 모습
24000 일반 24000
24000 쉼표 스타일 24,000
24000 통화 ₩24,000
46024 일반 46024
46024 날짜 2026-01-02

단가에 통화 형식을 적용하여 ₩24,000으로 표시되어도 셀에 저장된 값은 숫자 24000이다. 셀을 선택하면 수식 입력줄에 24000이 표시되는 것으로 확인할 수 있다. 따라서 표시 형식을 적용한 셀은 이후의 계산에 그대로 사용할 수 있다.

반대로 셀에 24,000원과 같이 문자를 함께 입력하면 저장된 값 자체가 문자가 되어 계산에 사용할 수 없다. 단위와 기호는 입력하지 않고 표시 형식으로 나타내는 것이 원칙이다.

값이 변하지 않았는지는 두 가지 방법으로 확인한다. 통화와 쉼표 스타일을 적용한 셀은 수식 입력줄에서 확인한다. 날짜 형식과 백분율 형식을 적용한 셀은 수식 입력줄에도 날짜와 백분율의 모습으로 표시되므로, 표시 형식을 [일반]으로 바꾸어 저장된 숫자를 확인한 뒤 Ctrl + Z로 되돌린다. 범위 전체는 상태 표시줄의 합계가 서식을 적용하기 전과 같은지로 확인한다.

표시 형식이 값을 바꾸지 않는 까닭. 엑셀은 셀마다 값과 표시 형식을 따로 저장한다. 표시 형식은 “이 값을 어떤 모양으로 그릴 것인가”를 적은 규칙(표시 형식 코드)이며, 엑셀은 셀을 화면에 그릴 때마다 저장된 값에 이 규칙을 적용하여 모양을 만든다. 모양은 그릴 때마다 새로 만들어질 뿐 어디에도 저장되지 않으므로, 표시 형식을 몇 번 바꾸어도 값은 처음 입력한 그대로 남는다. Microsoft의 지원 문서도 서식은 숫자가 표시되는 방식만 변경하며 값에는 영향을 주지 않는다고 설명한다.

다음은 핵심 실습의 완성 파일(판매현황_02_완성.xlsx)을 교수의 작업 PC에서 열어 세 셀의 값과 표시 형식 코드, 셀의 모양을 읽은 것이다(Microsoft 365, 2026-11-15). 표시 형식 목록에서 [통화]나 [쉼표 스타일]을 고르면 엑셀이 이와 같은 코드를 셀에 지정한다.

셀    저장된 값   표시 형식 코드                            셀의 모양
B4    46024       yyyy-mm-dd                                2026-01-02
E4    30          _-* #,##0_-;-* #,##0_-;_-* "-"_-;_-@_-     30
F4    24000       ₩#,##0                                    ₩24,000

코드를 해독할 필요는 없으나 몇 가지 기호를 알면 모양을 예상할 수 있다. #,##0은 천 단위마다 쉼표를 넣고 소수점 아래를 표시하지 않는다는 뜻이고, 0.00이면 소수 둘째 자리까지 표시한다. ₩처럼 코드에 적힌 글자는 모양에만 붙는다. yyyy, mm, dd는 일련번호를 연, 월, 일로 바꾸어 표시하라는 뜻이다. 수량의 코드가 세미콜론(;)으로 네 부분으로 나뉜 것은 양수, 음수, 0, 문자에 각각 다른 모양을 지정한 것이며, 0을 -로 표시하는 것은 셋째 부분 때문이다.

표시 형식이 값을 바꾸지 않는다는 원리에는 눈여겨볼 결과가 하나 있다. 모양이 반올림되어 보여도 값은 반올림되지 않는다는 것이다. 교수의 작업 PC에서 24000.4를 저장한 셀에 위의 통화 형식(₩#,##0)을 지정하였더니 셀에는 ₩24,000이 표시되었고 저장된 값은 24000.4 그대로였다. 같은 방식으로 2.5를 저장한 셀에 정수로 표시하는 형식을 지정하면 셀에는 3이 표시되지만 합계에는 2.5가 더해진다. 표에 보이는 숫자를 눈으로 더한 값과 상태 표시줄의 합계가 조금 다르면, 소수점 아래가 표시되지 않은 셀이 있는지 먼저 의심한다. 본 과목의 판매 자료는 모두 정수이므로 이 차이가 생기지 않는다.

3-2. 표시 형식의 종류

표시 형식은 [홈] 탭 → [표시 형식] 그룹의 위쪽에 있는 표시 형식 목록에서 선택한다. 서식을 지정하지 않은 셀에서는 이 목록이 [일반]으로 표시된다. 목록에 없는 세부 항목은 범위를 선택하고 Ctrl + 1을 눌러 여는 [셀 서식] 대화 상자의 [표시 형식] 탭에서 지정한다.

[그림 자리: [표시 형식] 그룹의 목록과 단추] [홈] 탭의 [표시 형식] 그룹에서 표시 형식 목록을 펼친 모습과, 그 아래 줄의 [회계 표시 형식], [백분율 스타일], [쉼표 스타일], [자릿수 늘림], [자릿수 줄임] 단추의 위치를 번호로 표시한다. 찍을 곳: Microsoft 365 엑셀, [홈] 탭.

표시 형식 표시하는 방법 24000을 저장한 셀의 표시
일반 입력한 그대로 표시한다. 서식을 지정하지 않은 셀의 기본 형식이다 24000
숫자 소수 자릿수와 천 단위 구분 기호의 사용 여부를 지정하여 표시한다 24000.00과 같이 소수 자릿수가 붙는다
통화 통화 기호를 숫자의 바로 앞에 붙여 표시한다 ₩24,000

날짜 숫자를 날짜의 일련번호로 보고 연, 월, 일로 표시한다 1965-09-15

위의 표에서 일곱 셀에 저장된 값은 모두 24000이다. 단가에 날짜나 백분율을 적용하면 1965-09-15나 2400000%와 같이 엉뚱한 모습이 되지만 값이 손상된 것은 아니므로, 올바른 표시 형식을 다시 지정하면 원래의 모습으로 돌아온다.

텍스트 형식은 다른 형식과 성격이 다르다. 텍스트 형식을 먼저 지정한 셀에 숫자를 입력하면 그 숫자는 문자로 저장되어 합계에 포함되지 않는다. 텍스트 형식은 우편번호와 같이 계산에 사용하지 않는 번호를 입력할 열에 미리 지정하는 용도로 쓰이며, 본 과목의 판매 자료에는 사용하지 않는다.

3-3. 쉼표 스타일, 통화, 회계

표시 형식 지정 방법 표시되는 모습
일반 표시 형식 목록에서 [일반]을 선택한다 24000
쉼표 스타일 [표시 형식] 그룹의 [쉼표 스타일] 단추를 누른다 24,000
통화 표시 형식 목록에서 [통화]를 선택한다 ₩24,000

쉼표 스타일은 천 단위마다 구분 기호를 표시한다. 수량과 같이 값이 1,000 미만이면 쉼표가 나타나지 않으나 형식은 적용된 상태이다.

셀 스타일 “쉼표”와 “쉼표 [0]”. [쉼표 스타일] 단추는 표시 형식 하나를 지정하는 것이 아니라, 엑셀에 미리 등록된 셀 스타일을 셀에 적용한다. 셀 스타일은 글꼴, 숫자 서식, 테두리, 음영 같은 서식 특성을 묶어 이름을 붙인 것이다. 쉼표를 표시하는 셀 스타일은 두 가지가 있으며 소수 자릿수만 다르다. 교수의 작업 PC(Microsoft 365, 2026-11-15)에서 두 스타일을 수량 30에 각각 적용한 결과와 각 스타일의 표시 형식 코드는 다음과 같았다.

셀 스타일   표시 형식 코드                                     30의 모양
쉼표        _-* #,##0.00_-;-* #,##0.00_-;_-* "-"??_-;_-@_-      30.00
쉼표 [0]    _-* #,##0_-;-* #,##0_-;_-* "-"_-;_-@_-              30

본 과목은 수량을 정수로 표시하므로 “쉼표 [0]”의 모양(30)을 기준으로 한다. 핵심 실습의 완성 파일에도 “쉼표 [0]”을 적용하였다. 같은 PC에서 리본의 쉼표 스타일 명령을 자동화로 실행하였을 때는 “쉼표 [0]”이 적용되었으나, 실습실의 화면에서 단추를 눌렀을 때 어느 스타일이 적용되는지는 수업 전에 다시 확인한다(준비 사항의 최신 자료 자리 (3)). 단추를 누른 뒤 수량이 30.00으로 표시되면 같은 범위를 선택한 채 [표시 형식] 그룹의 [자릿수 줄임] 단추를 두 번 누른다. 소수점 아래의 두 자리가 한 번에 한 자리씩 사라져 30이 된다. 어느 경우에도 저장된 값은 30이며, 상태 표시줄의 합계는 바뀌지 않는다.

두 스타일의 코드에서 쉼표가 들어가는 자리(#,##0)는 같고 소수점 아래의 .00만 다르다. “쉼표 [0]”의 [0]은 소수 자릿수가 0이라는 뜻으로 읽으면 된다. 같은 방식으로 통화 기호를 붙이는 셀 스타일에도 “통화”(소수 둘째 자리까지)와 “통화 [0]”(정수)이 있다. 본 과목의 단가는 셀 스타일이 아니라 표시 형식 목록의 [통화]로 지정한다. 완성 파일의 단가에 지정된 코드는 ₩#,##0(정수)이며, 셀에는 ₩24,000으로 표시된다. 목록의 [통화]를 고른 뒤 단가가 ₩24,000.00처럼 소수 자릿수와 함께 표시되면 [자릿수 줄임]으로 정수 모양을 만든다.

통화와 회계는 모두 금액을 표시하는 형식이지만 통화 기호의 위치가 다르다. 통화는 기호가 숫자의 바로 앞에 붙고, 회계는 기호가 셀의 왼쪽 끝에 놓여 열 안에서 기호끼리, 숫자끼리 정렬된다. 회계 형식은 값이 0인 셀을 -로 표시한다. [표시 형식] 그룹의 [회계 표시 형식] 단추는 회계 형식을 적용하는 단추이므로, 본 과목의 단가와 금액은 이 단추가 아니라 표시 형식 목록의 [통화]로 지정한다.

표시 형식을 잘못 지정한 경우에는 값을 다시 입력하지 않는다. 값은 변하지 않았으므로 올바른 표시 형식을 다시 지정하면 된다.

3-4. 날짜

엑셀은 날짜를 숫자로 저장한다. 1900년 1월 1일을 1로 하여 하루에 1씩 증가하는 일련번호이며, 2026년 1월 2일은 46024이다. 날짜 형식은 이 숫자를 연, 월, 일의 모습으로 표시하는 표시 형식이다. 판매일 셀의 표시 형식을 [일반]으로 변경하면 46024가 표시되고, 날짜 형식으로 되돌리면 다시 2026-01-02가 표시된다. 값은 변하지 않고 표시 방법만 변한 것이다.

Microsoft의 지원 문서(「Excel의 날짜 체계」)는 날짜를 입력하면 1900년 1월 1일 이후에 경과한 일 수를 나타내는 일련번호로 변환된다고 설명한다. 교수의 작업 PC에서 날짜를 입력하고 저장된 값을 읽은 결과는 다음과 같았다(2026-11-15). 2026년 1월 2일부터 1월 29일까지는 27일이므로 일련번호의 차이도 27이다.

입력한 날짜     저장된 값(일련번호)
1900-01-01      1
2026-01-02      46024
2026-01-29      46051
2026-02-02      46055
2026-02-27      46080

날짜가 숫자로 저장되므로 날짜끼리의 뺄셈으로 두 날짜 사이의 일수를 구할 수 있고, 날짜에 1을 더하면 다음 날이 된다. 1장에서 채우기 핸들로 날짜가 하루씩 증가한 것은 일련번호가 1씩 증가한 것이다.

날짜의 표시 방법은 [셀 서식] 대화 상자에서 선택한다. 범위를 선택하고 Ctrl + 1을 누르면 [셀 서식] 대화 상자가 열린다. [표시 형식] 탭의 범주에서 [날짜]를 선택하고, 형식 목록에서 2012-03-14와 같이 연-월-일의 순서로 표시된 항목을 선택한다. 본 과목의 판매일은 2026-01-02의 형태(연도 4자리, 월 2자리, 일 2자리)로 통일한다. 형식 목록에서 별표(*)로 시작하는 항목은 Windows의 국가 설정에 따라 표시되는 모습이 달라진다.

1장에서 판매일을 2026-01-02의 형태로 입력하였다면 엑셀이 입력 값을 날짜로 인식하여 날짜 형식을 자동으로 적용한 상태이다. 판매일이 셀의 왼쪽에 맞추어져 있으면 날짜가 아니라 문자로 입력된 것이며, 이 경우에는 표시 형식을 변경하여도 모습이 변하지 않는다.

3-5. 백분율

백분율 형식은 셀의 값에 100을 곱하고 % 기호를 붙여 표시한다. 0.25가 저장된 셀에 백분율 형식을 적용하면 25%로 표시되며, 저장된 값은 여전히 0.25이다. 따라서 비율은 0.25와 같은 소수로 계산하여 두고 표시만 백분율로 바꾼다. 25를 저장한 셀에 백분율 형식을 적용하면 2500%로 표시된다. [표시 형식] 그룹의 [백분율 스타일] 단추로 적용하며, 3장에서 구성비에 사용한다.

따라 하기

“서식연습” 시트에서 같은 값에 여러 표시 형식을 적용하여 비교한 뒤, “판매내역” 시트의 표에 표시 형식을 적용한다.

예상. 여섯 셀에는 같은 값 24000이 들어 있으므로 표시 형식을 어떻게 바꾸어도 여섯 셀의 합계는 24000 × 6 = 144000이다. 모양은 3-2의 표와 같이 셀마다 달라질 것이다. 특히 날짜 형식을 적용한 셀은 24000번째 날, 곧 1965년 9월 15일로 보인다.

  1. 시트 탭 “서식연습”을 선택하고 A1에 24000을 입력한다.
  2. A1을 선택하고 채우기 핸들을 A6까지 끌어 같은 값을 복사한다.
  3. A2를 선택하고 표시 형식 목록에서 [숫자]를 선택한다. 같은 방법으로 A3에 [통화], A4에 [회계], A5에 [간단한 날짜], A6에 [백분율]을 적용한다.
  4. #으로 표시되는 셀이 있으면 열 머리글 A의 오른쪽 경계선을 두 번 눌러 너비를 맞춘다.
  5. A1부터 A6까지 끌어 선택하고 상태 표시줄의 개수와 합계를 읽는다.
  • 확인 10 A3은 ₩24,000, A5는 1965-09-15로 표시되었고, A4는 ₩가 셀의 왼쪽 끝에, A6은 끝에 %가 붙어 표시되었다. 여섯 셀의 표시는 서로 다르지만 상태 표시줄의 개수는 6, 합계는 144000이다.
  1. A7을 선택하고 표시 형식 목록에서 [텍스트]를 선택한 뒤 24000을 입력한다.
  2. A1부터 A7까지 끌어 선택하고 상태 표시줄의 개수와 합계를 읽는다.
  • 확인 11 A7의 24000은 왼쪽에 놓였고, A1:A7의 개수는 7로 늘었으나 합계는 144000 그대로이다. 텍스트 형식의 셀에 입력한 숫자는 합계에 포함되지 않는다.

A1:A7의 합계가 168000이면 A7에 숫자를 먼저 입력하고 나중에 텍스트 형식을 지정한 것이다. 이 순서에서는 결과가 다를 수 있으므로, A7을 [모두 지우기]로 비운 뒤 형식을 먼저 지정하고 다시 입력한다.

예상. 다음은 반올림되어 보이는 모양을 확인한다. B1에 24000.4를 입력하고 통화 형식을 지정하면 셀에는 소수점 아래가 보이지 않는 ₩24,000이 표시되지만, 수식 입력줄에는 24000.4가 그대로 남을 것이다.

  1. B1에 24000.4를 입력하고 표시 형식 목록에서 [통화]를 선택한다. 소수 자릿수가 함께 표시되면 [자릿수 줄임]을 눌러 정수 모양으로 만든다.
  2. B1을 선택하여 셀의 모양과 수식 입력줄을 비교한 뒤, B1을 선택하고 [홈] 탭 → [편집] 그룹 → [지우기] → [모두 지우기]를 선택한다.
  • 확인 12 B1의 셀에는 ₩24,000이, 수식 입력줄에는 24000.4가 표시되었다. 모두 지운 뒤 B1은 빈 셀이다.

예상. 2026년 2월 2일의 일련번호는 46055이다. [일반]으로 바꾸면 이 숫자가 보이고, 되돌리면 다시 날짜의 모양이 된다.

  1. 시트 탭 “판매내역”을 선택한다. B4를 선택하고 표시 형식 목록에서 [일반]을 선택하여 표시되는 숫자를 읽은 뒤 Ctrl + Z로 되돌린다.
  • 확인 13 B4는 [일반]에서 46055로 표시되었고, 되돌린 뒤에는 2026-02-02로 표시되었다.

예상. 단계 11~13의 표시 형식은 모양만 바꾸므로, 적용하기 전과 후에 E4:E22의 합계는 532로 같다. 단가는 ₩와 쉼표가 붙고, 수량은 1,000 미만이므로 모양이 바뀌지 않거나 오른쪽에 약간의 여백이 생긴다.

  1. B4:B22를 선택하고 Ctrl + 1을 누른다. [표시 형식] 탭의 범주에서 [날짜]를 선택하고 연-월-일의 형식을 선택한 뒤 [확인]을 누른다.
  2. E4:E22를 선택하고 [홈] 탭 → [표시 형식] 그룹 → [쉼표 스타일]을 누른다. 수량이 33.00처럼 표시되면 [자릿수 줄임]을 두 번 누른다(3-3).
  3. F4:F22를 선택하고 표시 형식 목록에서 [통화]를 선택한다.
  4. F4를 선택하여 수식 입력줄을 읽고, E4:E22를 선택하여 상태 표시줄의 합계를 읽는다.
  5. #으로 표시되는 셀이 있으면 열 너비를 맞추고 Ctrl + S로 저장한다.
  • 확인 14 B4는 2026-02-02, F4는 ₩24,000, F5는 ₩85,000으로 표시되었다. F4의 수식 입력줄에는 24000이 표시되었고 수량의 합계는 532이다.

4. 인쇄 설정

4-1. 인쇄 미리 보기

시트는 용지보다 훨씬 넓은 작업 공간이므로 화면에 보이는 모습과 인쇄되는 모습이 일치하지 않는다. 인쇄 전에 반드시 인쇄 미리 보기로 출력 형태를 확인한다. [파일] 탭 → [인쇄]를 선택하거나 Ctrl + P를 누르면 화면의 오른쪽에 미리 보기가, 왼쪽에 인쇄 설정이 표시된다. 미리 보기의 아래쪽에는 현재 쪽과 전체 쪽 수가 표시되며, 그 옆의 화살표로 다음 쪽을 볼 수 있다. 시트로 돌아갈 때에는 Esc를 누른다.

미리 보기에서 확인할 사항은 다음과 같다.

확인 사항 내용
쪽 수 표가 한 쪽에 모두 출력되는가
표의 범위 오른쪽 열이나 아래쪽 행이 잘리지 않았는가

미리 보기에서 읽는 순서. 미리 보기는 그림처럼 훑어보지 않고 다음의 순서로 읽는다. 앞의 항목이 틀리면 뒤의 항목은 읽을 필요가 없다.

  1. 쪽 수. 미리 보기 아래쪽의 전체 쪽 수를 먼저 읽는다. 본 장의 표는 1이어야 한다. 2 이상이면 다음 쪽을 넘겨 무엇이 넘어갔는지 본다.
  2. 잘린 열. 첫 쪽에 머리글의 마지막 열(단가)이 있는지 본다. 없으면 오른쪽 열이 다음 쪽으로 넘어간 것이다. 아래쪽 행이 잘렸는지는 마지막 판매번호(핵심 실습은 1020)가 첫 쪽에 있는지로 본다.
  3. 위치와 여백. 표가 용지의 왼쪽 위에 붙어 있는지, 좌우의 여백이 같은지 본다. 페이지 가운데 맞춤을 지정하지 않았으면 왼쪽 여백만 있고 오른쪽에 빈 곳이 크게 남는다.
  4. 선과 모양. 테두리가 인쇄되는지, 날짜와 단가가 의도한 모양인지, #으로 표시되는 셀이 없는지 본다. 화면에서 #이었던 셀은 미리 보기에서도 #이다.

교수의 작업 PC에서 미리 보기가 여러 쪽이 되는 상황을 만들어 쪽 수를 읽은 결과는 다음과 같다(Microsoft 365, A4 세로, 위쪽 여백 3cm와 나머지 2cm, 배율 100%. 2026-11-15에 PDF로 내보내어 쪽 수를 셌다). 쪽 수가 예상보다 많으면 표의 크기보다 표 바깥을 먼저 의심하여야 하는 까닭을 보여 준다.

[여백] → [사용자 지정 여백]을 선택하면 [페이지 설정] 대화 상자의 [여백] 탭이 열린다. 여백의 값과 [페이지 가운데 맞춤]은 이 탭에서 함께 지정한다. 페이지 가운데 맞춤을 지정하지 않으면 표는 용지의 왼쪽 위에 붙어 출력된다. [세로]는 표를 용지의 상하 가운데에 배치하는 선택 사항이며 본 장에서는 사용하지 않는다. 여백과 그 밖의 인쇄 설정은 시트마다 따로 지정되며, 통합 문서를 저장할 때 함께 저장된다.

4-3. 배율과 한 페이지에 시트 맞추기

표가 용지의 너비나 길이를 조금 초과하면 초과한 열이나 행이 다음 쪽으로 넘어간다. 이때에는 인쇄되는 크기의 비율인 배율을 줄여 한 쪽에 들어가게 한다. 배율은 인쇄에만 적용되며 화면의 확대/축소와는 관계가 없다.

[한 페이지에 시트 맞추기]는 시트의 내용이 한 쪽에 들어가도록 인쇄 배율을 자동으로 축소하는 설정이다.

  1. [파일] 탭 → [인쇄]를 선택한다.
  2. 설정의 마지막 항목(기본 값은 [현재 설정된 용지])을 누른다.
  3. [한 페이지에 시트 맞추기]를 선택한다.

이 설정은 내용을 축소할 뿐 확대하지 않는다. 표가 이미 한 쪽에 들어가는 경우에는 출력 형태가 변하지 않는다. 본 장의 표는 6개의 열과 23개의 행이므로 설정하지 않아도 한 쪽에 출력되지만, 3장과 4장에서 열이 추가되어도 한 쪽을 유지하도록 미리 설정한다. 인쇄 설정은 통합 문서에 함께 저장되므로 이후의 장에서 다시 지정할 필요가 없다. 이후의 장에서 “2장의 방법으로 한 쪽에 맞춘다”라고 기재한 것은 이 설정을 가리킨다.

같은 설정은 [페이지 레이아웃] 탭에서도 지정한다. [너비]와 [높이]를 각각 [1페이지]로 지정하면 [한 페이지에 시트 맞추기]와 같고, [너비]만 [1페이지]로 지정하고 [높이]를 [자동]으로 두면 열은 한 쪽에 모두 들어가고 행은 여러 쪽으로 나뉜다. [배율]에 100보다 작은 값을 입력하면 그 비율로 축소되고 100보다 큰 값을 입력하면 확대된다.

표의 모양 적합한 설정
열과 행이 용지를 조금 넘는다 [한 페이지에 시트 맞추기]
열은 조금 넘고 행은 수백 행이다 [너비]를 [1페이지], [높이]를 [자동]으로 지정한다
열이 많아 한 쪽에 맞추면 글자가 지나치게 작다 용지 방향을 [가로]로 변경하거나 인쇄 영역으로 일부 열만 출력한다

한 쪽에 맞추는 설정은 내용이 많을수록 글자를 작게 만든다. 미리 보기에서 글자를 읽을 수 없는 크기이면 배율을 더 줄이지 않고 용지 방향이나 출력할 범위를 변경한다.

배율과 글자 크기의 관계. 배율은 시트 전체를 같은 비율로 줄이므로, 인쇄되는 글자의 크기는 글꼴 크기에 배율을 곱한 값이 된다. 11포인트의 글자를 50%로 인쇄하면 약 5.5포인트가 된다. 한 쪽 맞춤은 이 배율을 엑셀이 정하게 하는 설정이므로, 한 쪽 맞춤을 지정한 뒤에는 쪽 수만이 아니라 엑셀이 정한 배율을 함께 읽어야 한다. 지원 문서에 따르면 현재 적용된 배율은 [페이지 레이아웃] 탭의 [배율] (크기 조정) 상자에 표시된다.

배율이 정해지는 원리는 용지에서 여백을 뺀 인쇄 가능 영역과 표의 크기를 견주는 것이다. 본 장의 설정에서 A4 용지(21.0cm × 29.7cm)의 인쇄 가능 영역은 너비 21.0 - 2 - 2 = 17.0cm, 높이 29.7 - 3 - 2 = 24.7cm이다. 핵심 실습의 완성 파일에서 열 너비를 내용에 맞춘 A~F열의 너비는 합하여 약 11.5cm, 1~23행의 높이는 합하여 약 14.1cm였으므로 표는 이 영역 안에 들어가고 배율은 100%로 남는다. 이 표에 한 쪽 맞춤을 지정하여도 출력이 변하지 않는 것은 이 때문이다.

교수의 작업 PC에서 앞의 세 상태에 한 쪽 맞춤을 지정하고 PDF로 내보낸 뒤, PDF 안의 본문 글자 크기(11포인트 글꼴)를 읽은 결과는 다음과 같았다(2026-11-15).

본 장에서 한 쪽 맞춤을 미리 지정해 두는 까닭도 같은 측정으로 확인할 수 있다. 교수의 작업 PC에서 3장과 4장의 완성 파일을 같은 인쇄 설정으로 내보내어 읽은 결과는 다음과 같다(2026-11-15). 3장에서 금액과 구성비의 두 열이 더해져도 표는 인쇄 가능 영역의 너비(17.0cm) 안에 있어 배율이 100%로 남고, 4장에서 목표 달성의 열이 더해지면 너비가 17.0cm를 조금 넘어 엑셀이 글자를 약 96%로 줄여 한 쪽을 유지한다. 그 정도의 축소는 읽는 데 지장이 없다.

4-4. 인쇄 영역

인쇄 영역은 시트에서 인쇄할 범위를 지정하는 설정이다. 지정하지 않으면 내용이 있는 범위 전체가 인쇄되고, 지정하면 그 범위만 인쇄된다.

작업 조작
설정 인쇄할 범위를 선택하고 [페이지 레이아웃] 탭 → [페이지 설정] 그룹 → [인쇄 영역] → [인쇄 영역 설정]을 선택한다
해제 시트의 아무 셀이나 선택하고 [페이지 레이아웃] 탭 → [페이지 설정] 그룹 → [인쇄 영역] → [인쇄 영역 해제]를 선택한다

인쇄 영역은 통합 문서를 저장할 때 함께 저장된다. 따라서 인쇄 영역을 지정한 뒤에 그 범위의 바깥에 열이나 행을 추가하면 추가한 부분은 인쇄되지 않는다. 본 과목의 통합 문서는 3장과 4장에서 열과 요약 행이 추가되므로 인쇄 영역을 지정하지 않고, 표 바깥에 내용을 남기지 않는 방법으로 인쇄 범위를 관리한다. 인쇄 영역은 표의 일부만을 일시적으로 출력할 때 사용하고, 출력한 뒤에는 해제한다.

버전에 따른 차이: 인쇄 영역을 해제하는 항목은 Microsoft의 지원 문서에 [인쇄 영역 지우기]로 적혀 있다. [인쇄 영역]의 목록에서 [인쇄 영역 설정]의 아래에 있는 항목이다.

4-5. [선택] 페이지 나누기 미리 보기

페이지 나누기 미리 보기는 시트 위에 쪽의 경계를 표시하는 보기 방식이다. 인쇄 미리 보기가 용지의 모습을 보여 준다면, 페이지 나누기 미리 보기는 어느 셀까지가 몇 쪽에 인쇄되는지를 셀 주소와 함께 보여 준다.

작업 조작
페이지 나누기 미리 보기로 전환 [보기] 탭 → [통합 문서 보기] 그룹 → [페이지 나누기 미리 보기]
원래의 보기로 복귀 [보기] 탭 → [통합 문서 보기] 그룹 → [기본]

이 보기에서는 인쇄되는 범위와 쪽의 경계가 선으로 표시된다. 엑셀이 자동으로 정한 쪽의 경계는 파선으로, 사용자가 직접 지정한 경계는 실선으로 표시된다. 인쇄 영역을 지정한 시트에서는 인쇄 영역이 이 보기에 표시되므로, 지정된 범위를 확인하는 데에도 사용한다. 상태 표시줄의 오른쪽에 있는 보기 단추로도 두 보기를 전환할 수 있다.

[그림 자리: 페이지 나누기 미리 보기의 두 경우] 왼쪽은 표 전체가 한 쪽의 경계 안에 들어 있는 모습, 오른쪽은 열이 두 쪽으로 나뉘어 쪽의 경계(파선)가 표의 중간을 지나는 모습이다. 쪽 번호가 시트 위에 크게 표시되는 것도 함께 보인다. 찍을 곳: Microsoft 365 엑셀, [보기] 탭 → [페이지 나누기 미리 보기].

[기본] 보기로 돌아온 뒤에 시트에 표시되는 점선은 쪽의 경계를 나타내는 선이며 인쇄되지 않는다.

4-6. [선택] 머리글과 바닥글

머리글은 용지의 위쪽 여백에, 바닥글은 아래쪽 여백에 매 쪽마다 인쇄되는 내용이다. 문서의 제목, 작성자, 쪽 번호와 같이 모든 쪽에 반복되어야 하는 내용을 둔다. 머리글과 바닥글은 시트의 셀에 입력하는 것이 아니므로 [기본] 보기에서는 보이지 않고, 인쇄 미리 보기와 인쇄물에서만 나타난다.

  1. [페이지 레이아웃] 탭 → [페이지 설정] 그룹 → [여백] → [사용자 지정 여백]을 선택하여 [페이지 설정] 대화 상자를 연다.
  2. [머리글/바닥글] 탭에서 [머리글 편집] 또는 [바닥글 편집]을 누른다.
  3. 왼쪽 구역, 가운데 구역, 오른쪽 구역 가운데 내용을 둘 구역을 선택하고 내용을 입력한 뒤 [확인]을 누른다.

구역에는 문자를 직접 입력하거나, 대화 상자의 단추로 쪽 번호, 현재 날짜, 파일 이름과 같은 요소를 삽입한다. 요소로 삽입한 쪽 번호는 쪽마다 값이 달라진다. 셀에 입력한 제목은 첫 쪽에만 인쇄되지만 머리글은 모든 쪽에 인쇄된다는 점이 두 방법의 차이이다. 본 과목의 출력물은 한 쪽이므로 제목은 셀에 입력하고, 머리글과 바닥글은 학번과 같은 부가 정보를 표시할 때에만 사용한다.

버전에 따른 차이: [머리글 편집]과 [바닥글 편집] 단추는 Microsoft의 지원 문서에 [사용자 지정 머리글], [사용자 지정 바닥글]로 적혀 있다. [삽입] 탭의 [머리글/바닥글] 단추를 누르면 시트가 용지 모양의 보기로 전환되어 머리글과 바닥글의 구역에 직접 입력할 수 있다.

4-7. PDF 내보내기

PDF는 인쇄한 모습을 그대로 담는 파일 형식이다. 프린터가 없어도 출력 형태를 파일로 남길 수 있고, 엑셀이 설치되지 않은 환경에서도 같은 모습으로 열 수 있다. 본 과목의 출력물은 모두 PDF로 제출한다.

  1. [파일] 탭 → [내보내기] → [PDF/XPS 문서 만들기] → [PDF/XPS 만들기]를 선택한다.
  2. 대화 상자에서 저장할 폴더와 파일 이름을 지정하고 [게시]를 누른다.

[파일] 탭 → [다른 이름으로 저장]에서 파일 형식을 PDF (*.pdf)로 지정하여도 같은 결과를 얻는다. 대화 상자의 [게시 후 파일 열기]를 선택하여 두면 저장한 PDF가 바로 열려 결과를 확인할 수 있다.

PDF에는 현재 선택된 시트가 인쇄 설정에 따라 저장된다. 용지 방향, 여백, 배율, 인쇄 영역, 머리글과 바닥글이 모두 반영되므로, 인쇄 미리 보기에서 확인한 모습이 그대로 PDF가 된다. PDF는 내보낸 시점의 모습이므로, 통합 문서를 수정한 뒤에는 PDF를 다시 내보내야 한다. PDF를 내보내는 것은 통합 문서의 저장이 아니므로 .xlsx 파일은 Ctrl + S로 따로 저장한다.

PDF 결과의 확인. PDF를 내보낸 뒤에는 파일이 생겼다는 것만으로 끝내지 않고, PDF를 열어 다음을 확인한다. PDF는 내보낸 시점의 모습이 고정된 결과물이므로 제출하기 전에 확인할 수 있는 마지막 기회이다.

PDF를 연 프로그램(웹 브라우저 등)에 따라 쪽 수가 표시되는 곳은 다르다. 쪽 수가 보이지 않으면 PDF를 아래로 넘겨 둘째 쪽이 있는지를 본다.

따라 하기

연습용 통합 문서의 “판매내역” 시트에 인쇄 설정을 지정하고 PDF로 내보낸다. [선택]으로 표시한 단계(페이지 나누기 미리 보기와 바닥글)는 4-5, 4-6의 내용이며, 시간이 부족하면 교수의 시연을 보는 것으로 대신하고 건너뛴다. 건너뛰어도 이후의 단계와 핵심 실습에는 영향이 없다.

예상. 설정하기 전의 표는 너비가 용지보다 좁으므로 한 쪽에 들어가지만 용지의 왼쪽 위에 붙어 있을 것이다. 여백과 가운데 맞춤을 지정하면 표가 좌우 가운데로 옮겨지고, 위쪽 여백이 3cm로 넓어져 표가 조금 아래로 내려간다. 한 쪽 맞춤은 표가 이미 한 쪽에 들어가므로 모양을 바꾸지 않는다.

  1. “판매내역” 시트에서 Ctrl + P를 눌러 미리 보기를 열고, 4-1의 순서(쪽 수, 잘린 열, 위치와 여백, 선과 모양)로 읽은 뒤 Esc를 누른다.
  2. [페이지 레이아웃] 탭 → [페이지 설정] 그룹 → [용지 방향] → [세로]를 선택한다.
  3. [여백] → [사용자 지정 여백]을 선택한다. [여백] 탭에서 위쪽을 3, 아래쪽과 왼쪽과 오른쪽을 각각 2로 지정하고, [페이지 가운데 맞춤]에서 [가로]를 선택한 뒤 [확인]을 누른다.
  4. [파일] 탭 → [인쇄]를 선택하고, 설정의 마지막 항목에서 [한 페이지에 시트 맞추기]를 선택한다.
  • 확인 15 설정하기 전의 미리 보기에서는 표가 용지의 왼쪽 위에 붙어 있었고, 설정한 뒤의 미리 보기에서는 제목과 표가 테두리와 함께 용지의 좌우 가운데에 표시되었으며 전체 쪽 수는 1이다.

표가 가운데로 옮겨지지 않았으면 [페이지 설정] 대화 상자를 다시 열어 [여백] 탭의 [가로]가 선택되어 있는지 본다. 전체 쪽 수가 2 이상이면 Esc를 누르고 Ctrl + End로 표 바깥에 남은 셀을 찾는다.

예상. 한 쪽 맞춤을 지정하였어도 이 표는 인쇄 가능 영역 안에 들어가므로 엑셀이 정한 배율은 100%일 것이다.

  1. Esc를 눌러 시트로 돌아온 뒤 [페이지 레이아웃] 탭을 선택하고, [배율] 상자에 표시된 값을 읽는다.
  • 확인 16 [너비]와 [높이]가 [1페이지]로 표시되고, [배율] 상자의 값은 100%이다. 표가 이미 한 쪽에 들어가므로 축소되지 않았다.
  1. [선택] [보기] 탭 → [통합 문서 보기] 그룹 → [페이지 나누기 미리 보기]를 선택한다. 표가 놓인 범위를 관찰하고 [보기] 탭 → [통합 문서 보기] 그룹 → [기본]을 선택한다.

예상. A3:F12를 인쇄 영역으로 지정하면 1행의 제목과 13행 이하의 자료는 인쇄 대상에서 빠진다. 머리글 1행과 자료 9행(4~12행)만 남을 것이다.

  • 확인 18 인쇄 영역을 설정한 동안에는 제목 없이 머리글과 자료 9행(판매번호 1021~1029)만 미리 보기에 표시되었고, 해제한 뒤에는 제목과 자료 19행이 모두 표시되었다.
  1. [선택] [페이지 레이아웃] 탭 → [페이지 설정] 그룹 → [여백] → [사용자 지정 여백]을 선택하고, [머리글/바닥글] 탭에서 [바닥글 편집]을 누른다.

예상. PDF는 인쇄 설정을 그대로 따르므로, 방금 미리 보기에서 본 한 쪽(바닥글 포함)이 그대로 PDF가 된다. 대화 상자는 직전에 사용한 폴더를 제시하므로 실습 폴더가 제시될 가능성이 크다.

  1. [파일] 탭 → [내보내기] → [PDF/XPS 문서 만들기] → [PDF/XPS 만들기]를 선택한다.

  • 확인 20 출력 폴더에 판매연습_02_학번.pdf가 있고, 열어 보면 미리 보기와 같은 모습의 한 쪽이다. 실습 폴더에는 판매연습_02_학번.xlsx가 있다.

5. 핵심 실습: 판매 내역 표의 서식 적용과 PDF 출력

1장의 판매 내역 표에 제목과 서식을 적용하고, 인쇄 설정을 거쳐 한 쪽 분량의 PDF로 출력한다. 적용할 서식은 완료 기준의 서식 지정표에 정리하였다. 따라 하기에서 연습용 통합 문서에 수행한 조작을 1월 자료의 통합 문서에 적용하는 것이며, 자료가 20행이므로 자료의 범위는 4행부터 23행까지이다.

본 실습의 결과 가운데 세 가지는 교수의 작업 PC(Microsoft 365, 엑셀 16.0, 한국어)에서 같은 절차를 자동화로 수행하여 실제 엑셀의 결과로 확인하였다(2026-11-14). B4는 2026-01-02로, F4는 ₩24,000으로 표시되었고, 내보낸 PDF는 1쪽이었다. 아래의 [확인]과 완료 기준은 이 결과를 근거로 한다.

절차

단계 1. 파일의 준비

예상. 1장의 결과 파일을 열면 제목 표시줄은 판매현황_01_학번.xlsx이고, 다른 이름으로 저장한 뒤에는 판매현황_02_학번.xlsx로 바뀐다. 1장의 파일은 실습 폴더에 그대로 남는다.

  1. 컴퓨터활용\실습\판매현황_01_학번.xlsx를 연다. 시트 “판매내역”의 A1:F1에 머리글이, A2:F21에 자료가 있는지 확인한다.
  2. [파일] 탭 → [다른 이름으로 저장]에서 같은 폴더에 판매현황_02_학번.xlsx로 저장한다.
  • 확인 21 제목 표시줄에 판매현황_02_학번.xlsx가 표시되었다.

결과 읽기. 서식을 적용하기 전에 E2:E21을 선택하여 수량의 합계가 493인지 읽어 둔다. 이 값은 단계 4에서 서식을 적용한 뒤의 합계와 대조하는 기준이다. 493이 아니면 1장의 입력 오류이므로 서식을 적용하기 전에 고친다.

단계 2. 행의 삽입과 제목의 작성

예상. 두 행을 삽입하면 머리글은 A3:F3으로, 자료는 A4:F23으로 내려간다. 판매번호 1001의 수량 30은 E2에서 E4로, 마지막 판매번호 1020은 A21에서 A23으로 옮겨질 것이다.

  1. 행 머리글 1과 2를 끌어 두 행을 선택하고, 선택한 행 머리글 위에서 마우스 오른쪽 단추를 눌러 [삽입]을 선택한다.
  2. 머리글이 A3:F3에, 자료가 A4:F23에 있는지 확인한다. 1행과 2행은 빈 행이다.
  3. A1에 2026년 1월 판매 내역을 입력한다.
  4. A1:F1을 선택하고 [홈] 탭 → [맞춤] 그룹 → [병합하고 가운데 맞춤]을 누른다.
  5. A1이 선택된 상태에서 [홈] 탭 → [글꼴] 그룹의 [글꼴 크기]를 16으로 지정하고 [굵게]를 누른다. 2행은 비워 둔다.
  • 확인 22 A3에 “판매번호”가, A23에 1020이 있고, 제목이 A열부터 F열까지의 가운데에 굵게 표시되었다.

결과 읽기. 표의 위치는 3장 이후의 모든 셀 주소를 정하므로 두 곳을 읽는다. A3을 선택하였을 때 수식 입력줄에 판매번호가, A23을 선택하였을 때 1020이 표시되어야 한다. 이어서 Ctrl + ↓로 자료의 끝을 찾으면 A23에서 멈춘다. 제목의 행 높이는 글꼴 크기 16에 맞추어 자동으로 늘어난다(완성 파일에서 1행의 높이는 25.5포인트, 자료 행은 17포인트였다).

단계 3. 머리글의 서식과 테두리

예상. 서식 복사는 서식만 옮기므로 머리글의 글자는 바뀌지 않는다. 테두리는 A3:F23의 21행 6열, 126개의 셀에 적용되며, 표 바깥의 셀에는 선이 생기지 않는다.

  1. A3을 선택하고 [굵게]를 누른다. [채우기 색]의 목록 단추를 눌러 연한 회색을 선택하고, [맞춤] 그룹의 [가운데 맞춤]을 누른다.
  2. A3이 선택된 상태에서 [홈] 탭 → [클립보드] 그룹 → [서식 복사]를 누른 뒤 B3:F3을 끈다. 머리글 6개의 서식이 동일한지 확인한다.
  3. A3:F23을 선택하고 [홈] 탭 → [글꼴] 그룹 → [테두리]의 목록 단추를 눌러 [모든 테두리]를 선택한다.
  • 확인 23 머리글 여섯 개의 서식이 같고, A3:F23의 모든 셀에 테두리가 표시되었다.

결과 읽기. 테두리는 화면의 눈금선과 겹쳐 잘 보이지 않을 수 있다. 셀이 아닌 곳(예: H30)을 클릭한 뒤 표의 오른쪽 끝(F열)과 아래쪽 끝(23행)의 선이 눈금선보다 진하게 보이는지 읽는다. 단계 5의 미리 보기에서 다시 확인한다.

단계 4. 표시 형식과 맞춤

예상. 판매일의 모양은 1장에서 입력한 PC의 날짜 설정에 따라 이미 2026-01-02일 수도 있고 다른 모양일 수도 있으나, 날짜 형식을 지정한 뒤에는 모두 2026-01-02가 된다. 단가는 ₩24,000이 되고 수량은 모양이 거의 바뀌지 않는다. 세 열 모두 저장된 값은 바뀌지 않으므로 수량의 합계는 단계 1에서 읽어 둔 493과 같아야 한다.

  1. B4:B23을 선택하고 Ctrl + 1을 누른다. [표시 형식] 탭의 범주에서 [날짜]를 선택하고 연-월-일의 형식을 선택한 뒤 [확인]을 누른다. B4가 2026-01-02로 표시되는지 확인한다.
  2. B4를 선택하고 표시 형식 목록에서 [일반]을 선택하여 표시되는 숫자를 읽은 뒤 Ctrl + Z로 되돌린다.
  • 확인 24 B4는 [일반]에서 46024로 표시되었고, 되돌린 뒤에는 2026-01-02로 표시되었다.
  1. E4:E23을 선택하고 [홈] 탭 → [표시 형식] 그룹 → [쉼표 스타일]을 누른다. 수량이 30.00처럼 표시되면 [자릿수 줄임]을 두 번 누른다.
  2. F4:F23을 선택하고 표시 형식 목록에서 [통화]를 선택한다. F4가 ₩24,000으로 표시되는지 확인한다.
  3. F4를 선택하여 수식 입력줄에 24000이 표시되는지 확인한다. 표시 형식을 적용하여도 값은 변하지 않았다.
  4. A4:B23을 선택하고 [가운데 맞춤]을 누른다. 거래처, 품목, 수량, 단가의 맞춤은 변경하지 않는다.
  5. 열 머리글 A부터 F까지를 끌어 선택하고, 그중 한 경계선을 두 번 눌러 열 너비를 내용에 맞춘다. ####로 표시되는 셀이 없는지 확인한다.
  6. E4:E23을 선택하고 창 아래쪽의 상태 표시줄에 표시되는 합계가 493인지 확인한다. 1장의 값과 같으면 서식을 적용하는 동안 값이 변하지 않은 것이다.
  • 확인 25 B4는 2026-01-02, F4는 ₩24,000으로 표시되었고, F4의 수식 입력줄에는 24000이 표시되었다. ####로 표시되는 셀이 없고 수량의 합계는 493이다.

결과 읽기. 이 단계의 결과는 셀과 수식 입력줄을 짝지어 읽는다. 아래는 교수의 작업 PC에서 완성 파일의 세 셀을 읽은 모습이다(2026-11-15).

셀    셀의 모양      저장된 값
B4    2026-01-02     날짜(일련번호 46024)
E4    30             30
F4    ₩24,000        24000

판매일의 수식 입력줄은 날짜의 모양으로 표시되므로 일련번호는 단계 2의 [일반]으로 확인하였다. F4의 셀과 수식 입력줄이 다른 것이 정상이다. 수식 입력줄에도 ₩24,000이 보이면 1장에서 ₩나 쉼표를 함께 입력한 것이며, 값이 숫자이면 결과에는 지장이 없다.

단계 5. 인쇄 설정

예상. 표의 너비(약 11.5cm)와 높이(약 14.1cm)는 인쇄 가능 영역(17.0cm × 24.7cm)보다 작으므로 한 쪽에 들어가고, 한 쪽 맞춤을 지정하여도 배율은 100%로 남을 것이다. 여백과 가운데 맞춤을 지정하면 표가 용지의 좌우 가운데에 놓이고 위쪽에 3cm의 여백이 생긴다.

  1. [페이지 레이아웃] 탭 → [페이지 설정] 그룹 → [용지 방향] → [세로]를 선택한다.
  2. [페이지 레이아웃] 탭 → [페이지 설정] 그룹 → [여백] → [사용자 지정 여백]을 선택한다. [여백] 탭에서 위쪽을 3, 아래쪽과 왼쪽과 오른쪽을 각각 2로 지정한다.
  3. 같은 탭의 [페이지 가운데 맞춤]에서 [가로]를 선택하고 [확인]을 누른다.
  4. [파일] 탭 → [인쇄]를 선택하고, 설정의 마지막 항목에서 [한 페이지에 시트 맞추기]를 선택한다.
  5. 미리 보기에서 제목과 표 전체가 테두리와 함께 용지의 좌우 가운데에 출력되고 전체 쪽 수가 1인지 확인한다. Esc를 눌러 시트로 돌아간다.
  6. [페이지 레이아웃] 탭의 [배율] 상자에 표시된 값을 읽는다.
  7. Ctrl + S로 저장한다.
  • 확인 26 미리 보기에서 제목과 표 전체가 테두리와 함께 용지의 좌우 가운데에 표시되었고 전체 쪽 수는 1이다.
  • 확인 27 [배율] 상자의 값은 100%이다.

결과 읽기. 미리 보기는 4-1의 순서(쪽 수, 잘린 열, 위치와 여백, 선과 모양)로 읽는다. 첫 쪽의 오른쪽 끝에 단가 열이, 아래쪽 끝에 판매번호 1020의 행이 있으면 잘린 곳이 없다. 배율이 100%보다 작으면 표 바깥에 무엇인가 남아 있는 것이므로 Ctrl + End로 찾는다. 3장과 4장에서 열이 더해지면 이 배율이 100%보다 작아질 수 있으며, 그것은 한 쪽 맞춤이 의도대로 동작한 결과이다.

단계 6. PDF 출력

예상. PDF는 단계 5의 미리 보기와 같은 모습의 1쪽, A4 세로가 된다. 저장 대화 상자는 직전에 사용한 실습 폴더를 제시할 가능성이 크다.

  1. [파일] 탭 → [내보내기] → [PDF/XPS 문서 만들기] → [PDF/XPS 만들기]를 선택한다.
  2. 저장 위치를 컴퓨터활용\출력 폴더로 변경하고 파일 이름이 판매현황_02_학번인지 확인한 뒤 [게시]를 누른다.
  3. 출력 폴더의 판매현황_02_학번.pdf를 열어 한 쪽인지, 미리 보기와 같은 모습인지 확인한다.
  4. 파일 탐색기에서 실습 폴더에 판매현황_02_학번.xlsx가, 출력 폴더에 판매현황_02_학번.pdf가 있는지 확인한다.
  • 확인 28 출력 폴더의 판매현황_02_학번.pdf가 한 쪽이고 미리 보기와 같은 모습이다.

결과 읽기. PDF는 4-7의 「PDF 결과의 확인」 표의 다섯 항목으로 읽는다. 교수의 작업 PC에서 같은 절차로 만든 완성 PDF는 1쪽, A4 세로(595.32 × 841.92포인트), 본문 글자 약 11포인트였다. PDF에 바닥글로 학번이 보이면 따라 하기의 바닥글 설정을 핵심 실습의 통합 문서에도 수행한 것이며, 완료 판정에는 영향이 없다.

수량이 30.00처럼 소수 둘째 자리까지 표시된다 소수 둘째 자리까지 표시하는 셀 스타일 “쉼표”가 적용되었다. 정수로 표시하는 “쉼표 [0]”과는 소수 자릿수만 다르다 [자릿수 줄임]을 두 번 누른다. 값은 30 그대로이다
한 쪽으로 출력되었으나 글자가 매우 작다 한 쪽 맞춤이 표 바깥에 남은 셀까지 한 쪽에 넣으려고 배율을 크게 줄였다. 실습 PC에서 Z60에 값 하나가 남았을 때 글자는 원래의 약 34%가 되었다 [배율] 상자의 값을 읽고, Ctrl + End로 표 바깥의 셀을 찾아 행이나 열을 삭제한다
표에 보이는 숫자를 더한 값과 상태 표시줄의 합계가 조금 다르다 소수점 아래가 표시되지 않은 셀이 있다. 표시 형식은 모양만 반올림하고 값은 그대로 둔다 해당 셀의 수식 입력줄에서 저장된 값을 읽는다
날짜 형식을 지정하였는데 판매일 하나만 모양이 다르다 그 셀의 날짜가 문자로 입력되었다. 문자에는 날짜 형식이 적용되지 않는다(실습 PC에서 문자 2026.01.02에 yyyy-mm-dd를 지정하여도 모양이 그대로였다) 그 셀에 2026-01-…의 모양으로 다시 입력한다
텍스트 형식을 지정하였는데 숫자가 합계에 그대로 들어간다 숫자를 먼저 입력하고 나중에 텍스트 형식을 지정하였다. 이 순서에서는 값이 숫자로 남는다(실습 PC 확인) 텍스트 형식은 입력하기 전에 지정한다. 본 과목의 판매 자료에는 쓰지 않는다

심화 실습

핵심 실습을 완료한 수강생은 머리글과 바닥글에 요소를 삽입한다. 따라 하기에서는 바닥글에 문자를 직접 입력하였으나, 본 실습에서는 엑셀이 값을 채우는 요소(쪽 번호, 날짜)를 사용한다. 본 실습의 결과는 이후의 장에서 사용하지 않으므로 별도의 시트에서 수행하며 제출하지 않는다.

  1. 판매현황_02_학번.xlsx에서 시트 탭 “판매내역”을 Ctrl 키를 누른 채 오른쪽으로 끌어 시트를 복사하고, 복사된 시트의 이름을 “심화02”로 변경한다.
  2. “심화02” 시트에서 [페이지 레이아웃] 탭 → [페이지 설정] 그룹 → [여백] → [사용자 지정 여백]을 선택하여 [페이지 설정] 대화 상자를 연다.
  3. [머리글/바닥글] 탭에서 [머리글 편집]을 누른다. 오른쪽 구역을 선택하고 날짜를 삽입하는 단추를 누른 뒤 [확인]을 누른다.
  4. [바닥글 편집]을 누른다. 가운데 구역을 선택하고 쪽 번호를 삽입하는 단추를 누른 뒤 [확인]을 누른다. 대화 상자의 [확인]을 눌러 닫는다.
  5. [파일] 탭 → [인쇄]의 미리 보기에서 위쪽 여백의 오른쪽에 오늘의 날짜가, 아래쪽 여백의 가운데에 1이 표시되고 전체 쪽 수가 1인지 확인한다.
  6. “판매내역” 시트를 다시 선택한 뒤 Ctrl + S로 저장한다. 제출한 PDF는 다시 내보내지 않는다.

연습 문제

연습용 통합 문서(판매연습_02_학번.xlsx)의 “판매내역” 시트에서 수행한다. 절차는 제시하지 않으며, 본 장에서 다룬 조작만으로 해결할 수 있다. 문제마다 수행을 마친 뒤에는 시트를 문제를 풀기 전의 상태로 되돌린다.

문제 1. 판매일의 첫 값(B4)과 마지막 값(B22)이 셀에 어떤 숫자로 저장되어 있는지 확인하고, 두 날짜 사이의 일수를 구한다.

  • 기준 값: B4는 46055, B22는 46080, 두 날짜 사이는 25일이다. 되돌린 뒤에는 2026-02-02와 2026-02-27로 표시된다
  • 실마리: 날짜는 일련번호로 저장된다(3-4). 수식을 쓰지 않고 두 수를 읽어 뺀다.

문제 2. 10행의 위치에 빈 행 하나를 삽입한다. 이때 판매번호 1039의 단가가 놓이는 셀 주소와, 수량이 입력된 범위 전체의 개수와 합계를 구한다. 그 뒤에 삽입한 행을 제거한다.

  • 기준 값: 삽입한 뒤 1039의 단가는 F23에 있고, E4:E23의 개수는 19, 합계는 532이다. 행을 제거한 뒤 1039의 단가는 다시 F22에 있다
  • 실마리: 삽입에 따른 주소의 변화(1-2)와 삭제와 지우기의 차이(1-3). 개수가 20이 아닌 까닭을 생각한다.

문제 3. 제목을 제외하고 판매번호부터 품목까지의 네 열만(머리글 포함) 가로 방향의 용지 한 쪽에 인쇄되도록 설정하여 미리 보기로 확인한다. 그 뒤에 설정을 원래대로 되돌린다.

  • 실마리: 인쇄 영역(4-4)과 용지 방향(4-2). 숨기기로는 기준 값과 같아지지 않는다.
  • 기준 값: 인쇄 영역은 A3:D22이다. 미리 보기에는 네 개의 열과 20개의 행(머리글 1행, 자료 19행)이 가로 방향의 한 쪽에 표시되고 제목, 수량, 단가는 표시되지 않는다. 되돌린 뒤의 미리 보기에는 세로 방향의 한 쪽에 제목과 여섯 개의 열이 표시된다

개념 점검

  1. 1행과 2행의 위치에 두 행을 삽입하면 E2에 있던 값은 어느 셀에 놓이는지 적고, 이때 값 자체는 변하는지 변하지 않는지를 적는다.
  2. 눈금선과 테두리의 차이를 인쇄의 관점에서 설명한다.
  3. 단가 24000에 통화 형식을 적용한 셀과, 24000원을 직접 입력한 셀의 차이를 저장된 값의 종류와 계산의 가능 여부로 설명한다.
  4. 값과 서식이 모두 있는 셀에 Delete, [서식 지우기], [모두 지우기]를 각각 적용하였을 때 남는 것을 적는다.
  5. [한 페이지에 시트 맞추기]를 지정한 통합 문서에 열을 두 개 추가하여도 출력물이 한 쪽으로 유지되는 이유를 설명하고, 같은 통합 문서에 인쇄 영역이 A3:F23으로 지정되어 있었다면 추가한 열이 어떻게 되는지를 적는다.
