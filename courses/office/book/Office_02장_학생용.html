셀 서식과 인쇄 설정

2027학년도 「컴퓨터활용」의 준비 중인 교재입니다. 편집 상태를 검토하기 위해 미리 공개한 것으로, 수업 전에 내용과 순서가 바뀔 수 있습니다.

학사 3주차 · 교재 02 · 1부 엑셀

본 장은 1장 「파일 관리와 데이터 입력」에서 입력한 판매 내역 표의 위쪽에 제목을 두고 글꼴, 테두리, 맞춤, 표시 형식을 적용한 뒤, 인쇄 설정을 거쳐 한 쪽 분량의 PDF로 출력한다. 서식은 셀에 저장된 값을 변경하지 않고 표시되는 모습만 변경한다는 점이 본 장의 핵심이다. 본 장에서 확정하는 표의 위치(머리글 3행, 자료 4~23행)와 인쇄 설정은 3장 이후의 모든 장에서 그대로 사용한다.

1~4절은 설명과 시연이며, 각 절 끝의 「따라 하기」에서 연습용 통합 문서(2월 자료)에 같은 조작을 수행한다. 5절의 핵심 실습에서는 1장에서 입력한 통합 문서(1월 자료)에 같은 조작을 적용한다. 자료의 행 수가 다르므로(2월 19행, 1월 20행) 두 통합 문서의 셀 주소는 한 행씩 다르다.

수업 시간의 범위. 150분 수업에서는 번호를 붙인 절의 설명과 따라 하기, 핵심 실습까지 한다. 제목에 [선택]이 붙은 곳(4-5 페이지 나누기 미리 보기, 4-6 머리글과 바닥글)과 심화 실습, 연습 문제, 개념 점검은 시간이 남을 때나 수업 뒤에 한다.

학습 목표

  1. 행과 열을 삽입, 삭제하고 숨기며, 삽입에 따라 셀 주소가 변하는 규칙을 설명한다.
  2. 글꼴, 채우기, 테두리, 맞춤을 적용하고 [서식 복사]로 서식을 다른 셀에 적용하며, 내용 지우기와 서식 지우기를 구분한다.
  3. 표시 형식의 종류를 구분하여 날짜, 쉼표 스타일, 통화를 적용하고, 표시 형식이 셀의 값을 변경하지 않음을 확인한다.
  4. 용지 방향, 여백, 페이지 가운데 맞춤, [한 페이지에 시트 맞추기]를 설정하고 인쇄 미리 보기로 출력 형태를 확인한다.
  5. 시트를 PDF로 내보내어 지정된 폴더에 지정된 이름으로 저장한다.

1. 행과 열의 편집

1-1. 행과 열의 삽입

1장의 표는 1행에서 시작하므로 제목을 둘 자리가 없다. 표의 위쪽에 빈 행을 삽입하여 자리를 확보한다. 삽입할 위치의 행 머리글(시트 왼쪽의 행 번호)을 선택하고(두 행이면 두 개를 끌어 선택한다) 마우스 오른쪽 단추를 눌러 [삽입]을 선택하면, 선택한 행의 수만큼 빈 행이 위쪽에 삽입되고 기존의 행은 아래로 이동한다. [홈] 탭 → [셀] 그룹 → [삽입] → [시트 행 삽입]으로도 같다. 열은 열 머리글을 선택하여 같은 방법으로 삽입하며, 빈 열은 선택한 열의 왼쪽에 들어간다. 삽입된 행이나 열은 인접한 행이나 열의 서식을 이어받으며, 삽입 직후에 나타나는 [삽입 옵션] 단추에서 이어받을 서식을 변경할 수 있다.

1-2. 삽입에 따른 셀 주소의 변화

셀 주소는 값에 붙은 이름이 아니라 시트 위의 위치이다. 1행과 2행의 자리에 두 행을 삽입하면 같은 값이 다음과 같이 다른 주소에 놓인다.

내용 삽입 전 삽입 후
머리글 A1:F1 A3:F3
자료 20행 A2:F21 A4:F23
판매번호 1001의 수량 E2 E4
판매번호 1020의 단가 F21 F23

3장 이후에 기재된 셀 주소는 모두 삽입 후의 위치를 기준으로 하므로, 삽입 직후에 머리글이 3행에 있는지 반드시 확인한다. 시트에 수식이 있으면 엑셀이 수식 안의 셀 주소를 삽입된 행의 수만큼 자동으로 조정한다.

1-3. 행과 열의 삭제

행이나 열은 머리글을 선택하고 마우스 오른쪽 단추를 눌러 [삭제]를 선택하여 제거한다([홈] 탭 → [셀] 그룹 → [삭제]로도 같다). 아래의 행이나 오른쪽의 열이 이동하여 빈자리를 채우므로 셀 주소가 삽입과 반대 방향으로 변한다. 삭제는 Delete 키에 의한 지우기와 다르다.

조작 결과 셀 주소의 변화
행 머리글을 선택하고 Delete를 누른다 행의 내용만 지워지고 빈 행이 남는다 변하지 않는다
행 머리글을 선택하고 [삭제]를 선택한다 행 자체가 제거되고 아래의 행이 올라온다 아래쪽 셀의 주소가 한 행씩 줄어든다

삭제한 직후에는 Ctrl + Z로 되돌릴 수 있다. 삭제하기 전에 선택한 행이 의도한 행인지를 행 번호로 확인한다.

1-4. 행과 열의 숨기기

숨기기는 행이나 열을 삭제하지 않고 화면에서 보이지 않게 하는 기능이며, 값과 셀 주소는 그대로 남는다.

작업 조작
숨기기 열 머리글 또는 행 머리글을 선택하고 마우스 오른쪽 단추를 눌러 [숨기기]를 선택한다
숨기기 취소 숨긴 열의 양쪽에 있는 열 머리글을 함께 끌어 선택하고 마우스 오른쪽 단추를 눌러 [숨기기 취소]를 선택한다. 행도 같다

열 머리글의 문자가 A, C처럼 건너뛰거나 두 머리글 사이의 경계가 이중선이면 그 사이에 숨긴 열이 있다. 필요 없는 자료는 삭제하고, 필요하지만 일시적으로 보이지 않게 할 자료는 숨긴다.

1-5. 열 너비와 행 높이

열의 너비는 열 머리글 사이의 경계선을 끌어 조정하고, 경계선을 두 번 누르면 그 열의 가장 긴 내용에 맞추어진다. 여러 열을 선택한 상태에서 한 경계선을 두 번 누르면 선택한 열이 각각의 내용에 맞추어진다. 행의 높이도 행 머리글의 아래쪽 경계선으로 같은 방법으로 조정한다. 수치로 지정할 때에는 [홈] 탭 → [셀] 그룹 → [서식]에서 [열 너비] 또는 [행 높이]를 선택한다.

구분 단위 기본 값
열 너비 기본 글꼴의 문자 수 8.43
행 높이 포인트 15

숫자나 날짜가 ####로 표시되면 열의 너비가 부족한 것이며 값에는 이상이 없다. 문자는 ####가 되지 않고 오른쪽 셀로 넘치거나 잘린다. 글꼴 크기를 키우면 행 높이는 자동으로 늘어나지만 열 너비는 늘어나지 않으므로, 서식을 적용한 뒤에는 열 너비를 다시 맞춘다.

2. 글꼴, 테두리, 맞춤

2-1. 글꼴과 채우기

[홈] 탭 → [글꼴] 그룹의 단추로 글꼴을 변경한다.

단추 기능 본 장에서의 사용
[글꼴 크기] 글자의 크기를 지정한다 제목을 16으로 지정한다
[굵게] 글자를 굵게 표시한다. Ctrl + B로도 지정한다 제목과 머리글에 적용한다
[채우기 색] 셀의 배경색을 지정한다 머리글에 적용하여 자료와 구분한다

색은 흑백으로 인쇄하여도 구분되는 연한 회색을 쓴다.

2-2. 테두리

시트에 보이는 옅은 회색의 선은 눈금선이며 셀의 경계를 화면에 나타낼 뿐 기본 설정에서는 인쇄되지 않는다. 인쇄물에 선이 나타나게 하려면 [홈] 탭 → [글꼴] 그룹 → [테두리]의 목록에서 테두리를 적용한다. 본 장에서는 머리글과 자료를 포함한 범위 전체에 [모든 테두리] (범위 안의 모든 셀의 네 변)를 적용하며, 잘못 적용한 선은 [테두리 없음]으로 제거한다. 테두리는 범위를 먼저 선택한 뒤에 종류를 선택하며, 선택한 범위가 표보다 넓으면 빈 셀에도 선이 적용되어 인쇄된다.

[그림 자리: 눈금선과 테두리의 인쇄 결과] 같은 표의 인쇄 미리 보기 두 장을 나란히 놓는다. 왼쪽은 테두리를 적용하기 전(화면에는 눈금선이 보이나 미리 보기에는 선이 없다), 오른쪽은 [모든 테두리]를 적용한 뒤(미리 보기에 선이 있다)이다. 찍을 곳: Microsoft 365 엑셀, [파일] 탭 → [인쇄]의 미리 보기, 연습용 통합 문서의 “판매내역” 시트.

2-3. 맞춤

엑셀은 문자를 셀의 왼쪽에, 숫자와 날짜를 셀의 오른쪽에 맞춘다. [홈] 탭 → [맞춤] 그룹의 [왼쪽 맞춤], [가운데 맞춤], [오른쪽 맞춤]으로 맞춤을 직접 지정하며, 본 장의 기준은 다음과 같다.

대상 맞춤 이유
머리글 가운데 맞춤 열의 이름이다
판매번호, 판매일 가운데 맞춤 자릿수가 일정한 식별 값이다
거래처, 품목 왼쪽 맞춤(변경하지 않는다) 문자의 기본 맞춤이다
수량, 단가 오른쪽 맞춤(변경하지 않는다) 자릿수를 맞추어 크기를 비교한다

맞춤을 직접 지정한 셀은 값의 종류와 관계없이 지정한 쪽에 놓이므로, 가운데 맞춤을 적용한 판매번호와 판매일은 맞춤 위치로 자료의 종류를 판별할 수 없다. 자료의 종류는 맞춤을 지정하기 전에 점검한다.

2-4. 셀 병합

여러 셀을 하나의 셀로 합치는 것을 셀 병합이라고 한다. [홈] 탭 → [맞춤] 그룹 → [병합하고 가운데 맞춤]은 선택한 범위를 병합하고 내용을 가운데에 맞춘다.

  • 여러 셀에 값이 있는 범위를 병합하면 왼쪽 위 셀의 값만 남으므로, 값은 왼쪽 위 셀에만 입력한다.
  • 병합된 셀의 주소는 왼쪽 위 셀의 주소이다. A1:F1을 병합한 셀의 주소는 A1이다.
  • 같은 단추를 다시 누르거나 단추의 목록에서 [셀 병합 해제]를 선택하면 해제된다. 셀에 내용을 입력하는 중에는 병합할 수 없다.

병합은 제목처럼 계산에 쓰지 않는 셀에만 적용한다. 자료 범위 안의 셀을 병합하면 5장의 정렬과 필터가 정상적으로 동작하지 않으므로, 자료 범위에서는 반복되는 값도 행마다 입력한다.

2-5. 서식 복사

[서식 복사]는 셀의 값은 그대로 두고 서식(글꼴, 채우기, 테두리, 맞춤, 표시 형식)만 다른 셀에 복사한다. 서식이 적용된 셀을 선택하고 [홈] 탭 → [클립보드] 그룹 → [서식 복사]를 누르면 마우스 포인터에 붓 모양이 표시되며, 이 상태로 적용할 셀을 누르거나 범위를 끈다. 단추를 한 번 누르면 한 차례만 적용되고, 두 번 누르면 연속하여 적용되며 Esc로 해제한다. 서식 복사는 3장 이후에 열을 추가할 때마다 사용한다.

2-6. 서식 지우기와 내용 지우기

셀에는 내용(값)과 서식이 따로 저장되어 있으므로 지우는 대상도 구분된다. 서식은 [홈] 탭 → [편집] 그룹 → [지우기]의 목록에서 지운다.

조작 내용(값) 서식(글꼴, 채우기, 테두리, 표시 형식)
Delete 키 지운다 남긴다
[지우기] → [내용 지우기] 지운다 남긴다
[지우기] → [서식 지우기] 남긴다 지운다
[지우기] → [모두 지우기] 지운다 지운다

내용만 지운 셀에 서식이 남으면 다음에 입력하는 값이 그 서식으로 표시되고, 빈 셀로 보이는 곳의 채우기나 테두리가 인쇄된다. 서식을 잘못 적용한 범위는 [서식 지우기]로 서식만 제거한 뒤 다시 적용한다. 지우기는 셀을 빈 상태로 남기고, 1-3의 삭제는 셀 자체를 제거한다.

따라 하기

연습용 통합 문서의 표에 제목을 작성하고 글꼴, 테두리, 맞춤을 적용한 뒤, 새 시트에서 지우기의 차이를 확인한다.

  1. “판매내역” 시트의 A1에 2026년 2월 판매 내역을 입력한다.
  2. A1:F1을 선택하고 [홈] 탭 → [맞춤] 그룹 → [병합하고 가운데 맞춤]을 누른다. 일부 값만 남는다는 안내가 나타나면 [취소]를 누르고, B1:F1에 들어간 값을 Delete로 지운 뒤 다시 병합한다.
  3. A1이 선택된 상태에서 [글꼴 크기]를 16으로 지정하고 [굵게]를 누른다.

3. 표시 형식

3-1. 값과 표시의 구분

셀에는 저장된 값과 표시되는 모습이 따로 존재한다. 표시 형식은 저장된 값을 화면과 인쇄물에 나타내는 방법을 지정하는 서식이다. 표시 형식은 값을 변경하지 않고 표시 방법만 변경한다.

저장된 값 표시 형식 표시되는 모습
24000 일반 24000
24000 쉼표 스타일 24,000
24000 통화 ₩24,000
46024 일반 46024
46024 날짜 2026-01-02

단가에 통화 형식을 적용하여 ₩24,000으로 표시되어도 셀에 저장된 값은 숫자 24000이며(수식 입력줄에 24000이 표시된다), 이후의 계산에 그대로 쓸 수 있다. 반대로 24,000원처럼 문자를 함께 입력하면 저장된 값 자체가 문자가 되어 계산에 쓸 수 없다. 단위와 기호는 입력하지 않고 표시 형식으로 나타내는 것이 원칙이다.

값이 변하지 않았는지는 통화와 쉼표 스타일의 셀은 수식 입력줄로, 날짜와 백분율의 셀은 표시 형식을 [일반]으로 바꾸어 읽은 뒤 Ctrl + Z로 되돌리는 방법으로(수식 입력줄에도 날짜와 백분율의 모습으로 표시되기 때문이다), 범위 전체는 상태 표시줄의 합계로 확인한다.

엑셀은 셀마다 값과 표시 형식을 따로 저장한다. 표시 형식은 값을 어떤 모양으로 그릴지 적은 규칙(표시 형식 코드)이며, 모양은 셀을 그릴 때마다 새로 만들어질 뿐 저장되지 않는다. 다음은 핵심 실습의 완성 파일(판매현황_02_완성.xlsx)을 교수의 작업 PC에서 열어 세 셀의 값과 표시 형식 코드, 셀의 모양을 읽은 것이다(Microsoft 365, 2026-11-15).

셀    저장된 값   표시 형식 코드                            셀의 모양
B4    46024       yyyy-mm-dd                                2026-01-02
E4    30          _-* #,##0_-;-* #,##0_-;_-* "-"_-;_-@_-     30
F4    24000       ₩#,##0                                    ₩24,000

#,##0은 천 단위 쉼표를 넣고 소수점 아래를 표시하지 않는다는 뜻이고(0.00이면 소수 둘째 자리까지), ₩처럼 코드에 적힌 글자는 모양에만 붙으며, yyyy, mm, dd는 연, 월, 일이다. 수량의 코드는 세미콜론(;)으로 양수, 음수, 0, 문자의 모양을 나눈 것이다.

모양이 반올림되어 보여도 값은 반올림되지 않는다. 교수의 작업 PC에서 24000.4를 저장한 셀에 위의 통화 형식(₩#,##0)을 지정하였더니 셀에는 ₩24,000이 표시되었고 저장된 값은 24000.4 그대로였다. 눈으로 더한 값과 상태 표시줄의 합계가 조금 다르면 이런 셀을 의심한다. 본 과목의 판매 자료는 모두 정수이다.

3-2. 표시 형식의 종류

표시 형식은 [홈] 탭 → [표시 형식] 그룹의 표시 형식 목록에서 선택하며, 서식을 지정하지 않은 셀은 [일반]이다. 목록에 없는 세부 항목은 Ctrl + 1로 여는 [셀 서식] 대화 상자의 [표시 형식] 탭에서 지정한다.

[그림 자리: [표시 형식] 그룹의 목록과 단추] [홈] 탭의 [표시 형식] 그룹에서 표시 형식 목록을 펼친 모습과, 그 아래 줄의 [회계 표시 형식], [백분율 스타일], [쉼표 스타일], [자릿수 늘림], [자릿수 줄임] 단추의 위치를 번호로 표시한다. 찍을 곳: Microsoft 365 엑셀, [홈] 탭.

3-3. 쉼표 스타일, 통화, 회계

수량에는 [표시 형식] 그룹의 [쉼표 스타일] 단추를, 단가에는 표시 형식 목록의 [통화]를 쓴다. 수량은 1,000 미만이므로 쉼표 스타일을 적용하여도 쉼표가 나타나지 않는다.

[쉼표 스타일] 단추는 엑셀에 미리 등록된 셀 스타일(글꼴, 숫자 서식, 테두리, 음영 같은 서식 특성을 묶어 이름을 붙인 것)을 셀에 적용한다. 쉼표를 표시하는 셀 스타일은 소수 자릿수만 다른 두 가지가 있다. 교수의 작업 PC(Microsoft 365, 2026-11-15)에서 두 스타일을 수량 30에 각각 적용한 결과는 다음과 같았다.

셀 스타일   표시 형식 코드                                     30의 모양
쉼표        _-* #,##0.00_-;-* #,##0.00_-;_-* "-"??_-;_-@_-      30.00
쉼표 [0]    _-* #,##0_-;-* #,##0_-;_-* "-"_-;_-@_-              30

본 과목은 수량을 “쉼표 [0]”의 모양(30)으로 표시하며, 완성 파일에도 “쉼표 [0]”을 적용하였다. 같은 PC에서 리본의 쉼표 스타일 명령을 자동화로 실행하였을 때는 “쉼표 [0]”이 적용되었다(준비 사항의 최신 자료 자리 (3)). 단추를 누른 뒤 수량이 30.00으로 표시되면 같은 범위를 선택한 채 [자릿수 줄임]을 두 번 눌러 30으로 만든다. 저장된 값은 30 그대로이다. 단가의 코드는 ₩#,##0(정수)이며, [통화]를 고른 뒤 ₩24,000.00처럼 표시되면 같은 방법으로 고친다.

통화는 기호가 숫자의 바로 앞에 붙고, 회계는 기호가 셀의 왼쪽 끝에 놓여 열 안에서 기호끼리, 숫자끼리 정렬되며 0을 -로 표시한다. [표시 형식] 그룹의 [회계 표시 형식] 단추는 회계 형식을 적용하므로, 본 과목의 단가와 금액은 이 단추가 아니라 표시 형식 목록의 [통화]로 지정한다.

3-4. 날짜

엑셀은 날짜를 1900년 1월 1일을 1로 하여 하루에 1씩 증가하는 일련번호로 저장한다(지원 문서 「Excel의 날짜 체계」). 날짜 형식은 이 숫자를 연, 월, 일의 모습으로 표시하는 표시 형식이다. 교수의 작업 PC에서 날짜를 입력하고 저장된 값을 읽은 결과는 다음과 같았다(2026-11-15).

입력한 날짜     저장된 값(일련번호)
1900-01-01      1
2026-01-02      46024
2026-01-29      46051
2026-02-02      46055
2026-02-27      46080

날짜가 숫자이므로 날짜끼리 빼면 두 날짜 사이의 일수가 되고(1월 2일부터 1월 29일까지 27일), 날짜에 1을 더하면 다음 날이 된다. 1장에서 채우기 핸들로 날짜가 하루씩 증가한 것은 일련번호가 1씩 증가한 것이다.

판매일은 [셀 서식] 대화 상자(Ctrl + 1)의 [표시 형식] 탭에서 범주 [날짜]의 연-월-일 형식(2012-03-14처럼 표시된 항목)을 골라 2026-01-02의 형태로 통일한다. 별표(*)로 시작하는 항목은 Windows의 국가 설정에 따라 모습이 달라진다.

판매일이 셀의 왼쪽에 맞추어져 있으면 날짜가 아니라 문자로 입력된 것이며, 표시 형식을 변경하여도 모습이 변하지 않는다(실습 PC에서 문자 2026.01.02에 yyyy-mm-dd를 지정하여도 모양이 그대로였다). 그 셀에 2026-01-02의 모양으로 다시 입력한다.

3-5. 백분율

백분율 형식은 셀의 값에 100을 곱하고 % 기호를 붙여 표시한다. 0.25가 저장된 셀은 25%로 표시되고 값은 0.25 그대로이며, 25를 저장한 셀은 2500%가 된다. 따라서 비율은 0.25와 같은 소수로 계산하여 두고 표시만 백분율로 바꾼다. [표시 형식] 그룹의 [백분율 스타일] 단추로 적용하며, 3장에서 구성비에 사용한다.

4-1. 인쇄 미리 보기

시트의 모습과 인쇄되는 모습은 일치하지 않으므로 인쇄 전에 인쇄 미리 보기로 출력 형태를 확인한다. [파일] 탭 → [인쇄] 또는 Ctrl + P를 누르면 오른쪽에 미리 보기가, 왼쪽에 인쇄 설정이 표시되고, 미리 보기의 아래쪽에 현재 쪽과 전체 쪽 수가 표시된다. 시트로 돌아갈 때에는 Esc를 누른다.

[그림 자리: [인쇄] 화면에서 읽을 곳] [파일] 탭의 [인쇄] 화면에 왼쪽의 설정 항목(용지 방향, 용지 크기, 여백, 크기 조정), 오른쪽의 미리 보기, 미리 보기 아래쪽의 쪽 수 표시와 쪽 이동 화살표를 번호로 표시한다. 찍을 곳: Microsoft 365 엑셀, Ctrl + P, 연습용 통합 문서의 “판매내역” 시트(설정하기 전).

4-3. 배율과 한 페이지에 시트 맞추기

표가 용지를 조금 초과하면 초과한 열이나 행이 다음 쪽으로 넘어간다. 이때 인쇄되는 크기의 비율인 배율(화면의 확대/축소와는 관계가 없다)을 줄여 한 쪽에 넣는다. [한 페이지에 시트 맞추기]는 시트의 내용이 한 쪽에 들어가도록 인쇄 배율을 자동으로 축소하는 설정이다.

  1. [파일] 탭 → [인쇄]를 선택한다.
  2. 설정의 마지막 항목(기본 값은 [현재 설정된 용지])을 누른다.
  3. [한 페이지에 시트 맞추기]를 선택한다.

이 설정은 축소만 하고 확대하지 않는다. 본 장의 표는 설정하지 않아도 한 쪽에 출력되지만, 3장과 4장에서 열이 추가되어도 한 쪽을 유지하도록 미리 설정한다. 이후의 장에서 “2장의 방법으로 한 쪽에 맞춘다”라고 기재한 것은 이 설정을 가리킨다. [페이지 레이아웃] 탭에서 [너비]와 [높이]를 [1페이지]로 지정하여도 같다.

인쇄되는 글자의 크기는 글꼴 크기에 배율을 곱한 값이다. 한 쪽 맞춤은 배율을 엑셀이 정하게 하므로, 지정한 뒤에는 쪽 수와 함께 [페이지 레이아웃] 탭의 [배율] 상자의 값을 읽는다. 배율은 용지에서 여백을 뺀 인쇄 가능 영역과 표의 크기를 견주어 정해진다. 본 장의 설정에서 A4 세로의 인쇄 가능 영역은 17.0cm × 24.7cm이고 핵심 실습의 표는 약 11.5cm × 14.1cm이므로 배율은 100%로 남는다.

4-4. 인쇄 영역

인쇄 영역은 시트에서 인쇄할 범위를 지정하는 설정이다. 지정하지 않으면 내용이 있는 범위 전체가 인쇄되고, 지정하면 그 범위만 인쇄된다.

작업 조작
설정 인쇄할 범위를 선택하고 [페이지 레이아웃] 탭 → [페이지 설정] 그룹 → [인쇄 영역] → [인쇄 영역 설정]을 선택한다
해제 시트의 아무 셀이나 선택하고 [페이지 레이아웃] 탭 → [페이지 설정] 그룹 → [인쇄 영역] → [인쇄 영역 해제]를 선택한다

인쇄 영역은 통합 문서와 함께 저장되므로, 지정한 뒤에 그 바깥에 추가한 열이나 행은 인쇄되지 않는다. 본 과목의 통합 문서는 3장과 4장에서 열과 요약 행이 추가되므로 인쇄 영역을 지정하지 않는다. 인쇄 영역은 표의 일부를 일시적으로 출력할 때 쓰고 출력한 뒤에 해제한다.

버전에 따른 차이: [인쇄 영역 해제]는 지원 문서에 [인쇄 영역 지우기]로 적혀 있다.

4-5. [선택] 페이지 나누기 미리 보기

페이지 나누기 미리 보기는 어느 셀까지가 몇 쪽에 인쇄되는지를 시트 위에 쪽의 경계로 표시하는 보기 방식이다.

작업 조작
페이지 나누기 미리 보기로 전환 [보기] 탭 → [통합 문서 보기] 그룹 → [페이지 나누기 미리 보기]
원래의 보기로 복귀 [보기] 탭 → [통합 문서 보기] 그룹 → [기본]

엑셀이 정한 쪽의 경계는 파선으로, 사용자가 지정한 경계는 실선으로 표시되며, 지정한 인쇄 영역도 표시된다. 상태 표시줄 오른쪽의 보기 단추로도 전환한다. [기본] 보기로 돌아온 뒤에 남는 점선은 쪽의 경계이며 인쇄되지 않는다.

[그림 자리: 페이지 나누기 미리 보기의 두 경우] 왼쪽은 표 전체가 한 쪽의 경계 안에 들어 있는 모습, 오른쪽은 열이 두 쪽으로 나뉘어 쪽의 경계(파선)가 표의 중간을 지나는 모습이다. 쪽 번호가 시트 위에 크게 표시되는 것도 함께 보인다. 찍을 곳: Microsoft 365 엑셀, [보기] 탭 → [페이지 나누기 미리 보기].

4-6. [선택] 머리글과 바닥글

머리글과 바닥글은 용지의 위쪽과 아래쪽 여백에 매 쪽마다 인쇄되는 내용이며, 셀에 입력하는 것이 아니므로 인쇄 미리 보기와 인쇄물에만 나타난다. [페이지 설정] 대화 상자([여백] → [사용자 지정 여백])의 [머리글/바닥글] 탭에서 [머리글 편집] 또는 [바닥글 편집]을 누르고, 왼쪽, 가운데, 오른쪽 구역 가운데 하나에 문자를 입력하거나 단추로 쪽 번호, 현재 날짜 같은 요소를 삽입한다. 본 과목의 출력물은 한 쪽이므로 제목은 셀에 입력한다.

버전에 따른 차이: [머리글 편집]과 [바닥글 편집] 단추는 Microsoft의 지원 문서에 [사용자 지정 머리글], [사용자 지정 바닥글]로 적혀 있다.

4-7. PDF 내보내기

PDF는 인쇄한 모습을 그대로 담는 파일 형식이다. 본 과목의 출력물은 모두 PDF로 제출한다.

  1. [파일] 탭 → [내보내기] → [PDF/XPS 문서 만들기] → [PDF/XPS 만들기]를 선택한다.
  2. 대화 상자에서 저장할 폴더와 파일 이름을 지정하고 [게시]를 누른다.

[파일] 탭 → [다른 이름으로 저장]에서 파일 형식을 PDF (*.pdf)로 지정하여도 같은 결과를 얻는다. 대화 상자의 [게시 후 파일 열기]를 선택하여 두면 저장한 PDF가 바로 열린다.

PDF에는 현재 선택된 시트가 인쇄 설정에 따라 저장되므로 인쇄 미리 보기의 모습이 그대로 PDF가 된다. PDF는 내보낸 시점의 모습이므로 통합 문서를 수정한 뒤에는 다시 내보내며, .xlsx 파일은 Ctrl + S로 따로 저장한다. 내보낸 뒤에는 PDF를 열어 다음을 확인한다(「PDF 결과의 확인」).

절차

단계 1. 파일의 준비

  1. 컴퓨터활용\실습\판매현황_01_학번.xlsx를 연다. 시트 “판매내역”의 A1:F1에 머리글이, A2:F21에 자료가 있는지 확인한다.
  2. [파일] 탭 → [다른 이름으로 저장]에서 같은 폴더에 판매현황_02_학번.xlsx로 저장한다.
  3. E2:E21을 선택하여 수량의 합계가 493인지 읽어 둔다. 단계 4에서 서식을 적용한 뒤의 합계와 대조하는 기준이며, 493이 아니면 서식을 적용하기 전에 1장의 입력 오류를 고친다.

단계 2. 행의 삽입과 제목의 작성

  1. 행 머리글 1과 2를 끌어 두 행을 선택하고, 선택한 행 머리글 위에서 마우스 오른쪽 단추를 눌러 [삽입]을 선택한다.

  4. A1:F1을 선택하고 [홈] 탭 → [맞춤] 그룹 → [병합하고 가운데 맞춤]을 누른다.

단계 3. 머리글의 서식과 테두리

단계 4. 표시 형식과 맞춤

  1. B4:B23을 선택하고 Ctrl + 1을 누른다. [표시 형식] 탭의 범주에서 [날짜]를 선택하고 연-월-일의 형식을 선택한 뒤 [확인]을 누른다. B4가 2026-01-02로 표시되는지 확인한다.
  2. B4를 선택하고 표시 형식 목록에서 [일반]을 선택하여 표시되는 숫자를 읽은 뒤 Ctrl + Z로 되돌린다.
  3. E4:E23을 선택하고 [홈] 탭 → [표시 형식] 그룹 → [쉼표 스타일]을 누른다. 수량이 30.00처럼 표시되면 [자릿수 줄임]을 두 번 누른다.
  4. F4:F23을 선택하고 표시 형식 목록에서 [통화]를 선택한다. F4가 ₩24,000으로 표시되는지 확인한다.
  5. F4를 선택하여 수식 입력줄에 24000이 표시되는지 확인한다.
  6. A4:B23을 선택하고 [가운데 맞춤]을 누른다. 거래처, 품목, 수량, 단가의 맞춤은 변경하지 않는다.
  7. 열 머리글 A부터 F까지를 끌어 선택하고, 그중 한 경계선을 두 번 눌러 열 너비를 내용에 맞춘다. ####로 표시되는 셀이 없는지 확인한다.

연습 문제

연습용 통합 문서(판매연습_02_학번.xlsx)의 “판매내역” 시트에서 수행하며, 문제마다 마친 뒤에는 시트를 풀기 전의 상태로 되돌린다.

문제 1. 판매일의 첫 값(B4)과 마지막 값(B22)이 셀에 어떤 숫자로 저장되어 있는지 확인하고, 두 날짜 사이의 일수를 구한다.

  • 기준 값: B4는 46055, B22는 46080, 두 날짜 사이는 25일이다. 되돌린 뒤에는 2026-02-02와 2026-02-27로 표시된다
  • 실마리: 날짜는 일련번호로 저장된다(3-4).

문제 2. 10행의 위치에 빈 행 하나를 삽입한다. 이때 판매번호 1039의 단가가 놓이는 셀 주소와, 수량이 입력된 범위 전체의 개수와 합계를 구한다. 그 뒤에 삽입한 행을 제거한다.

  • 기준 값: 삽입한 뒤 1039의 단가는 F23에 있고, E4:E23의 개수는 19, 합계는 532이다. 행을 제거한 뒤 1039의 단가는 다시 F22에 있다
  • 실마리: 삽입에 따른 주소의 변화(1-2)와 삭제와 지우기의 차이(1-3). 개수가 20이 아닌 까닭을 생각한다.

문제 3. 제목을 제외하고 판매번호부터 품목까지의 네 열만(머리글 포함) 가로 방향의 용지 한 쪽에 인쇄되도록 설정하여 미리 보기로 확인한다. 그 뒤에 설정을 원래대로 되돌린다.

  • 실마리: 인쇄 영역(4-4)과 용지 방향(4-2). 숨기기로는 기준 값과 같아지지 않는다.
  • 기준 값: 인쇄 영역은 A3:D22이다. 미리 보기에는 네 개의 열과 20개의 행(머리글 1행, 자료 19행)이 가로 방향의 한 쪽에 표시되고 제목, 수량, 단가는 표시되지 않는다. 되돌린 뒤의 미리 보기에는 세로 방향의 한 쪽에 제목과 여섯 개의 열이 표시된다

개념 점검

  1. 1행과 2행의 위치에 두 행을 삽입하면 E2에 있던 값은 어느 셀에 놓이는지 적고, 이때 값 자체는 변하는지 변하지 않는지를 적는다.
  2. 눈금선과 테두리의 차이를 인쇄의 관점에서 설명한다.
  3. 단가 24000에 통화 형식을 적용한 셀과, 24000원을 직접 입력한 셀의 차이를 저장된 값의 종류와 계산의 가능 여부로 설명한다.
  4. 값과 서식이 모두 있는 셀에 Delete, [서식 지우기], [모두 지우기]를 각각 적용하였을 때 남는 것을 적는다.
  5. [한 페이지에 시트 맞추기]를 지정한 통합 문서에 열을 두 개 추가하여도 출력물이 한 쪽으로 유지되는 이유를 설명하고, 같은 통합 문서에 인쇄 영역이 A3:F23으로 지정되어 있었다면 추가한 열이 어떻게 되는지를 적는다.
