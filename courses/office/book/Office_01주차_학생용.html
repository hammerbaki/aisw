1주차

파일 관리와 데이터 입력

2027학년도 「컴퓨터활용」의 준비 중인 교재입니다. 편집 상태를 검토하기 위해 미리 공개한 것으로, 수업 전에 내용과 순서가 바뀔 수 있습니다.

학사 2주차 · 교재 01 · 1부 엑셀

「컴퓨터 활용」은 엑셀에서 작성한 하나의 판매 자료를 서식, 수식, 함수, 차트, 피벗 테이블로 확장하고, 같은 자료를 파워포인트, 파이썬, 생성형 AI, 액세스에서 다시 사용하는 과목이다. 본 장은 그 출발점으로서, 이후의 모든 장이 사용하는 판매 자료 20행을 직접 입력하여 지정된 위치에 지정된 이름으로 저장한다.

본 장의 수업은 두 종류의 자료로 진행한다. 1~5절은 설명과 시연이며, 각 절의 끝에 있는 「따라 하기」에서 배포받은 2월 자료를 사용하여 시연한 조작을 직접 수행한다. 6절의 핵심 실습에서는 1월 자료 20행을 빈 통합 문서에 직접 입력한다. 완료 여부는 핵심 실습의 완료 기준에 제시된 값으로 판정한다. 서식의 적용과 인쇄 설정은 2장 「셀 서식과 인쇄 설정」에서 다루므로, 본 장에서는 값의 입력과 저장만을 수행한다.

학습 목표

  • 파일을 지정된 폴더에 지정된 이름과 형식으로 저장할 수 있다.
    • 예시: 컴퓨터활용 폴더의 실습 폴더에 판매현황_01_학번.xlsx라는 이름의 Excel 통합 문서로 저장한다.
    • 활용: 결과물을 지정된 위치와 이름으로 저장하는 일은 이 과목의 모든 장과 후속 과목의 실기에서 공통으로 요구된다.
  • 셀과 범위를 선택하고 문자, 숫자, 날짜 자료를 구분하여 입력할 수 있다.
    • 예시: B2부터 F21까지의 범위에 판매일, 거래처, 품목, 수량, 단가를 입력하고, 입력 직후의 맞춤 위치로 자료의 종류를 판별한다.
    • 활용: 자료의 종류가 올바르게 입력되어야 이후의 장에서 수식, 정렬, 집계의 결과가 올바르게 산출된다.
  • 채우기 핸들로 연속된 값을 입력하고, 상태 표시줄의 값으로 입력 결과를 검산할 수 있다.
    • 예시: 판매번호 1001부터 1020까지를 채우기 핸들로 입력하고, 수량의 합계가 493인지 확인한다.
    • 활용: 입력을 마친 자료는 눈으로 훑어보는 것이 아니라 기준 값과 대조하여 검증한다. 이 절차는 이 과목의 모든 실습에 적용된다.

1. 실습 폴더의 구성

1-1. 폴더와 경로

파일(file)은 자료가 저장되는 단위이고, 폴더(folder)는 파일과 다른 폴더를 담는 단위이다. 경로(path)는 드라이브에서 출발하여 해당 파일에 이르기까지의 폴더를 순서대로 기재한 것이며, 폴더와 폴더 사이는 역슬래시(\)로 구분한다. 한글 글꼴에서는 역슬래시가 원화 기호(₩)로 표시되기도 한다.

C:\Users\사용자이름\Documents\컴퓨터활용\실습\판매현황_01_2027000.xlsx

위의 경로는 C 드라이브의 Users, 사용자이름, Documents(문서), 컴퓨터활용, 실습 폴더를 차례로 거쳐 판매현황_01_2027000.xlsx 파일에 이른다는 뜻이다. 파일을 저장할 때에는 파일 이름과 함께 이 경로가 의도한 위치인지를 확인하여야 한다.

1-2. 실습 폴더의 구조

이 과목의 파일은 모두 컴퓨터활용 폴더에 보관한다. 이 폴더를 실습 폴더라 하며, 그 아래에 용도가 다른 폴더 세 개를 둔다.

컴퓨터활용
├─ 자료
├─ 실습
└─ 출력
폴더 용도 규칙
자료 수업에서 배포하는 파일(판매_2026_01.xlsx 등)을 보관한다 내용을 수정하지 않는다. 수정이 필요하면 파일을 연 뒤 실습 폴더에 다른 이름으로 저장하여 사용한다
실습 수강생이 직접 작성하는 파일을 보관한다 장마다 결과 파일을 새 이름으로 저장한다
출력 PDF로 출력한 파일을 보관한다 다음 장부터 사용한다
  • 실습 폴더는 [문서] 폴더에 둔다.
  • 폴더 이름과 파일 이름에는 공백을 넣지 않는다.
  • 수업을 마칠 때에는 실습 폴더 전체를 개인 저장 매체나 클라우드 저장소에 복사하여 보관한다.

자료 폴더와 실습 폴더를 구분하는 이유는 원본의 보존에 있다. 배포받은 파일을 직접 수정하면 기준 값과 대조할 원본이 없어진다. 원본을 한 곳에 수정하지 않은 상태로 두면 작업 파일에 오류가 발생하였을 때 언제든지 원본에서 다시 시작할 수 있다.

1-3. 파일 탐색기의 조작

폴더의 작성과 파일의 복사는 파일 탐색기에서 수행한다. 파일 탐색기의 창은 왼쪽의 탐색 창, 위쪽의 주소 표시줄, 가운데의 파일 목록으로 구성된다. 탐색 창에서 폴더를 선택하면 그 폴더의 내용이 파일 목록에 표시되고, 주소 표시줄에는 현재 폴더의 위치가 표시된다.

그림 필요: (파일 탐색기에서 컴퓨터활용 폴더를 연 화면에 탐색 창, 주소 표시줄, 파일 목록의 위치를 표시한 그림)

작업 조작
파일 탐색기의 실행 Win + E
새 폴더의 작성 폴더를 작성할 위치를 연 상태에서 Ctrl + Shift + N을 누르고, 이름을 입력한 뒤 Enter를 누른다
이름의 변경 대상을 선택하고 F2를 누른다
복사 대상을 선택하고 Ctrl + C를 누른 뒤, 붙여 넣을 폴더를 열고 Ctrl + V를 누른다
이동 대상을 선택하고 Ctrl + X를 누른 뒤, 옮길 폴더를 열고 Ctrl + V를 누른다
삭제 대상을 선택하고 Delete를 누른다. 삭제한 항목은 휴지통으로 이동한다
직전 조작의 취소 Ctrl + Z
경로의 확인 주소 표시줄의 빈 곳을 클릭하거나 Alt + D를 누른다
상위 폴더로의 이동 Alt + ↑

복사는 원본을 그대로 둔 채 사본을 작성하고, 이동은 원본의 위치를 변경한다. 따라서 복사한 뒤에는 같은 파일이 두 곳에 존재하고, 이동한 뒤에는 한 곳에만 존재한다. 자료 폴더의 파일을 다른 곳에서 사용할 때에는 이동이 아니라 복사를 사용하여야 원본이 남는다.

여러 파일을 한꺼번에 다룰 때에는 먼저 대상을 모두 선택한다.

선택 대상 조작
폴더 안의 모든 항목 Ctrl + A
연속하여 나열된 항목 첫 항목을 클릭한 뒤 Shift를 누른 채 마지막 항목을 클릭한다
떨어져 있는 항목 Ctrl을 누른 채 항목을 하나씩 클릭한다

Delete로 삭제한 파일은 휴지통에 남아 있으므로 복원할 수 있다. Shift + Delete는 휴지통을 거치지 않고 영구적으로 삭제하므로 이 과목에서는 사용하지 않는다.

버전에 따른 차이: 파일 탐색기의 메뉴 구성은 Windows의 버전에 따라 다르다. 위 표의 단축키는 Windows 10과 Windows 11에서 동일하게 동작한다.

따라 하기

실습 폴더를 작성하고 배포받은 월별 파일 12개를 자료 폴더로 옮긴다.

  1. Win + E를 눌러 파일 탐색기를 실행하고 탐색 창에서 [문서] 폴더를 선택한다.
  2. Ctrl + Shift + N을 눌러 새 폴더를 작성하고 이름을 컴퓨터활용으로 입력한 뒤 Enter를 누른다.
  3. 작성한 폴더를 더블 클릭하여 열고, 같은 방법으로 자료, 실습, 출력 폴더를 작성한다.
  4. 주소 표시줄의 빈 곳을 클릭하여 경로를 확인한 뒤 Esc를 누른다.
  • 확인 1 컴퓨터활용 폴더에 자료, 실습, 출력 폴더 세 개가 있고, 주소 표시줄의 경로가 컴퓨터활용으로 끝났다.
  1. 부록 A의 안내에 따라 받은 월별 파일 12개가 있는 폴더를 연다.
  2. 첫 파일을 클릭한 뒤 Shift를 누른 채 마지막 파일을 클릭하여 12개를 모두 선택하고 Ctrl + X를 누른다.
  3. 컴퓨터활용 폴더의 자료 폴더를 열고 Ctrl + V를 누른다.
  • 확인 2 자료 폴더에 판매_2026_01부터 판매_2026_12까지 12개의 파일이 있고, 파일을 받았던 폴더에는 이 파일들이 남아 있지 않다.
  1. 자료 폴더에서 3월 파일(판매_2026_03)을 선택하고 Ctrl + C를 누른다.
  2. Alt + ↑를 눌러 컴퓨터활용 폴더로 이동하고, 실습 폴더를 열어 Ctrl + V를 누른다.
  • 확인 3 실습 폴더에 3월 파일의 사본이 1개 있고, 자료 폴더의 파일은 12개 그대로이다.

2. 파일 이름과 저장 형식

2-1. 파일 이름과 확장자

파일 이름은 이름.확장자의 형태이다. 확장자(extension)는 파일의 형식을 나타내며, Windows는 확장자에 따라 파일을 여는 프로그램을 결정한다. 엑셀 통합 문서의 확장자는 .xlsx이다.

파일 탐색기의 기본 설정에서는 확장자가 표시되지 않는다. 확장자가 표시되지 않으면 이름이 같고 형식이 다른 파일(예: 판매현황_02_학번.xlsx와 판매현황_02_학번.pdf)을 아이콘의 모양으로만 구분하여야 한다. 이 과목에서는 확장자가 표시되도록 설정하여 사용한다.

버전에 따른 차이: Windows 11에서는 파일 탐색기의 [보기] → [표시] → [파일 이름 확장명]을 선택한다. Windows 10에서는 [보기] → [옵션] → [폴더 및 검색 옵션 변경]을 선택하고, 대화 상자의 [보기] 탭에 있는 [고급 설정]에서 [알려진 파일 형식의 확장명 숨기기]의 선택을 해제한다.

파일 이름에는 \ / : * ? " < > |의 아홉 가지 문자를 사용할 수 없다. 확장자가 표시된 상태에서 이름을 변경할 때에는 확장자를 지우지 않도록 유의한다. 확장자를 지우거나 다른 것으로 바꾸면 Windows가 그 파일을 여는 프로그램을 찾지 못한다. 확장자를 바꾸어 적는 것만으로는 파일의 형식이 변환되지 않으며, 형식의 변환은 프로그램에서 [다른 이름으로 저장]으로 수행한다(2-4).

2-2. 파일 이름의 규칙

이 과목의 엑셀 결과 파일은 다음의 규칙으로 이름을 정한다.

판매현황_장 번호_학번.xlsx      핵심 실습의 통합 문서(제출한다)
판매연습_장 번호_학번.xlsx      연습용 통합 문서(제출하지 않는다)
  • 장 번호는 두 자리로 기재한다. 본 장의 파일은 판매현황_01, 판매연습_01로 시작한다.
  • 구분에는 밑줄(_)을 사용하고 공백을 넣지 않는다.
  • 예시: 학번이 2027000인 수강생의 본 장 결과 파일은 판매현황_01_2027000.xlsx이다.

장마다 앞 장의 파일을 열어 새 이름으로 저장하므로 장별 결과가 별도의 파일로 남는다. 오류가 발생하면 앞 장의 파일에서 다시 시작할 수 있다. 장 번호를 두 자리로 적는 이유는 파일 탐색기가 이름의 순서로 파일을 나열할 때 02가 10보다 앞에 놓이게 하기 위한 것이다.

2-3. 저장과 다른 이름으로 저장

명령 단축키 동작
저장 Ctrl + S 현재의 위치와 이름에 덮어쓴다. 한 번도 저장하지 않은 문서에서는 위치와 이름을 묻는다
다른 이름으로 저장 F12 [다른 이름으로 저장] 대화 상자를 열어 위치, 이름, 형식을 새로 지정한다
열기 Ctrl + O 저장된 통합 문서를 연다. 파일 탐색기에서 파일을 더블 클릭하여도 같다
닫기 Ctrl + W 현재의 통합 문서를 닫는다. 저장하지 않은 변경이 있으면 저장 여부를 묻는다

[저장]과 [다른 이름으로 저장]의 차이는 원본의 보존 여부이다. 자료 폴더의 파일을 열어 [저장]을 수행하면 원본이 변경된다. 열자마자 [다른 이름으로 저장]으로 실습 폴더에 새 이름을 부여하면 그 뒤의 [저장]은 새 파일에만 적용되고 원본은 그대로 남는다. 이 과목의 모든 장은 이 순서로 시작한다.

[다른 이름으로 저장] 대화 상자에서는 세 가지를 확인한다.

  1. 위쪽의 주소 표시줄에 표시된 폴더가 저장하려는 위치인가.
  2. [파일 이름]에 입력한 이름이 규칙과 일치하는가. 확장자는 입력하지 않아도 [파일 형식]에 따라 자동으로 부여된다.
  3. [파일 형식]이 Excel 통합 문서 (*.xlsx)인가.

그림 필요: ([다른 이름으로 저장] 대화 상자에서 주소 표시줄, [파일 이름], [파일 형식]의 세 곳을 표시한 그림)

저장이 완료되면 엑셀 창의 제목 표시줄에 파일 이름이 표시된다. 작업 중에는 Ctrl + S로 수시로 저장한다. 저장은 실행 취소의 대상이 아니므로, 잘못된 상태를 저장한 뒤에는 Ctrl + Z로 저장 이전의 파일로 되돌릴 수 없다.

인터넷에서 내려받은 파일을 열면 창의 위쪽에 노란색 메시지 표시줄이 나타나고 입력이 되지 않는 경우가 있다. 이 상태를 제한된 보기라 하며, 출처가 안전하지 않을 수 있는 파일을 읽기 전용으로 여는 보호 기능이다. 수업에서 배포한 파일과 같이 출처를 신뢰할 수 있는 파일이면 메시지 표시줄의 [편집 사용]을 선택하여 편집할 수 있는 상태로 전환한다.

버전에 따른 차이: 새 문서에서 Ctrl + S를 누르거나 [파일] 탭 → [다른 이름으로 저장]을 선택하였을 때 나타나는 화면은 오피스의 버전에 따라 다르며, 버전에 따라서는 클라우드 저장소가 기본 위치로 제시된다. F12는 버전과 관계없이 [다른 이름으로 저장] 대화 상자를 직접 연다. 노트북에서는 Fn 키와 함께 눌러야 하는 경우가 있다. 제목 표시줄의 왼쪽에 있는 [자동 저장] 스위치는 클라우드 저장소(OneDrive 등)에 저장된 파일에서만 동작한다. [문서] 폴더와 같은 PC의 폴더에 저장한 파일은 자동으로 저장되지 않으므로 직접 저장하여야 한다.

2-4. 저장 형식

[다른 이름으로 저장] 대화 상자의 [파일 형식] 목록에는 여러 형식이 있다. 형식에 따라 파일에 저장되는 내용이 다르다.

형식 확장자 저장되는 내용 이 과목에서의 사용
Excel 통합 문서 .xlsx 모든 시트의 값, 수식, 서식, 차트, 인쇄 설정 엑셀의 기본 형식이다. 이 과목의 엑셀 파일은 모두 이 형식으로 저장한다
Excel 97-2003 통합 문서 .xls 구 버전의 형식이다. 새 버전의 일부 기능이 저장되지 않을 수 있다 사용하지 않는다
Excel 매크로 사용 통합 문서 .xlsm .xlsx의 내용과 매크로(자동 실행 코드) 사용하지 않는다
CSV(쉼표로 분리) .csv 현재 시트 하나의 값만 쉼표로 구분한 텍스트로 저장한다. 서식, 수식, 다른 시트는 저장되지 않는다 사용하지 않는다. 다른 프로그램과 자료를 주고받을 때 쓰이는 형식이다
PDF .pdf 인쇄되는 모습을 저장한다. 문서의 모양은 유지되나 엑셀에서 다시 계산하거나 수정할 수 없다 다음 장부터 출력물의 제출에 사용한다

.xlsx가 아닌 형식으로 저장하면 일부 서식, 자료, 기능이 저장되지 않을 수 있다. 예를 들어 서식을 적용한 표를 CSV로 저장한 뒤 다시 열면 테두리와 표시 형식이 모두 사라져 있다. 따라서 작업 중인 통합 문서는 항상 .xlsx로 저장하고, 다른 형식이 필요하면 .xlsx를 저장한 뒤에 사본을 그 형식으로 추가로 저장한다.

3. 엑셀 화면의 구성

3-1. 통합 문서, 워크시트, 셀

엑셀의 파일 하나를 통합 문서(workbook)라 한다. 통합 문서는 하나 이상의 워크시트(worksheet, 이하 시트)로 구성되고, 시트는 행(row)과 열(column)이 교차하는 셀(cell)로 구성된다.

  • 열은 A, B, C와 같은 영문자로, 행은 1, 2, 3과 같은 숫자로 구분한다. Z 열의 다음 열은 AA이다.
  • 셀의 주소는 열 문자와 행 번호를 이어 쓴다. B3은 B열과 3행이 교차하는 셀이다.
  • 하나의 셀에는 하나의 값을 입력한다.
  • 시트 하나는 1,048,576개의 행과 16,384개의 열로 구성된다. 화면에 보이는 부분은 시트의 왼쪽 위 일부이다.

3-2. 화면의 구성 요소

구성 요소 위치 기능
제목 표시줄 창의 맨 위 현재 통합 문서의 파일 이름을 표시한다
빠른 실행 도구 모음 제목 표시줄의 왼쪽 [저장], [실행 취소] 등 자주 사용하는 단추를 모아 둔 곳이다
리본 메뉴 제목 표시줄의 아래 명령을 탭과 그룹으로 분류하여 제시한다. 탭은 [파일], [홈], [삽입], [페이지 레이아웃], [수식], [데이터], [검토], [보기] 등이다
이름 상자 리본 메뉴의 아래, 왼쪽 현재 선택된 셀의 주소를 표시한다. 주소를 입력하여 셀을 선택할 수도 있다

그림 필요: (엑셀의 통합 문서 화면에 위 표의 구성 요소 아홉 가지의 위치를 번호로 표시한 그림)

상태 표시줄의 왼쪽 끝에는 셀의 입력 상태가 표시된다. 셀을 선택만 한 상태에서는 [준비], 셀에 내용을 입력하는 중에는 [입력], 기존의 내용을 수정하는 중에는 [편집]으로 표시된다. 리본 메뉴의 명령이 선택되지 않을 때에는 이 표시가 [준비]인지를 먼저 확인한다.

3-3. 리본 메뉴의 표기와 표시

이 교재는 리본 메뉴의 명령을 [탭] 탭 → [그룹] 그룹 → [명령]의 순서로 표기한다. 예를 들어 [홈] 탭 → [편집] 그룹 → [지우기]는 [홈] 탭을 선택하고 [편집] 그룹에서 [지우기]를 선택한다는 뜻이다.

리본 메뉴는 접어 둘 수 있다. Ctrl + F1을 누르면 리본 메뉴가 숨겨져 탭의 이름만 남고, 다시 누르면 표시된다. 리본 메뉴의 단추가 보이지 않을 때에는 Ctrl + F1을 누르거나, 리본 메뉴의 오른쪽 끝에 있는 [리본 표시 옵션]에서 [항상 리본 표시]를 선택한다.

버전에 따른 차이: 리본 메뉴의 탭 구성과 단추의 모양은 오피스의 버전에 따라 다르다. 엑셀을 실행하였을 때 시작 화면이 나타나는 버전에서는 [새 통합 문서]를 선택하여야 빈 시트가 열린다.

3-4. 시트의 추가와 이름 변경

통합 문서에는 시트를 여러 개 둘 수 있다. 시트 탭의 오른쪽에 있는 [새 시트] 단추(더하기 모양)를 누르면 새 시트가 추가된다. 시트의 이름은 시트 탭을 더블 클릭하거나 마우스 오른쪽 단추로 클릭하여 [이름 바꾸기]를 선택한 뒤 입력한다. 시트를 제거할 때에는 시트 탭을 마우스 오른쪽 단추로 클릭하여 [삭제]를 선택한다. 이 과목에서는 자료가 있는 시트의 이름을 판매내역으로 통일하며, 이후의 장에서 시트를 추가할 때마다 교재가 이름을 지정한다.

  1. D2 셀을 클릭하고 이름 상자와 수식 입력줄에 표시된 내용을 읽는다.
  2. B2 셀을 클릭하고 수식 입력줄에 표시된 내용을 읽는다.
  3. 이름 상자를 클릭하여 F20을 입력하고 Enter를 누른다.
  • 확인 7 D2의 수식 입력줄에는 A4 복사용지, B2의 수식 입력줄에는 2026-02-02, F20의 수식 입력줄에는 24000이 표시되었다.
  1. H1 셀을 선택하고 상태 표시줄의 왼쪽 끝이 [준비]인지 확인한다.
  2. 1을 입력하고(아직 Enter를 누르지 않는다) 상태 표시줄의 표시를 확인한 뒤 Esc를 누른다.
  3. Ctrl + F1을 두 번 눌러 리본 메뉴가 숨겨졌다가 다시 표시되는 것을 확인한다.
  • 확인 8 입력 중에는 상태 표시줄의 왼쪽 끝이 [입력]으로 바뀌었고, Esc를 누른 뒤에는 [준비]로 돌아왔으며 H1은 빈 셀이다.
  1. 시트 탭의 오른쪽에 있는 [새 시트] 단추를 누른다.
  2. 추가된 시트의 탭을 더블 클릭하고 입력연습을 입력한 뒤 Enter를 누른다.
  3. 시트 탭 판매내역을 클릭하여 자료가 있는 시트로 돌아온 뒤 Ctrl + S로 저장한다.
  • 확인 9 시트 탭이 판매내역과 입력연습의 두 개이고, 판매내역 시트의 A1:F1에 머리글이 표시되어 있다.

4. 셀과 범위의 선택

엑셀의 명령은 선택된 셀을 대상으로 동작하므로, 조작의 순서는 항상 선택이 먼저이고 명령이 나중이다. 굵은 테두리로 표시된 셀 하나를 활성 셀(active cell)이라 하며, 입력한 내용은 활성 셀에 들어간다.

4-1. 셀의 이동

활성 셀은 마우스로 클릭하여 옮기거나 키로 옮긴다. 자료를 입력하는 중에는 손이 키보드에 있으므로 키에 의한 이동이 빠르다.

키 이동하는 위치
방향키 한 셀 위, 아래, 왼쪽, 오른쪽
Tab, Shift + Tab 한 셀 오른쪽, 한 셀 왼쪽
Enter, Shift + Enter 한 셀 아래, 한 셀 위
Home 현재 행의 첫 열(A열)
Ctrl + Home 시트의 첫 셀(A1)
Ctrl + End 시트에서 사용된 마지막 셀(사용된 가장 오른쪽 열과 가장 아래쪽 행이 만나는 셀)
Ctrl + 방향키 자료가 연속하여 입력된 영역의 가장자리
Page Down, Page Up 한 화면 아래, 한 화면 위

Ctrl + 방향키는 자료의 끝을 찾는 데 사용한다. 자료가 입력된 열에서 Ctrl + ↓를 누르면 그 열에서 자료가 끊기기 직전의 셀로 이동하므로, 이동한 셀의 행 번호로 자료의 행 수를 알 수 있다. Ctrl + End로 이동한 셀이 표의 오른쪽 아래 모서리가 아니면 표의 바깥에 내용이나 서식이 남아 있는 것이다.

4-2. 범위의 선택

범위(range)는 직사각형 모양으로 연속된 셀의 묶음이다. 범위는 왼쪽 위 셀의 주소와 오른쪽 아래 셀의 주소를 쌍점(:)으로 이어 표기한다. A2:F21은 A2부터 F21까지의 범위이며 20행, 6열, 120개의 셀로 구성된다.

선택 대상 조작
셀 하나 셀을 클릭한다. 또는 이름 상자에 주소를 입력하고 Enter를 누른다
연속된 범위 첫 셀에서 끝 셀까지 끈다. 또는 첫 셀을 클릭한 뒤 Shift를 누른 채 끝 셀을 클릭한다
주소를 아는 범위 이름 상자에 A2:F21과 같이 입력하고 Enter를 누른다
선택 영역의 확장 Shift + 방향키를 누르면 선택 영역이 한 셀씩 넓어진다
자료가 입력된 끝까지 첫 셀을 선택한 뒤 Ctrl + Shift + 방향키를 누른다
떨어져 있는 범위 첫 범위를 선택한 뒤 Ctrl을 누른 채 다음 범위를 선택한다
열 전체, 행 전체 열 머리글 또는 행 머리글을 클릭한다. 여러 열이나 행은 머리글을 끌어 선택한다
표 전체 표 안의 셀 하나를 선택하고 Ctrl + A를 누른다. 한 번 더 누르면 시트 전체가 선택된다

범위를 선택하는 방법은 범위의 크기에 따라 정한다. 화면 안에 들어오는 작은 범위는 끌어서 선택하고, 화면을 벗어나는 긴 범위는 이름 상자에 주소를 입력하거나 Ctrl + Shift + 방향키를 사용한다. 긴 범위를 끌어서 선택하면 화면이 빠르게 넘어가 끝 셀을 지나치기 쉽다.

4-3. 상태 표시줄에 의한 검산

숫자가 입력된 범위를 선택하면 상태 표시줄에 그 범위의 평균, 개수, 합계가 표시된다. 수식을 입력하지 않고도 값을 확인할 수 있으므로, 본 장에서는 상태 표시줄의 값을 입력 결과의 검산에 사용한다. 값이 표시되지 않으면 상태 표시줄을 마우스 오른쪽 단추로 클릭하여 [평균], [개수], [합계]를 선택한다.

그림 필요: (숫자 범위를 선택한 상태에서 상태 표시줄에 평균, 개수, 합계가 표시된 모습)

항목 표시되는 값 기본 설정
[평균] 선택한 셀 가운데 숫자가 입력된 셀의 평균 표시된다
[개수] 선택한 셀 가운데 내용이 있는 셀의 수. 문자가 입력된 셀도 센다 표시된다
[숫자 개수] 선택한 셀 가운데 숫자가 입력된 셀의 수 표시되지 않는다
[최소값], [최대값] 선택한 셀의 숫자 가운데 가장 작은 값과 가장 큰 값 표시되지 않는다
[합계] 선택한 셀의 숫자의 합 표시된다

[개수]와 [숫자 개수]는 세는 대상이 다르다. 2, 3, 문자, 4가 입력된 네 셀을 선택하면 [개수]는 4, [숫자 개수]는 3이다. 숫자를 입력하여야 하는 열에서 두 값이 다르면 문자로 입력된 셀이 있다는 뜻이다. 검산의 판단 기준은 다음과 같다.

관찰한 값 판단
[개수]가 기준 값보다 작다 빈 셀이 있다. 행이 누락되었거나 입력하지 않은 셀이 있다
[개수]는 맞고 [숫자 개수]가 작다 문자로 입력된 셀이 있다. 왼쪽에 맞추어진 셀을 찾는다
[개수]와 [숫자 개수]는 맞고 [합계]가 다르다 값을 잘못 입력한 셀이 있다. 범위를 나누어 합계를 대조하여 구간을 좁힌다

버전에 따른 차이: 숫자가 입력된 셀의 수를 표시하는 항목의 이름은 Microsoft의 지원 문서에 [숫자 개수]로 적혀 있다. 제품의 화면에는 [숫자 셀 수]와 같이 다른 이름으로 표시될 수 있으며, 목록에서 [개수]의 바로 아래에 있는 항목이다.

따라 하기

연습용 통합 문서의 판매내역 시트에서 키로 이동하고, 범위를 선택하여 상태 표시줄의 값을 읽는다.

  1. Ctrl + Home을 눌러 A1로 이동한다.
  2. Ctrl + ↓를 누르고 이름 상자의 주소를 읽는다.
  3. Ctrl + →를 누르고 이름 상자의 주소를 읽는다.
  • 확인 10 Ctrl + ↓를 누른 뒤의 주소는 A20, Ctrl + →를 누른 뒤의 주소는 F20이다. 자료는 2행부터 20행까지 19행이다.
  1. 이름 상자에 E2:E20을 입력하고 Enter를 눌러 수량의 범위를 선택한다.

  • 확인 11 상태 표시줄에 평균 28, 개수 19, 합계 532가 표시되었다.
  1. E2를 선택하고 Ctrl + Shift + ↓를 눌러 같은 범위가 선택되는지 확인한다.

5. 자료의 입력과 자동 채우기

5-1. 자료의 종류

엑셀은 입력된 내용을 문자, 숫자, 날짜로 구분하여 저장한다. 종류에 따라 계산과 정렬의 결과가 달라지므로 의도한 종류로 입력되었는지를 확인하여야 한다.

종류 예 기본 맞춤 입력할 때의 유의 사항
문자 한빛상사, A4 복사용지 왼쪽 앞뒤에 공백을 넣지 않는다
숫자 30, 24000 오른쪽 쉼표와 단위를 붙이지 않고 숫자만 입력한다
날짜 2026-01-02 오른쪽 연도, 월, 일을 붙임표(-)로 구분하여 연도까지 입력한다

엑셀이 인식한 종류는 입력을 확정한 직후의 맞춤 위치로 판별한다. 맞춤을 따로 지정하지 않은 셀에서 문자는 왼쪽에, 숫자와 날짜는 오른쪽에 놓인다. 숫자나 날짜를 입력하였는데 왼쪽에 맞추어지면 문자로 입력된 것이다. 이 판별은 가운데 맞춤과 같은 서식을 적용하기 전에만 유효하므로, 입력을 마친 직후에 수행한다.

입력한 내용 엑셀이 인식한 종류 판별의 근거와 결과
24000 숫자 오른쪽에 놓인다
24000원 문자 왼쪽에 놓인다. 계산에 사용할 수 없다
2026-02-02, 2026/2/2 날짜 오른쪽에 놓인다. 붙임표와 빗금은 모두 날짜의 구분 기호이다
2026.02.02 문자 왼쪽에 놓인다. 마침표는 날짜의 구분 기호가 아니다
2-2 날짜 오른쪽에 놓인다. 연도를 생략하면 입력하는 시점의 연도가 적용된다
010 숫자 10 오른쪽에 놓이고 앞의 0이 사라진다
'010 문자 010 왼쪽에 놓인다. 아포스트로피(')는 셀에 표시되지 않는다
  • 천 단위 쉼표와 통화 기호는 값에 포함하여 입력하지 않고, 다음 장에서 표시 형식으로 지정한다.
  • 엑셀은 날짜처럼 보이는 입력을 날짜로 자동 변환한다. 1-2나 1/2를 입력하면 1과 2가 아니라 1월 2일이 저장된다. 이 변환은 끌 수 없다.
  • 우편번호나 전화번호와 같이 0으로 시작하고 계산에 사용하지 않는 번호는 숫자가 아니라 문자로 입력하여야 앞의 0이 유지된다. 입력하는 내용의 앞에 아포스트로피를 붙이면 문자로 입력된다. 이렇게 입력한 셀의 왼쪽 위 모서리에는 작은 녹색 삼각형이 표시되기도 하며, 숫자가 문자로 저장되어 있음을 알리는 표시이다.
  • 본 과목의 판매번호는 계산과 정렬에 사용하는 일련번호이므로 숫자로 입력한다.

5-2. 입력, 수정, 삭제, 실행 취소

셀을 선택하고 내용을 입력한 뒤 확정하여야 값이 셀에 들어간다. 입력 중에는 리본 메뉴의 명령 대부분이 동작하지 않으므로 입력을 확정하거나 취소한 뒤에 다음 조작을 수행한다.

키 동작
Enter 입력을 확정하고 아래의 셀로 이동한다
Tab 입력을 확정하고 오른쪽 셀로 이동한다
Esc 입력을 취소한다. 셀은 입력을 시작하기 전의 상태로 돌아간다
F2 선택한 셀의 내용을 수정한다. 커서가 내용의 끝에 놓인다. 셀을 더블 클릭하여도 같다
Delete 선택한 셀의 내용을 지운다. 범위를 선택하면 범위 전체의 내용을 지운다
Ctrl + Z 직전의 조작을 취소한다(실행 취소)
Ctrl + Y 취소한 조작을 다시 수행한다(다시 실행)

수정에는 두 가지 방법이 있다. 내용이 있는 셀을 선택하고 바로 입력하면 기존의 내용 전체가 새 내용으로 대체된다. F2를 누른 뒤 입력하면 기존의 내용을 유지한 채 일부만 고칠 수 있다. 값 전체가 틀렸으면 앞의 방법을, 한두 글자만 틀렸으면 뒤의 방법을 사용한다.

Delete는 셀의 내용만 지우고 셀에 적용된 서식은 남긴다. 날짜를 입력하였던 셀의 내용을 지우고 숫자를 입력하면 그 숫자가 날짜의 모습으로 표시되는 것은 이 때문이다. 서식까지 지우는 방법은 다음 장에서 다룬다.

Ctrl + Z는 누를 때마다 한 단계씩 이전의 상태로 되돌린다. 여러 단계를 되돌릴 수 있으나 파일의 저장은 되돌릴 수 없다. 조작의 결과가 예상과 다르면 다른 조작을 시도하기 전에 먼저 Ctrl + Z로 되돌린다.

5-3. 행 단위의 입력

표의 자료는 한 행씩 입력한다. Tab으로 오른쪽으로 이동하며 입력하고 행의 마지막 셀에서 Enter를 누르면, 활성 셀이 다음 행에서 입력을 시작한 열로 이동한다. 이 방법을 사용하면 마우스를 사용하지 않고 연속하여 입력할 수 있다. 입력 도중에 방향키나 마우스로 다른 셀을 선택하면 시작한 열의 기억이 사라지므로, 한 행의 입력을 마칠 때까지는 Tab만 사용한다.

5-4. 자동 완성

문자를 입력할 때 같은 열의 위쪽에 앞 글자가 같은 자료가 있으면 엑셀이 나머지 글자를 제시한다. 제시된 내용이 입력하려는 내용과 같으면 Enter 또는 Tab으로 확정하고, 다르면 무시하고 계속 입력한다. 자동 완성은 입력 시간을 줄이는 동시에 같은 상호를 서로 다르게 입력하는 오류를 줄인다. 다만 미래유통을 입력하려는데 앞 글자가 같은 다른 자료가 제시될 수 있으므로, 확정하기 전에 제시된 내용을 원본과 대조한다.

5-5. 화면의 표시와 실제 값

셀에 표시된 모양과 실제로 입력된 값은 다를 수 있다. 실제 값은 셀을 선택하였을 때 수식 입력줄에 표시되는 내용이다.

  • 문자가 열의 너비보다 길면 오른쪽 셀이 비어 있을 때에는 넘쳐서 표시되고, 오른쪽 셀에 내용이 있으면 잘려서 표시된다.
  • 숫자나 날짜가 열의 너비보다 길면 ####으로 표시된다.
  • 12자리 이상의 큰 숫자는 1.23E+11과 같은 지수의 모습으로 표시된다.

세 경우 모두 값은 정상적으로 입력되어 있다. 열의 너비는 다음 장에서 조정한다.

5-6. 채우기 핸들과 자동 채우기

채우기 핸들(fill handle)은 선택한 셀 또는 범위의 오른쪽 아래 모서리에 있는 작은 사각형이다. 마우스 포인터를 채우기 핸들에 올리면 포인터가 가는 십자 모양으로 바뀌며, 이 상태에서 끌면 선택한 내용을 바탕으로 끈 방향의 셀이 채워진다. 이 기능을 자동 채우기라 한다.

그림 필요: (선택한 셀의 오른쪽 아래 모서리에 있는 채우기 핸들과, 그 위에서 가는 십자 모양으로 바뀐 마우스 포인터)

채워지는 내용은 선택한 자료에 따라 다르다.

숫자가 입력된 셀 둘(예: 1001, 1002) 두 값의 차이만큼 증가하는 값이 채워진다
숫자가 입력된 셀 둘(예: 10, 20) 10씩 증가하는 값(30, 40, …)이 채워진다
날짜가 입력된 셀 하나 하루씩 증가하는 날짜가 채워진다

  • 채우기를 마치면 채워진 범위의 오른쪽 아래에 [자동 채우기 옵션] 단추가 나타난다. 이 단추에서 [셀 복사]와 [연속 데이터 채우기]를 선택하여 결과를 변경할 수 있다.
  • 자동 채우기로 입력한 번호는 입력한 시점의 값으로 고정된다. 중간의 행을 삭제하여도 번호가 다시 매겨지지 않는다.
  • 마우스 포인터가 가는 십자 모양이 아닌 상태에서 셀의 테두리를 끌면 셀의 내용이 이동한다. 의도하지 않게 이동하였으면 Ctrl + Z로 취소한다.
  • 채우기 핸들이 보이지 않으면 [파일] 탭 → [옵션] → [고급]의 [편집 옵션]에서 [채우기 핸들 및 셀 끌어서 놓기 사용]이 선택되어 있는지 확인한다.

  3. 컴퓨터활용 폴더의 실습 폴더로 이동한다.

합계가 기준 값과 다르면 오류가 있는 구간을 먼저 찾는다. 아래의 범위를 차례로 선택하여 상태 표시줄의 합계를 대조하고, 값이 다른 구간의 다섯 행을 원본과 대조한다.

판매번호 수량의 범위 수량의 합계 단가의 범위 단가의 합계
1001~1005 E2:E6 132 F2:F6 209000
1006~1010 E7:E11 155 F7:F11 64000
1011~1015 E12:E16 115 F12:F16 131000
1016~1020 E17:E21 91 F17:F21 128000

개수가 20보다 작으면 빈 셀이 있는 것이다. 개수는 20인데 합계가 기준 값보다 작으면 문자로 입력된 셀이 있을 수 있다. 문자로 입력된 셀은 개수에는 포함되고 합계에는 포함되지 않기 때문이다. 이 경우에는 상태 표시줄의 [숫자 개수]가 20인지 확인하고(4-3), 수량과 단가의 열에서 왼쪽에 맞추어진 셀을 찾아 다시 입력한다.

  • 확인 24 완료 기준 표의 열 개 항목이 모두 기준 값과 일치하였다.

심화 실습

핵심 실습을 완료한 수강생을 위한 선택 실습이며 제출하지 않는다.

입력 원본의 판매일은 2026년 1월 2일부터 1월 29일까지의 평일 20일이다. 이 날짜를 채우기 핸들로 채운다.

  1. Ctrl + N을 눌러 새 통합 문서를 연다.
  2. A1에 2026-01-02를 입력한다.
  3. A1을 선택하고 채우기 핸들을 A20까지 끈다. A20에 2026-01-21이 채워진다.
  4. [자동 채우기 옵션] 단추를 선택하고 [평일 단위 채우기]를 선택한다.
  5. A20의 값이 2026-01-29로 바뀌었는지 확인한다.
  6. 새 통합 문서는 저장하지 않고 닫는다.

연습 문제

연습용 통합 문서(판매연습_01_학번.xlsx)에서 수행한다. 절차는 제시하지 않으며, 본 장에서 다룬 조작만으로 해결할 수 있다. 결과가 기준 값과 일치하면 완료된 것이다.

문제 1. 판매내역 시트에서 판매번호 1030부터 1039까지 10건의 수량에 대하여 합계, 평균, 개수를 구한다.

문제 2. 판매내역 시트에서 거래처가 한빛상사인 판매 건의 수량만을 선택하여 개수와 합계를 구한다.

  • 기준 값: 개수 4, 합계 86

문제 3. 입력연습 시트의 빈 열 두 개에 다음의 값을 채우기 핸들로 입력한다. (가) 5에서 시작하여 5씩 증가하는 수 10개. (나) 2026년 2월의 월요일에 해당하는 날짜 전부(첫 월요일은 2026-02-02이다).

  • 기준 값: (가) 마지막 값 50, 합계 275. (나) 날짜 4개, 마지막 값 2026-02-23

개념 점검

  1. 경로 C:\Users\사용자이름\Documents\컴퓨터활용\실습\판매연습_01_2027000.xlsx에서 파일이 들어 있는 폴더의 이름, 파일 이름, 확장자를 각각 적는다.
  2. 자료 폴더의 파일을 열어 작업할 때 [저장]보다 [다른 이름으로 저장]을 먼저 수행하여야 하는 이유를 설명한다.
  3. 단가를 입력하는 셀에 24000원을 입력하였다. 이 셀이 놓이는 위치(왼쪽 또는 오른쪽), 엑셀이 인식한 자료의 종류, 그로 인하여 발생하는 문제를 적는다.
  4. 수량 20개를 입력한 범위를 선택하였더니 상태 표시줄의 [개수]는 20, [숫자 개수]는 19였다. 이 범위에 어떤 오류가 있는지 설명한다.
  5. 1001이 입력된 셀 하나를 선택하여 채우기 핸들을 끈 결과와, 1001과 1002가 입력된 두 셀을 선택하여 끈 결과의 차이를 설명한다.
