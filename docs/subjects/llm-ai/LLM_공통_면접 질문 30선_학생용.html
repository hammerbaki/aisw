면접 질문 30선

  • 과목: LLM AI 개발 및 활용, Claude Code 마스터 트랙 | 버전: v1.3
  • 이 질문은행은 취업 면접에서 실제로 나오는 질문을 이 과목의 학습 순서에 맞춰 정리한 것입니다. 모든 질문의 답은 이 과목의 공식 문서 원전과 실습 경험 안에 있습니다. 각 질문의 실마리는 답이 들어 있는 주제를 가리킵니다. 답을 외우지 않습니다. 실마리의 실습 기록을 다시 열고, 자기 언어로 답을 만들어 소리 내어 연습합니다.

A. LLM 원리 (7문)

  1. LLM은 왜 텍스트를 토큰으로 쪼개서 처리합니까? (실마리: 토크나이저 실험)
  2. 환각(그럴듯한 오답)은 왜 발생합니까? (실마리: LLM 동작 원리, 확률적 생성)
  3. 같은 질문에 답이 매번 달라지는 이유와, 이것이 개발에 주는 함의는 무엇입니까? (실마리: 샘플링, 재현성 실험, TDD)
  4. 컨텍스트 윈도우가 가득 차면 무슨 일이 일어나고, 어떻게 관리합니까? (실마리: 컨텍스트 실측, 컴팩션·유실 실험)
  5. 모델 양자화는 무엇이고 무엇을 얻고 무엇을 잃습니까? (실마리: 소형 모델 설치, VRAM 계산)
  6. 임베딩은 무엇이며 어디에 씁니까? (실마리: 유사도 검색기 구현)
  7. 생성은 상용 API를 쓰면서 임베딩은 로컬 모델을 쓰는 구성은 왜 나옵니까? (실마리: 검색기와 챗봇의 모델 구성)

B. Claude Code 운용 (8문)

  1. 에이전트 루프를 설명해 보세요. (실마리: 에이전트 루프의 세 국면, ReAct 직접 구현)
  2. CLAUDE.md와 Skill과 Hook은 각각 언제 씁니까? (실마리: 확장 기능 지도, 트리거 표)
  3. 지시로 부탁하는 것과 훅으로 강제하는 것은 무엇이 다릅니까? (실마리: 가드레일은 훅에, 강제력 사다리)
  4. 서브에이전트는 왜 씁니까? 같은 세션에 검토를 시키면 안 되는 이유는요? (실마리: 컨텍스트 격리, 배포 전 점검 검토자)
  5. MCP(Model Context Protocol)는 왜 필요합니까? (실마리: 도구의 MCP 서버화)
  6. 권한 모드와 체크포인트는 왜 있고 어떻게 씁니까? (실마리: 권한 4모드, 되감기)
  7. 대화형이 아니라 스크립트에서 Claude Code를 쓰려면 어떻게 합니까? (실마리: 헤드리스 모드, 파이프라인)
  8. 스킬을 만들 때 피해야 할 안티패턴은 무엇입니까? (실마리: 안티패턴 3종 진단)

C. LLM 애플리케이션 개발 (8문)

  1. tool use(function calling)의 사이클을 설명하고, 도구 인자를 왜 검증해야 하는지 말해 보세요. (실마리: 도구 호출 사이클 관찰, run_tool의 인자 검증)
  2. 명세 주도 개발(SDD)은 무엇이고, AI 협업에서 왜 중요합니까? (실마리: Charter·Spec 작성, EARS 문형, 코드-문서 동기화 게이트)
  3. RAG(Retrieval-Augmented Generation, 검색 증강 생성)의 구조를 설명하고, 어떤 문제를 풉니까? (실마리: 검색기 구현, 챗봇 조립)
  4. 유사도 문턱을 낮추면, 높이면 각각 무엇이 잘못됩니까? (실마리: 문턱 실험)
  5. 청킹은 왜 하며 청크 크기는 무엇을 절충합니까? (실마리: 청킹 실습)
  6. 에이전트를 직접 구현하는 것과 SDK·프레임워크를 쓰는 것은 언제 각각 선택합니까? (실마리: ReAct 직접 구현과 SDK 대조)
  7. AI 산출물의 품질은 무엇으로 측정합니까? (실마리: 정답셋, 규칙 채점과 Judge)
  8. 외부 API를 부르는 코드는 어떻게 테스트합니까? (실마리: Mock 어댑터)

D. 운영·보안·배포 (7문)

  1. 기업이 로컬(온프레미스) LLM을 쓰는 이유는 무엇입니까? (실마리: 온프레미스 보안 이론, 로컬 모델 실습)
  2. AI 도구 도입 심사에서 회사는 무엇을 봅니까? (실마리: 데이터 사용 정책, 엔터프라이즈 운영)
  3. API 키는 어떻게 관리해야 합니까? (실마리: 키 보안, 배포 전 점검)
  4. 모델 출력을 웹 화면에 표시할 때 무엇을 조심해야 합니까? (실마리: XSS 소독)
  5. 배포 파이프라인에 검사를 넣는 이유와 구조를 설명해 보세요. (실마리: 점검 통과 시에만 배포)
  6. 반복 프롬프트의 비용은 어떻게 줄입니까? (실마리: 프롬프트 캐싱, 토큰 사용량 추적)
  7. 무인 자동화가 실패할 때를 어떻게 설계합니까? (실마리: 재시도 상한, 폴백)

사용법

  1. 각 질문에 대해 실마리의 실습 기록과 원전 문서를 다시 열어 자기 언어로 답을 만듭니다. AI가 만든 문장을 그대로 외우면 면접에서 되묻는 질문에 무너집니다.
  2. 짝과 번갈아 묻고 답하는 모의 문답으로 연습합니다. 답한 뒤에는 “실제로 해 본 것”을 한 가지 붙이는 훈련을 합니다. 이 과목의 모든 질문에는 붙일 실습이 있습니다.
