# 예비 · 응답 샘플 (API가 막혔을 때 읽는 용도)

API 호출이 안 되어(키 · 429 · 네트워크) 실습 1 · 2 · 4의 응답을 볼 수 없을 때, 아래를 화면 대신 읽고 다음 단계로 갑니다. 숫자와 문장은 덱의 화면 예시이며 실제 답은 실행마다 다릅니다.

## 실습 1 · hello_claude.py

```
# 안녕하세요! 👋
저는 Claude라고 하는 AI 어시스턴트입니다. …
35 106
```

system 두 줄을 넣은 뒤:

```
안녕하세요. 학과 조교입니다. 궁금한 점을
말씀해 주시면 안내해 드리겠습니다.
48 21
```

temperature 0.0으로 세 번(거의 같은 답):

```
낙엽이 소복이 내려앉는 가을 하늘 아래, …
```

1.0으로 세 번(매번 다른 답):

```
낙엽이 소복이 내려앉은 길 위로, …
낙엽이 소복이 내려앉으니, 세상이 한 폭의 …
낙엽이 소복이 소복이 내려앉으며, …
```

## 실습 2 · chat.py

이력을 쌓기 전:

```
나: 내 이름은 민수야
AI: 안녕하세요, 민수님! 만나서 반갑습니다. …
   (input_tokens=48, output_tokens=42)
나: 내 이름이 뭐라고 했지?
AI: 죄송하지만, 이름을 말씀해주신 적이 없습니다. …
   (input_tokens=54, output_tokens=81)
```

이력을 쌓은 뒤: 두 번째 질문에 "민수라고 말씀하셨습니다"로 답하고 `input_tokens=109`가 찍힙니다. 이력이 없을 때(54)보다 55 늘었고, 첫 질문과 답이 함께 간 몫입니다.

## 실습 4 · rag_chat.py

```
$ .venv/bin/python rag_chat.py ask "API 키를 잃어버렸어요"
API 키는 재발급할 수 있어. 교수에게 계정 이름과
함께 재발급을 요청하면 기존 키는 회수되고 새 키가
발급돼. 새 키는 홈 폴더의 환경 설정 파일에 다시
등록하면 돼.
(근거1)

$ .venv/bin/python rag_chat.py ask "학생 식당 메뉴 알려줘"
주어진 자료에서 찾을 수 없습니다.
```

괄호 안 숫자가 없으면 지시(프롬프트)가 거절한 것이고, 있으면 유사도 필터(코드)가 거른 것입니다.

사내규정/에서 같은 챗봇을 돌리면 세 질문 모두 거절됩니다. 정답 조항이 근거 3개 안에 들지 못한 검색 단계의 결과입니다.

```
$ ../.venv/bin/python ../rag_chat.py ask "재택근무는 어떻게 신청하나요"
주어진 자료에서 찾을 수 없습니다.
(자료에는 유연근무 · 지각과 조퇴 · 경조사 휴가만 있음)

$ ../.venv/bin/python ../rag_chat.py ask "할머니가 돌아가시면 며칠 쉬어?"
주어진 자료에서 찾을 수 없습니다.
(자료에는 유연근무(제7조) · 병가(제18조)만 있음)

$ ../.venv/bin/python ../rag_chat.py ask "구내식당 메뉴 알려줘"
주어진 자료에서 찾을 수 없습니다.
(자료에는 경조사 휴가 · 육아휴직만 있음)
```
