# week06 · API 연동과 RAG 챗봇 실습 폴더

## 프로젝트 개요
- chat.py(미니 챗봇) · embed_search.py(검색기) · rag_chat.py(RAG 챗봇)의 미완성 함수를 채우는 실습 폴더다.
- 검색 대상 문서는 학과FAQ.md와 사내규정/복무규정.md다. 둘 다 실습용 가상 문서다.

## 실행 명령
- 테스트: .venv/bin/python -m pytest -q
- 파이썬 실행은 .venv/bin/python 으로 한다. python3로 실행하지 않는다.

## 작업 규칙
- 함수를 완성할 때는 그 함수의 독스트링에 적힌 순서대로 구현한다.
- 지시받은 함수만 고친다. 다른 함수와 상수는 그대로 둔다.
- 작업을 마치면 테스트를 실행하고, 통과 · 실패 개수를 그대로 보고한다.

## 금지 사항
- tests/ 아래 파일은 수정하지 않는다.
- API 키를 코드나 파일에 쓰지 않는다. 키는 환경변수 ANTHROPIC_API_KEY로만 읽는다.
- 학과FAQ.md · 사내규정/ · 평가문항.csv는 수정하지 않는다.
- 예비/ · 예비_검색기/는 수정하지 않는다.
