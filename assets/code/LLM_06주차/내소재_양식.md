## 비용 어림 (덱 「정리」 장)

한 질문 비용 = 입력 토큰 × 입력 단가 + 출력 토큰 × 출력 단가. 단가는 Haiku 4.5 기준 100만 토큰당 입력 약 1,400원 · 출력 6,800원입니다(1달러 1,360원 환산, 입력은 백 원 단위로 올림. 당일 가격은 교수가 화면으로 확인).

사내규정 챗봇 한 질문 ≈ 입력 __ · 출력 __토큰 ≈ 약 __원. __명이 하루 __번 쓰면 하루 약 __원, 한 달 약 __원이다.
