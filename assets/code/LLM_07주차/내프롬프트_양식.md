# 내 프롬프트 · 7주차 (쓰는 파일: week07/내프롬프트.md)

실습 1 · 3에서 Claude Code에 맡길 때 보내는 프롬프트 세 개입니다. 코드는 직접 타이핑하지 않고 맡긴 뒤, 채운 결과를 읽고 고정 테스트로 판정합니다. 이 파일을 `내프롬프트.md`로 복사해 쓰고, 고친 문장은 거기에 남깁니다.

    cp -n ~/week07/내프롬프트_양식.md ~/week07/내프롬프트.md

**전제** · Claude Code는 `~/week07`에서 `claude`로 엽니다(터미널 1). 이때 키트의 `CLAUDE.md`(테스트 수정 금지 · 키를 코드에 쓰지 않음 · 실행 명령)가 함께 읽힙니다. 세션은 열어 둔 채로 두고, 판정 명령(pytest · wc · grep)은 터미널 2(서버 터미널)에서 칩니다.

## 1) handle_tool_use 완성 (실습 1 · 2/5에서 보냅니다)

먼저 `/clear`로 앞 대화를 비운 뒤 보냅니다.

```
@faq_tool_chat.py 이 파일의 handle_tool_use를 독스트링의
①②③ 구성대로 완성하라. FAQ_TOOL의 description과
다른 함수는 건드리지 말라
```

**확인할 것(3/5)** · 보고에 `tests/` 수정이 없는가. 「완성했습니다」는 AI의 요약이므로, 터미널 2에서 `.venv/bin/python -m pytest -q tests/test_faq_tool_chat.py`가 3 passed인지 내 눈으로 봅니다. 점 셋은 차례로 ① 모르는 도구 이름이면 「오류: 알 수 없는 도구 …」 ② 빈 query면 「오류: query가 비어 있습니다」 ③ 검색 결과를 「유사도 0.72: <청크 내용>」 줄로 이어 반환하는지의 검사입니다. Claude Code가 전체 테스트를 돌려 「5 failed」를 보고해도, 아직 하지 않은 실습 2 · 3의 테스트라 정상입니다.

## 2) SKILL.md 발전형 (실습 3 · 3/4에서 보냅니다)

```
@.claude/skills/portfolio-check/SKILL.md 를 @skills/SKILL_골격.md 의
네 절(출력 서식 · 절차 · 규칙 · 환각 방지)로 발전시켜라. 규칙은 두 개이고
각각 「왜냐하면」으로 이유를 붙여라. 60줄을 넘기지 말라
```

**확인할 것** · 머리말의 description에 「무엇을」과 「언제 쓰나」가 있는가, 규칙마다 이유가 있는가, 환각 방지 절(출처 명시 · 확인 필요 표시)이 있는가. 고친 SKILL.md는 열린 세션에 바로 반영되므로 나오지 않습니다. 터미널 2에서 `.venv/bin/python -m pytest -q tests/test_skill.py`가 3 passed인지 보고, 터미널 1의 같은 세션에서 `/portfolio-check 포트폴리오를 점검하라`를 다시 불러 산출물이 달라졌는지 봅니다. 완성 예시는 `예비/SKILL.md`입니다.

## 3) 안티패턴 진단 (실습 3 · 4/4에서 보냅니다)

```
@antipattern/진단기준.md 의 기준으로
@.claude/skills/portfolio-check/SKILL.md 를 진단하라.
발현 여부와 해결 권고를 표로 출력하라
```

**확인할 것** · 진단 표의 실측이 터미널 2에서 잰 숫자와 같은가. `week07`에서 아래 세 명령을 칩니다. 줄 수가 60 이하면 ① 거대 본문 없음, 반드시 · 절대 · 금지가 5회 미만이면 ③ 이유 없는 규칙 없음입니다. ② 참조 분리 부재는 본문을 읽어 판정합니다(분기 4개 이상인데 references/가 없으면 해당). 표와 숫자가 다르면 숫자를 믿습니다.

    wc -l .claude/skills/portfolio-check/SKILL.md
    grep -c -E "반드시|절대|금지" .claude/skills/portfolio-check/SKILL.md
    grep -c -E "왜냐하면|때문" .claude/skills/portfolio-check/SKILL.md

---

## 왜 「60줄을 넘기지 말라」가 있는가

스킬은 호출될 때마다 본문이 통째로 컨텍스트에 실립니다. 안티패턴 ① 거대 본문의 수업용 기준이 60줄입니다. 경우에 따라 필요한 상세는 references/로 분리하고 본문에는 「언제 어느 파일을 읽을지」 한 줄만 남깁니다. 고정 테스트 `test_skill.py`도 60줄을 넘으면 실패합니다.
