# week07 · 하네스와 루프 엔지니어링 실습 폴더

## 프로젝트 개요
- faq_tool_chat.py(검색 도구 챗봇) · calc_tool_bare.py(계산 도구) · mcp/calc_mcp.py(MCP 서버)와 .claude/skills/(스킬)를 다루는 실습 폴더다.
- 검색 대상 문서는 학과FAQ.md와 사내규정/복무규정.md, 스킬의 점검 예시는 포트폴리오/다. 모두 실습용 가상 자료다.

## 실행 명령
- 테스트: .venv/bin/python -m pytest -q
- 파이썬 실행은 .venv/bin/python 으로 한다. python3로 실행하지 않는다.

## 작업 규칙
- 함수를 완성할 때는 그 함수의 독스트링에 적힌 순서대로 구현한다.
- 지시받은 함수와 파일만 고친다. 다른 함수와 상수는 그대로 둔다.
- 작업을 마치면 관련 테스트를 실행하고, 통과 · 실패 개수를 그대로 보고한다.

## 금지 사항
- tests/ 아래 파일은 수정하지 않는다.
- API 키를 코드나 파일에 쓰지 않는다. 키는 환경변수 ANTHROPIC_API_KEY로만 읽는다.
- 학과FAQ.md · 사내규정/ · 포트폴리오/는 수정하지 않는다. 포트폴리오/는 점검 대상이다.
- 예비/ · antipattern/은 수정하지 않는다.
