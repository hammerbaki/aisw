# 요구사항명세서 · 포트폴리오

CLAUDE.md 수업에서 쓴 가상 포트폴리오를 이 수업 스킬 실습(`/portfolio-check`)의 점검 예시로 다시 씁니다. `index.html` 한 장짜리 정적 페이지이고, 인물 · 연락처는 가상입니다(`프로필.md`). 자기 프로젝트가 있으면 스킬의 대상 폴더를 그 프로젝트로 바꿔 씁니다.

## 요구사항

REQ-01 [상시] 시스템은 `index.html` 한 장에 소개 · 기술 · 프로젝트 · 연락처를 표시해야 한다. 네 섹션의 id는 about · skills · projects · contact이다.
REQ-02 [사건] 사용자가 프로젝트 카드를 누를 때, 시스템은 상세 설명을 펼쳐야 한다.
REQ-03 [상시] 시스템은 `프로필.md`에 있는 연락처만 표시해야 한다.
REQ-04 [상시] 시스템은 전화번호와 집 주소를 표시하지 않아야 한다.

## 테스트

`tests/test_page.py`의 테스트 세 개가 REQ-01 · REQ-03 · REQ-04를 확인합니다. **고정 테스트이므로 고치지 않습니다.** TDD에서 동결한 테스트와 같은 역할입니다. REQ-02(카드 펼치기)는 브라우저에서 사람이 확인합니다.

`pytest`와 표준 라이브러리만 씁니다.

## 실행

- 테스트: `cd ~/week07/포트폴리오` → `../.venv/bin/python -m pytest -q`
- 화면: VS Code 탐색기에서 `index.html` 우클릭 → Download → 브라우저로 열기
