# notice-writer

공지 유형을 판별한 뒤 해당 유형의 절차를 따른다.

## 휴강 공지일 때

과목명, 원래 일시, 사유를 첫 단락에 쓴다. 보강 일정이 정해졌으면 두 번째 단락에 쓰고, 미정이면 추후 공지를 예고한다. 출결 처리 방침을 마지막에 쓴다.

## 시험 공지일 때

과목명, 일시, 장소, 범위를 표로 쓴다. 지참물과 금지 물품을 나눠 쓴다. 부정행위 처리 기준 문서로 연결한다. 좌석 배치 발표 시점을 예고한다.

## 행사 공지일 때

행사명, 일시, 장소, 대상, 신청 방법을 쓴다. 신청 마감과 정원을 굵게 표시한다. 우천 등 취소 조건이 있으면 명시한다. 문의처를 끝에 쓴다.

## 장학 공지일 때

장학금명, 신청 자격, 제출 서류, 마감 일시를 쓴다. 서류별 발급처를 표로 정리한다. 지난 학기 선발 인원을 참고로 붙인다. 개인정보 수집 동의 안내를 포함한다.

## 시설 공지일 때

대상 시설, 중단 기간, 사유, 대체 수단을 쓴다. 공사 소음 등 영향 범위를 명시한다. 완료 후 재개 공지를 예고한다.
