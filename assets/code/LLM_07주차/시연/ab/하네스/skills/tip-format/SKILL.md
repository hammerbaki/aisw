# tip-format

팁 하나를 한 파일로 만들고, 모든 팁이 같은 뼈대를 갖게 한다.

## 서식 (팁 1건 = 파일 1개)

1. 제목: 팁을 한 문장으로
2. 상황: 언제 필요한가
3. 방법: 실행 순서 또는 명령
4. 예시: 그대로 입력할 수 있는 명령·설정 예 1건
5. 주의점: 실수하기 쉬운 지점 1가지

## 규칙

- 한 파일에는 한 주제만 담는다. 왜냐하면 여러 주제가 섞이면 나중에 찾아 쓸 수 없기 때문이다.
- 파일을 만들면 tips/INDEX.md에 한 줄(제목, 파일명)을 추가한다. 왜냐하면 인덱스가 없는 문서 더미는 누적될수록 쓰이지 않기 때문이다.
