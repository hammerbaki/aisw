# 팁 검증 절차

팁에 적힌 내용이 실제 동작과 다르면 팁이 아니라 소음이다. 팁을 쓰거나 고친 뒤 다음을 점검한다(출처 명시 · 환각 방지).

1. 각 주장에 출처(파일 경로나 URL)를 붙인다.
   이유: 출처가 없으면 독자가 확인할 수 없다. 버전이 바뀌었을 때 검증할 방법도 없다.
2. 확실하지 않은 내용은 "확인 필요"로 표시한다.
   이유: 추측으로 채우면 틀린 내용이 사실처럼 남는다.
3. 명령 · 설정 예시는 실제 형식 그대로 옮긴다.
   이유: 비슷하게 지어낸 명령은 그대로 쳤을 때 실패한다.
