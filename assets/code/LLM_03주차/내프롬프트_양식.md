# 내 프롬프트 · 3주차 (쓰는 파일: week03/내프롬프트.md)

실습 2 · 준비 2에서 **AI가 이 두 개를 만들어 `내프롬프트.md`로 저장합니다.**
AI가 만든 것을 열어 읽고, 아래와 견주어 빠진 곳을 내 말로 채웁니다.
AI가 엉뚱하게 만들었으면 이 파일을 `내프롬프트.md`로 복사해 그대로 써도 됩니다.

    cp -n ~/week03/내프롬프트_양식.md ~/week03/내프롬프트.md

**전제** · `내소재.md` 3주차 칸 1)에 새 요구 한 문장, 2)에 테스트 문장 세 줄이 이미 적혀 있어야 합니다.
비어 있으면 AI가 요구를 대신 고릅니다. 그러면 내 테스트가 아닙니다.

---

## 1) 테스트 옮기기 (실습 2 · 4/6에서 mine 폴더에서 보냅니다)

```
내소재.md 3주차 칸의 1) 새 요구와 2) 테스트 문장 세 줄을 읽어라.
새 요구를 요구사항명세서.md에 EARS 라벨과 ← 추가 표시로 먼저 반영하라.
그다음 그 세 줄을 tests/test_mine.py로 옮겨라. 함수는 껍데기까지만.
```

**확인할 것** · 파일 이름이 `tests/test_mine.py`인가. 테스트 문장 세 줄이 내가 쓴 그대로인가.
껍데기(본문이 `NotImplementedError` 한 줄인 함수)까지만 있고 구현이 들어가 있지 않은가.
껍데기가 없으면 `1 error`, 있으면 `N failed`가 납니다(5/6의 갈래표).

---

## 2) 통과시키기 (실습 2 · 6/6에서 동결한 뒤 보냅니다)

```
tests/test_mine.py 를 통과하도록 index.html 을 고쳐라.
테스트 파일은 수정하지 마라. 통과하지 못하면 통과하지 못했다고 보고하라.
완료 조건: pytest -q tests 전체 통과.
브라우저는 열지 마라. 브라우저 확인은 내가 한다.
```

**확인할 것** · 「테스트 파일은 수정하지 마라」가 들어 있는가. 완료 조건이 적혀 있는가.
「브라우저는 열지 마라」가 있는가.
통과한 뒤에도 껍데기가 그대로 남아 계속 실패하면 「테스트가 부르는 함수도 구현하라」를 한 줄 더 보냅니다.

---

## 왜 「브라우저는 열지 마라」인가

서버에는 브라우저가 없습니다. AI는 페이지를 열어 볼 수 없으므로 「열어서 확인했습니다」는
**근거 없는 보고**입니다. 오늘 배운 것을 그대로 적용하는 자리입니다.

브라우저 확인은 실습 1 · 2/3에서 배운 방법으로 내가 합니다.

    VS Code 탐색기에서 week03/mine/index.html 우클릭 → Download… → 크롬으로 열기
