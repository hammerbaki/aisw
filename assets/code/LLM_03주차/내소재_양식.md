## 1. 3주차 칸 (실습 2)

- 아직 구현되지 않은 것 하나 (`요구사항명세서.md` 끝의 「3주차에 더할 요구 후보」 중 하나를 내 말로)
  →
- 내 에러 상황 한 문장 (지금 잘못 나오거나, 아직 없거나, 확인할 길이 없는 것)
  →

**2) 테스트 문장 세 줄 (정상 2 · 경계 1)** · "무엇을 열면 → 무엇이 나와야 한다". 셋 중 하나는 1)의 요구를 검사합니다.

- 정상 1 (index.html에 있어야 할 글자) →

- 경계 (그 부분을 지운 사본을 만들어 확인) →

- 사람이 눌러 볼 것 (버튼 동작) →
