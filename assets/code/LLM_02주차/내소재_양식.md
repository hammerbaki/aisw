## 예제 A · 수영 강좌 찾기 (운동/)

**명세 읽기** · `운동/spec/요구사항명세서.md`를 열고 REQ를 위에서부터 읽습니다.

- ① "잘" · "적절히"처럼 확인할 수 없는 말이 든 REQ
  →
- ② 잘못됐을 때(없는 번호 입력 · csv 없음)를 정한 REQ가 있는가
  →
- ③ REQ 하나를 확인 문장 한 줄로 ("~하면 ~가 보여야 한다")
  →
- ④ 내가 쓸 프로그램이라면 고치고 싶은 곳, REQ 번호와 이유 (선택, 문장은 파일에서 고치고 `← 고침`)
  →

**만들어 보고**

- AI가 물어 온 질문 목록 (명세의 첫 빈틈 후보)
  →
- 내 결과는 어느 갈래인가 (전체 목록만 나온다 / 없는 번호에서 멈춘다 / 명세에 있는 항목이 없다 / 내 조건으로 찾을 수 있다 / 표가 아니라 터미널 글자로 나온다)
  →
- 명세에 더한 한 줄의 REQ 번호 (선택, 문장은 `rebuild/요구사항명세서.md`에 `← 추가`)
  →

**내 것으로** (실행은 안 해도 됩니다) 내가 이 프로그램을 쓴다면 더하고 싶은 한 줄
  →
