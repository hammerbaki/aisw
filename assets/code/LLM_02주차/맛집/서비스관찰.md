# 서비스 관찰 메모 (사람이 쓴 것 · 예제 C 데모 1/5의 예시)

# 대상: 구글맵 · 「경기광주역 맛집」 검색
[화면] 검색창 → 결과 목록 → 가게 상세 → 길찾기 / 즐겨찾기
[동작] 검색어 입력 · 결과 카드 누르기 · 지도 이동 · 저장
[가게 정보] 이름 · 종류 · 별점 · 리뷰 수 · 거리 · 영업시간 · 주소 · 전화
[정렬 · 필터] 정확도 / 거리 / 인기 · 영업중만 보기
[불편] 걸어서 몇 분인지 바로 안 보인다 · 광고 가게가 위에 섞인다
[알 수 없음] 별점이 어떻게 계산되나 · 광고와 일반 결과의 기준
[내가 아는 가게] 월미당 태전점 · 아시아 요리· 고산동 · 별점 3점

이 메모는 예전 방식(사람이 화면을 보고 적기)의 예시입니다. 지금은 같은 항목을 브라우저 AI가 채웁니다. AI가 쓴 결과는 네이버지도-구조분석.md(캡처 4장은 캡처/ 폴더에도 있음)입니다.
