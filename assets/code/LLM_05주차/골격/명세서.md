# 주문 관리 샘플 프로젝트 명세서

CLAUDE.md 실습의 재료입니다. 리버스 엔지니어링 회차에서 배운 EARS(Easy Approach to Requirements Syntax, 정형 요구사항 문형 기법) 문형을 따르며, CLAUDE.md 작성 실습의 원천 자료로 사용합니다.

## 요구사항

- 사용자가 주문을 생성하면, 시스템은 재고를 차감하고 주문 상태를 "접수"로 기록해야 한다.
- 재고보다 많은 수량이 요청되면, 시스템은 주문을 거절하고 오류를 반환해야 한다.
- 수량이 1 미만으로 요청되면, 시스템은 주문을 거절해야 한다.
- 존재하지 않는 주문이 조회되면, 시스템은 오류를 반환해야 한다.

## 구조 규칙

- `app/`은 업무 규칙만 담고 외부 라이브러리에 의존하지 않는다.
- 모든 기능 변경은 `tests/`의 테스트와 함께 제출한다.
- 함수 이름은 동사로 시작한다.

## 실행

- 테스트: `~/week05/.venv/bin/python -m pytest -q`
